WeatherSystem — Rain mode

game/src/effects/WeatherSystem.ts · pixi.js v8 Graphics
IMPACT HIGH COST LOW P1
단일 Graphics 객체에 매 프레임 입자/splash 를 immediate-mode 로 그린다. Sprite 풀 없음 — 입자 수가 적고 (rain 220 / snow 140 cap), 한 draw call 로 끝난다. 파라미터: mode · intensity (0..1) · wind (-1..1) · collision.grid · coverageCheckTiles (덮임 검사 깊이).

IntGrid 충돌: 각 입자가 매 tick grid[row][col] 을 1회 샘플. isSolid(v) 기본값은 v !== 0 && v !== 10 (empty 와 void 만 통과). 충돌 시 비는 surface 에 splash tick, 눈은 그냥 소멸.

실내 차단: spawn 마다 컬럼 상단 N tile 을 스캔해 solid 가 있으면 입자 생성 자체를 스킵. 카메라 바로 위의 지붕 1–3 tile 검사로 건물 안엔 비 없음, 동굴 천장은 멀리 떨어져 있으면 비 통과.
DEMO · CSS 모사 (RAIN)

// LdtkWorldScene.ts / ItemWorldScene.ts
import { WeatherSystem } from '@/effects/WeatherSystem';

// On level enter:
this.weather = new WeatherSystem({
  mode: 'rain',
  intensity: 0.7,           // 0..1
  wind: -0.18,             // drift to the left
  coverageCheckTiles: 3,   // roof scan depth
  collision: {
    grid: level.collisionGrid,
    tileSize: TILE_SIZE,
    originX: level.worldX,
    originY: level.worldY,
  },
});
this.weatherLayer.addChild(this.weather.container);

// Per tick:

// On level exit:
this.weather.destroy();

IntGrid 충돌 / 실내 차단 로직 요약

WeatherSystem.isCoveredAbove() + per-tick grid[row][col] 샘플
IMPACT HIGH COST LOW P1
입자는 두 단계로 IntGrid 와 상호작용한다.

(A) Spawn-time coverage check: spawn 좌표의 컬럼을 위로 coverageCheckTiles 줄 만큼 스캔. solid 셀이 있으면 그 컬럼은 *덮여 있음* 으로 보고 입자 자체를 생성하지 않는다. 카메라 바로 위 1–3 tile 만 검사하므로 동굴의 멀리 떨어진 천장은 통과시키고, 가까운 건물 지붕만 차단한다.

(B) Per-tick collision: 살아 있는 입자는 매 tick 자기 셀의 IntGrid 값을 본다. isSolid(v) 가 true 면 위치 row 의 surface (top edge) 좌표로 splash 를 남기고 소멸 (비) / 그냥 소멸 (눈). 기본 isSolid 는 v !== 0 && v !== 10 이라 water (2) / one-way (3) / updraft (4) 도 막힘. 필요 시 옵션으로 override 가능 (collision.isSolid).

비용: spawn rate × coverageCheckTiles 의 행 스캔 + 입자당 1 회 grid 룩업. 220 입자 + 480 spawn/s × 3 tile = 초당 ~1.6k 의 단순 정수 인덱싱. 무시 가능.
상황컬럼 상단 검사결과
넓은 공동 한가운데 (천장 멀리)3 tile 내 solid 없음비/눈 ●
공동 안 건물 지붕 아래1–2 tile 위 solid차단 ✕
좁은 동굴 천장 바로 아래1 tile 위 solid차단 ✕
건물 지붕 가장자리 (지붕 끝)컬럼별로 다름자연스러운 경계
지붕 위 (옥상)검사 범위 비어 있음비/눈 ●
튜닝 노트: coverageCheckTiles = 0 으로 차단을 끄면 입자는 어디서나 spawn 되고 충돌만 IntGrid 로 처리 — 좁은 동굴 안에서 천장 아래 빛샘 효과가 필요할 때. = 6+ 으로 키우면 큰 동굴 천장도 차단 — 진짜 야외 공간에서만 비가 내리는 모드. 카메라가 지붕 위로 올라가면 다시 비가 보이도록 즉시 전환됨 (state 캐시 없음, 매 spawn 재계산).

weather.setStreakLength(streakPx);            // 빗줄기 길이

// Dynamic indoor — replace the IntGrid scan with a custom rect mask.
// Equivalent to "moving the roof at runtime" in the playground.
weather.setCoverageMask((x, y) => {
  const dy = (roof.y + roof.h) - y;
  return dy >= 0 && dy <= coverageDistance * tileSize
      && x >= roof.x && x <= roof.x + roof.w;
});

// Revert to default IntGrid-based coverage check:
weather.setCoverageMask(null);
