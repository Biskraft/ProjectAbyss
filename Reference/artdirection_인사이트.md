## 0. 핵심 명제

아트 디렉션은 **장식이 아니라 체계적 문제 해결**이다. "예쁜 그림"과 다르다. 모든 게임이 초현실적 비주얼을 필요로 하지는 않지만, **모든 게임은 좋은 아트 디렉션을 필요로 한다.** 나쁜 아트 디렉션은 혼란과 빈약한 시각 위계로 게임을 플레이 불가능하게 만든다.

저자의 정의:

> 아트 디렉션이란 모든 시각 요소가 제작의 목표에 정렬되고 플레이어 경험을 풍부하게 만들도록 보장하는 과정이다.

아트 디렉션의 세 가지 목적:

1. 씬의 메시지를 **전달**한다.
2. 그 메시지를 뒷받침하는 **감정적 충전**을 만든다.
3. 시각적으로 **흥미롭고 매혹적**이다.

### 아트 디렉션 ≠ 아트 스타일 / 컨셉 아트

아트 스타일이 정적인 미학 선택이라면, 아트 디렉션은 **게임 상태와 플레이어 상호작용에 따라 적응하는 시스템 레벨 규율**이다. 한 장의 키 비주얼을 정하는 일이 아니라, 플레이의 모든 순간에 걸쳐 시각이 제 기능을 하도록 설계하는 일이다.

## 1. 세 기둥 (Three Pillars)

### 기둥 1 — 가독성 / 효과적 전달 (Legibility)

플레이어가 이미지가 전달해야 할 중요 정보를 **읽고 이해**할 수 있어야 한다.

- **시각 위계(visual hierarchy)** 를 **중요도 위계(importance hierarchy)** 와 일치시킨다.
- **대비(contrast)** 로 중요 요소를 부각한다.
- **친연(affinity)** 으로 덜 중요한 요소를 묶고 가라앉힌다.
- 원칙: **신호를 키우고 잡음을 줄인다 (boost the signal, reduce the noise).**

중요도 위계는 고정값이 아니라 **게임 상태에 따라 이동**한다. (예: 보상 순간엔 성공 애니메이션이 위계 최상위, 평소엔 주변 요소가 부차적.)

### 기둥 2 — 감정적 공명 (Emotional Resonance)

> 우리가 보는 모든 것은 개인적 경험의 기억을 촉발한다. 특정한 것을 연상시키는 비주얼은 그 기억에 결부된 감정을 느끼게 한다.

감정은 **연상(association)** 을 통해 발생한다. 시각 요소가 플레이어의 경험과 연결될 때 감정이 일어난다.

- **무드보드(mood board)** 가 핵심 도구. 목표 감정을 촉발하는 이미지를 모으고, 그 공통 속성을 분석해, 게임 비주얼에 적용한다.
- 원칙: **무엇을 말하는가(메시지)와 어떻게 말하는가(시각)를 연상을 통해 정렬한다.**

### 기둥 3 — 시각적 흥미 (Visual Interest)

매력적인 비주얼은 **변주(variation)** 로 몰입을 유지한다 (색·형태·크기·리듬·텍스처·위치 등). 단, 과도한 변주는 혼돈을 부른다.

- **조화(harmony) 원칙:** 변주는 뇌가 인식할 수 있는 단순한 비율(예: 1:2:4)로 서로 관계 맺어야 한다. 무작위 조합이 아니라 이해 가능한 비율.
- 조화 ↔ 혼돈: 이해 가능한 변주 vs 이해 불가능한 무작위.

## 2. 시각 속성 프레임워크 (Visual Attributes)

이미지를 이해하는 차원들. 진단과 설계의 분석 도구.

| 레벨 | 속성 |
| :--- | :--- |
| 저차원 | 위치, 색(명도/색상/채도), 형태, 크기, 방향 |
| 중차원 | 텍스처, 라이팅, 리듬 |
| 고차원 | 용도(utility), 문화(culture), 재질(material), 의미(semantics) |

- **대비(contrast):** 요소를 다르게 만들어 시각 위계 상위로 끌어올린다.
- **친연(affinity):** 요소를 유사하게 만들어 묶고 위계 하위로 내린다.

이미지를 진단할 때: 색·대비·친연·형태 다양성·라이팅·리듬·의미 등 각 속성에서 어떻게 작동하는지 살피고, **현 게임 상태에 가장 도움이 되는 속성을 조작**한다.

## 3. 워크플로 (Process)

### 1단계 — 게임을 프레임으로 분해

> 이 모든 이미지를 하나하나 아트 디렉팅하고, 개별적으로도 시간에 걸쳐서도 작동하게 하면, 게임 전체를 아트 디렉팅한 것이다.

영화 제작처럼 핵심 순간의 스냅샷·스토리보드를 사용한다.

### 2단계 — 게임 루프 매핑

게임의 구분되는 상태들을 식별한다 (예: 패턴 인식 → 평가 → 연결 시도 → 성공/실패). **각 상태마다 중요도 위계 표**를 만들어 플레이어가 무엇을 이해해야 하는지 나열한다.

### 3단계 — 스코프 제약

> 스코프를 제한하는 것이 좋은 아트 디렉션의 가장 쉬운 비결이다.

가능한 곳에서 플레이어 자유를 제약한다 — 카메라 앵글 고정, 선형 진행, 모드 전환 — 아트 디렉션 복잡도를 줄인다.

### 4단계 — 고자유도 게임 대응

자유가 필수라면, **중요한 시점과 경로를 우선**한다. 전역 영향이 큰 속성(색·폼 랭귀지·텍스처 밀도)에 집중하고, 세심하게 디렉팅한 핵심 순간들 사이를 보간(interpolation)한다. 시점에 따라 흔들리는 디테일(라인 모티프 등)보다 전역 속성을 우선.

### 5단계 — 시각 속성으로 분석

§2의 속성 프레임워크로 이미지를 진단하고, 현 게임플레이 상태에 가장 잘 맞는 속성을 조정한다.

## 4. 게임 디자인과의 관계

아트 디렉션은 게임플레이와 분리 불가능하다.

- **중요도 위계는 게임 상태에 따라 이동한다.** (Transistor: 탐험 모드에선 환경 서사가 지배, 턴제 전투에선 월드가 단색으로 녹아 전술 요소를 부각.)
- **플레이어 상호작용이 지각을 형성한다.** (Counter-Strike: 전략적 시점은 게임플레이 논리로 주목받는다. 대비는 강화할 뿐 주목 자체를 만들진 못한다.)
- **게임 시스템이 시각 필요를 규정한다.** (Stronghold: 인력 부족 생산 건물에 붉은 정지 표지 — 시스템이 그 정보를 결정적으로 만들기 때문.)
- **시각이 너무 많은 걸 요구하면 게임 디자인 문제다.**
  > 게임플레이가 한 시점에 플레이어에게 너무 많은 것을 요구한다면, 아트 디렉션 문제 이상이다. 게임 디자인 문제다.

---

## 5. 모션 — 시간 차원

모션은 **시간을 설계 차원으로 추가**한다. 프레임 간 속성 변화(위치·색·크기·회전·텍스처 밀도)도 동일 원칙을 따른다 — 가독성엔 대비, 묶음엔 친연, 흥미엔 변주.

- 예: 공 하나가 움직이면 주목을 끈다. 모든 공이 움직이면 특별한 공의 가독성이 무너진다.
- **하이더-지멜 착시(Heider-Simmel Illusion):** 움직임 패턴 자체가 실제 의미와 무관하게 감정적 서사와 연상을 촉발한다.

## 6. 핵심 용어

| 용어 | 정의 |
| :--- | :--- |
| 중요도 위계 (importance hierarchy) | 주어진 순간 플레이어가 이해해야 할 것의 순위 |
| 시각 읽기 위계 (visual read hierarchy) | 실제로 제시된 요소들의 가독성 순위 |
| 신호 vs 잡음 (signal vs noise) | 결정적 정보 vs 방해 요소 |
| 친연 / 대비 (affinity / contrast) | 유사성으로 묶기 / 차이로 부각하기 |
| 다이제틱 vs 논다이제틱 | 게임 월드 내부 vs UI 오버레이 |
| 조화 vs 혼돈 (harmony vs chaos) | 이해 가능한 변주 vs 이해 불가능한 무작위 |
| 시각 멘탈 모델 | 인간이 속성을 통해 이미지를 이해하는 방식 |

## 7. 입문자 4점 체크리스트

1. **플레이어가 무엇을 봐야 하는가? 그것을 읽히게 하라.** 시각 위계 = 중요도 위계.
2. **감정적 공명.** 무엇을 말하는지와 어떻게 말하는지를 연상으로 정렬하라.
3. **조화/대비를 모니터링하며 변주를 더하라.** 변주는 이해 가능한 비율로 관계 맺어야 한다.
4. **시간에 걸쳐 속성을 점검하라.** 모션에서 시각이 어떻게 변하는지 살피고 중요한 스냅샷을 우선하라.

### 조직 원칙

좋은 아트 디렉션은 명확한 의사결정 경로를 요구한다:

- 비주얼이 달성할 목표의 명시
- 기대에 맞는 리소스 예산
- **목표 설정(aiming)과 실행(execution)의 분리**
- 책임과 창작 자율성의 병행
- 성공 측정 지표
- **"위원회식 설계(design by committee)"는 시각 품질을 죽인다** — 끝없는 주관적 논쟁을 막기 위해 전문성 경계를 정의하라.

## 8. 사례 연구

| 게임 | 아트 디렉션 포인트 |
| :--- | :--- |
| **Transistor** (Supergiant) | 아르데코 미학이 제국주의·유토피아 서사를 강화. 붉은 캐릭터는 내부 대비(명도+색상)로 배경 무관하게 가시성 유지. 전투 시 월드를 단색으로 녹여 위계 재편. |
| **Puzzling Places** (VR) | 루프 상태별로 다른 위계 요구. 성공 시 확장 링 애니메이션이 위계 최상위. 청-황 팔레트가 차분한 명료함을 환기. 기하학적 리듬이 만족감을 재현. |
| **Hitman** | 탐험 모드: 환경이 위계 지배. 계획/감각 모드: 상호작용 객체·경비가 최상위. 무기 선택: 무기가 최상위, 나머지는 녹아 내림. |
| **Counter-Strike (Train)** | 시점 자체엔 시각적 구별 없음. 게임플레이 논리가 주목을 유도. 고대비 플레이어 모델은 팀 밸런스를 바꾼다. |
| **Stronghold** | 회전하는 붉은 정지 표지 = 대비(녹색 풍경) + 리듬(모션) + 의미(정지 기호)의 다층 가독성. |
| **Hollow Knight / Control / Journey** | 무드·감정 톤·시각 속성이 게임플레이·서사를 뒷받침하도록 정렬. |
