## 0. 발표자 및 핵심 명제

Miriam Bellard 는 Rockstar Games 의 VP of Art: Visual Development 로, 인게임 아트의 프리프로덕션과 비주얼 설계를 총괄한다. 오클랜드 대학교 건축학 1급 우등 학위를 보유하며, 영화 King Kong (2005) 의 세트 디자이너를 거쳐 인디·AAA 게임을 두루 작업했다. 건축·영화·게임 세 분야에 걸친 20년 경력이 그녀의 방법론적 기반이다.

핵심 명제:

> 많은 게임에서 카메라는 플레이어가 조작한다. 그러나 개발자는 환경 설계를 통해 화면에 무엇이 보이는지를 통제할 수 있다.

이를 그녀는 **"건축가가 곧 촬영감독 (architect as cinematographer)"** 으로 정식화한다. 카메라가 플레이어에게 묶여 있어도, 환경이 플레이어의 이동과 시선을 유도하면 결과적으로 화면 구성을 설계할 수 있다. 환경 디자인은 곧 공간을 매개로 한 촬영 행위다.

## 1. 다섯 설계 기준 (Five Design Criteria)

Bellard 는 환경 설계를 다섯 가지 상위 기준으로 분류한다.

| 기준 | 정의 |
| :--- | :--- |
| Spatial Cinematography (공간적 시네마토그래피) | 환경으로 화면 구성·시선·이동을 통제 |
| Visual Storytelling (시각적 스토리텔링) | 환경이 하나의 캐릭터처럼 서사 의미를 운반 |
| Player Interaction (플레이어 상호작용) | 게임은 일상 도구처럼 사용성(usability)을 갖춘 제품 |
| Aesthetics (미학) | 시각적으로 매혹적일 것 |
| Pragmatics (실용성) | 아트·애니메이션·최적화 측면에서 기술적으로 실현 가능할 것 |

본 정리는 이 중 가장 비중 있게 다뤄진 **Spatial Cinematography** 를 세 축으로 전개한다.

## 2. 공간적 시네마토그래피의 세 축

GDC 강연은 공간적 시네마토그래피를 **2D 화면 / 이동 / 시간** 세 프레임으로 구조화한다.

### 축 1 — 2D 화면 (3D 공간을 2D 화면으로 작곡)

플레이어는 환경을 2D 화면을 통해 경험한다. 따라서 3D 공간은 **2D 화면에서 어떻게 보이는가** 를 기준으로 설계한다. 사진·영화의 구성 원칙이 그대로 적용된다.

| 기법 | 내용 |
| :--- | :--- |
| 초크 포인트(choke point)·경로 활용 | 플레이어 위치가 예측 가능한 지점을 잡아 구성을 통제 |
| 삼분할 법칙(rule of thirds) | 천장·바닥·벽 등 환경 기하에 삼분할 적용 |
| 탄젠트(tangent) 회피 | 오브젝트 가장자리가 어긋나게 겹쳐 가독성을 떨어뜨리는 정렬을 피함 |
| 전경/중경/배경 레이어링 | 깊이감 형성 |
| 반복 요소로 거리 표현 | 동일 건축 요소를 크기 차이로 반복해 원근·거리를 전달 |

깊이감 형성 3대 기법으로 강연은 ① 레이어링(전경·중경·배경의 카메라 속도 차이), ② 동일 요소의 크기 변주 반복, ③ 형태(shape) 활용을 통한 분위기 형성을 든다.

### 축 2 — 이동 (현저성과 어포던스)

이동 축은 **시선을 어디로 두는가(현저성, saliency)** 와 **어디로 움직이는가(어포던스, affordance)** 두 메커니즘으로 나뉜다.

**현저성 (Saliency) — 시선 통제**

| 유형 | 작동 |
| :--- | :--- |
| 대비(Contrast) 현저성 | 색·크기·형태·텍스처·움직임의 차이로 시선을 끈다 |
| 의미(Meaning) 현저성 | 감정적·목표 관련 의미로 시선을 끈다 |

핵심 발견:

> 의미 현저성이 대비 현저성보다 더 우세한 것으로 보인다.

즉 시선 유도에서는 동적 라이팅이나 색 선택 같은 대비 요소보다 **건축적 흥미(architectural interest)** 가 더 무겁게 작동한다. 환경 아티스트는 라이팅·색 대비보다 공간 구조 자체의 의미에 더 비중을 두라는 권고로 이어진다.

**어포던스 (Affordance) — 이동 통제**

| 유형 | 작동 |
| :--- | :--- |
| 표면적 어포던스(surface affordance) | 넓고 시야 좋은 명료한 경로 — 자연스럽게 유도 |
| 복합 어포던스(complex affordance) | 좁고 시야가 나쁘지만 보상이 있어 플레이어가 스스로 택하는 경로 |
| 시그니파이어(signifier) | 붉은 배럴, 노란 하이라이트처럼 가능한 행동을 알리는 신호 |

### 축 3 — 시간 (리듬과 강도)

> 공간은 시간에 걸쳐 경험된다. 시간에 걸친 경험을 통제하려면 공간에 걸친 경험을 통제해야 한다.

방 하나를 한눈에 다 보지 않고 점진적으로 인지하듯, 공간 진행이 곧 시간 경험을 형성한다.

| 기법 | 내용 |
| :--- | :--- |
| 공간 = 시간 | 플레이어는 환경을 시간에 걸쳐 점진 흡수한다 |
| 반복 = 리듬 | 동일 건축 요소의 반복이 플레이어가 환경을 읽는 리듬을 만든다 |
| 요소 밀도 변주 | 요소 밀도를 변화시켜 시간축의 강도(intensity)를 통제 |
| 강도 진동(oscillation) | 강도를 오르내리게 유지해 마비·지루함을 방지 |
| 전이 공간(transitional space) | 두 미학 양식을 섞는 전이 구간 (디즈니랜드 존 전환 모델) |

## 3. 형태 심리 (Shape Psychology)

강연은 형태 자체가 정서를 전달한다고 정리한다.

| 형태 | 연상 |
| :--- | :--- |
| 원형(circle) | 긍정·안전 |
| 날카로운/뾰족한 형태(jagged) | 위험 |
| 수직/수평(vertical / horizontal) | 권력·안정 |

## 4. 프로세스 및 핵심 용어

| 용어 | 정의 |
| :--- | :--- |
| 건축가 = 촬영감독 | 환경으로 화면 구성을 설계하는 관점 |
| 프리비스 / 블록아웃(pre-vis / blockout) | 초기 환경 배치 모델 |
| 탄젠트(tangent) | 가독성을 해치는 가장자리 정렬 |
| 현저성(saliency) | 시선·시각 초점을 유도하는 요인 (대비 / 의미) |
| 어포던스(affordance) | 플레이어 이동·카메라 위치를 유도하는 공간 속성 |
| 시그니파이어(signifier) | 가능한 행동을 알리는 시각 신호 |
| 공간 = 시간 / 반복 = 리듬 | 공간 진행으로 시간 경험과 리듬을 설계 |

프로세스 관점의 메모:

- Rockstar North 에서는 게임 디자인보다 **건축적 레이아웃 결정이 선행**한다.
- 정적 검토로는 발견하기 어려운 구성 문제를 정기 플레이테스트가 드러낸다.
- GTA Online DLC 환경 제작 워크플로가 이론을 실증하는 주 사례로 사용된다.

## 5. ECHORIS 적용 메모

본 문서는 환경 디자인 일반 원칙 정리다. ECHORIS 실제 디렉션은 `Documents/Design/Design_Art_Direction.md` (D-15) 가 SSoT 다. 일반 아트 디렉션 원칙은 [artdirection_인사이트.md](artdirection_인사이트.md) 를 함께 참조한다.

ECHORIS 는 웹 기반 2D 픽셀 아트 횡스크롤 액션 RPG 다. Bellard 의 원칙은 3D 환경 전제이나, 핵심 개념은 횡스크롤 2D 의 카메라·패럴랙스·층위 설계에 직접 번역된다. 횡스크롤은 화면이 처음부터 2D 이므로 "3D 를 2D 로 작곡한다" 라는 명제가 더 직접적으로 성립한다.

| :--- | :--- |
| 건축가 = 촬영감독 (환경으로 시선·이동 통제) | BLAME! 식 거대 수직 메가구조가 곧 카메라 프레이밍 장치 — 빌더 스케일 대비(에르다 1:40)로 화면 구성 통제 |

| 반복 = 리듬 (동일 요소 크기 변주 반복으로 거리 표현) | §0.6 3층 패럴랙스(Far/Mid/Near) — 첨탑·다리의 반복과 크기 차이로 깊이·거리 운반 |
| 공간 = 시간 (강도 진동으로 마비 방지) | §8.2 UI 점진 노출 일정 + §4.2 포지 격발 5단계 시퀀스 — 시간축 강도 설계 |
| 전이 공간 (두 미학을 섞는 전환) | §5.1 메가구조 ↔ 에코 내부 위상 전환 — 회색·호박 듀얼리티에서 청록 잔향 위상으로 미학 전이 |
| 시그니파이어 (가능 행동을 알리는 신호) | §3.1 빌더의 적색 시공 광원 점광 — 적대가 아닌 작업 신호로서의 시각 시그니파이어 |
| 어포던스 (표면적/복합 경로) | 메트로베니아 비선형 탐험의 명료 경로 vs 게이트 너머 보상 경로 분기 설계에 적용 |
