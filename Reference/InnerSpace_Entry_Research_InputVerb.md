## Section 1 — What Remains of Edith Finch (2017) · Lewis's Cannery

Giant Sparrow · Ian Dallas 디렉팅 · Annapurna 퍼블리싱 · 2017년 출시. 본 시퀀스는 가족 구성원 Lewis Thorpe 의 마지막 날을 회상하는 챕터로, 통조림 공장 노동자였던 Lewis 가 마약을 끊은 직후 단조로운 작업을 견디지 못해 점차 머릿속 환상 왕국에 잠식되어 결국 자기 손으로 자신을 처형하기까지를 *플레이어의 손이 직접 그 분열을 수행* 하게 만든다. 본 챕터는 "현실 공간에서 상상 공간으로 *들어가는*" 입력 grammar 의 정점으로 평가받는다 [확인함 — 2017 출시 사실, Dallas GDC 2018 talk "The Theory of Walking Sims" 및 Game Maker's Toolkit 2018 영상 "How Edith Finch Pulls You In"에서 직접 해설].

### 1. Interactive verb input description [확인함]

- **좌측 스틱 (LS)** — 통조림 공장 절단기 앞에 선 Lewis 의 *오른손* 을 좌→우 으로 반복 swipe. 물고기 머리를 한 마리씩 절단기에 밀어넣는 단조 동작. 정확히 좌→우 1 cycle 당 1마리 처리.
- **우측 스틱 (RS)** — 처음에는 화면 우상단 작은 창에 표시되는 *왕* 으로서의 Lewis 가 자신의 왕국을 향해 한 걸음 걷는 입력. RS 를 위·아래·좌·우 8방향으로 기울이면 환상 속 Lewis 가 isometric 미니어처 지도 위를 걷는다.
- **시간 흐름** — 챕터는 약 13-15분. 그 사이 RS 환상 창이 화면의 25% → 50% → 75% → 100% 로 점진 확장된다. LS 의 통조림 작업은 *동시에 계속 요구된다*. 환상이 화면을 다 덮어도 LS 를 멈추면 narration 의 "Lewis 가 손을 멈췄다" 라는 boss 의 호통이 들어오고 game over 에 가까운 압박이 가해진다 [확인함].

### 2. Body-schema shift [확인함]

플레이어의 *주의가 물리적으로 두 손에 나뉜다*. 좌손은 단조·기계적·끝없는 반복을, 우손은 자유로운 모험을 수행한다. 시각 주의는 RS 의 환상 창으로 끌려가지만 LS 의 muscle memory 가 도살을 계속해야 한다. 마지막 3-4 분 동안 RS 환상이 화면을 점령하면 플레이어는 *LS 가 무엇을 하는지 더는 보이지 않는 상태에서 손가락만으로 절단을 이어간다*. "내가 지금 무엇을 손으로 하고 있는가" 가 *눈을 떠나 손가락 끝의 감각으로 옮겨간다*. 이것이 *body-schema 의 분열* 이며, 게임이 끝날 때쯤 플레이어 본인이 "나는 두 공간 안에 동시에 있다" 라고 느낀다 [추측임 — phenomenology 해석, Dallas 본인이 명시하지는 않았으나 GMTK Mark Brown 의 해석과 일치].

### 3. Animation contract [확인함]

LS swipe 1회 당 약 1.2초 — 물고기 잡기·끌어당기기·절단기 통과·머리 떨어짐 4-beat 애니메이션이 강제 재생된다. 입력은 가속할 수 없다(skipping 불가). RS 환상 측 캐릭터의 걸음은 약 0.4초/step 으로 LS 보다 3배 빠르다 — 환상이 훨씬 *유혹적인 입력 grammar* 라는 점이 입력 속도 차이로 박힌다. 환상 창이 확장될 때 transition 은 ease-in 약 2-3 초로 *플레이어가 알아차리지 못하게* 진행된다 [확인함, GMTK 2018 frame-by-frame 분석].

### 4. Audio-haptic contract [확인함 — 음향, 추측임 — rumble]

- **음향** — 절단기 click + 물고기 떨어짐 wet thud 가 LS swipe 마다 박힌다. Narration 은 부드러운 fairy-tale 음색으로 환상 측을 묘사하며 작업 소음 위에 *덮인다*. 챕터 말미에 narration 이 점차 작업 소음을 완전히 압도하며 절단기 소리가 *왕국의 행렬 북소리* 로 cross-fade 된다.
- **rumble** — DualShock 4 / Xbox controller 에서 LS swipe 마다 약한 좌측 rumble pulse (절단기 진동) + RS step 마다 우측 rumble pulse (왕국 행진 발걸음). Rumble 좌우 분리가 두 입력의 *공간 분리* 를 손바닥으로 박는다 [추측임 — 직접 출처 확인 X, 다만 PS4 출시 사양 + Giant Sparrow 의 audio-tactile 설계 일관성으로 강하게 추정].

### 5. What's different from menu click [확인함]

표준 메뉴 클릭은 *한 손가락의 단 한 번 입력* 이며 입력 직후 화면이 전환된다. 환자는 *기다린다*. Edith Finch 의 cannery 는 *13-15분 동안 두 손이 끊임없이 입력을 요구* 받으며 그 시간 동안 *공간 전환이 점진 발생* 한다. 즉 "공간에 들어갔다" 는 사건이 *클릭 후* 가 아닌 *클릭이 지속되는 동안* 일어난다. 이것이 cannery 시퀀스의 핵심 발명품이다 — *entry-as-duration* 이며, *entry-as-dual-input* 이다.

### ECHORIS 적용 즉시 시사점

- 모루 진입은 *두 입력이 동시 필요* 한 구조로 재설계 가능 → 한 손은 Erda 의 외부 동작 (이동/holding), 다른 손은 검의 내부 진입 (attack pulse).
- *Duration 이 entry 다* — 0.0초 fade 가 아닌 2-4초 동안 두 손이 입력을 지속해야 진입이 완성되는 grammar.
- 자세한 안 → Section "ECHORIS 제안 B" 참조.

## Section 2 — Death Stranding (2019) · DualSense / DualShock haptics

Kojima Productions · Hideo Kojima 디렉팅 · Sony Interactive Entertainment 퍼블리싱 · 2019년 11월 PS4 출시. Director's Cut 은 2021년 9월 PS5 에서 DualSense 햅틱·adaptive trigger 풀 지원으로 재출시 [확인함]. 본 게임은 *짐꾼* 으로서의 Sam Porter Bridges 가 황무지를 가로질러 화물을 운반하는 grammar 를 *컨트롤러 입력이 곧 신체 균형* 인 방식으로 제시한 사례로, AAA 게임 중 가장 *embodied* 한 trigger 매핑으로 평가된다.

### 1. Interactive verb input description [확인함]

- **L2** — Sam 의 *왼쪽 어깨 끈* 을 잡는 입력. 가벼운 hold 면 가벼운 균형 보정, deep hold 면 화물의 좌측 무게를 적극적으로 좌측으로 끌어당김.
- **R2** — Sam 의 *오른쪽 어깨 끈*. 좌우 대칭.
- **L2+R2 동시 hold** — Sam 이 화물을 *몸에 밀착시켜 안정화*. 그러나 스태미너 소모 증가. 가파른 경사·강풍·강물에서 강제됨.
- **L1/R1 tap** — 화물 재정렬 + 사다리/로프 등 도구 사용.
- **R2 hold (총)** — *동일한 트리거가 무기일 때는 trigger pull 의 progressive resistance* 로 변한다. PS5 DualSense 에서 adaptive trigger 가 총의 firing point 직전에 *deliberate stop* 을 만든다 [확인함, PS Blog 2021-09-15].

### 2. Body-schema shift [확인함 · 추측임 일부]

L2/R2 가 어깨 끈으로 매핑되는 순간 플레이어의 두 *검지(혹은 중지)* 가 Sam 의 두 어깨가 된다. 컨트롤러를 든 손바닥은 Sam 의 *몸통* 이 되고, 좌우 트리거의 비대칭 hold 가 Sam 의 *체중 이동* 으로 직접 번역된다. 이것은 단순한 metaphor 가 아니라 *muscle coupling* 으로, 가파른 비탈에서 한 쪽 트리거를 놓으면 손가락에서 *놓은 쪽이 무너지는* 감각이 발생한다 [추측임 — 일관된 플레이어 보고이나 학술 검증 자료는 부재].

### 3. Animation contract [확인함]

Sam 의 stumble animation 은 약 0.8-1.5초 ease-out 곡선으로 *반드시 재생되며* skip 불가. L2/R2 입력으로 *recover* 가 가능한 윈도우가 약 0.4초. 이 0.4초 안에 균형을 잡지 못하면 화물이 떨어지거나 Sam 이 넘어진다. *Recover gesture* 는 LS 가 아닌 L2/R2 — 이동이 아닌 *체중 재배치* 가 입력 layer 로 분리되어 있다.

### 4. Audio-haptic contract [확인함]

- **DualSense 햅틱** — Sam 의 발자국마다 좌우 분리된 햅틱 pulse 가 *지면 재질별로 다르다*. 자갈은 sharp tick 군집, 진흙은 dull thump, 눈은 muffled crunch. 트리거 hold 시 *어깨 근육 긴장* 을 모사하는 sustained low-frequency hum 이 트리거 쪽에 발생한다 [확인함, PS Blog].
- **BB pod heartbeat** — Sam 이 등에 멘 BB (Bridge Baby) 의 심장 박동이 controller 중앙 햅틱으로 약 60-80 BPM 으로 지속 펄스 [확인함]. BB 가 흥분하거나 BT (Beached Things) 근처에 가면 BPM 이 120+ 로 가속한다. 이것이 *baby-as-anchor* — 플레이어는 *손바닥에 다른 생명체의 심장* 을 항상 들고 있다.
- **Adaptive trigger** — 강풍 노출 시 L2/R2 의 actuator 가 trigger 를 *밀어내며* 플레이어의 손가락이 *바람과 싸우는* 감각을 만든다.

### 5. What's different from menu click [확인함]

표준 메뉴 click 은 *trigger 가 binary* (눌렸다/안눌렸다). Death Stranding 의 L2/R2 는 *analog gradient* + *resistance gradient* + *left/right asymmetry* 의 3차원 입력이다. "Sam 이 황무지를 *지나가고 있다*" 가 컷씬·로딩 없이 *손가락의 지속 노력* 으로 박힌다.

### ECHORIS 적용 즉시 시사점

- 모루에 검을 *내려놓는* 순간 controller 의 L2/R2 가 *검의 두 어깨* 가 되어 *조심스럽게 놓을수록 trigger hold 가 길어지는* grammar 가능.
- DualSense adaptive trigger 가 *검이 모루에 박힐 때 점진 저항 후 give-way* 를 줄 수 있음 (Section "ECHORIS 제안 E" 참조).

## Section 3 — Cocoon (2023) · 들고-내려놓고-들어가기

Geometric Interactive · Jeppe Carlsen 디렉팅 (Limbo · Inside 메인 게임플레이 디자이너 출신) · Annapurna 퍼블리싱 · 2023년 9월 출시. Cocoon 은 *세계가 구슬(orb) 안에 들어있고, 그 구슬을 들고 다닐 수 있으며, 구슬을 내려놓고 그 안으로 들어갈 수 있다* 라는 단일 메커닉을 전체 게임 grammar 로 확장한 작품이다. ECHORIS 의 *아이템 안으로 들어간다* 와 가장 직접적으로 정합하는 입력 grammar 를 가지고 있다 [확인함 — 출시 사실, Annapurna 공식 페이지].

### 1. Interactive verb input description [확인함]

- **A (Xbox) / Cross (PS) hold** — 구슬에 접근 후 버튼을 누르면 캐릭터가 구슬을 *들어올린다*. 약 0.6초 정도의 lift animation 동안 버튼은 *계속 hold* 되어야 한다.
- **A hold + LS** — 구슬을 들고 LS 로 이동. 입력 grammar 의 핵심은 *버튼이 hold 되는 동안에만 캐릭터가 구슬을 들고 있다* 라는 것이다. 그러나 Cocoon 의 단순화된 grammar 는 한 번 lift 가 완료되면 buton 을 놓아도 들고 있는 상태가 유지된다. *내려놓기* 가 별도 입력이다.
- **A tap (들고있는 상태)** — 구슬을 *내려놓는다*. drop animation 약 0.4초.
- **A tap (구슬 위에 서 있는 상태)** — 구슬 안으로 *들어간다*. 카메라가 구슬 표면으로 zoom-in 하면서 표면이 *부풀어 올라 플레이어를 삼킨다*. 약 2-3초 transition.

→ 즉 3-input combo: (1) hold-to-lift → (2) carry → (3) drop → (4) tap-to-enter. *Carry phase 가 별도 verb 로 존재* 한다는 점이 핵심이다. ECHORIS 의 현재 grammar 는 (1)-(2)-(3) 이 모두 *menu* 안에 추상적으로 일어나고 (4) 만 button click 으로 노출된다.

### 2. Body-schema shift [확인함]

플레이어는 *세계를 손에 들고 있다*. 들고 있는 동안 다른 세계로 *통과 가능한 게이트* (color-coded membrane) 가 활성화된다. 구슬을 내려놓으면 그 구슬은 *세계 안의 한 점이자 동시에 그 자체로 세계* 가 된다. 입력 verb 가 *Russian doll metaphysics* 를 매 step 박는다. 플레이어의 인지가 "이 공간 = 그 공간을 포함하는 더 큰 공간 = 또 그 공간 안의 점" 으로 무한 nesting 된다.

### 3. Animation contract [확인함]

- Lift: 0.6초, 캐릭터 양손이 구슬을 잡고 어깨 위로 올림. 무게감 ease-out.
- Drop: 0.4초, 양손이 펴지며 구슬이 *살짝 통통* 튕긴다.
- Enter: 2-3초, 카메라 dolly-in + 구슬 표면 ripple + 표면이 막처럼 *벌어진다*. 캐릭터 실루엣이 막을 통과하는 약 0.5초 *push-through* shot 이 핵심 — *통과* 가 보인다.
- Exit: 동일 transition 의 역재생. 플레이어는 *어느 방향으로든 진입/탈출* 이 같은 grammar 임을 학습한다.

### 4. Audio-haptic contract [확인함]

- **음향** — Lift 시 low-frequency hum + 구슬의 *bioluminescent pulse* 와 동기화. Carry 동안 hum 이 지속. Enter 시 hum 이 *내면 공간 음색* 으로 cross-fade (외부 ambient 가 muffled 되고 inner ambient 가 surfaces).
- **rumble** — Carry 동안 controller 중앙에 *낮은 지속 진동*. Enter 시 진동이 0.5초 *spike* 후 *내면 공간의 새로운 진동 텍스처* 로 전환. 진동이 *공간 음색* 처럼 변하는 것이 entry 의 signal.

### 5. What's different from menu click [확인함]

표준 메뉴 click 은 *carry phase 가 0초*. 클릭 직전에는 무기가 인벤토리 안에 *추상* 으로 존재했고 클릭 직후에는 *던전이 화면에 떠 있다*. 구슬-and-drop grammar 는 carry phase 를 *플레이어의 손에 실재* 시키는 점이 결정적이다. *세계를 손에 들고 다니는 시간* 이 있어야 *내가 그 세계의 외부에 있다* 가 인지되고, 외부에 있던 자가 내부로 *들어가는* 사건이 비로소 일어난다.

### ECHORIS 적용 즉시 시사점

- 검을 *Erda 의 허리에서 뽑아 손에 들고 모루까지 걸어가 모루 위에 내려놓는* carry phase 를 *입력 grammar* 로 노출시켜야 한다. 현재 인벤토리 click 은 carry phase 를 abstract 시켜 *외부/내부* 분리가 박히지 않는다.
- ECHORIS 제안 C 의 핵심 출처.

## Section 4 — Astro's Playroom (2020) · DualSense 환경별 햅틱

Team Asobi · Nicolas Doucet 디렉팅 · Sony Interactive Entertainment · 2020년 11월 PS5 런칭 동시 출시. Astro's Playroom 은 *DualSense feature demo* 로 설계된 무료 동봉 게임이며, *환경별로 controller 햅틱과 trigger 저항이 변하는 것* 이 entry/transition signal 의 핵심 발명이다 [확인함, Sony PR 2020-11-12].

### 1. Interactive verb input description [확인함]

- **standard run** — LS 이동 + X jump. 무난한 binary 입력.
- **frog suit (점프 공간)** — L2/R2 *동시 hold = squat* + *동시 release = jump*. 트리거가 다리 근육이 된다.
- **monkey suit (와이어 끝 매달림)** — L2/R2 *교대 hold = climb*. 좌우 트리거가 좌우 손이 된다.
- **ball mode (구체 안)** — gyro 기울임으로 ball 굴림. 컨트롤러 자체가 ball 의 inner 공간이 된다.
- **cooling tube 내부** — 입력은 LS 이동이지만 *햅틱이 바뀐다*. 통로를 지나가는 동안 *공기 흐름* 햅틱이 손바닥 전체에 분산 진동으로 발생한다 [확인함, PS Blog Doucet 인터뷰].

### 2. Body-schema shift [확인함]

플레이어가 *어느 공간 안에 있는지* 를 *손바닥 진동 텍스처로 인지* 하게 된다. 같은 LS 입력이 cooling tube 안에서는 *공기* 처럼, metal 위에서는 *금속 발자국* 처럼, 수영 중에는 *유체 저항* 처럼 손에 박힌다. 시각이 아닌 *촉각이 공간 식별자* 가 된다. 이것이 *haptic-as-room-tag* 이며, Astro 의 유일무이한 발명이다.

### 3. Animation contract [확인함]

각 공간 진입 transition 자체는 0초 — 카메라 cut 으로 즉시 전환. 그러나 *진입 직후 첫 3-5초* 동안 *햅틱이 명시적으로 다르다* 는 점을 플레이어가 알아챌 수 있도록 디자인되어 있다. 즉 "이 공간에 들어왔다" 는 인지가 *transition cut* 이 아닌 *입력 후 첫 햅틱 체험* 에서 일어난다.

### 4. Audio-haptic contract [확인함]

- **cooling tube** — 공기 흐름 hiss + 손바닥 전체 분산 low-freq 진동.
- **금속 walkway** — sharp tick-tock 좌우 분리 햅틱 (발자국 정확도).
- **수영** — sustained dull thump + adaptive trigger 가 *물 저항* 으로 변함.
- **모래** — granular crunch 음 + grainy mid-freq 진동.
- **각 환경별 햅틱이 모두 다른 actuator pattern 으로 hard-coded** 되어 있어 플레이어는 *눈 감고도* 어디에 있는지 안다 [확인함, Doucet 인터뷰].

### 5. What's different from menu click [확인함]

표준 메뉴 click 은 *입력 후 화면이 바뀌면 그것이 entry 의 signal*. Astro 는 *입력 후 손바닥 진동 텍스처가 바뀌면 그것이 entry 의 signal*. *공간 식별이 시각에서 촉각으로 outsource* 되었다.

### ECHORIS 적용 즉시 시사점

- ECHORIS 는 PixiJS 2D 픽셀아트로 *시각 transition 의 정보 밀도가 낮다* — 메뉴 click 이 spatial entry 로 안 느껴지는 근본 원인 중 하나가 *시각에만 의존* 하기 때문일 가능성.
- Steam Input + Tauri 환경에서 DualSense / Xbox controller 햅틱을 활용해 *아이템계 진입 직후 첫 3초의 햅틱 텍스처가 명시적으로 다른* grammar 를 만들 수 있다. *키보드+마우스* 페르소나에는 audio cross-fade 로 대체.

## Section 5 — Outer Wilds (2019) · Quantum Moon / Ash Twin

Mobius Digital · Alex Beachum 디렉팅 · Annapurna 퍼블리싱 · 2019년 5월 출시. Outer Wilds 의 두 시퀀스 — Quantum Moon 착륙과 Ash Twin Project 진입 — 는 *입력 grammar 가 spatial reasoning 자체* 로 작동하는 사례이다 [확인함, GDC 2020 Beachum talk "Outer Wilds: A New Perspective"].

### 1. Interactive verb input description [확인함]

- **Quantum Moon (양자 달)** — 양자 객체는 *직접 보고 있지 않을 때* 만 이동한다. Quantum Moon 에 착륙한 후 *카메라 (mouse / right stick)* 를 *어떤 방향으로 돌리느냐* 가 다음에 어느 위치에 있을지를 결정한다. 카메라를 달 표면에서 떼면 달 자체가 사라질 수 있다. 입력 verb 가 *시선 유지* 다.
- **Ash Twin Project** — 모래 행성 Ash Twin 의 표면이 시간 경과로 마모되어 *특정 시간에 특정 wormhole 이 노출* 된다. 플레이어는 *jetpack 으로 표면에 도착해 wormhole 직전에 jetpack 입력 (스페이스 hold)* 으로 진입 타이밍을 맞춰야 한다. 입력 grammar 는 *jetpack thrust timing + 정확한 wormhole 정렬*.
- **standard 입력** — WASD 이동, 마우스 시선, 스페이스 jetpack hold, Shift 카운터.

### 2. Body-schema shift [확인함]

Quantum Moon 의 *시선 유지* 입력은 플레이어를 *눈 깜빡임에 책임지는 자* 로 만든다. *내 시야가 우주의 양자 상태를 붕괴시킨다* 가 마우스 hold 동안 *지속 sensation* 으로 박힌다. 시각 입력 = 양자 입력. Ash Twin 의 wormhole 통과는 *jetpack hold 의 정확성* + *물리적 정렬* 로 *입력의 정밀도가 그대로 공간 진입 가능 여부* 가 된다.

### 3. Animation contract [확인함]

- Quantum Moon — 시선을 떼고 다시 보면 달이 *깜빡 없이* 다른 위치에 있다. transition 자체는 0 frame. 그러나 *내가 시선을 뗀 그 짧은 순간* 이 entry/exit 의 시간이다.
- Ash Twin wormhole — 진입 시 약 1.5초 *모래에 빨려들어가는* spiral animation. 카메라 control 은 유지된다.

### 4. Audio-haptic contract [확인함]

- 양자 객체 근처에는 *whispering* ambient sound 가 발생. 시선이 떼지기 시작하면 *whisper 가 커진다* — 양자 붕괴 임박 signal.
- Wormhole 진입 시 모래 storm 음 + 저주파 hum.
- 일반 마우스+키보드 게임이라 rumble 은 제한적이나 controller 플레이 시 wormhole 진입에서 lateral spin rumble pulse 발생 [추측임].

### 5. What's different from menu click [확인함]

표준 메뉴 click 은 *클릭하면 전환*. Outer Wilds 의 양자 grammar 는 *입력을 의도적으로 떼야* 전환된다 — *not-input 이 input* 인 역설 grammar. Spatial entry 가 *플레이어의 인지 행위* 그 자체로 정의된다.

### ECHORIS 적용 즉시 시사점

- *시선 떼기* 를 PixiJS 2D 에서 구현하긴 어려우나 *입력을 의도적으로 멈춰야* 진입이 완성되는 grammar 는 ECHORIS 휴식·아이템계 진입에 일부 차용 가능 (예: 모루 앞에서 *움직이지 않고 2초* 가 진입 trigger).

## Section 6 — Souls bonfire / Hollow Knight bench · 휴식 동작

FromSoftware *Dark Souls* (2011) bonfire · Team Cherry *Hollow Knight* (2017) bench. 두 게임은 *세이브 포인트가 동시에 세계 상태 anchor* 인 grammar 를 정립했고, *휴식이라는 의례적 입력 verb* 의 표준을 만들었다 [확인함, Miyazaki 인터뷰 IGN 2016 + Hollow Knight Wiki].

### 1. Interactive verb input description [확인함]

- **Dark Souls bonfire** — 화톳불 (bonfire) 근처에서 *A (Xbox) / Cross (PS)* 한 번 누르면 캐릭터가 한 쪽 무릎을 꿇고 *주먹 위에 불꽃이 솟는다*. 입력은 단발 tap.
- **Hollow Knight bench** — 벤치 위에 정확히 서서 *L (Up direction) + interact* 또는 *interact* 버튼으로 *앉기*. 캐릭터가 벤치 위에 앉아 다리를 늘어뜨리고 cloak 이 살짝 펄럭인다.
- **rising** — 화톳불/벤치에서 *일어나기* 는 *방향 입력 (LS)* 만으로 자동 발생. 휴식 종료가 *명시 입력* 이 아닌 *재이동 의지* 로 박힌다.

### 2. Body-schema shift [확인함]

플레이어가 *세계의 외부 관찰자에서 세계 안의 한 점에 정착한 자* 로 전환된다. 휴식 input 직후 캐릭터의 *시야가 고정* 되고, *적 spawn 이 reset* 되며, *HP 가 회복* 되고, *세계가 다시 시작*되는 종합 grammar 가 *단 한 번의 tap* 에 묶여있다. 한 번의 tap 이 *공간을 anchor 화* 하는 weight 를 갖는다.

### 3. Animation contract [확인함]

- Bonfire 앉기: 약 2.5초 무릎꿇기 → 불꽃 점화 → 정지 자세. Skip 불가.
- Bench 앉기: 약 1.0초 앉기 + cloak idle loop 무한.
- 화면 효과: 미세한 bloom 증가, 주변 ambient 가 *bonfire 음색* 으로 cross-fade.

### 4. Audio-haptic contract [확인함]

- Bonfire — 불꽃 점화 *whoosh* + 지속 *crackle* loop. Rumble 은 약한 low-freq sustained pulse [확인함, DS3 PS4].
- Bench — Christopher Larkin 의 piano motif 가 short cue 로 들어옴. *세계가 잠시 노래한다* — 이것이 휴식의 음향 signature.

### 5. What's different from menu click [확인함]

화톳불/벤치는 *menu 자체가 아니다* — *세계 안의 한 물체 (bonfire / bench) 에 다가가서 그 물체와의 spatial 관계로* 입력이 들어간다. *menu 가 공간으로 외화* 되어 있다. 휴식 input 의 *목적* 도 다르다 — 단순 save 가 아니라 *세계의 음색을 잠시 멈추고 듣는* 의례.

### Hollow Knight bench 의 ECHORIS 적용 가능성 [확인함 — 2D pixel-art 직접 정합]

ECHORIS 는 2D 픽셀아트 + 메트로베니아 + 영구 거점 grammar 라는 점에서 Hollow Knight 의 bench 가 *가장 직접적인 prior art* 이다. ECHORIS 모루(anvil) 는 다음 두 가지 grammar 를 동시에 만족해야 한다:

1. *bench-like* — 세이브, 회복, HUD 일부 reset 같은 *anchor* 기능
2. *anvil-as-portal* — 검의 아이템계로 *진입* 하는 transit 기능

이 두 grammar 는 *상충* 한다. bench 는 *멈춤*, anvil-as-portal 은 *이동*. ECHORIS 모루는 *멈춤과 진입이 동일 spatial point* 에서 일어나야 한다.

### ECHORIS 적용 즉시 시사점

- 모루 앞 *근접* 시 자동으로 sit-like idle (Erda 가 모루 앞에 무릎꿇고 검을 꺼냄) animation 이 발생.
- *이 idle 자체* 가 menu 가 아니라 *공간 의례* 가 되어야 한다.
- 진입은 sit 직후 *별도 input verb* 로 분리 — 휴식과 진입을 같은 input 으로 묶으면 spatial entry 의 무게가 사라진다.

## Section 7 — Journey (2012) · 단일 버튼 + 스카프 물리

thatgamecompany · Jenova Chen 디렉팅 · Sony Computer Entertainment 퍼블리싱 · 2012년 3월 PS3 출시 [확인함]. Journey 의 grammar 는 *입력의 양을 줄여 입력의 무게를 늘리는* 패러다임의 정점이다.

### 1. Interactive verb input description [확인함]

- **LS** — 이동.
- **R1 / O** — 점프 (스카프 길이에 따라 활공 가능).
- **Circle button (단일 chirp)** — 소리 한 번 내기. 길게 누르면 큰 chirp.
- **그 외 모든 menu 없음** — Journey 에 inventory, dialog, choice menu 가 존재하지 않는다.

### 2. Body-schema shift [확인함]

플레이어의 *주의 전체* 가 *이동 + 발성* 두 verb 에 응축된다. *다른 플레이어와의 만남* 도 chirp 한 번으로만 일어난다. *최소 입력 → 최대 embodiment* — 입력 vocabulary 가 작아서 *각 입력 하나하나가 의례적* 으로 느껴진다.

### 3. Animation contract [확인함]

- chirp 시 캐릭터 주위 mandala glyph 가 *발광 + 확산*. 약 1.5초.
- 스카프 cloth simulation 이 *입력에 직접 반응* — 점프하면 스카프가 뒤로 휘날리고, 활공 동안 진행 방향에 대해 항력으로 흔들린다.

### 4. Audio-haptic contract [확인함]

- chirp 의 음색이 *플레이어 진척도에 따라 진화* (Austin Wintory 의 music score 와 동기화).
- 다른 플레이어의 chirp 는 *다른 음색* 으로 들려와 *그 chirp 가 내가 아닌 누군가의 것* 임이 청각으로 박힌다.

### 5. ECHORIS 적용 시사점

- *입력 vocabulary 의 축소* 가 *각 입력의 의례적 무게* 를 만든다. ECHORIS 의 아이템계 진입 input 도 *현재의 menu click + 다중 confirm* 을 *단 한 verb* 로 응축하면 무게가 살아난다.
- 스카프-as-feedback 패러다임 — Erda 의 *외투/머리카락/검 어깨끈* 이 cloth-like 반응을 하면 입력 결과가 *항상 visible feedback* 으로 박힌다.

## Section 8 — Brief mentions

### Half-Life: Alyx (2020) · Valve · VR gravity glove [확인함]

Alyx 의 *gravity glove* 는 멀리 있는 오브젝트를 *손짓으로 잡아 던지듯 호출* 하는 VR input verb. 손을 향해 오브젝트가 *물리적 호* 를 그리며 날아온다. *내 손이 멀리에 있는 것까지 닿는다* 의 body schema 확장이 *공간 entry 의 prerequisite* 임을 보여준다. ECHORIS 는 VR 미지원이지만 *원거리 오브젝트가 플레이어 손 위로 호를 그리며 호출되는* 시각 grammar 는 2D 픽셀아트로 재현 가능. 아이템을 인벤토리에서 모루로 *옮길 때* gravity-glove-like arc 사용 가능.

### Resident Evil 4 Remake / Village (2021-2023) · Capcom · 인벤토리 Tetris [확인함]

inventory 가 *grid Tetris* 로 각 아이템이 cells 차지 + 회전 가능. *cursor 가 grid 위를 휘청거리며* 아이템을 끌고, 회전 시 *별도 tap*. 메뉴이지만 *공간 grammar* 가 stuffed 되어 있어 *공간감* 이 발생한다. ECHORIS 인벤토리도 grid-Tetris 보다 spatial weighting 이 약하다면 *menu click 의 무게* 가 약해질 수밖에 없다.

### Brothers: A Tale of Two Sons (2013) · Starbreeze · 두 스틱 = 두 형제 [확인함]

LS = 형, RS = 동생. L2 = 형 interact, R2 = 동생 interact. *한 controller 가 두 캐릭터* 를 동시 운행하는 grammar. Edith Finch dual-input 의 직접 prior art. 마지막 시퀀스에서 형 죽음 후 동생이 강을 건너는 장면에서 *형의 LS 입력을 동생의 stick 으로 넘기는* 입력 grammar 가 narrative 의 핵심이 된다. ECHORIS Erda + 검 Ego 의 *두 주체* 를 controller 양손으로 분리하는 prior art.

### The Last of Us Part II (2020) · Naughty Dog · 기타 입력 [확인함]

Ellie 가 기타를 칠 때 LS = chord 선택, RS = strum. 두 스틱이 *두 손* 으로 직접 매핑. *내가 음악을 만들고 있다* 가 controller 손가락의 실시간 입력으로 박힌다. ECHORIS 의 *대장간 단조* 시퀀스도 LS = 망치 각도, RS = 검 위치로 매핑 가능 (현재 미구현). 단조 entry → 아이템계 entry 의 ritual chain 으로 확장 여지.

### Tears of the Kingdom (2023) · Nintendo · Ultrahand fuse [확인함]

Ultrahand 는 두 오브젝트를 *공간상에서 가져다 대고 fuse* 입력. *gluing* 의 verb. *fuse 의 sticky moment* 에 controller rumble + audio click 으로 *합쳐졌다* 가 박힌다. ECHORIS 의 *검 + 모루 = 아이템계 진입* 도 fuse-like grammar 로 재해석 가능 — 검을 모루에 *붙이는* 입력 후 *별도 입력으로 들어간다*.

### Steve Swink *Game Feel* (2008) · 기초 텍스트 [확인함]

CRC Press 출판. Swink 는 game feel 을 *real-time control* + *simulated space* + *polish* 의 3요소로 정의. 본 문서의 모든 grammar 는 Swink 의 frame 내에서 *입력의 real-time 응답성이 simulated space 의 entry 를 만든다* 는 thesis 의 변주. 필독 [확인함, ISBN 9780123743282].

## Central Synthesis — 12-15 명명된 Entry Verb 사전

각 verb 는 (1) 정의 (2) 출처 게임 (3) body-schema 효과 (4) 2D pixel-art / KB+mouse 적용성 (5) 구현 비용 (dev-week) 순.

### V1. **Dual-Hand Split** (양손 분열)

- *정의*: 양 손이 *서로 다른 spatial layer* 에서 동시 입력을 강요받는 grammar. 한 손은 외부 공간, 다른 손은 내부 공간을 운행한다.
- *출처*: Edith Finch (Lewis cannery), Brothers (두 형제), Death Stranding (좌우 어깨끈).
- *body-schema*: 주의가 두 손에 분열되어 *두 공간에 동시 거주* 의 phenomenology 발생.
- *2D / KB+mouse 적용*: KB 좌손 (WASD) + 마우스 또는 KB 우손 (J/K/L) 분리 가능. 컨트롤러는 즉시 적용. **적용성 ★★★★☆**
- *구현 비용*: 3-4 dev-week (입력 추상화 + dual-channel animation).

### V2. **Carry-and-Drop** (들고-내려놓기)

- *정의*: 오브젝트를 *visible 하게 hold → carry → drop* 한 후 별도 입력으로 진입. Carry phase 가 *별도 verb 로 노출* 된다.
- *출처*: Cocoon (구슬), TotK (Ultrahand), Death Stranding (화물).
- *body-schema*: *세계를 손에 들고 다니는 시간* 이 외부/내부 분리를 박는다.
- *2D / KB+mouse 적용*: 픽셀아트 carry sprite + 이동 grammar 로 직접 구현. **적용성 ★★★★★**
- *구현 비용*: 2-3 dev-week (sprite + state machine + drop hitbox).

### V3. **Hold-to-Commit** (지속 입력 의례)

- *정의*: 단발 click 이 아닌 *N초 hold* 를 통해 input 의 의례 무게를 만드는 grammar. Hold 중 progressive visual/audio buildup.
- *출처*: Souls bonfire kindle (꺾여듦 동작), Death Stranding 화물 안정화, Cocoon lift.
- *body-schema*: *시간 자체가 commitment*. 0초 click 으로는 진입의 무게가 박히지 않는다.
- *2D / KB+mouse 적용*: KB 에서 *E hold 2-3초* 표준. **적용성 ★★★★★**

### V4. **Adaptive-Trigger Resistance** (트리거 저항 곡선)

- *정의*: DualSense adaptive trigger 가 *입력 진행도에 따라 점진 저항 → give-way* 곡선을 만든다.
- *출처*: Death Stranding (총 격발), Astro's Playroom (수영), 다수 PS5 타이틀.
- *body-schema*: 손가락 끝이 *물리적 침투* 를 느낀다. *give-way 순간* 이 entry moment 와 정확히 동기화.
- *2D / KB+mouse 적용*: KB 미지원. DualSense 전용 — 전체 페르소나의 일부에만 적용. **적용성 ★★☆☆☆**

### V5. **Haptic Room-Tag** (공간별 햅틱 텍스처)

- *정의*: 진입 직후 *햅틱 텍스처가 명시적으로 다르다*. 시각 transition 보다 햅틱이 entry 의 1차 signal.

## ECHORIS 제안 — 5개 대안 입력 grammar + 휴식 비교 논증

ECHORIS 제약 재확인:

- 2D 픽셀아트 사이드스크롤
- PC 키보드+마우스 + 컨트롤러 (Phase 3+ Steam Input)
- 웹 (PixiJS) 초기 → Tauri PC port
- VR 미지원
- 기존 컨트롤: WASD/방향키, 공격, 점프, 대시, interact
- 현재 진입 grammar: 인벤토리 click → 검 선택 click → 모루 click → F → fade → spawn

위 grammar 의 핵심 결함: *carry phase 0초*, *hold-to-commit 0초*, *audio cross-fade 가 fade 와 동시* (분리 없음), *cloth/animation feedback 없음*, *body-schema shift 없음*. 즉 *scene-load* 와 동일한 input pattern.

### 제안 A. **Hold-to-Place** (1 dev-week) — 최소 비용 baseline

**입력 grammar**

1. Erda 가 모루로 *근접* (모루 hitbox 내).
2. *E key (또는 컨트롤러 A) 를 2초 hold*.
3. Hold 중 KeyPrompt gauge 가 #FFA41B (브랜드 키컬러) 로 점진 채워짐.
4. Hold 0.5초부터 검이 Erda 의 등에서 *어깨 너머로 arc* 를 그리며 *모루 위로 천천히 이동*.
5. Hold 2.0초에 검이 모루에 *snap* 하며 단조 불꽃 + 햅틱 spike.
6. Snap 직후 자동 push-through-membrane transition (V8) 1.5초.

**Frame-by-frame**

- 0.0초: hold 시작, Erda 무릎 꿇기 시작.
- 0.5초: Erda 가 검을 등에서 뽑아 어깨 위로 올림.
- 1.0초: 검이 모루 위 약 30px 상공에 떠 있음, 회전 시작.
- 1.5초: 검끝이 모루 표면에 접촉 시작 (resistance hum 시작).
- 2.0초: 검이 모루에 박힘 (snap + 불꽃 + 햅틱 spike).
- 2.0-3.5초: membrane push-through (V8) — 모루 표면에 ripple 발생, 카메라 zoom-in, 외부 ambient ducked, inner ambient surfaces.
- 3.5초: 아이템계 spawn.

**Animation length**: 총 3.5초 (현재 fade 약 1초의 3.5배).
**Audio**: hold 동안 low-freq hum buildup → snap 시 강한 hit + ember crackle → push-through 동안 외부 wind 음 0.7→0.0, 내부 cathedral hum 0.0→1.0 cross-fade.
**Haptic**: hold 동안 점진 강해지는 low-freq pulse → snap spike → 진입 직후 inner ambient 햅틱 텍스처로 전환.
**Dev cost**: 1주.
**2D pixel-art 적합성**: ★★★★★ — sprite 추가만 필요.
**Prior art**: V3 + V7 + V8 조합. Souls bonfire (kindle hold) 의 직접 변형.

### 제안 B. **Edith Finch Dual-Input** (3 dev-week)

**입력 grammar**

1. Erda 모루 접근.
2. 진입 시퀀스 시작: 화면이 좌(Erda 외부) + 우(검 표면 zoom) 의 *split 분할* 로 분리.
3. 플레이어가 *동시에 두 입력을 유지* 해야 진입 진행:
   - LS (이동) — Erda 의 손이 검을 모루에 *밀어넣는* 좌→우 입력.
   - RS / 마우스 — 검 표면의 *menbrane 안* 으로 *spectral Erda 가 걸어들어가는* 입력.
4. 양 입력이 *동시 유지 2-4초* 시 진입 완성. 한 쪽이 끊기면 진입이 일시 정지.
5. 진입 완성 시 좌측 화면이 우측 화면에 *흡수* (Edith Finch 의 환상 창 확장과 동형).

**Animation length**: 2-4초 가변 (플레이어 입력 정확도에 따라).
**Audio**: 좌측에는 모루 metal 음, 우측에는 inner cathedral 음. 진입 완성 시 좌측 음이 *우측 음에 흡수*.
**Haptic**: LS 쪽은 metal 진동, RS 쪽은 hum 진동. 좌우 분리 햅틱.
**Dev cost**: 3주 (split rendering + dual-channel state machine + animation set 2배).
**2D pixel-art 적합성**: ★★★★☆ — 기술적 가능, UX 학습 곡선 risk.
**Prior art**: V1 + Edith Finch cannery 직접 인용.
**Risk**: dual-input 은 metroidvania 의 *단일 캐릭터 운행* grammar 와 충돌 가능. 진입 전용 *one-off ritual* 로 한정 권장.

### 제안 C. **Cocoon Carry-and-Drop** (3 dev-week) [추천]

**입력 grammar**

1. Erda 인벤토리에서 검 선택 (현 grammar 유지).
2. *그러나 선택 직후 검이 인벤토리 UI 안에 있지 않다*. 검이 *Erda 손에 visible sprite 로 등장* — *carry mode* 진입.
3. Carry mode 동안 Erda 의 이동 속도 -20%, 공격 불가, 점프만 가능 (Sam 의 화물 운반과 동형).
4. Erda 가 검을 들고 모루까지 *걸어간다* (carry phase, V14).
5. 모루 hitbox 내에서 *E tap = drop on anvil*. 검이 Erda 손에서 모루 위로 0.4초 ease-out arc.
6. Drop 직후 검은 모루 위에 *visible 상태로 놓여있음*. 진입은 *별도 input verb*.
7. 모루 위 검에 *상호작용 prompt* 표시. *E hold 1초* 로 진입 (V3 hold-to-commit).
8. Hold 완료 → push-through-membrane transition (V8).

**Frame-by-frame (carry phase)**

- 인벤토리 close 직후: 검이 인벤토리에서 *나와* Erda 손 위치로 0.3초 sprite 이동.
- Carry walking: Erda 의 어깨가 약간 무겁게 흔들리는 idle animation, 검이 손에 들린 채 sway.
- Drop: 0.4초 arc → 모루 위 snap.
- 진입 hold: 1.0초 + push-through 1.5초.

**Audio**: carry 중에는 검의 *희미한 hum* (Ego 가 말하고 있다는 signal). Drop 시 metal-on-metal clink. 진입 hold 동안 hum buildup, push-through 시 cross-fade.
**Haptic**: carry 중 컨트롤러 중앙 sustained low pulse (Ego 의 heartbeat, V14 + DS BB pod). Drop 시 sharp click. 진입 hold 동안 점진 buildup → push-through spike.
**Dev cost**: 3주 (carry state + visible sprite + animation set + Ego heartbeat 햅틱).
**2D pixel-art 적합성**: ★★★★★ — 픽셀아트 픽토그램이 잘 받는다.
**Prior art**: V2 + V14 + V3 + V8 의 최적 합성. Cocoon 의 핵심 grammar 의 직접 이식.
**왜 추천**: ECHORIS 의 *스파이크* 인 "아이템에 들어가면, 그 안에 살아있는 세계가 있다" 와 가장 정합. Carry phase 가 *검 Ego 의 존재* 를 *플레이어 손에 sustained haptic 으로* 박는다.

### 제안 D. **Death Stranding Triggers-as-Shoulder** (4 dev-week, 컨트롤러 한정)

**입력 grammar**

1. Erda 모루 앞에 *정확한 위치* 에 정렬.
2. L2 hold = Erda 의 *왼쪽 어깨* 가 검을 모루 위로 천천히 내림.
3. R2 hold = Erda 의 *오른쪽 어깨* 가 동시 평행 운동.
4. *L2 + R2 balance* 가 50:50 에 가까울수록 검이 *수직* 으로 모루에 박힘. 한 쪽이 더 강하면 검이 *기울어 박힘* → 진입 실패 (검이 튕겨나옴).
5. 정확한 balance 로 2초 hold 완성 시 진입.

**Animation length**: 2초.
**Audio**: 좌우 분리 stereo metal 음. Balance 가 어긋나면 metal grinding 음.
**Haptic**: L2 강도 → 좌측 햅틱 강도, R2 강도 → 우측 햅틱 강도. Balance 직관적 feedback.
**Dev cost**: 4주 (Steam Input adaptive trigger + balance state machine + UX 학습 곡선 컨트롤).
**2D pixel-art 적합성**: ★★★☆☆ — 컨트롤러 한정. KB+mouse 페르소나에 fallback 필요.
**Prior art**: V4 + Death Stranding 직접.
**Risk**: ECHORIS 의 KB+mouse 주력 페르소나와 충돌. 컨트롤러 enrichment 로 한정 권장.

### 제안 E. **DualSense Adaptive-Trigger Punch-Through** (5 dev-week, PS5 only)

**입력 grammar**

1. Erda 모루 접근.
2. R2 (또는 L2) trigger 를 *천천히 누르기 시작*.
3. Trigger 가 *25% 깊이까지는 부드럽다*. 25% 부터 *progressive resistance* 가 시작 — 손가락이 점점 강하게 밀려난다 (검이 모루 표면을 누르고 있음).
4. Trigger 75% 깊이에서 *peak resistance*. 이 지점에서 트리거가 *give-way* (검이 모루를 뚫고 들어감).
5. Give-way 직후 trigger 가 *0 resistance* 로 떨어지며 진입 transition 시작.

**Animation length**: 가변 (플레이어 trigger 진행 속도에 따라 1-4초).
**Audio**: trigger 25-75% 동안 metal *grinding* sustained. 75% give-way 시 *crack* + inner space audio surfaces.
**Haptic**: trigger 저항 + heartbeat 햅틱 (V1 Death Stranding BB) — 검 Ego 의 심장이 진입 직전 가속.
**Dev cost**: 5주 (Steam Input adaptive trigger curve + Tauri DualSense passthrough + PS5 cert 별도).
**2D pixel-art 적합성**: ★★☆☆☆ — DualSense 전용. PS5 console 페르소나 한정.
**Prior art**: V4 + Astro's Playroom (Aqua biome) 직접.

### 휴식 동작 (Bench/Bonfire) 대비 ECHORIS 모루 — 정합/디버전스

**Hollow Knight bench 와 ECHORIS 모루의 정합점:**

- 둘 다 *영구 spatial point* 이며 player 가 *물리적으로 다가가는* 입력이 선행.
- 둘 다 *세이브* 기능 포함.
- 둘 다 *세계 reset* 효과 (HK bench = 적 spawn reset, ECHORIS 모루 = 검 강화 → 세계 변형).
- 둘 다 *시각적 ritual idle* — HK 의 cloak sway, ECHORIS 의 단조 idle.

**디버전스 (모루는 bench 와 다르다):**

- HK bench = *멈춤* (rest). ECHORIS 모루 = *진입* (transit).
- HK bench 의 sit input 은 *그 자체로 종료* 점. ECHORIS 모루의 sit-like idle 은 *진입의 시작* 점.
- HK bench 는 *세계의 a-point*. ECHORIS 모루는 *세계 간 portal*.

**결론**: ECHORIS 모루는 *bench-like 휴식 idle (V7) + portal-like push-through (V8) 이 sequential 결합* 된 hybrid grammar. 그러나 *입력 verb 자체는 분리* 되어야 한다. *한 input 으로 둘 다 처리* 하면 휴식의 무게가 진입에 흡수되어 *둘 다 가벼워진다*.

**구체적 분리안:**

1. 모루 *접근* — 자동 sit-like idle (Erda 가 모루 앞에 무릎 꿇음). 이것이 *bench-like rest* phase. 별도 input 없이 트리거.
2. 이 phase 에서 player 가 *진입 의지* 있을 때만 *E hold (제안 A)* 또는 *carry-and-drop (제안 C)* 의 별도 input verb 발동.
3. 즉 휴식 = passive idle, 진입 = active input verb.

이렇게 분리할 때 ECHORIS 모루는 *bench 의 anchor 무게 + portal 의 transit 무게* 가 모두 보존된다.

### 최종 권고

- **즉시 (Phase 2)**: 제안 A 도입. 인벤토리 click 후의 fade 를 *2초 hold + 1.5초 push-through* 의 3.5초 의례로 교체.
- **확장 (Phase 3)**: 제안 C 의 carry-and-drop 도입. *carry phase 의 visible sprite + sustained heartbeat haptic* 으로 검 Ego 의 존재를 손에 박는다.
- **컨트롤러 enrich (Phase 3+)**: 제안 D 또는 E 를 *컨트롤러 페르소나에 한해 enrichment* 로 추가. KB+mouse 페르소나에는 A+C 가 final form.

본 grammar 는 *menu click = scene-load* 의 phenomenology 를 *carry + commit + push-through* 의 3-beat embodied ritual 로 교체하여, ECHORIS 의 스파이크 *"아이템에 들어가면, 그 안에 살아있는 세계가 있다"* 를 *플레이어 손에 박는* 1차 도구가 된다.
