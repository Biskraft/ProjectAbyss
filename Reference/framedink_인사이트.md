## 0. 핵심 명제

*Framed Ink* 는 한 장의 그림 또는 한 시퀀스가 **관객을 감정적으로 이야기 속에 들어가게 만드는 방법**을 다룬다. 저자 Marcos Mateu-Mestre 는 DreamWorks·Sony Pictures 에서 20년 이상 레이아웃·콘셉트 아티스트로 일한 경력을 바탕으로, 구성을 장식이 아니라 **서사 전달의 도구**로 다룬다.

저자의 출발점:

> 구성은 미적 취향의 문제 이전에, 관객의 눈과 감정을 의도한 방향으로 이끄는 의사결정의 연속이다.

책 전체를 관통하는 세 가지 질문:

1. 이 프레임이 **무엇을 말하려 하는가** (메시지 명료성).
2. 그 메시지를 **어떤 감정 톤**으로 전달할 것인가 (드라마).
3. 관객의 **눈이 어디로 먼저, 어디로 다음** 이동하는가 (시선 유도).

구성 책 중에서 *Framed Ink* 의 특징은 이론보다 **직접 적용 예시**가 압도적으로 많다는 점이다. 230장이 넘는 흑백 일러스트가 동일 장면을 다른 조명·앵글·구성으로 반복 제시하여, 선택 하나가 만드는 극적 차이를 시각으로 증명한다.

## 1. 책의 구조 (3단계 진행)

저자는 구성을 좁은 단위에서 넓은 단위로 쌓아 올린다.

| 단계 | 다루는 단위 | 핵심 질문 |
| :--- | :--- | :--- |
| 1단계 | 내러티브 아트 개론 | 시각 예술가는 무엇을 책임지는가 |
| 2단계 | 단일 이미지 (single image) | 한 프레임 안에서 시선과 감정을 어떻게 설계하는가 |
| 3단계 | 안정된 샷 (steady shots) | 정지된 한 컷의 구성을 어떻게 다듬는가 |
| 4단계 | 연속성 (continuity) | 샷과 샷 사이를 어떻게 이어 흐름을 만드는가 |
| 적용 | 세 편의 서사 실연 | 열차 사고, 카우보이 이야기, 수상한 집의 바이커들 |
| 보강 | 캐릭터·환경 | 자세·실루엣·표정과 배경이 서사를 어떻게 운반하는가 |

핵심 흐름: **단일 이미지 → 안정된 샷 → 샷 간 연속성**. 한 프레임을 통제하지 못하면 시퀀스도 통제할 수 없다는 전제다.

## 2. 단일 이미지 구성 (Designing the Single Image)

### 2.1 프레이밍 — 포함과 배제

프레이밍은 한 샷에 **무엇을 넣고 무엇을 뺄지** 결정하는 행위다. 프레임 경계가 곧 의미를 만든다. 잘라낸 것이 남긴 것만큼 이야기한다.

### 2.2 시선 유도 (Leading the Eye)

구성의 첫 책임은 관객의 눈을 **의도한 순서로** 움직이게 하는 것이다.

- **선과 형태의 방향**이 눈을 끌고 간다 (대각선·곡선·수렴선).
- 관심 지점(focal point)을 명도·대비·고립으로 만든다.
- 보조 요소는 주 초점으로 시선을 되돌리는 **순환 경로**를 형성한다.

### 2.3 명암 구성 (Tonal Composition / Chiaroscuro)

저자는 컬러 이전에 **흑백 명암 덩어리**로 구성을 본다.

- 화면을 큰 톤 덩어리(밝음·중간·어둠)로 단순화하면 가독성이 드러난다.
- 명암 대비가 강한 곳이 시선의 닻이 된다.
- 조명 방향 하나로 동일 장면의 분위기가 완전히 달라진다 (책의 대표 비교 예시군).

### 2.4 네거티브 스페이스 (Negative Space)

비어 있는 공간은 낭비가 아니라 **호흡과 강조**의 도구다.

- 빈 공간이 주제를 고립시켜 부각한다.
- 빽빽함과 비어 있음의 리듬이 긴장과 이완을 만든다.

## 3. 구성 무드 어휘 (Compositional Mood Vocabulary)

저자가 동일 주제를 다른 구성으로 반복하며 정리한 **의미-구성 대응표**다. 각 구성 선택이 곧 감정 신호다.

| 구성 선택 | 전달되는 의미·감정 |
| :--- | :--- |
| 질서(order) vs 혼돈(chaos) | 안정·통제 vs 불안·위협. 수직·수평 정렬은 질서, 사선·불규칙은 혼돈 |
| 위에서 내려다보기 (looking down) | 대상이 약하고 짓눌린 상태. "내려다봐서 가라앉는다" |
| 아래에서 올려다보기 (upshot) | 대상이 압도적·위협적·영웅적 ("Overpowering upshots") |
| 수평 강조 | 평온·정적·안정 |
| 수직 강조 | 위엄·장엄·고립 |
| 대각선 강조 | 운동·긴장·불안정 |
| 밀집 vs 여백 | 압박·폐소감 vs 해방·고독 |
| 클로즈업 | 친밀·내면·감정 집중 |
| 롱샷 | 맥락·고립·인물과 환경의 관계 |

핵심 원리: **카메라 위치와 선의 방향이 곧 감정의 언어**다. 같은 사건도 앵글 하나로 피해자/가해자, 강자/약자가 뒤바뀐다.

## 4. 명료성 vs 드라마 (Clarity vs Drama)

저자가 반복 강조하는 핵심 긴장 관계다.

- **명료성(Clarity):** 관객이 무슨 일이 일어나는지 즉시 읽을 수 있어야 한다. 정보가 깨지면 서사가 무너진다.
- **드라마(Drama):** 그 정보를 가장 강렬한 감정으로 전달해야 한다. 밋밋하면 기억에 남지 않는다.

| 축 | 우선할 때 | 위험 |
| :--- | :--- | :--- |
| 명료성 | 정보 전달이 결정적인 순간 (사건의 발단, 단서 제시) | 과하면 도식적·무미건조 |
| 드라마 | 감정의 정점, 전환점 | 과하면 가독성 붕괴, 혼란 |

원칙: **드라마는 명료성을 희생하지 않는 선에서 극대화한다.** 두 가지를 동시에 만족시키는 구성이 최선이며, 충돌할 경우 그 샷이 서사에서 맡은 역할(정보 전달인가 감정 고조인가)이 우선순위를 결정한다.

---

## 5. 안정된 샷 (Steady Shots) — 정적 구성의 균형

정지된 한 컷을 다듬는 단계. 화면 내 **시각적 무게의 균형**을 조정한다.

- **균형(balance):** 대칭은 안정·격식, 비대칭은 긴장·활력.
- **시각적 무게:** 큰 것·어두운 것·고대비·인물 얼굴이 무게를 가진다. 무게 분포로 화면이 한쪽으로 쏠리거나 안정된다.
- **3분할·황금 분할 등 격자**는 절대 규칙이 아니라 초점 배치의 참고선으로 다룬다.
- **실루엣 우선:** 인물·물체는 실루엣만으로 읽혀야 한다. 형태가 겹쳐 뭉개지면 가독성이 죽는다.

---

## 6. 연속성 (Continuity) — 샷 간 흐름

여러 샷을 이어 시간과 공간의 흐름을 만드는 단계.

| 요소 | 설명 |
| :--- | :--- |
| 시선·동작 방향의 일관성 | 인물의 시선·이동 방향을 컷 사이에서 유지해 공간을 혼동시키지 않는다 |
| 180도 선 (화면 방향) | 가상의 축을 넘지 않아 좌우 관계를 보존 |
| 반복 모티프 | 재등장하는 형태·색·구도로 장면을 묶고 정체성을 유지 |
| 리듬 변화 | 샷의 크기·길이를 변주해 페이스(긴장 고조/이완)를 조절 |
| 시선 연결 (eye trace) | 한 컷의 초점 위치를 다음 컷의 초점과 연결해 눈의 점프를 매끄럽게 |

핵심: 각 샷이 개별로 좋아도, **샷 간 시선 이동이 끊기면** 시퀀스 전체의 흐름이 깨진다.

## 7. 캐릭터와 환경 (Character & Environment)

| 영역 | 원칙 |
| :--- | :--- |
| 자세(posture)·실루엣 | 감정과 의도가 실루엣만으로 읽혀야 한다. 극적 자세가 서사를 운반한다 |
| 표정·정서적 스탠스 | 인물의 감정 상태를 명확한 시각 신호로 표현 |

| 캐릭터-환경 정합 | 디자인이 서사의 무드·톤과 일관되어야 한다 |

## 8. 핵심 용어

| 용어 | 정의 |
| :--- | :--- |
| 프레이밍 (framing) | 한 샷에 포함·배제할 요소의 선택 |
| 시선 유도 (leading the eye) | 관객의 눈을 의도한 순서로 이동시키는 구성 |
| 초점 (focal point) | 시선이 가장 먼저 닿도록 설계된 지점 |
| 명암 / 키아로스쿠로 (chiaroscuro) | 빛과 그림자의 명암 덩어리로 구성을 잡는 방식 |
| 네거티브 스페이스 | 주제를 부각하는 의도적 빈 공간 |
| 명료성 vs 드라마 | 읽힘과 감정 강도의 긴장 관계 |
| 질서 vs 혼돈 (order vs chaos) | 정렬된 선 vs 불규칙한 선이 만드는 안정·불안 |
| 업샷 / 다운샷 (upshot / downshot) | 올려다봄(위압) / 내려다봄(위축)의 앵글 의미 |
| 시각적 무게 (visual weight) | 크기·명도·대비로 결정되는 요소의 화면 내 무게 |
| 연속성 (continuity) | 샷 간 방향·시선·리듬의 일관된 흐름 |
| 실루엣 가독성 | 외곽선만으로 형태·의도가 읽히는 정도 |

## 9. 실무 체크리스트 (책 원리 요약)

1. **흑백 명암 덩어리로 먼저 본다.** 컬러·디테일 이전에 톤 구성으로 가독성을 검증하라.
2. **관객의 눈이 어디로 가는지 추적하라.** 초점 1순위가 명확한가, 보조 요소가 초점으로 되돌리는가.
3. **앵글이 감정을 말하게 하라.** 업샷·다운샷·수평·대각으로 인물의 강약과 분위기를 결정하라.
4. **명료성과 드라마를 동시에.** 충돌 시 그 샷의 서사 역할로 우선순위를 정하라.
5. **실루엣으로 검증하라.** 형태가 겹쳐 읽히지 않으면 구성을 다시 잡아라.
6. **샷 간 시선을 이어라.** 개별 컷이 아니라 흐름으로 평가하라.
