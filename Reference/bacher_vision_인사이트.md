## 0. 저자와 책의 위치

Hans P. Bacher 는 40년 경력의 디즈니 프로덕션 디자이너이다. *Beauty and the Beast*, *Aladdin*, *The Lion King*, *Mulan* 등의 비주얼 설계를 담당했다. 본서는 그의 전작 *Dream Worlds: Production Design for Animation* 의 이론적 후속이며, 공동 저자 Sanatan Suryavanshi 와 함께 구성·색·라이팅의 원리를 체계화했다.

핵심 명제는 다음과 같다.

> 비주얼 스토리텔러처럼 보고 사고하라. 이미지의 배열 자체가 이야기를 전달한다.

본서의 원칙은 애니메이션에 한정되지 않는다. 실사 영화, 다큐멘터리, 사진, 회화, 무대 등 배열로 이야기를 만드는 모든 시각 예술에 적용된다. 책 전체를 관통하는 목적은 관객의 감정 반응을 의도적으로 통제하여 올바른 무드와 기억을 환기하는 것이다.

## 1. 이미지의 심리 (The Psychology of Images)

이미지가 왜 감정을 일으키는가를 다루는 토대 장이다.

| 개념 | 정의 |
| :--- | :--- |
| 연상 (Association) | 모든 시각 요소는 관객 개인 경험의 기억을 촉발한다. 비주얼은 그 기억에 결부된 감정을 불러온다. |
| 메커닉 (Mechanics) | 인간 시지각이 이미지를 처리하는 물리적·인지적 작동 방식. |
| 공명 (Resonance) | 의도한 감정이 관객 내부에서 증폭되어 잔향을 남기는 효과. |

원칙: 이미지는 무엇을 말하는가(메시지)와 어떻게 말하는가(시각 배열)를 연상을 통해 정렬할 때 감정을 전달한다.

## 2. 이미지의 해부 (The Anatomy of an Image)

한 프레임을 구성하는 기본 변수의 목록이다. 이후 모든 장의 분석 단위가 된다.

| 변수 | 역할 |
| :--- | :--- |
| 주제 (Subject) | 프레임이 전달해야 할 핵심 대상. |
| 포맷 (Format) | 화면비와 프레임 형태. 가로/세로/정사각의 정서적 차이. |
| 깊이 (Depth) | 전경·중경·배경의 층위 구성. |
| 프레이밍 (Framing) | 주제를 어디에 두고 어디를 잘라낼지의 결정. |

---

## 3. 선 (Line)

| 하위 개념 | 요지 |
| :--- | :--- |
| 구조선 (Structural lines) | 프레임 내부에 잠재된 골격선. 시선을 이끄는 경로. |
| 방향 (Orientation) | 수평(안정)·수직(위엄)·사선(긴장·운동)의 정서값. |
| 배치 (Placement) | 선이 화면의 어느 위치를 가르느냐가 위계를 결정. |
| 질감 (Quality) | 선의 굵기·곡률·거칠기가 무드를 형성. |
| 조화와 대비 (Harmony & contrast) | 유사 선은 묶이고, 이질 선은 부각된다. |
| 리듬 (Rhythm) | 선의 반복 간격이 시각적 박자를 만든다. |

---

## 4. 형태 (Shape)

| 하위 개념 | 요지 |
| :--- | :--- |
| 영감 (Inspiration) | 자연·건축·회화에서 형태 어휘를 수집. |
| 형태의 발견 (Discovering shape) | 복잡한 대상을 단순 형태로 환원하는 시각화. |
| 가독성 (Legibility) | 실루엣만으로 대상이 읽혀야 한다. |
| 시각적 흥미 (Visual interest) | 형태의 변주로 지루함을 회피. |
| 감정의 형상화 (Shaping emotions) | 둥근 형태(친근)·각진 형태(위협) 등 형태 자체의 정서값. |

핵심 원칙: 실루엣 가독성. 형태가 검은 실루엣으로 환원되어도 주제와 행동이 읽혀야 한다.

## 5. 명도 (Value)

본서가 가장 강조하는 통제 도구다. 색보다 명도가 먼저다.

| 하위 개념 | 요지 |
| :--- | :--- |
| 명도 보기 (Seeing value) | 색을 흑백으로 환원해 명도만 분리해 본다. |
| 명도 분포 (Value distribution) | 화면 전체의 밝고 어두운 비율 설계. |
| 초점 통제 (Controlling focus) | 명도 대비가 가장 큰 지점에 시선이 박힌다. |
| 명도 패턴 (Value patterns) | 화면을 소수의 명도 그룹(예: 3톤)으로 단순화한 골격. |
| 명도와 감정 (Value & emotion) | 하이키(밝음·개방)·로키(어둠·긴장)의 정서 분기. |

핵심 원칙: 명도 대비로 초점을 만든다. 밝은 것 앞에 어두운 것, 어두운 것 앞에 밝은 것을 배치한다.

## 6. 색 (Color)

| 하위 개념 | 요지 |
| :--- | :--- |
| 색은 어디에나 있다 (Colour is everywhere) | 환경광·반사광까지 포함한 색의 편재성. |
| 색상환 (Color wheel) | 보색·유사색·삼각 배색의 관계 지도. |
| HSB | 색상(Hue)·채도(Saturation)·명도(Brightness)의 3축 분해. |
| 색의 지각 (Perceiving color) | 동시 대비 등 인접색에 의한 색 인지 왜곡. |
| 색과 감정 (Color & emotion) | 난색(따뜻함·접근)·한색(차가움·후퇴)의 정서값. |
| 색과 디자인 (Color & design) | 제한 팔레트로 통일감과 위계 확보. |
| 색과 명도 (Color & value) | 색은 명도 골격 위에 입혀지는 층이다. |
| 색의 힘 (The power of color) | 화면 내 소수 강조색이 시각 닻을 만든다. |
| **컬러 스크립트 (Color scripts)** | 영화 전체의 시퀀스별 색·무드 변화를 한 줄로 펼친 정서 지도. 장면 간 색의 흐름을 사전에 설계한다. |

핵심 원칙: 색은 명도 골격에 종속된다. 제한된 팔레트와 소수의 강조색이 통일감과 초점을 동시에 만든다. 컬러 스크립트로 시간축 색 흐름을 통제한다.

| 하위 개념 | 요지 |
| :--- | :--- |
| 라이팅 셋업의 해부 (Anatomy of a lighting setup) | 키·필·림 등 광원의 역할 분담. |

핵심 원칙: 라이팅은 무드 생성기이자 초점 유도 도구다.

## 9. 구성 — 여덟 가지 재료 (Composition)

Bacher 가 블로그와 본서에서 정리한 강한 구성의 8대 재료다. 본서 구성 장(시각 질서·섬네일)의 핵심 골자이기도 하다.

| # | 재료 | 요지 |
| :-- | :--- | :--- |
| 1 | 배치와 가독성 (Placement & Readability) | 황금 분할·삼분할·삼각 균형으로 주제를 앉힌다. |
| 2 | 명암 대비 (Light Contrast) | 밝은 것 앞에 어두운 것, 그 역. |
| 3 | 프레이밍 (Framing) | 테두리와 공간 가둠으로 주제를 강조. |
| 4 | 균형 — 음양 (Balance, Yin & Yang) | 양(陽) 공간과 음(陰) 공간의 평형. |
| 5 | 앵글 (Angles) | 카메라 틸트와 수직/수평 배치. |
| 6 | 무대 효과 (Stage Effect) | 주제를 무대 위에 세우듯 입체적 존재감 부여. |
| 7 | 리듬과 흐름 (Rhythm & Flow) | 편집 속도와 시각 시퀀스 관리. |
| 8 | 깊이 (Depth) | 층위로 공간 차원을 형성. |

### 작업 방법론

- **섬네일링 (Thumbnailing):** 작은 흑백 스케치로 명도 패턴과 구성을 빠르게 다수 탐색한다. 디테일 전에 골격을 확정한다.
- **단순화 (Simplification):** 복잡한 장면을 소수의 형태·명도 그룹으로 환원한다. 단순한 골격이 강한 이미지를 만든다.
- **리서치:** 실사 영화·광고·고전 회화·독일 표현주의를 분석해 색·라이팅·구성 선택을 학습한다.

## 10. 핵심 용어

| 용어 | 정의 |
| :--- | :--- |
| 컬러 스크립트 (Color script) | 영화 전체 시퀀스별 색·무드 변화를 한 줄로 펼친 정서 지도 |
| 명도 패턴 (Value pattern) | 화면을 소수 명도 그룹으로 단순화한 골격 |
| 실루엣 가독성 (Silhouette legibility) | 검은 실루엣만으로 주제·행동이 읽히는 성질 |
| 무대 효과 (Stage effect) | 주제를 무대 위에 세우듯 부각하는 구성 |
| 음양 균형 (Yin & Yang balance) | 양/음(positive/negative) 공간의 평형 |
| 섬네일링 (Thumbnailing) | 흑백 소형 스케치로 구성·명도를 다수 탐색 |
| 하이키 / 로키 (High-key / Low-key) | 밝은 명도 우세 / 어두운 명도 우세 |
| 연상 (Association) | 비주얼이 기억과 그에 결부된 감정을 촉발하는 작용 |

## 11. ECHORIS 적용 메모

본 문서는 영화·애니메이션 구성 원칙의 일반 정리다. ECHORIS 실제 디렉션은 `Documents/Design/Design_Art_Direction.md` (D-15) 가 SSoT 다. ECHORIS 는 웹 기반 2D 픽셀아트 횡스크롤 액션 RPG 이며, 5톤 팔레트(Industrial Grey / Cold Cyan-Teal / Warm Amber / Deep Black / Auburn Red)를 사용한다. Bacher 원칙과 D-15 의 연결점은 다음과 같다.

| Bacher 원칙 | ECHORIS 대응 |
| :--- | :--- |
| 명도가 색보다 먼저 — 명도 패턴 소수 그룹화 | Deep Black 과 Industrial Grey 로 명도 골격을 깔고, 그 위에 색을 입히는 픽셀아트 셰이딩 순서 |
| 색의 힘 — 소수 강조색이 시각 닻 | Auburn Red 5% 상시 강조 — 모든 화면의 시선 닻 |
| 명암 대비로 초점 통제 | 어두운 산업 배경 앞 Cold Cyan-Teal 발광 요소 배치(밝은 것 앞 어두운 것 원칙) |
| 색과 감정 — 난색/한색 정서 분기 | 한색 Cold Cyan-Teal(정체성·잔향)과 난색 Warm Amber(온기·안식처)의 정서 대비 |
| 컬러 스크립트 — 시퀀스별 색 흐름 | 핵심 루프(탐험 → 다이브 → 포지 → 게이트 해금) 각 상태별 톤 비중 흐름을 컬러 스크립트로 설계 |
| 실루엣 가독성 | 32px 스프라이트가 검은 실루엣만으로 적/플레이어/오브젝트가 구분되도록 형태 설계 |
| 섬네일링·단순화 | 인게임 픽셀 단순화 vs 키 비주얼 디테일 분리. 명도 섬네일로 화면 골격 선검증 |
| 무대 효과·깊이 | 횡스크롤 패럴랙스 층위(전경/중경/배경)로 주제 캐릭터를 무대 위에 세움 |
| 라이팅 — 그림자가 구성 요소 | 발광원 기반 캐스트 섀도와 림 라이트로 픽셀 캐릭터 초점 유도 |
