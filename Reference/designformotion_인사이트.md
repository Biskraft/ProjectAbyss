## 0. 핵심 명제

이 책은 소프트웨어 사용법 매뉴얼이 아니다. 저자는 본문에서 명시한다.

> 이 책은 how-to 소프트웨어 책이 아니다. 업계 표준 도구와 소프트웨어가 언급되긴 하지만, 나는 모션 디자인의 근간이 되는 미술/디자인 원리를 식별하는 데 집중했다.

핵심 주장은 모션 디자인의 품질을 결정하는 단계가 애니메이션 실행이 아니라 그 앞단의 **디자인(design)** 이라는 점이다.

> 디자인 — 스타일 프레임, 컨셉 아트, 캐릭터 디자인, 디자인 보드의 형태로 — 이 작업의 성패를 가른다.

따라서 이 책은 모션 프로젝트의 **프리 프로덕션(pre-production)**, 즉 리서치 → 컨셉 → 디자인 개발 단계를 다룬다. 결과물은 움직이는 영상이 아니라 그 영상을 설계하는 **스타일 프레임(style frame)** 과 **디자인 보드(design board)** 다.

### 모션 디자인의 위치

모션 디자인은 그래픽 디자인의 전통 위에 시간(time)을 더한 분야다. 저자는 "Building on Traditions"(전통 위에 쌓기)를 서론의 출발점으로 삼는다. 정적 그래픽 디자인의 구성·타이포그래피·색·형태 원칙이 그대로 유효하며, 여기에 타이밍·리듬·전환이라는 시간 차원이 추가된다.

## 2. 핵심 워크플로 (Concept → Design)

저자의 방법론은 넓게 시작해 점진적으로 좁히는 순서를 따른다.

> 넓게 작업하고, 아이디어를 점진적으로 구체적인 섹션으로 정련하라.

| 단계 | 활동 | 산출물 |
| :--- | :--- | :--- |
| 1. 브리프 해석 | 크리에이티브 브리프 분석, 목표·청중·메시지 파악 | 문제 정의 |
| 2. 리서치 | 시각 레퍼런스 수집, 무드 보딩 | 무드 보드 |
| 3. 아이디에이션 | 마인드맵, 자유 연상 글쓰기, 발산적 사고 | 컨셉 후보군 |
| 4. 썸네일 | 빠른 손스케치로 구도·아이디어 탐색 | 썸네일 스케치 |
| 5. 디자인 보드 | 톤·방향성·시각 언어를 보여주는 정련된 보드 | 디자인 보드 |
| 6. 스타일 프레임 | 최종 영상의 한 프레임을 완성도 높게 렌더 | 스타일 프레임 |
| 7. 프레젠테이션 | 프로세스 북/디자인 덱으로 클라이언트 피치 | 디자인 덱 |

핵심 원칙: 초기 단계에서 **모호함과 불확실성을 끌어안는다(embracing ambiguity)**. 발산(divergence) 단계에서 섣불리 수렴하지 않는다.

### 스타일 프레임과 디자인 보드의 직업적 기능

스타일 프레임과 디자인 보드는 단순 산출물이 아니라 세 가지 실무 기능을 수행한다.

1. **피칭(pitching):** 영상을 만들기 전에 방향성을 팔고 승인받는다.
2. **프로덕션 가이드:** 후속 애니메이션 제작의 시각 기준선을 제공한다.
3. **기대 관리(client expectation):** 클라이언트와 합의된 결과 이미지를 고정한다.

| 용어 | 정의 |
| :--- | :--- |
| 스타일 프레임 (style frame) | 완성될 모션 영상의 특정 한 프레임을 최종 완성도로 렌더한 정지 이미지. "이 영상은 이렇게 보일 것이다"를 증명한다. |
| 디자인 보드 (design board) | 스타일·톤·시각 방향을 묶어 보여주는 보드. 한 영상의 전반적 룩 앤 필을 설득한다. |
| 프로세스 북 (process book) | 브리프부터 완성까지의 창작 여정을 문서화한 포트폴리오. 채용 시 창작 프로세스를 증명한다. |

## 3. 컨셉 개발 (Concept Development)

저자는 컨셉을 디자인보다 우선한다. 좋은 시각 실행이 약한 컨셉을 구원하지 못한다.

| 도구 | 용도 |
| :--- | :--- |
| 마인드맵 (mind mapping) | 중심 주제에서 연관 개념을 방사형으로 확장 |
| 자유 연상 글쓰기 (free writing) | 검열 없이 키워드/문장을 쏟아내 발상 폭 확보 |
| 무드 보드 (mood board) | 목표 톤·감정을 환기하는 이미지 군집 수집 |
| 비주얼 인스피레이션 수집 | 레퍼런스 라이브러리 구축 |

작업 순서는 항상 **발산 → 수렴**이다. 넓게 펼친 뒤 가장 강한 방향으로 정련한다.

## 4. 도구·기술·기법 (Ch.5)

2판이 다루는 핵심 제작 기술 카탈로그. 각 기법은 디자인 보드의 시각 언어를 결정한다.

| 기법 | 설명 |
| :--- | :--- |
| 일러스트레이션 (illustration) | 손/벡터/래스터 일러스트로 룩 구축 |
| 타이포그래피 (typography) | 텍스트 자체를 디자인 주체로 운용 (Ch.9 타입 주도 보드로 연결) |
| 컴포지팅 (compositing) | 다층 요소 합성, 라이팅·그레이딩 통합 |
| 시네마토그래피 (cinematography) | 카메라·구도·프레이밍의 영화적 언어 |
| 3D 통합 (3D elements) | 3D 렌더를 2D 디자인에 결합 (Beeple 사례) |
| 매트 페인팅 (matte painting) | 환경·배경을 회화적으로 구축 |
| 시각 스토리텔링 (visual storytelling) | 단일 이미지로 서사·감정 전달 |

| 유형 | 주도 요소 | 특징 |
| :--- | :--- | :--- |
| Type-Driven (Ch.9) | 타이포그래피 | 텍스트가 주인공. 키네틱 타이포그래피의 기반 |
| Illustrative (Ch.10) | 일러스트 | 손맛/스타일 일러스트가 톤을 규정 |

| Modern (Ch.14) | 추상/모던 | 추상·기하·동시대 미학 |

## 6. 소셜·모바일 우선 (Ch.6, 2판 신규)

2판의 가장 큰 추가는 소셜·모바일 환경 대응이다. 업계가 모바일·소셜 플랫폼으로 이동한 변화를 반영한다.

| 원칙 | 설명 |
| :--- | :--- |
| 빠른 주목 확보 (capture attention quickly) | 소셜 콘텐츠의 최우선 원칙. 첫 순간에 시선을 잡는다 |
| 사운드 오프 설계 (sound-off viewing) | 소리 없이 재생되는 환경을 전제로 디자인 |
| 멀티 플랫폼 버저닝 | 다양한 화면비/종횡비 대응 |
| 크리에이티브 캡셔닝 | 타이포그래피와 캡션을 디자인 요소로 통합 |

| 신조어 | 의미 |
| :--- | :--- |
| Snackables | 짧게 소비되는 단편 콘텐츠 |
| Thumbstoppers | 스크롤을 멈추게 만드는 콘텐츠 (엄지를 멈추는 것) |

저자는 교육 과정에서 고정 종횡비 요구를 제거하면서도 디자인 선택에 대한 책임은 유지하도록 조정했다.

## 7. 프레젠테이션과 피칭 (Ch.7)

스타일 프레임/디자인 보드는 결국 설득의 도구다. 프로세스 북과 디자인 덱으로 패키징해 피치한다.

- **프로세스 북:** 창작 여정을 보여줘 잠재 고용주/리크루터에게 프로세스 역량을 증명한다.
- **디자인 덱:** 클라이언트 피치용 정련 문서. 컨셉의 정당성과 시각 방향을 함께 제시한다.
- 핵심: 디자인 선택의 **근거(rationale)** 를 함께 제시한다. 결과 이미지만이 아니라 왜 그 방향인지를 설득한다.

## 8. 디자인 주도 프로덕션 (Design-Driven Production)

저자가 현대 스튜디오 모델을 설명하기 위해 사용하는 개념. 개인의 작가성(individual artistry)과 협업적 산출(collaborative output)이 융합되며, 다양한 매체·스타일을 가로지른다. 모션 스튜디오의 작업이 애니메이션 기술이 아니라 디자인 결정에 의해 추동된다는 관점이다.

교육 철학에서도 동일한 우선순위가 드러난다.

- 소프트웨어 훈련보다 **기초(foundation) 구축**을 우선한다.
- 3D를 디자인·2D 애니메이션 기초와 **함께** 가르친다. 통합적으로 훈련하면 학생이 자연스럽게 도구를 결합한다.

## 10. 핵심 교훈 요약

1. **디자인이 성패를 가른다.** 애니메이션 실행 이전의 디자인 단계(스타일 프레임/디자인 보드)가 작업 품질을 결정한다.
2. **소프트웨어가 아니라 원리.** 도구는 바뀌어도 미술/디자인 원리는 유효하다.
3. **넓게 시작해 정련한다.** 컨셉 → 아이디에이션 → 썸네일 → 디자인 보드 → 스타일 프레임의 발산-수렴 흐름.
4. **모션은 그래픽의 전통 위에 시간을 더한 것.** 정적 디자인 원칙이 그대로 살아 있다.
5. **프리비주얼라이제이션이 곧 설득.** 스타일 프레임으로 결과를 미리 증명하고 피치한다.
6. **소셜/모바일은 별도 규칙.** 빠른 주목, 사운드 오프, 멀티 종횡비를 전제로 설계한다.

## 11. ECHORIS 적용 메모

본 문서는 일반 모션 디자인 원칙 정리다. ECHORIS 실제 디렉션은 `Documents/Design/Design_Art_Direction.md` (D-15) 가 SSoT. ECHORIS는 PixiJS v8 기반 웹 2D 픽셀아트 횡스크롤 액션 RPG이며, 애니메이션 스프라이트 아틀라스·5단계 포지 격발 시퀀스·날씨/파티클 이펙트를 보유한다. 이 책의 프레임워크와의 연결점:

| 책의 원칙 | ECHORIS 대응 |
| :--- | :--- |
| 스타일 프레임 = 결과를 미리 증명 | 신규 스프라이트/이펙트 제작 전, 키 프레임 스타일 프레임을 먼저 확정해 제작 기준선 고정 |
| 디자인 = 애니메이션의 성패를 가른다 | 32px 스프라이트 모션 작업 전 포즈·실루엣·타이밍을 디자인 보드로 선설계 (PixelLab → Aseprite 이전 단계) |
| 발산 → 수렴 워크플로 | 이펙트 컨셉 단계에서 무드 보드/썸네일 발산 후 D-15 톤 비중에 맞게 수렴 |
| 시간 = 그래픽 위에 더해진 차원 | 포지 격발 5단계 시퀀스 = 정적 비주얼 위계에 타이밍 차원을 부여한 키네틱 설계 |
| 타입 주도 보드 / 키네틱 타이포 | UI 텍스트·토스트·게이트 해금 연출의 키네틱 타이포그래피 톤 기준 |
| 촉각/질감 주도 보드 | 날씨/파티클·잔향 이펙트의 머티리얼 질감 설계 레퍼런스 |
| 빠른 주목 확보 (소셜 원칙) | 보상 순간(아이템 드랍, 게이트 해금) 첫 프레임에 시선을 즉시 잡는 연출 우선순위 |
| 프로세스 북 = 의사결정 근거 문서화 | 자산 제작 파이프라인의 디자인 결정 근거를 D-15 와 위키에 기록 |
| 디자인 주도 프로덕션 | PixelLab → Aseprite → 인게임 파이프라인을 디자인 결정이 추동하도록 정렬 |

> Q2 — 포지 격발 5단계 시퀀스를 이 책의 발산-수렴 워크플로(컨셉 → 썸네일 → 디자인 보드 → 스타일 프레임)에 맞춰 단계별 사전 설계 문서로 재정리해 드릴까요?
>
> Q3 — 디자인 보드 6유형 분류(타입/일러스트/정보/촉각/캐릭터/모던)를 ECHORIS 이펙트·UI 자산군에 매핑해, 자산 유형별 시각 언어 체크리스트를 만들어 둘까요?
