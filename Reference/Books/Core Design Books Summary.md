# B01: Designing Virtual Worlds — Richard Bartle (2003)

> **상태:** 🤖 AI 학습 지식 기반 요약 (원문 PDF 미보유)

## 핵심 내용 요약

### 1. Bartle의 플레이어 유형 분류 (Bartle Taxonomy)

| 유형 | 동기 | 행동 | Chrono Odyssey 대응 콘텐츠 |
|------|------|------|--------------------------|
| **Achiever (성취자)** | 목표 달성, 수치 성장 | 레벨업, 컬렉션, 도전 | 매트릭스, 장비 파밍, 칭호, 크로노 게이트 |
| **Explorer (탐험가)** | 세계 발견, 시스템 이해 | 맵 탐험, 히든 퀘스트, 실험 | 오픈월드 탐험, "사용하기", 미궁, 시공의 균열 |
| **Socializer (사교가)** | 사람과의 상호작용 | 채팅, 길드, 교류 | 길드, 거래소, 파티 콘텐츠, 하우징 |
| **Killer (정복자)** | PvP, 경쟁, 지배 | PvP, 랭킹, 영역 다툼 | 에덴 PvPvE, 과거시 RvR, 아레나 |

### 2. 가상 세계의 설계 6축
- Physics(물리), Interaction(상호작용), Economy(경제), Politics(정치), Society(사회), Culture(문화)

### 3. 핵심 교훈
- 플레이어 유형은 고정이 아닌 **스펙트럼** — 같은 유저도 상황에 따라 유형 변화
- 4유형의 비율이 월드 생태계 영향: Killer가 많으면 Socializer 이탈 → Achiever 이탈 → Killer만 남는 "죽음의 나선"
- 월드 거버넌스(규칙/제재)가 유형 간 균형의 핵심 도구

# B03: A Theory of Fun — Raph Koster (2nd Ed.)

> **상태:** 🤖 AI 학습 지식 기반 요약

## 핵심 테제
- **재미 = 패턴 학습의 즐거움** — 뇌가 패턴을 발견하고 마스터하는 과정이 재미
- 패턴이 너무 쉬우면 지루, 찾을 수 없으면 좌절 → **Flow 채널**
- 모든 패턴이 소진되면 "게임을 깼다" → 이탈
- **소울라이크 보스 패턴 학습 = Koster 이론의 완벽한 구현**

# B05: Game Balance — Schreiber & Romero

> **상태:** 🤖 AI 학습 지식 기반 요약

## 핵심 밸런스 원칙

| 개념 | 설명 | Chrono Odyssey 적용 |
|------|------|-------------------|
| **Transitive** | A>B>C 상하관계 | 장비 티어 (상위 = 강함) |
| **Intransitive** | 가위바위보 | 클래스 상성 (6클래스 간) |
| **Pareto Optimality** | 장점 올리면 다른 것 희생 | 매트릭스 빌드 트레이드오프 |
| **Power Curve** | 성장 곡선 수학 | 로그/선형/지수 중 로그 권장 |
| **Soft Cap** | 수확 체감 구간 | 스탯 소프트캡 설계 |
