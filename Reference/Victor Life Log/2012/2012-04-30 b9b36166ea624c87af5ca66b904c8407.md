# 2012-04-30

지형 편집기의 개선과 관련하여 pt를 했다. pc가 없었기 때문에 아이패드로 했는데, 발표 자체엔 전혀 무리가 없었다. 만약 pc가 있었다면 현재 엔진 툴을 보여주고, 좀 더 다른 대화를 할 수 있었을지도 모른다. 아무튼 좋았다.

키노트 리모트 앱도 구매했다. 아이폰으로 아이패드의 키노트를 조작할 수 있다. 이래저래 무지막지하게 돈을 쓰고있지만, 아직 내 돈은 마르지 않았다. 아무튼 난 돈을 쓸 만큼 버는 것 같다. 비정상적인 집값만 아니었다면 난 매우 풍족한 삶을 살 수 있었을 것이다. 새삼 정치와 정책이 삶에 미치는 영향에 대해 느끼고, 생각하는 것 같다. 어른이 되어간다.

지난주 수요일 날 pvp_titan의 더미맵을 배경 아트팀에 넘겼는데 이미 모크업 되어있었다. 정말 터무니없이 빠른 작업속도와 퀄리티다. 이런게 진짜 배경 모델러구나. 압도적인 속도와 퀄리티에 긴장마저 든다. 캐노피가 나의 레벨을 마음에 들어하는 것은 다행이다. 난 이런 사람들과 일하게 된 게 그냥 운이 좋은 것 같다. 내 경력과 실력은 이들에 미치지 못하지만, 단지 FPS전문 레벨 디자이너로서 이들의 마음에 든 것이다. 굳굳.

저녁엔 어벤저스를 선경이랑 봤다. 재밌었다. 다 때려부시고 신난다. 폭격할 때 차량들이 한꺼번에 폭발하던데, 환경 인터랙션 요소로서 아이디어를 내는것도 좋을 것 같다. 플레이어가 실내에 있는데, 건물이 무너졌지만 실내에 살아있다거나. 흥미로울 것 같다.

이거 쓰다보니 블로그에 써도 좋겠어. 뭔가 환상정원 느낌의 블로그가 되겠지만, 내 블로그는 아무도 안읽겠지. 사실 환상정원은 본인의 포트폴리오 하나 올리지 않은 것 같은데 그렇게 많은 사람들이 방문하는 것도 신기하다. 꼭 엄청난 게임/작품을 만든 사람의 블로그가 인기있을 필욘 없다. GDC에서 레벨 디자인 발표자들은 꼭 모던워페어 급의 FPS를 만든게 아니듯이. 아이러니 하게도 모던워페어를 만든 사람들은 아무도 GDC에서 레벨 디자인에 대해 발표하지 않았다.
