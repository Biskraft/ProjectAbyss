# 2016. 3. 16.

![](2016%203%2016/_2016-03-16__7.28.36.png)

Garmin Swim을 통한 첫 기록. 보통 1000m 정도 도는데, 30분도 안걸린다. 즉 하루에 30분도 운동을 안했다는 건데… 아무튼. 아침 6시 자유 레인을 갔는데, 사람도 많고 호전적인 것 같았다. 내가 갔던 레인은 여러 명이 자유형을 빠르게 진행중이었는데, 느리다고 쫒겨났다. 사실 일 주일에 2-3회 정도로는 그런 속도를 따라갈 수 없다. 그리고 완력도 부족해서 추가적인 운동이 있어야 더 빠르게 돌 수 있을 것 같다. 팔뚝이 너무 얇아. 개인적으론 8시에 가는게 훨씬 여유롭고 좋은 것 같다.
