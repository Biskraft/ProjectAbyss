# 2021. 1. 24.

2013년 회고를 정리했다. 오지게도 많이 썼다는 생각이 들었다. 이때 쓴 회사의 잡무나 메모는 별로 도움이 되지 않았는데, 길게 쓴 성찰의 글은 항상 도움이 됐다. 성찰의 글은 그것이 올바른 이야기이던, 아니던 모두 도움이 된다. 

이렇게 많이 쓸 수 있었던 비결은 아마 PostEver 앱 때문이라고 생각한다. 빠르게 에버노트에 글을 쓰게 해주는 앱이며, 심지어 매일 자동으로 날짜까지 입력되어 수고를 덜어준다. 이렇게 높은 접근성으로 짧은 글을 많이 쓰게되고, 이것이 습관화되어 긴 글도 자주 쓰게 되는 것이다.

지금은 노션으로 개인 데이터베이스를 모두 옮겼는데, 노션엔 빠른 메모 기능이 없다. 노션에 몇 가지 단점과 아쉬운점이 있는데,

- 전반적으로 속도가 느리다. 특히 DB가 느리다. DB때문에 이사했는데 아이러니하다.
- 외부 API가 없어서 외부 앱이 없다(최근에 API 공개됨).
    - 빠른 메모가 불가능하다.
- 스크랩 기능이 형편없고, 테이블을 지원하지 않는다.
- 아이패드 사용 시 제약이 있다.

그냥 아쉬울 따름이고... 언제 개선될 지 기약은 없다. PostEver 같은 앱 하나 만들어주면 소원이 없겠다. 4만원 정도해도 구매할 듯. 아니 연간 구독으로 해도 구매하겠어.
