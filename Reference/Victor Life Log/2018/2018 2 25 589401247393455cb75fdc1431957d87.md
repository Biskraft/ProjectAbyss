전반적으로 멋진 하루였다.

- 배변을 세 번 했다.
- 짐을 패킹해 봤다.
- 스타벅스에서 집중력 있게 작업했다.
- 백패킹 글을 카페에 올렸다.
- 마사지 샵에서 마사지를 받았다.

특히 마사지 샵에서 마사지를 받았는데 좋았다. 태국인이 마사지사이고, 여자였다. 등과 엉덩이쪽을 마사지했는데 특히 엉덩이가 좋았다. 그리고 이렇게 외부에서 옷을 벗고 누군가 서비스한다는 것 자체가 내게 흥분을 준다. 병원과 비슷한 것 같다. 전체적인 마사지의 느낌은 발리에서 받은 것과 거의 비슷하다. 외국인이라 더 좋은 것 같다. 한국인 아줌마라면... 웬지 어머니나 다른 사람이 생각날 거 같다. 젊은 사람이면 선경이가 생각나겠지.

이제 일 주일 동안 목표를 제대로 달성하면 마사지를 받아야겠다. 4만원 정도지만 괜찮다.

2022년 1월 4일 마사지의 시작이군. 지금은 2주에 한 번 정도 마사지를 받는 것 같다. 가격은 90분에 48000원(10회)이지만, 이후에 스페셜 마사지가 있어서 3만원 이상이 추가된다. 대체로 기분이 좋아서 스페셜 마사지를 계속 받는 것 같다.
