# 2014. 11. 23.

마을 아이디어. 베스트 샷 버튼. 가장 멋진 장면으로 카메라 이동

오후 12:36 [Map](http://maps.google.com/maps?q=37.481871+126.928824&z=14)

맥도날드에서 작업하러 왔다. 커피점 보다 저렴할 거라 생각하고 음식을 주문했는데, 맥 너겟 6조각에 2600원. 생각없이 주문했더니 커피점이 더 싼 판이다. 그냥 아무데나 가서 생수 하나 시키고 뻐길까. 매번 그러기도 짜증날 것 같기도 한데. 음료없이 맥너겟만 먹기도 빡세다. 맥너겟 보니 갑자기 예전에 고속도로 휴게소에서 맥너겟+콜라 마신거 생각나네.
