# 2014. 2. 20.

- 만약 타이탄폴에서 무엇을 빼면 똥이된다
- 그것은 탑승과 탈출의 연출이다
- 다들 거대한 타이탄에만 집중한다
- 그러나 이 연출이 없다면, 타이탄폴은 엣지가 없어진다
- 우리 기획의 흐름
- 뭔가 새로운, 참신한(그러나 허점이 가득한) 기획
- 모던과 다르다, 모던과 똑같다
- 기획 기각
- 팀원들의 판단 : 우린 모던이랑 똑같이 만들어야 기획이 통과된다
- 반복결과: 모던이랑 똑같고, 개성없는 아이언 사이트
