# 2014. 2. 4.

나는 하나의 게임에 너무 중독되었다. 나의 뇌는 롤을 계속 원한다. 아예 안하는 건 괜찮지만, 플레이 도중 멈추는게 불가능하다. 그리고 가끔 게임을 다시 하게되면 멈출수가 없다.
이게 나에게 도움이 되네마네는 아무 의미없는 토론이다. 다만 나는 현상과 반응을 분리해야 좀 더 명확하고 논리적인 사고가 가능하다. 게임을 패배 도중에 멈추는게 아주 힘든 것이다. 처음 만난 여자와 섹스 도중 절정에 다다르기 전에 빼는 것과 같다. 이 게임에서의 패배란 정말 중독적이다.
게임의 처음과 끝이 다른 게임모드를 만들자. 게임 내에 성장을 넣자. 반드시 성공할 것이다.
