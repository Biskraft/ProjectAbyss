# 2010-04-11

오랜만의 회고다. 버전이 끝나면 회고도 중단되는 경우가 많다. 그리고 다시 일정이 잡히고, 마감 한달전 부터 바빠지고 발표가 끝나면 한가해진다. 지금 걱정되는 것은 게임 공개까지 1년도 남지 않았지만 아직 핵심 시스템도 완비되지 못했다. 사실 지금까지 플레이 한건 TPS게임이지 MOTPS는 아니다. 아이템 파밍, 난이도 시스템, 방어구, 무기, 스킬 등 많은 부분이 아직 완성되지 못했다. 물론 레벨도 많이 남았다. 현재까지 만든 레벨은 약 20개인데, 40개의 레벨이 더 필요하다. 현재의 예상으론 올해 안에 남은 8개월 동안 21개의 레벨을 만들 수 있지만, 적어도 30개의 레벨은 만들어야 한다. 따라서 뭔가 다른 방법을 써야 9개의 레벨을 더 채울 수 있을 것이다.

현재 나온 가장 주요한 대안은 기존의 메인 미션을 재활용 하여 서브 미션으로 만드는 것이다. 원래 서브 미션의 취지는 생산성 높은 레벨을 제작하여 양을 채우는 것이지만, 지금의 서브미션은 제작 기간도 예산도 모두 메인 미션과 똑같으며, 매번 서브미션을 만들 때 마다 새로운 재미를 찾기 위해 시간을 소모하고 있다. 게다가 플레이타임도 메인 미션과 비슷한 15분 정도로 길고, 모델링을 대부분 새로 해야 한다는 점에서도 생산적이지 못하다.

문제

1. '한달 레벨 디자인 + 두달 배경 제작'의 메인 미션과 같은 제작 기간

2. 새로운 재미를 찾고 검증하기 위해 시간을 소모

3. 메인 미션과 비슷한 15분의 플레이 타임

4. 많은 리소스를 새로 제작한다

개선

1. '한 달 레벨 디자인 + 한달 배경 제작'으로 1개월 줄인다

2. 기존에 미리 준비된 5개의 모드에서 검증된 게임 플레이를 사용한다

3. 플레이 타임을 10분 내외로 정한다

4. 리소스는 되도록 기존의 메인 미션에서 가져온다

5. 프리펩을 활용하여 각 모드별로 반복 사용되는 요소는 계속 그대로 쓴다

이런 개선점을 토대로 이번주 부터 새로운 서브 미션을 제작하게 될 것이다. 기존의 챕터2에서 썼던 리소스를 활용한 예정이며, 가장 최근의 것일수록 규격이 정확하므로 낙도씨의 맵이나 광호씨의 맵 중 하나를 사용하면 좋다. 서브 미션으로는 수색 모드를 제작하면 좋을 것이다. 특히 기존의 수색 미션은 모두 야외에서 진행되므로, 실내에서 진행되는 수색 모드를 해도 좋을 것 같다.

CheckList

기초 아이디어 : 수집한다.

1-시간 : 2010년 4월 12일 ~ 2010년 5월 20일

2-기술 : Jupiter EX Engine

3-제한사항 : 기존의 메인 미션의 리소스로 제작

4-요구사항 : 특정 오브젝트를 수색하는 '수색 미션'

5-목표 : 생산성 높고 보장된 재미를 가지는 맵을 제작한다

6-게임플레이 : 오브젝트를 찾기 위해 레벨을 수색한다. 반복 플레이를 위해 랜덤 요소가 추가될 수 있으며, 패스도 정해진 길 보다는 오픈 필드를 지향한다.

7-테마 : 산업(아직 미정)
