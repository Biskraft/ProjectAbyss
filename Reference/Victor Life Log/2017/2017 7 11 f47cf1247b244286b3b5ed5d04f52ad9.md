# 2017. 7. 11.

오늘 계속 멍한 상태다. 어제 늦게 자서 수면이 부족한 거 같다. 3시 넘어서 잤다. 물론 롤 하다가.. 롤은 이제 그만해야지. 유튜브 동영상도 전부 구독해지 했다. 아침부터 계속 무언가 해야하는 상태라는 걸 알겠는데, 잘 되지 않는다. 일정 관리와 실무를 함께하긴 어려운가 보다.

오전에는 시도니아의 기사에 나오는 파종선 시도니아 내부 건축물을 조금 만들어보려고 했다. 아이언사이트에 적용하기 보다는 그냥 한 번 만들어보고 싶었다. 어떤 느낌일까 하고... 생각보다 느낌이 잘 나지 않는다. 너무 조금 만들어서 그런가. 이제 겨우 몇 초 움직일 분량밖에 되지 않는다. 그리고 앞으로 어떤 엔진으로 만들지도 고민해야 한다. 아마도 유니티겠지. 그래도 아직 뭘 만들지에 대해서 확정되진 않았다. 배틀그라운드 → 시도니아 판을 만들어볼까. 함선을 이끌고 우주를 돌아다니면서 파밍하는 게임도 괜찮아보이는데... 어딘가에 있을법한 게임이군.
