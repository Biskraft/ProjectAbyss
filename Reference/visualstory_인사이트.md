## 0. 핵심 명제

이미지는 작가가 이야기를 구조화하듯, 작곡가가 음악을 구조화하듯 **의도적으로 구조화**할 수 있다. 본서는 화면에 보이는 모든 것을 만질 수 있는 단위로 분해한다. **시각 구조(visual structure)** 는 우연히 만들어지는 미학이 아니라 설계 가능한 체계다.

저자의 중심 주장:

> 스토리 구조와 시각 구조는 평행하게 움직여야 한다. 극적 강도가 올라가면 시각 강도도 함께 올라간다.

본서가 다루는 시각 구조의 통제 대상은 카메라 앵글, 렌즈, 배우 동선, 구도, 세트·로케이션, 라이팅, 스토리보드, 커버리지, 편집까지 제작 전 영역에 걸친다. 핵심은 이 모든 결정을 **일곱 가지 기본 시각 요소**와 **대비·친연이라는 단일 원리**로 환원해 통제한다는 점이다.

## 1. 일곱 가지 시각 요소 (The Seven Visual Components)

움직이는 그림과 정지된 그림 모두에 존재하는 기본 단위. 모든 시각 분석과 설계의 어휘다.

| 요소 | 정의 | 핵심 하위 개념 |
| :--- | :--- | :--- |
| 공간 (Space) | 카메라가 담는 물리적 환경 | 딥/플랫/리미티드/앰비규어스 스페이스 |
| 선 (Line) | 톤 대비가 생기는 곳에 지각되는 선. 윤곽·경계·면 교차·이동 궤적이 만든다 | 방위(수평/수직/사선), 방향, 곡률 |
| 형태 (Shape) | 선과 톤 대비로 정의되는 윤곽. 실루엣이 객체 자체보다 중요 | 2D(사각·원·삼각) / 3D(육면체·구·피라미드) |
| 톤 (Tone) | 밝기. 인간은 가장 밝은 지점에 먼저 주목 | 미술(반사율), 라이팅, 노출 / 일치·불일치 |
| 색 (Color) | 가산(빛)·감산(안료) 혼합 체계 | 색상(Hue)·채도(Saturation)·명도(Lightness) |
| 움직임 (Movement) | 상대·객체·카메라·시선 이동 | 2D 무브(팬·틸트·줌) vs 3D 무브(달리·트랙·크레인) |
| 리듬 (Rhythm) | 음악적 리듬처럼 시각 비트 | 교대(alternation)·반복(repetition)·템포 |

### 1.1 공간 (Space)

다른 모든 요소가 존재하는 토대. 네 종류로 나뉜다.

- **딥 스페이스:** 깊이 단서(수렴, 크기 변화, 공기 원근, 톤 분리)로 3차원성을 강조. 광각 렌즈가 효과를 키운다.
- **플랫 스페이스:** 정면 평면, 일관된 크기, 얕은 심도, 압축된 그레이스케일, 망원 렌즈로 2차원성을 강조.
- **리미티드 스페이스:** 깊이 방향으로 평면이 층층이 쌓인 절충형.
- **앰비규어스 스페이스:** 크기·공간 관계·카메라 위치를 판단할 수 없는 공간. 인물이 들어오는 순간 모호함은 사라진다.

깊이 단서(소실점, 텍스처, 색 분리, 중첩, 형태 변화, 공기 확산, 지평선 위치)는 초점이 풀리면 함께 소실된다.

### 1.2 선 (Line)

방위가 강도를 결정한다. **사선이 가장 강하고, 수직, 수평 순**으로 약해진다. 직선은 공격성·강함·질서·경직을, 곡선은 수동성·자연·낭만·유연을 암시한다. 이미지를 기본 선으로 환원해 분석하는 도구가 **선형 모티프(linear motif)** 다.

### 1.3 형태 (Shape)

2D에서는 원과 삼각형, 3D에서는 구와 피라미드가 최대 대비를 만든다. 객체 자체보다 실루엣이 의미를 전달한다.

### 1.4 톤 (Tone)

가장 중요한 요소 중 하나. 시선은 가장 밝은 지점으로 끌린다. 어둠은 비극을, 밝음은 행복·희극을 연상시킨다. 톤 분리(밝기 차)가 깊이 지각을 만든다. 톤 범위가 주체를 드러내는지(일치) 숨기는지(불일치)가 통제 변수다.

### 1.5 색 (Color)

따뜻한 색(적·주황·노랑)은 다가오고, 차가운 색(청·녹)은 물러난다. HSL(색상·채도·명도)로 기술하며, 보색·분할보색 구성이 시각 전달을 강화한다. 관객의 색 기억은 부정확하므로 절대값보다 관계가 중요하다.

### 1.6 움직임 (Movement)

- **상대 이동:** 정지 기준 대비 위치 변화.
- **객체 이동:** 방향·질·복합 특성을 가진 궤적(track)을 만든다.
- **카메라 이동:** 2D 무브(팬·틸트·줌, 화면 내 균일 속도) vs 3D 무브(달리·트랙·크레인, 시차 발생).
- **시선 이동(point of attention):** 움직임·밝기·얼굴·소실점·새 객체로 시선이 끌린다.

### 1.7 리듬 (Rhythm)

교대·반복·템포로 구성. 주로 정지 객체(선형 모티프로 드러남)가 만들고, 편집 컷과 샷 간 요소 대비가 강화한다. 빠른 템포는 흥분을, 느린 템포는 평온·슬픔을 암시한다.

## 2. 대비 & 친연 (Contrast & Affinity) — 핵심 원리

본서 전체를 떠받치는 단일 원리. 일곱 요소 각각에 동일하게 적용된다.

> **대비의 원리:** 한 시각 요소의 대비가 클수록 그림의 시각 강도가 증가하고, 친연(유사)이 클수록 시각 강도가 감소한다.

| 개념 | 정의 | 예 (톤 기준) |
| :--- | :--- | :--- |
| 대비 (Contrast) | 요소를 서로 다르게 만들어 강도를 높임 | 흑과 백 — 그레이스케일 최대 대비 |
| 친연 (Affinity) | 요소를 유사하게 만들어 강도를 낮춤 | 비슷한 회색 묶음 — 톤 친연 |

- 대비와 친연은 **샷 안에서만이 아니라 샷 대 샷, 시퀀스 대 시퀀스에 걸쳐** 적용된다.
- 특정 요소를 제작물 전반에서 고정(lock)하면 일관된 **시각 스타일**이 만들어진다.
- "정답" 배열은 없다. 요소를 어떻게 조합하느냐가 무드와 시점을 결정한다.

---

## 3. 시각 강도 (Visual Intensity)

일곱 요소의 대비·친연 정도가 합산되어 한 장면의 **시각 강도**를 결정한다. 시각 강도는 단일 게이지가 아니라 각 요소별 강도의 종합이며, 제작자는 현재 필요에 맞는 요소를 골라 조절한다.

- 대비를 늘리면 강도가 오른다 → 긴장·불안·갈등의 장면.
- 친연을 늘리면 강도가 내린다 → 안정·평온·해소의 장면.
- 한 요소만 조작해도(예: 톤 대비만) 전체 강도가 움직인다.

---

## 4. 평행 구조 (Parallel Structure) — 스토리와 시각의 정렬

본서의 결론적 주장. **시각 구조는 스토리 구조와 평행하게 흘러야 한다.**

- 전형적 극적 곡선: 발단(exposition) → 갈등(conflict) → 절정(climax) → 해소(resolution).
- 시각 강도 곡선이 이 극적 강도 곡선을 따라 함께 오르내리도록 요소들을 배치한다.
- 발단·해소 구간은 친연(낮은 강도)으로, 갈등·절정 구간은 대비(높은 강도)로 설계.

| 극적 단계 | 권장 시각 처리 | 효과 |
| :--- | :--- | :--- |
| 발단 (Exposition) | 친연 우세, 안정 구도, 플랫/딥 일관 | 차분한 도입 |
| 갈등 (Conflict) | 대비 증가, 사선·톤 대비 도입 | 긴장 상승 |
| 절정 (Climax) | 최대 대비, 움직임·리듬 가속 | 정점 |
| 해소 (Resolution) | 친연 회복, 강도 하강 | 안도·종결 |

### 규칙의 의도적 위반

규칙을 깨는 것 자체가 강력한 도구다. 큐브릭의 *The Shining* 은 딥 스페이스와 각진 형태로 시각 규칙을 확립한 뒤, 237호실에서 규칙을 깨뜨려 시각적 충격을 만든다. 일관된 규칙이 먼저 서야 위반이 의미를 가진다.

## 5. 핵심 용어

| 용어 | 정의 |
| :--- | :--- |
| 시각 요소 (visual component) | 공간·선·형태·톤·색·움직임·리듬 — 모든 그림의 기본 단위 |
| 대비 / 친연 (contrast / affinity) | 차이로 강도 높이기 / 유사로 강도 낮추기 |
| 시각 강도 (visual intensity) | 요소별 대비·친연의 종합으로 결정되는 장면의 시각적 세기 |
| 평행 구조 (parallel structure) | 시각 강도 곡선을 극적 강도 곡선에 맞추는 원리 |
| 딥/플랫 스페이스 | 3차원 강조 / 2차원 강조 공간 |
| 선형 모티프 (linear motif) | 이미지를 기본 선으로 환원하는 분석 도구 |
| 일치 / 불일치 (coincidence) | 톤 범위가 주체를 드러냄 / 숨김 |
| 시선 이동 (point of attention) | 시선이 끌리는 지점의 이동 |

## 6. 실무 적용 체크리스트

1. **요소별로 분해하라.** 화면을 공간·선·형태·톤·색·움직임·리듬으로 각각 진단한다.
2. **대비·친연을 의식적으로 선택하라.** 각 요소에서 무엇을 다르게 하고 무엇을 묶을지 결정한다.
3. **시각 강도 곡선을 그려라.** 작품 전체에 걸친 강도의 오르내림을 스토리 곡선 위에 겹쳐 본다.
4. **요소를 고정해 스타일을 만들라.** 특정 요소를 전반에서 잠가 일관된 시각 정체성을 확립한다.
5. **규칙을 세운 뒤에 깨라.** 위반은 규칙이 확립된 다음에만 충격으로 작동한다.
