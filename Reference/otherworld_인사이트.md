# 이세계(Otherworld) 공간 연출 레퍼런스 — 색-독립 시그니처

> 조사 범위: Control(Oldest House / Astral Plane), Breath of the Wild(Shrine), Split Fiction(Hazelight)
> 일자: 2026-05-30
> 목적: ECHORIS 아이템 세계의 "아 여기구나" 즉시 인식 시그니처를 **색에 의존하지 않고** 설계하기 위한 타 게임 분석.

---

## 0. 왜 색-독립인가 (제약 정의)

ECHORIS 아이템 세계의 색은 **무기 정체성에 예약**되어 있다. 무기별 5기질(forge / iron / rust / spark / shadow)과 디스트릭트 그라디언트가 위상의 hue 를 결정하므로, "청록 = 아이템 세계" 같은 단일 색을 보편 시그니처로 박을 수 없다. 색을 보편 신호로 쓰면 무기별 팔레트와 충돌한다.

따라서 "이세계 인식"은 **색이 아닌 채널**에 실어야 한다:

> 기하 · 중력 거동 · 반복 도상 · 재질/가장자리 · 경계(보이드) · 스케일 · 진입 의례.

본 문서는 세 작품에서 이 색-독립 채널을 추출한다. 부유(floating)는 이미 채택된 시그니처이며, 본 조사는 그것을 보강하는 나머지 채널을 정리한다.

---

## 1. Control — Oldest House + Astral Plane (Remedy, 2019)

가장 직접적인 레퍼런스. ECHORIS의 부유 + 보이드 컨셉과 가장 가깝다.

### 1.1 Oldest House (현실 측 본거지)

- **브루탈리즘 = 질서.** 게임 월드 디자인 디렉터 Stuart Macdonald: 브루탈리즘은 "힘·무게·견고·안정"의 감각을 줘서 SF 배경에 좋다. ([Game Developer](https://www.gamedeveloper.com/art/the-real-buildings-that-inspired-i-control-i-s-oldest-house) )
- **질서 vs 혼돈의 충돌.** 통제되고 엄격한 기하학적 브루탈리즘 위에, 규칙을 따르지 않는 초자연 세력(Hiss)이 건축을 자기 필요대로 재구성한다. ([SuperJump](https://www.superjumpmagazine.com/the-architectural-battleground-of-controlcontrols-oldest-house-is-a-haunted-labyrinth-of-brutalist-architecture-but-why-delve-into-a-long-dead-architectural-style/) )
- **비인간 스케일** → 플레이어가 작아지고 "삼켜지는" 느낌. 공간 자체가 압도.
- **Threshold(문턱)** — 자발적으로 발생하는 차원 경계로 대체 차원에 연결. 경계 통과가 곧 위상 전환.

### 1.2 Astral Plane (이세계 그 자체) — ECHORIS 핵심 매핑

- **끝없는 순백 보이드** + 검은빛 기하 부유 구조물. ([Control Wiki](https://control.fandom.com/wiki/Astral_Plane) )
- 구조물이 **이동·재배열**된다 — 정적이지 않고 천천히 형태가 바뀜.
- **머리 위 상수 랜드마크** — 거대한 검은 피라미드가 항상 보임(방향 닻 + 소통 매개).
- **결정적: 외형이 "통제 주체"에 따라 바뀐다.** Hiss 가 침입하면 Astral Plane 이 밝은 적색·유동 형태로 변함(Hiss 자신을 닮음).

> **ECHORIS 직접 매핑.** Control 은 "**같은 이세계 구조에, 통제 주체별로 다른 스킨**"을 이미 구현했다. ECHORIS 의 모델과 동형:
> - 불변 구조 = 보이드 + 부유 기하 + 상수 랜드마크 → **아이템 세계 보편 시그니처**
> - 가변 스킨 = 통제 주체(=무기 기질)의 색 → **무기 정체성**
>
> 즉 Control 의 "Hiss 적색화"가 ECHORIS 의 "forge 무기 = 단조 주황 / shadow 무기 = 흑청" 에 대응한다. 구조는 같고 색만 무기를 따라간다.

### 1.3 추출한 색-독립 단서

부유 기하 / 보이드 경계 / 느린 재배열 / 머리 위 상수 랜드마크 / 비인간 스케일 / 문턱 전환.

## 2. Breath of the Wild — Shrine (Nintendo, 2017)

"맥락(대지)에서 뚝 떨어진 별개 공간"을 색에 거의 의존하지 않고 만든 모범.

### 2.1 반복 도상 (Iconography) — 가장 강한 색-독립 신호

- **시카족 눈(Sheikah eye) 모티프**가 모든 시린·슬레이트·고대 구조물에 동일하게 박힘. ([Architecture of Zelda](https://www.architectureofzelda.com/ancient-sheikah-art-and-architecture.html) )
- 단일 심볼의 반복이 **맥락과 무관하게 1초 인식**을 만든다. 색이 무엇이든 그 심볼이 보이면 "시린/고대 기술"이다.
- Jomon 토기에서 파생한 통일된 고대 미감 — 모든 고대 오브젝트가 한 미감을 공유.

### 2.2 재질·발광 라인

- 매끈한 고대석 + **발광 인레이 라인(별자리 패턴)**이 외벽·내벽에 흐름. 내/외부 디자인을 결속. ([UX Collective](https://uxdesign.cc/shrine-design-in-zelda-breath-of-the-wild-f3b1093469cf) )
- 발광 라인은 hue 를 바꿔도 *패턴 자체*가 신호로 남는다 — 색-독립.

### 2.3 형태 언어 대비

- 시린 외부는 원형·기하 매끈 형태로 유기적 대지와 대비/혼합. 내부는 통일된 기하 미니멀.
- 대지 = 유기·불규칙, 시린 = 기하·정연. **형태 언어의 대비**가 위상을 가른다.

### 2.4 진입 의례

- 받침대 + 슬레이트 인증 + **하강 엘리베이터 플랫폼**. 반복되는 진입 세리머니가 "이제 다른 공간으로 내려간다"를 각인.

### 2.5 색의 역할은 *상태* 신호 (세계 신호 아님)

- 미해결 시린 = 주황 발광, 해결 = 청 발광, 중단 = 상하 분리. ([cjleo Game Design Blog](https://cjleo.com/blog/shrine-colours-in-tears-of-the-kingdom-and-breath-of-the-wild/) )
- 즉 BOTW 에서 **색은 진행 상태를 말하고, 세계 정체성은 도상·재질·형태가 말한다.** ECHORIS 에 그대로 적용 가능 — 색을 무기/상태에 쓰고, 세계 정체성은 형태·도상에 둔다.

### 2.6 추출한 색-독립 단서

반복 도상 / 발광 인레이 라인 재질 / 기하 형태 언어 대비 / 하강 진입 의례.

## 3. Split Fiction — 반면교사 (Hazelight, 2025)

세계를 **색으로 가르는** 방식. ECHORIS 가 피해야 할 접근의 사례이자, 그 안에서 건질 색-독립 단서.

### 3.1 색 의존 (회피 대상)

- SF 구간 = 쿨 팔레트, 판타지 구간 = 웜 팔레트로 대비. ([Indie Hive](https://indie-hive.com/split-fiction/) , [ArtStation Magazine](https://magazine.artstation.com/2025/04/hazelight-studios-split-fiction-art-blast/) )
- 이 방식은 ECHORIS 에서 무기별 색과 충돌한다 — 보편 시그니처로 쓸 수 없음을 확인해 주는 사례.

### 3.2 그래도 건질 색-독립 단서

- **세계별 건축·기믹 차별** — 중세 왕국 vs 사이버펑크 도시가 구조와 플레이 메커닉으로 구분. 색이 같아도 건축이 다르면 세계가 다르다.
- **전환 시 아바타 변화** — 세계를 옮기면 의상이 그 세계 테마로 바뀜. *플레이어 자신*이 위상을 입는다. ([Unreal Engine 인터뷰](https://www.unrealengine.com/en-US/developer-interviews/sci-fi-and-fantasy-worlds-collide-in-ue5-powered-co-op-adventure-split-fiction) )
- **진입 경외 모먼트** — 새 세계 진입마다 "awe" 스펙터클을 배치.

### 3.3 교훈

색에만 의존하면 무기 팔레트와 충돌한다. 차별은 **건축·기믹·전환 연출·아바타 변화**로 분산해야 한다.

## 4. 합성 — 색-독립 시그니처 7채널

세 작품에서 추출한 채널과 ECHORIS 적용.

| # | 채널 | 정의 | 출처 | ECHORIS 적용 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **중력 거동** | 부유·상승·재배열 | Control Astral | **채택됨** — 잔해 부유 + 상승 드리프트(다이브 하강 강화) |
| 2 | **경계·보이드** | 지평선 없음, 무한, 비네트 | Control Astral, 리미널 | 위상 가장자리가 보이드로 소멸 — 월드의 솔리드 메가스트럭처와 대비 |
| 3 | **반복 도상** | 단일 모티프 반복 | BOTW 눈 | **에코 공명 도상** — 동심 공명 원(언어화된 소리) 이 부유 파편·바닥·라인에 반복 |
| 4 | **재질·가장자리** | 발광 인레이 라인 + 소프트 해체 | BOTW + 리미널 | 매끈 표면에 발광 라인 패턴 + 부드럽게 녹는 가장자리 |
| 5 | **형태 언어** | 직교 격자 ↔ 동심·방사·파쇄 | Control 브루탈 vs 변형 | 월드 = 수직 직교 격자 / 아이템계 = 동심·방사·파쇄 비격자 |
| 6 | **스케일 반전** | 압도 ↔ 친밀 | Control / 아트 §5.1 | 월드 1:40 압도 → 아이템계 친밀 스케일 |
| 7 | **진입 의례·스펙터클** | 문턱·받침대·경외 | Control Threshold, BOTW pedestal, Split Fiction | **포지 격발 5단계**(아트 §4.2) 이 진입 세리머니 |

핵심: 이 7채널은 모두 hue 를 바꿔도 신호가 살아남는다. 색은 무기에 자유롭게 내준다.

## 5. ECHORIS 시그니처 스택 — 구조(불변) / 색(가변) 분리

Control Astral Plane 의 "구조 상수 + 주체별 스킨" 모델을 ECHORIS 골격으로 채택한다.

### 5.1 구조 시그니처 (불변, 무기 무관) — "아 여기구나"를 담당

1. **부유 + 상승 드리프트** (채널 1) — 잔해가 떠올라 회전·상승. 다이브 하강 시 카메라를 스쳐 위로.
2. **보이드 경계** (채널 2) — 공간이 사방 보이드로 소멸. 출구·지평선 없음.
3. **공명 도상** (채널 3) — 동심 원(frozen sound) 이 파편·바닥·발광 라인에 반복. BOTW 눈에 대응하는 ECHORIS 단일 모티프.
4. **발광 라인 + 소프트 가장자리** (채널 4) — 매끈 표면 + 인레이 라인, 녹는 경계.
5. **친밀 스케일** (채널 6) — 월드의 압도와 반대.
6. **상수 랜드마크** — Control 피라미드처럼, *공간 중심/심부에 빛의 핵* 하나가 항상 보임(에코의 음성 응결체, 아트 §5.2). 형태·위치는 상수, hue 만 가변.
7. **느린 재배열** — 부유 기하가 천천히 형태를 바꿈(Control).

### 5.2 색 스킨 (가변, 무기별) — 무기 정체성을 담당

- 5기질 hue + 디스트릭트 그라디언트가 위 구조 위에 입혀진다.
- forge 무기 → 단조 주황 스킨 / shadow 무기 → 흑청 스킨 / spark → 전기 청백 … (Control 의 "통제 주체별 스킨"과 동형).
- 구조는 동일하므로, 색이 무엇이든 플레이어는 "아이템 세계"임을 형태·중력·도상으로 인식한다.

### 5.3 아트 디렉션 §14 채널 분리와의 정합

| 채널 | 점유 | 신호 대상 |
| :--- | :--- | :--- |
| 형태·중력·도상·경계 | 위상(World/Builder/Item Stratum) | **세계 정체성** (불변) |
| Hue | 무기 5기질·디스트릭트 | **무기 정체성** (가변) |

두 채널이 분리되므로 충돌하지 않는다. §14 "환경 vs 아이템 색 분리" 원칙의 확장 — 이번엔 "구조(세계) vs 색(무기)" 분리.

---

## 6. 적용 권고 요약

- "아 여기구나"의 1순위는 **부유 + 보이드 + 공명 도상** 세 가지(모두 색-독립).
- 색은 무기 스킨으로 완전히 양보. Control Astral 의 주체별 스킨이 그 정당성을 보증.
- 진입 순간(포지 격발)에 7채널을 동시 플립해 경계에서 가장 강하게 각인(아트 §15.3).
- 반복 도상(공명 원)을 신규 아트 자산으로 우선 확정 — BOTW 눈처럼 단일 모티프가 인식의 닻.
