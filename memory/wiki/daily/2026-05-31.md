# 2026-05-31

## Session - Cyro Weather Visibility

- Fixed Item World cyro weather not appearing after IntGrid collision was added.
- Cause: rising stratum particles spawned below the viewport, which often placed them inside or below floor IntGrid cells; collision removed them before they became visible.
- `WeatherSystem` now spawns rising stratum motes from visible air just above floor/one-way surfaces when possible, with a visible-air fallback.
- `ItemWorldScene` now resolves weather profile from weapon `temperamentPrimary` before area fallback, so `iron` weapons always use cyro rising frost even if their visual theme changes.
- `WeatherProfile=cyro` is accepted as the project-spelling alias for `cryo`; `iw_coolant_*` rows now use `cyro`.
- Verification: `npm run build` from `game/` passes. Existing CSV/LDtk/font/chunk warnings only.

## Session - Anvil Ghost Terrain Collision

- Fixed anvil Item World ghost terrain burying/covering the player.
- Cause: ghost terrain containers were added above `entityLayer`, and ghost collision was stamped into the streamed `collisionGrid` as soon as reveal began, before the tile visually reached its final position.
- `ItemWorldGhostOverlay` now stamps collision only after a tile finishes its scale/settle animation.
- `LdtkWorldScene` inserts ghost terrain below entities and resolves the player out of newly stamped solid overlap.
- Verification: `npm run build` from `game/` passes. Existing CSV/LDtk/font/chunk warnings only.

## Session - Item World Entry Color Hold

- Changed the entry corridor handoff color effect so the actual Item World start room stays grayscale/contrast-filtered for 1000 ms after the fall.
- After that hold, the filter fades back to full color over the next 1000 ms.
