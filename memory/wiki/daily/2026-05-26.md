# 2026-05-26 Work Log

## Session 1 - WorldPullIn component spec

- Added `WorldPullIn - Center Sink` to `game/docs/ui-components.html`.
- Purpose: PixiJS transition effect where the surrounding world collapses into a central sink while HUD/UI layers remain readable.
- Implementation recipe documented: render world layers into a `RenderTexture`, split the snapshot into a capped grid of cropped sprites, animate each fragment toward the camera center with radial pull, tangential spin, scale-down, and fade.
- Usage rule: reserve this for spatial rupture moments such as Item World entry, memory recall, world collapse, or one-way portal activation. Do not use it for ordinary hit impacts, pickups, or menu transitions.
- Performance rule: cap fragments at 84 sprites, reuse sprites/render textures, and provide a reduced-motion fallback using only a radial vignette and core flash.
