Verification: `npx tsc --noEmit` and `npm run build` pass.

- Fixed enemy wall-block jump accumulation after the pixel-sweep change. Frames where horizontal intent exists but pixel remainder rounds `moveX` to 0 use an ahead-wall probe instead of resetting `wallBlockedTimer`, and wall-height scanning now uses intended movement direction instead of stale facing. `npm run build` passes.
- Added a short horizontal carry for wall-block navigation jumps. The X collision that triggers the jump zeros `vx`, and ground enemy AI skips chase while airborne, so without carry the enemy can jump in place and land back at the same wall. Verification: `npx tsc --noEmit` and `npm run build` pass.
