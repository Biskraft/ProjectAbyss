### 핵심 시스템 추가

#### 1. Hades-style Ego Shard Cast (`effects/EgoShard.ts`)
- **Hold-and-release charge** — V/Y 누르고 있는 동안 `egoCastChargeMs` 증가. release 시 `getShardVelocity(charge, facing)` 으로 vx/vy 결정
- 차징 범위: 0~900ms. vx 140~480 / vy -30~-130 (절반으로 줄여 평탄 ~ 작은 호)
- **Trajectory preview** — `EgoShardPreview` 신규. 차징 중 quadraticCurveTo 곡선 + 외곽 glow + tip ring. 시뮬레이션은 실제 shard 와 1:1 일치 (gravity 240, solid 충돌 시 stop)
- **회수 큐** — fire 시 `shardCooldowns.push(8000)`. 매 프레임 카운트다운. 0 도달 시 `removeOldestShard` + count++. **방 이동 시 큐 유지** (Player 객체 persist)
- **Manual retrieve** — player AABB 24px padding 으로 stuck shard 탐색. 회수 1개당 queue 의 최대 잔여시간 항목 pop. ring 폭발 VFX
- **CAST_MIN_GAP_MS = 1000** — 연사 방지
- **Spawn 위치 정렬** — 권총 muzzle 라인 (`facing × 14`, `height × 0.38 - 5`)
- **Aim animation** — `Player.isAiming` flag → erdaAnim 'aim' 우선. 4 프레임 (atlas idx 26-29). 정지 시 26 freeze / 이동 시 110ms cycle. **이동 속도 1/2**

#### 2. ThrowableContainer 시스템 (`entities/ThrowableContainer.ts`)
- 6 종 catalog: **Crate / MetalCrate / OilDrum / WaterBarrel / MagmaCrucible / AcidVial** (32×32 통일)
- **Atlas-driven 외형** — `crate_01_atlas.png` 슬라이스
  - Row 0: wood_01~04 (Crate 무작위 variant 0-3)
  - Row 1: metal_01~04 (MetalCrate 무작위 variant 0-3)
  - Row 2: oil_01 / acid_01 / magma_01 / water_01 (fluid 컨테이너 전용 슬라이스, fluid stamp 제거)
- `variantIdx` readonly — spawn 시 1회 결정, 생애 고정
- **물리** — gravity (760 px/s²), 벽/다른 컨테이너 충돌 시 vx*0.3 정지 (kinetic 으로 파괴 안 됨). **wasThrown** 플래그가 던졌는지 표시. **settleAtSpawn()** raycast 로 spawn 즉시 floor/stack 안착
- **Stack** — `cellBlockedBy(gx, gy)` 가 다른 컨테이너 AABB 도 solid 로 취급. grounded 시 더 높은 floor (grid floor 또는 다른 컨테이너 top) 자동 snap
- **Player ↔ container 충돌** — `resolvePlayerContainerCollision` 최소 침투축. overlapTop 시 player stand + `forceGrounded()`. overlapLeft/Right 시 player 가 vx > 20 이면 컨테이너 push. **overlapBottom 시 컨테이너를 위로 밀어내 stack** (이전엔 player 를 floor 로 매장하던 버그 fix)
- **Container ↔ container 충돌** — `resolveContainerContainerCollision` 50/50 push apart (overlap 시)
- **Grab/Throw** — B/RB. AABB inflated 8px 로 인접 컨테이너 탐색. 던지기 vx 80 / vy -170 (이전 1/4 사거리). 들고 있을 때 `Player.isLifting = true` → lift 애니메이션 (atlas idx 30-33) + **이동 속도 1/2**
- **takeAttack(damage)** — 외부 공격 인터페이스. HP ≤ 0 시 `{gx, gy}` impact 반환
- **MetalCrate** — hp 4, paintTile=0. **검·Ego Shard 모두 면역** (hit spark 만, 데미지 무효). acid 셀 노출 4초만이 유일한 파괴 경로
- **Wood family 환경 파괴** (`tickEnvironment`):
  - magma 셀 1.5초 노출 → burn out + 페인트
  - fire (burning 셀 overlay) 1.5초 → burn out + 페인트
  - acid 셀 3초 노출 → 부식 + 페인트
- **Destroy VFX 통일** — `destroyContainerWithVFX(c)` 헬퍼: `propShatter.spawn` (texture/color) + `SFX.play('breakable_destroy')` + hitstop 3 + camera shake 2

#### 3. LDtk Container Entity 파싱
- Entity type = `Container`, fields: `Kind` (enum: Crate/MetalCrate/OilDrum/WaterBarrel/MagmaCrucible/AcidVial) + `FluidVolume` (Integer, optional)
- LdtkWorldScene 의 spawn 시 `ent.grid * 16` (피벗-독립 좌표) + `settleAtSpawn` 자동 정착
- 로그 형식: `[Container] level="..." found=N spawned=N` + 인스턴스별 px/grid/vol

#### 4. Container Paint BFS (`paintFluidSplash`)
- BFS-flood. paintable = air(0) / grass(16) / **fluid (water, oil, acid, magma)** — 다른 fluid 위에 painting 가능
- `quantity` 셀 도달 시 종료. 솔리드 셀은 expansion 차단
- **Magma 페인트 → 인접 flammable 즉시 ignite** (`tryIgnite` 4-이웃) — 600ms passive tick 대기 없이 즉발 화재

#### 5. Oil 진입 처리 강화
- **Oil 잠수 → 산소 게이지** — Player.submerged 가 head cell value 11 도 인정. waterBreathing 능력이 oil 도 우회
- **Oil 풀 drain** — player AABB 안 모든 oil 셀 한 번에 (200ms tick). FluidSystem gravity refill 보다 빠른 속도 → 풀이 가시적으로 위에서부터 줄어듦. 각 drain 셀당 `FluidResidue.dropAt('oil', 1.0)` 잔존 (lifetime: oil 만 10s, 나머지 2s)

#### 6. Player 상태 통합
- `Player.extraGroundedSticky` — scene 의 forceGrounded 가 sticky flag 설정. physics 직후 `grounded = grid_grounded || sticky` → 점프 가능. update 끝에 reset, scene 이 매 프레임 재set
- `isAiming` / `isLifting` 동시 적용 시 lift 우선 (손 막힘 — aim 불가)
- 이동 속도 `(isAiming || isLifting) ? 0.5 : 1`

#### 7. Hybrid fluid render (`FluidSystem.ts`)
- **COLUMN_SPACING 8 → 4 px** (셀당 컬럼 2 → 4) — 표면 spring 갯수 2배. 작은 풀에서도 자연스러운 wave
- **quadraticCurveTo midpoint 곡선** — top surface / inline glow / halo (outer/inner/hot core) / surface stroke 모두 직선 segments 제거. Catmull-Rom 식 곡선
- **물리 / 시뮬레이션 / IntGrid 데이터는 16×16 그대로** — refactor 0. render-side 만 부드러움
- Noita 식 sub-cell physics 검토 후 hybrid 채택 결정 (refactor 비용 vs 시각 ROI 분석)

#### 8. Magma 데미지 5배
