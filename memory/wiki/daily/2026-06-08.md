  - `completeExit()` now guarantees one-shot return preparation (`prepareReturnResult`) before callback execution, even when `startPreparedExitFade()` is not the first call.
  - Reuses `returnPreparationStarted` to keep direct return paths and fade-mediated return paths behavior aligned.

- Scene-level return entry points were further tightened:
  - Added `startPreparedExitFadeForReason` / `completeExitWithReason` on `ItemWorldReturnFlowRuntime`.
  - `ItemWorldScene` now uses reason-aware methods for clear/escape/prologue/death-complete paths, reducing direct `progressController.request*Exit()` coupling.
  - 추가 정리: 흡수 연출 완료 콜백과 페이드 종료 분기에서 사유 없는 반환 진입(`startPreparedExitFade`, `completeExit`)이 남지 않도록 `progressController.getExitReason()` 기반 분기로 일원화.
- 추가: 종료 사유 전달 의존성을 `requestEscape/clear/death`에서 `requestExitWithReason(reason)` 단일 인터페이스로 압축, `ItemWorldProgressController` 경계를 단순화.

- Added AGENTS.md rule: recurrent state-transition bugs should be systematized with a single owner/state/reconcile path instead of scattered direct toggles. This codifies the HUD on/off lesson for future agents.

- Extended AGENTS.md bug-fix workflow: before editing for a bug, agents should recommend either a one-shot fix or a systemic fix and briefly justify the choice. Systemic fixes should outline owner/state/reconcile before code changes.
