# 2026-05-28 Work Log

## Session 1 - Item World corridor sequence

- Item World entry corridors now compose LDtk levels by prefix: `_1`, `_2`, `_3` first, then a deterministic shuffled 10-segment tail from `_4+`.
- Corridor completion now spawns the player at the start room's LDtk `Player` entity instead of preserving the corridor x-position.
- `ItemStratum_Corridor_*` levels are excluded from normal ItemStratum room template selection.
- Verification: `npx tsc --noEmit`, `npm run build`, and port 3000 `/play/?debug` returned 200. Existing warnings are the LDtk/CSV asset warnings plus Vite chunk-size warning.

## Session 2 - Item World corridor background brightness

- Entry corridor parallax keeps the corridor grayscale/contrast treatment but now applies an additional brightness pass so the background matches the bright outside-world look.

## Session 3 - Player jump physics

- Player movement now uses integer pixel-sweep collision with sub-pixel remainders, following the Actor movement model described by Maddy Thorson's Celeste/TowerFall physics write-up.
- Ground, wall, and double jumps now set their own takeoff velocity before entering the `jump` state, preventing generic jump entry from overwriting special jump velocities.
- Descending carrier platforms no longer reduce grounded jump height, while upward carrier velocity can still add lift.
- `Player.Jump.VarJumpCutMult` changed from `0.85` to `0.55` for a clearer tap short-hop.

## Session 4 - Item World corridor exit condition

- Entry corridor handoff no longer fires at the right edge; it only completes after the player lands on the bottom floor.

## Session 5 - Item World corridor opening shuffle

- Entry corridor `_1`, `_2`, and `_3` are no longer fixed in numeric order. They are deterministically shuffled before the `_4+` shuffled tail, so sequences like `2,1,3,7,4,5...` are valid.

## Session 6 - Item World corridor bottom handoff

- Entry corridor bottom exit now uses the corridor map's bottom boundary instead of the lowest authored platform surface. Walking right onto low platforms no longer completes the corridor.

## Session 7 - Windows offline demo package

- Added Electron packaging for Windows offline demo builds: `game/electron/main.cjs`, `build:offline`, `build:offline:ko`, and `package:win`.
- Offline Vite modes use `base: './'`, keep Korean locale via `ko-offline`, and strip remote Google Fonts/Analytics from `index.html`.
- Added package root readmes under `game/offline/`; final generated zip is `game/release/ECHORIS_Demo_Offline_Windows_2026-05-28.zip`.
- Verification: `npm run build:offline:ko`, `npx electron-builder --win dir --x64`, and a short `ECHORIS.exe` process-start smoke test passed. Existing warnings are LDtk/CSV tileset warnings plus Vite large chunk warning.
