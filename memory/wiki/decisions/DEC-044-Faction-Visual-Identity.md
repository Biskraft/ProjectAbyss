# DEC-044: 세력 비주얼 정체성 + 몬스터 재분류 ("모든 몬스터=말소자" 폐기)

## 맥락
세력을 메커닉이 아닌 **디자인 정체성 그룹**(공유 비주얼 문법)으로 확정하는 과정에서, Victor 가 v3 의 "모든 몬스터 = 말소자 개체" 장치를 폐기. 드론(slime/skeleton/ghost)과 말소자를 명확히 분리.

## 결정
세력 4그룹 (메커닉 아님 — 평판·소속·퀘스트 없음. 공유 실루엣·팔레트·모티프):

1. **잔존자** — 인간 공동체. 생활 천, 무채색 + 따뜻한 점광, 정(情) 소품(식기·죽·단조 망치).
2. **인덱서** — 인간 등재 신앙. 의례 천·모자, 응결재 질감, 합창 군집. 묵정만 가장 어두운 모자로 구별.
3. **말소자** — 코스믹 절멸 시스템. **BLAME! 세이프가드식 흰색 언캐니 인간형 호러.** 희귀 — 특정 공간·특정 이벤트에만 등장. 귀여운 드론과 동시 등장하지 않음. 32px 표현 난제(단일 명도 near-white + 비정상 비율 + 절제된 불쾌 모션).
4. **드론** (slime/skeleton/ghost) — 평범한 잔존 환경 생물 (Hollow Knight 기본 벌레 격). **말소자 아님.** 픽셀 정합 위해 다소 귀엽게 표현됨.

- "모든 몬스터=말소자" 폐기 → "슬라임도 말소자다" 코스믹 호러는 사라지되, 말소자의 **희소성·등장 연출**로 공포를 집약. 평범(드론) vs 절대 이질(말소자) 의 강한 위계·대비.
- **boss_01 ≠ 말소자** (시공 부산물/인덱서 의례 호위 메카 — `Design_Art_Direction.md` §1 기존 분류 유지). 시놉시스의 "boss_01 = 온전한 말소자 유닛" 표기 정정 대상.
- 코스믹 층(빌더/말소자/관리 권위) 구조는 유지 — 말소자는 그중 절멸 시스템.
