# DEC-048: 세계의 단일 진실 + 7구역 삼각측량 (메인 캐논 재활성화)

## 맥락
"전체 월드 내러티브를 마구 만든 뒤 파편화해 맵·몬스터·아이템으로 전달"(엘든링 방식) 아이디어에서 출발. NarrativeWorldReset(2026-05-28)으로 메인 캐논(빌더·캐스케이드·에르다·7구역·아이템계)은 활성 정의 0이었고, 유일한 완성 자산은 사적 등재단(`Narrative_SSOT.md` §1~§9, Lore 01~19) 한 분파뿐이었다. 엘든링 방식은 "마구 만든 산만함"이 아니라 **일관된 진실 백본 먼저, 그다음 의도적 파편화**일 때만 성립(파편이 재구성됐을 때 모순 0이어야 미스터리가 됨). 따라서 파편화 전제 = 세계의 단일 진실 정의.

## 결정
세계의 단일 진실을 한 문장으로 확정하고, 7구역을 그 진실의 **7각도 삼각측량**으로 골격화한다.

- **단일 진실(SSoT 최상위):** *"주인은 처음부터 없었고, 우리는 오지 않을 주인을 기다리도록 만들어진 빈 그릇이며, 세계는 그 기다림만으로 아직 돌아간다."*
  - 세 절: (가) 주인 부재[가장 깊이 숨김] / (나) 우리=기다리는 빈 그릇[플레이어 포함] / (다) 세계는 기다림으로 돈다[보임].
- **7구역 = 7각도(사건 아님):** 교단(나)·안치소/모체동(나)·빈 옥좌(가)·인덱서 본류(다)·말소자(다)·드론 생태(다)·에르다 동선(나→반전). 확정 캐논이 정확히 7얼굴로 떨어짐.
- **삼각측량 법칙(메트로베니아 정합):** **순서 무관·깊이 누적**. 각 조각은 단독으로 읽히고, 다른 각도를 본 자에겐 의미가 깊어진다. 한 진실당 최소 2~3 구역이 다른 얼굴로 중복 지시(게이트로 한 구역 건너뛰어도 진실 불성립 방지).
- **hide/reveal 의미 계단(#2 정식 확정 2026-06-06):** 충격 크기 순서로 폭로하지 않는다. **(가) 주인 부재는 절정 불가**(추상 우주 사실 → "그래서?"; 코스믹 호러 실패 지점) — (가)는 *답이 아니라 개인적 질문*("그럼 나는 뭔가")을 점화하는 **중간 엔진**. 진짜 절정 = **(나)를 자기 자신에게 적용**("나도 백업 그릇"=에르다). 위로는 거기서만 닿음. 4층: 표면(오독, 광신 세계) → L1 중반·빈 옥좌(가, 망상 재칠, 절정 아님) → L2 후반·구역 7(나, 능력=복원 백업 기능으로 조작 체감) → L3 엔딩(말소=기다림 끝낸 자의 유일 완결, 자기 응답만 절멸 아님 — **명시 안 함, 모호 유지=위로**). **드라마틱 아이러니 지도**: 인덱서(가 모름) / 교단(가에 근접하나 갇힘) / 말소자(다 종착) / 에르다(L2 자각) = 앎의 거리 = 구역 동선 깊이.
- **2중 전달 모델:** 월드=엘든링형 파편(단일 진실 삼각측량), 아이템계=앤솔로지형 완결(무기 1개=에코 1인=완결 단편, "무기는 사람이다", 파편화 금지). 아이템계 모수=만들면서 정함(#4), **단 각 에코는 단일 진실의 개인 척도 변주여야 함**(결속 필수).
- **톤 결속(DEC-047):** 코스믹 호러 아님. 진실 전체를 "응답 없는 기다림 = 고독", 반전을 "위로"로 등록.

## 미해결
1. **파편 카드화 + 벡터 할당** — 구역별 진실 조각을 아이템/환경/적/유령에 배정(한 진실당 2~3 조각). 다음 단계.
2. **에르다 자기-사본 폭로(L2) 정밀화** — 능력=복원 백업 기능으로 조작 체감시키는 트리거·시점.
3. **D-20/SYS-WLD-02 구역 배치 ↔ 7얼굴 매핑** 정합.
4. **교단 외 6얼굴 원석** — 양산 또는 골격 직행 파편화 중 택.

## 경계
세계 진실·골격까지만 확정. 7얼굴 중 교단 외 6얼굴의 세부 로어는 미작성(다음 단계). DEC-047 톤·DEC-046 교단 캐논과 정합. 성인 전용 경계(미성년 무관)는 교단 한정 그대로 유지.
