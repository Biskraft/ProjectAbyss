# DEC-046: 사적 등재단 (the Bonded) — 인덱서 하위 분파 캐논화

## 맥락
`Documents/Idea/Idea_WorldBuilding.md` 의 떠도는 권력교환(주종·복종=해방) 아이디어를 ECHORIS 캐논 안의 잔존자 분파로 정박하는 과정. 작품 중심 테마(복종=거짓 해방, 통제의 양도)의 한 변주로 정합. RES-PWX-01(복종=해방 거짓 신앙)·RES-PSY-01(보유/배출 통제 심리)·CNT-STR-001(등재·인덱서·반전)에 직접 결속.

## 결정
사적 등재단(가칭 the Bonded) = **인덱서의 하위 분파**로 확정. 인덱서 본류가 "시스템(빌더)에 등재하라"면, 사적 등재단은 "사람에게 등재하라"로 신체화한 갈래. 같은 거짓의 더 친밀한 버전.

- **명칭(확정):** 주(主)=등재인(the Registrar), 종(從)=색인체(the Indexed/Entry), 관계·의례=사적 등재(Private Registration), 공동체=사적 등재단. 인덱서 등재 어휘를 사적(私的) 버전으로 직계 차용 — 행정 용어가 인간을 항목(엔트리)으로 만드는 도착(倒錯)이 섬뜩함의 축.
- **구성:** 전원 젊은 성인 여성(등재인·색인체 모두). 단성 격리 공동체. "젊은"=성인 연령대, 미성년(율 등) 절대 무관.
- **기원(§1.1):** 복원 모체동(the Vessel Ward) 생존 집단. 관리권위가 백업(자아)을 되살릴 복원 그릇을 젊은 여성 신체로 규격화·보존 → 그 그릇만 모은 단일 병동이 캐스케이드에서 유일하게 온전 생존 → 채워질 자아(백업)가 오지 않자 "서로의 주인이 되어 서로를 채운다"며 사람에게 등재 시작. 에르다(백업-그릇 계보)와 직계 평행 = 거울 비트.
- **게임 등장(확정):** 등장시킨다. 노출 수위 = 환경 서사(분위기·구조)만. 명시 신체·성적 묘사 없음(전체 게임 톤=고독·인물 서사·위로; 단 교단 내부 레지스터는 **공포·위협 기반 통제 유지** — 체벌·규율 실제 위협 + 빈 그릇의 비극 공존, DEC-047 톤 층위. 에로티카 아님).
- **시각(§6.1~6.2):** 무채색 보존 셀 결. 색인체=스스로 못 여닫는 봉합 보존복 + 탯줄 1가닥 + 색인 태그(번호) + 빈 손. 등재인=같은 무채색·더 구조적 + 계류 릴(탯줄 권양). 채도 0 = 자아(붉 닻) 부재 = "빈 그릇". 모티프=봉합+탯줄+계류(구속=연결=의존 수렴). 고딕 가죽 구속구 아님 → sci-fi 의료-보존 결.
- **스타일 프레임:** "벽면 슬럼 + 탯줄 군집" 1컷 발주 대상 승격(의상 기준=§6.2). 선결=배치 구역 확정 후 구역 컬러 스크립트 정합. (거주=공중 현수 아님; 수직 벽면에 붙인 단순 규격 거처[IntGrid 격자 타일 친화] + 병적 청결[병동형 멸균, 다른 잔존자 구역과의 시각 분리점]; 탯줄=등재인에 묶인 예속·안전줄, IntGrid 지형 아닌 장식 오버레이. 2026-06-06 정정.)
