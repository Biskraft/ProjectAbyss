# DEC-047: 톤 재정의 — 코스믹 호러 폐기, 고독 + 인물 서사

## 맥락
`Idea_WorldBuilding.md`(사적 등재단) 작업 중 톤 논의에서, 작품 전반의 정서 레지스터를 재정의. 기존 캐논 다수가 작품 톤을 "코스믹 호러(·위로)" 로 명시해 왔다(Vision·Synopsis·D-15·D-20·보스·존 설계 등 13개 캐논 문서). 사용자 결정으로 코스믹 호러를 톤에서 전면 폐기한다.

## 결정
**ECHORIS의 톤 = 두 기둥 + 보상.**
1. **고독(孤獨)** — 메가 스트럭처에서 오는 적막·외로움. 거대하고 텅 빈 구조, 응답하지 않는 권위, 잊혀진 존재.
2. **인물 서사** — 아이템계(에코 다이브) 에서 길어 올리는 인물에 대한 이야기.
3. **위로(慰勞)** — 별도 기둥이 아니라 인물 서사가 닿는 정서적 보상. 고독의 해독.

**코스믹 호러는 톤에서 말살.** 우주적 공포·이해 불가능성을 '두려움'으로 연출하던 레지스터를 제거하고, 같은 세계 사실을 '고독·쓸쓸함'으로 재연출한다.

## 전파 원칙 (재서술 규칙)
1. **톤 단언** ("ECHORIS 톤/분위기 = 코스믹 호러") → "고독 + 인물 서사, 위로는 서사의 보상" 으로 교체.
2. **구조 비트 유지·라벨 교체** — 빌더의 무관심, Cascade 불가지, 빈 옥좌(응답할 자 부재), 말소자(잊혀짐의 절멸), 무력함은 **사실로 유지**하되, 정서 레지스터를 우주적 공포 → **고독·적막·잊혀짐**으로 재명명. "코스믹 호러" 라벨만 삭제.
3. **"코스믹 호러 4원칙"**(이해 불가능성·무력함·점진적 발견·이성의 배신) → 명칭에서 '코스믹 호러' 제거, **"고독·불가지 4원칙"** 으로 개칭. 4항 내용은 유지(불가지·무력=고독의 장치로 자연 정합).
4. **내러티브 가이드 §14**(일반 호러 작법 레퍼런스) → 범용 지식으로 **존치**하되, "ECHORIS 적용 톤 = 고독(코스믹 호러 톤 아님, DEC-047)" 포인터 추가. 크래프트 지식 삭제 금지.
5. **인간 척도 불안 유지** — 언캐니(말소자), 쓸쓸함, 불온함은 유지. **우주적 공포만** 제거.
6. **사적 등재단 = 공포·위협 통제 + 비극 공존** (2026-06-06 정정 — Victor). '호러를 걷어낸 순수 비극'이 아니다. 교단은 공포·위협으로 구성원을 통제하는 어두운 톤(체벌·규율 = 실제 위협)을 **유지**하며, 동시에 빈 그릇의 고독이라는 비극을 품는다. 두 층이 공존.

## 톤 층위 구분 (2026-06-06 보강 — Victor)
코스믹 호러를 **게임 전체의 지배적 정서 레지스터**로서 폐기하는 것이지, 다음 둘은 유지한다.

1. **세계 사실 = 통제 불가능성.** 메가 스트럭처·빌더는 인간이 통제할 수 없다. 이 불가지·무력이 ⓐ 고독을 낳고 ⓑ **교단(신앙) 발생의 정합 근거**다 — 통제할 수 없는 것 앞에서 인간은 복종/신앙으로 도피한다.
2. **교단 내부 레지스터 = 공포·위협 기반 통제(유지).** 두 교단 모두 — 인덱서(빌더 신앙/등재) + 사적 등재단(인간 신앙) — 공포·위협으로 구성원을 통제하는 어두운 톤을 유지한다(체벌·규율은 실제 위협). 교단은 메뉴스(menace)가 사는 자리다.

**톤 지형:** 탐험·빌더·앰비언트 = **고독** / 교단(등재·사적 등재) = **공포·위협 통제 + 비극.**
이 구분으로, 전체 톤 폐기(코스믹 호러)와 교단 톤 존치(공포·위협)가 모순 없이 양립한다.
