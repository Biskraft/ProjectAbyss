# DEC-055: 벽/천장 이동 모드 = 선결조건부 플래그십

## 맥락
이동 모드 5종 중 벽/천장만 0커버. 횡스크롤 메트로베니아 특성상 천장낙하·벽도약은 수직성 압박으로 체감 임팩트가 큼. "단일 투자 대비 다양성 최대인가" 검토.

## 선택지
1. **즉시 플래그십 착수** — 임팩트 크나 선결비용 간과 위험.
2. **선결조건부 플래그십** — 임팩트 인정하되 비용·의존성 게이트.
3. 후순위 — 비행 하이브리드·fluid 봉쇄군이 시간당 효율 우위.

## 결정
**선결조건부 플래그십 채택.**
- 셀당 체감 다양성은 최고(유일 0커버 축 + 1모듈 3셀 + 수직성 기둥 보강). 단 엔지니어링 단가도 최고.
- 고유 선결비용: 신규 이동 코드(중력 반전·표면 부착) + 스폰 지오메트리(현 `computeSpawnPoints`는 바닥 전용) + 가독성(§1.3 화면 밖 금지).
- 게이트: ① 방 천장·벽 보장 검증 → ② shadow(oil) 권속과 묶어 1회성 이동 모듈 데뷔 → ③ 동일 모듈로 W-ch·W-dp 저비용 확장.
