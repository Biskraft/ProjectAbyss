# DEC-045 — 몬스터 로스터 수량 스펙 확정 (아키타입별 고유 디자인 수)

> **일자:** 2026-06-05
> **상태:** 확정
> **영향 문서:** `Documents/System/System_Enemy_MonsterArchetype.md` (SYS-ENM-ARC) §1.3.3 · 아키타입 요약표 · 신규 §2.12

## 결정

손저작 몬스터 디자인 총량을 **MVP 11종(아키타입당 1) → 본격 제작 40종**으로 확정. 아키타입별 고유 디자인 수를 출현 빈도 가중으로 차등 배정한다.

| 아키타입 | 디자인 | | 아키타입 | 디자인 |
|:---|:---:|:-:|:---|:---:|
| A-01 Charger | 5 | | A-06 Swarmer | 4 |
| A-02 Jumper | 4 | | A-07 Ambusher | 3 |
| A-03a Shooter | 4 | | A-08 Summoner | 2 |
| A-03b Bombardier | 3 | | A-10 Sentinel | 3 |
| A-04 Shielder | 3 | | **몹 base 소계** | **36** |
| A-05 Flier | 5 | | A-09 Elite(파생) | 7 |
| | | | 말소자 몹 계열 | 4 |

- 순수 고유 실루엣/스킨 = 40, 명명 로스터 ≈47.
- 곱셈: 36 base × 6 속성 × 8 MOD → 체감 변종 수백. 300무기 검증 표면을 300 스프라이트 없이 충족.

## 근거

- "고유 디자인"은 곱셈 레이어(속성·MOD·스케일) 제외 단위. 다양성 주력은 곱셈이 담당하고 손저작은 40종으로 묶는다.
- 백본(Charger/Flier 5)과 희소 전문형(Summoner 2)의 격차 = 출현 빈도 피로 곡선.
- 말소자 4종은 일반 몹 풀과 분리(드론과 동석 금지). 다수는 보스 F4(말소자 추격체)로 흡수.
- 세력 분배: 드론 ~22 / 잔존자 ~8 / 인덱서 ~6 / 말소자 ~4. 외형 정의 SSoT = `Design_Art_Direction.md` §14.3~14.4.
