# DEC-043: 프롤로그 = 플레이 가능 다이브 + 첫 말소자 보스

## 맥락
"시그니처 메카닉(아이템계 다이브)을 게임 시작 5분 내에 보여줘야 한다"는 디렉터 판단. 레퍼런스 조사 결과 Bloodstained(샤드 즉시 노출)·Super Metroid(풀파워 맛보기 후 박탈)·Hades/Returnal(첫 런은 결과 무관 종료)·Half-Life(플레이 가능 콜드 오픈 → 재앙)가 이 패턴을 검증. ECHORIS v3 시놉시스는 이미 Half-Life식 콜드 오픈(실험실 → Cascade → 백업)을 프롤로그로 채택하고 있었으나, 첫 30분 문서는 프롤로그를 "무전투 관찰 튜토리얼"로 박제해 둔 상태였다.

## 선택지
1. **중단된 다이브 (Super Metroid형)** — 다이브 시작 직후 실패로 찢김. 맛보기만. (초기 선택)
2. **플레이 가능 1층 다이브 + 보스 (채택)** — 에코 1지층(Normal=단일 지층) 라이트 전투 + 보스. 승/패 무관 아웃.
   - 보스 정체 분기: A) 첫 말소자(격파 불가, 불가지) / B) 정상 에코 수호자(처치 가능) + 외부 Cascade.

## 결정 (2026-06-02 최종)
- **플레이 가능 1층 다이브** 채택. 구성: 간단 전투 튜토리얼(약한 적 1-2체) → 말소자 첫 등장(흰색 언캐니 호러, 비교전 위협) → 말소자가 위상을 찢고 연구 시설 파괴 = Cascade → 아웃.
- **DEC-044 정정 반영:** 드론(slime/skeleton/ghost)은 말소자 아님(평범한 환경 생물), boss_01 도 말소자 아님. 프롤로그의 호러 행위자 = 진짜 말소자(희귀·특정 이벤트·흰색 언캐니). 따라서 초안의 "두 말소자 분리"는 **단일 말소자 호러 이벤트**로 단순화.
- "선택의 결과 부재"(가이드 §1.2 #3, Jonas Tyroller §7.3 Impact) 함정은 자연 해소: 플레이어는 말소자와 **교전하지 않는다**(비교전 호러 이벤트). 초반 약한 적 전투는 정상 결과를 갖고, 말소자 절멸은 그와 분리된 외부 불가지 사건(플레이어 패배 아님).
- 말소자 32px 표현 난제 → 단일 명도(near-white) + 비정상 비율 + 절제 모션, 실루엣 게이트(Art §11.2) 통과 설계 후속.
- 다이브 루프 완주(강화·귀환)는 본편 [7] 첫 진짜 다이브로 보류 → 신선함 보존.
- `ItemWorldScene` 기존 자산(다이브 전환·위상) 재사용.
