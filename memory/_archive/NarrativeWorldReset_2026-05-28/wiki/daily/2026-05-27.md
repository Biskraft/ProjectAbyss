## Session 13 - Walkable ItemStratum ghost extension

- The anvil deployment ghost room now acts as a temporary streamed extension of the Shaft level.
- `LdtkWorldScene` extends collision row widths and camera bounds while the ghost is active, stamps ItemStratum air/solid cells into the extension, and restores the old grid/camera state on cleanup.
- `ItemDeploymentController` can read a scene-provided entrance AABB, so the Item World trigger sits inside the ghost room instead of at the original Shaft edge.
- Room edge transitions are suppressed while item deployment is active so walking into the streamed ghost space does not accidentally load an adjacent LDtk room.
- Performance audit: worst LDtk anvil ghost extension adds about 2,688 collision cells; browser loop microbench for 2,048 cells stayed under 0.3ms max. `releaseWorldVisualsForItemWorld()` now restores ghost/tunnel collision without tilemap rerender because the return path rebuilds with `loadLevel()`.
- Verification: `npx tsc --noEmit` and `npm run build` from `game/` pass. Dev server `http://127.0.0.1:3000/play/` returns 200 and boots with one canvas; 3s boot frame sample averaged about 4.2ms with p95 about 4.6ms.
