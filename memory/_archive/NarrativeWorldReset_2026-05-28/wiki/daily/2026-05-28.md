# 2026-05-28 Work Log

## Session 1 - Corridor filter and laser zoom lock

- `ItemStratum_Corridor` now applies grayscale plus contrast 0.5 to both the corridor render container and the live Item World parallax background while the corridor entry state is active.
- Corridor exit/scene teardown restores the previous `game.backgroundContainer.filters` so the filter does not leak into normal Item World rendering.
- Camera zoom can now be locked by gameplay flows. The anvil deployment laser locks zoom to 1.0 as soon as the tunnel laser fires and unlocks on Item World handoff or controller destroy.
- Debug zoom keys still bypass the lock by updating the locked zoom value directly.
- Verification: `npx tsc --noEmit`, `npm run build`, and `/play/?debug` browser boot on port 3000 pass. Remaining warnings are existing LDtk/CSV tileset divergence warnings plus the existing Vite large chunk warning; browser-only 404 remained non-blocking.

## Session 2 - Acid fluid particle budget

- Reduced `SteamPuffManager` from 4 to 3 puffs per spawn and capped active steam puffs at 80.
- Reduced `WaterSplashManager` droplet bursts from 9 to 6, capped crowns at 24, and capped active drops at 96.
- Passive `TileMutator` steam VFX now has a per-frame budget of 8 generic steam events and 2 large steam-burst events; terrain mutation and acid damage callbacks are not suppressed by the VFX budget.
- Acid-water burst scenes now add one toxic puff instead of three extra puffs after the generic steam event.
- Verification: `npx tsc --noEmit` and `npm run build` pass. Existing warnings remain the LDtk/CSV tileset divergence warnings and the Vite large chunk warning.

## Session 3 - LDtk weather entity wiring

- `LdtkWorldScene` now creates a world-space weather layer and instantiates `WeatherSystem` when the loaded LDtk level contains a `Weather` entity.
- The first `Weather` entity controls `WeatherType` (`Rain`/`Snow`), `Density`, `Wind`, `StreakLength`, and `StreakWidth`; extra weather entities in the same level log a warning.
- Weather collision uses the runtime level-local collision grid and treats solid tiles plus one-way platforms as impact/roof blockers.
- Verification: `npx tsc --noEmit` and `npm run build` pass. Existing warnings remain the LDtk/CSV tileset divergence warnings and the Vite large chunk warning.

## Session 4 - Long rain streak collision

- Fixed rain collision to use the drawn streak tip instead of the particle head. Long `StreakLength` values now despawn when the visible lower endpoint touches solid/one-way tiles.
- Added a swept segment check between the previous and current streak tip so fast rain does not tunnel through thin platforms.
- Verification: `npx tsc --noEmit` and `npm run build` pass. Existing warnings remain the LDtk/CSV tileset divergence warnings and the Vite large chunk warning.

## Session 5 - Rain splash sprite budget

- Rain impacts now spawn one randomly selected splash sprite instead of drawing splash ticks as particle-like Graphics each frame.
- Splash sprites are capped at 48 active instances and pooled to avoid repeated DisplayObject allocation during dense rain.
- Verification: `npx tsc --noEmit` and `npm run build` pass. Port 3000 `/play/?debug` returns 200. Existing warnings remain the LDtk/CSV tileset divergence warnings and the Vite large chunk warning.

## Session 6 - Builder weather collision

- `WeatherSystem` now supports dynamic grid colliders in addition to the static level collision grid.
- `LdtkWorldScene` passes the active `GiantBuilder` collision grid at its current `container.x/y` every weather tick, while static weather collision ignores builder-stamped host-grid cells.
- Rain splash sprites spawned from dynamic hits follow the collider-local impact point while fading, so moving Builder surfaces do not leave splashes behind.
- Verification: `npx tsc --noEmit` and `npm run build` pass. Port 3000 `/play/?debug` returns 200. Existing warnings remain the LDtk/CSV tileset divergence warnings and the Vite large chunk warning.
