## 3. 메트로베니아 설계 패턴 요약

### 3.1 능력 게이트 원칙
게이트는 3가지를 동시에 해야 가치 있다: (1) 특정 공간 차단, (2) 획득 후 기존 공간 재맥락화/지름길 생성, (3) 전역적으로 이동·사고 방식 변경. (1)만 하면 그것은 열쇠지 시스템이 아니다.

- 카피 위험: 안개/위상 변신(SotN Mist), 모프볼(Metroid), 전체 맵 반전(SotN 역성). ECHORIS는 안개 변신을 올바르게 폐기했다.
- 안전: 대시(필수급), 벽 타기, 이단 점프(클리셰지만 기대됨).
- 6번째 렐릭이 필요하면 위상/축소보다 그래플·스피드부스트 우선.

### 3.2 맵 토폴로지
4 아키타입: 상호연결 웹(SotN/HK) / 허브-스포크(지양) / 선형+분기(Dread) / 수직 척추(ECHORIS).
- 수직 척추: "깊을수록 강함" 직관, 티어 정체성 명확, ATK/INT 게이트 심화에 자연.
- 약점: 티어 간 수평 연결이 어색, 수직 빠른 이동 인프라 필요.
- 해법(Blasphemous 계층): 각 하강 티어 = District, 내부에 수평 Zone 다수. 티어 간 지름길은 전용 수직 인프라(엘리베이터/붕괴 샤프트).
- 티어는 선형 순서지만 내부는 웹 로직으로 비선형 확보.

### 3.3 백트래킹 & 빠른 이동
- 보스 사망 = 항상 지름길 개방(Blasphemous 원칙).
- 빠른 이동 노드: 티어/주요 구역당 1개, 클리어 후, 티어 출구/세이브 지점에 배치. 너무 촘촘하면 지리 무의미.
- 죽은 백트래킹 방지: 복귀 시 새 통로/적 강화/환경 변화 중 최소 1개.
- 시퀀스 브레이크: 숙련자에게 신호하되 광고하지 않음(Dread ~20개 의도 배치).

### 3.4 비밀/보상 밀도
- 주요 구역당 비밀 2-4개: 1개는 미획득 렐릭 요구(이연 보상), 1개는 관찰(가짜 벽), 1개는 스킬 표현.
- 보상 위계: 영구 진행 > 수치 업글 > 장비/루트 > 로어 > 통화.

### 3.5 난이도/페이싱
- 톱니파: 렐릭 획득 → 스파이크 → 숙련 → 하강 → 다음 보스 스파이크.
- 적 도입: 단독 통제 조우 후 조합. cold-throw 금지.
- 보스 간격: 비숙련자 기준 45-60분 이내.
- 무언 튜토리얼: 요구 전 예고(랜드마크 먼저, 해금 나중).

### 3.6 이중 게이트 공존 (ATK/INT)
- 능력 게이트 = 지형 절대(렐릭 필수, 루트로 우회 불가).
- 스탯 게이트 = 레어리티 티어 연동, 색상 코드(레어리티 팔레트). "노란 게이트 = Rare 장비 필요".
- 아이템계 = 스탯 게이트 해금의 유일 경로 → 아이템계 루프가 월드 진행에 필요해짐.
- 한 통로에 ATK·INT 동시 요구 금지. 티어마다 축 교번.

### 3.7 흔한 실패 모드
1. 맵 혼란(랜드마크 부재) 2. 죽은 백트래킹 3. 능력 블로트(획득 후 미사용) 4. 게이트 중복(같은 문에 2종) 5. 약한 중반(신규 능력 부재) 6. 지름길 접근성 7. 게임 깨는 시퀀스 브레이크 8. 절차적 정체성 희석.
- ECHORIS 중반(T4)이 핵심 페이싱 체크포인트. T4 직전 반중력 부여로 재맥락화 이벤트.

## 7. 액션RPG 전투·루트·스킬 레퍼런스

### 7.1 무기 차별화 4축
Range / Speed / Area / Gimmick. 각 무기는 최소 2축에서 교차하지 않아야 함. 단순 수치 증가는 차별화 아님(Dead Cells 원칙). Hades Aspect(동일 무기 3 조작 언어), Hollow Knight Nail Arts(3 입력 패턴).

### 7.2 루트/레어리티 (Diablo)
Affix 슬롯: Normal 0 / Magic 2 / Rare 3 / Legendary 4+Aspect / Unique 고정. Prefix/Suffix 분리 풀 → 곱셈 조합. 최소 Affix 풀 ~35-42(공격 14/방어 10/조건 10/유틸 8). 절차 affix가 핸드오서링 아이템 수 절감.

### 7.3 적 아키타입 (8 핵심 AI)
Chaser/Charger/Ranged/Flyer/Shielded/Summoner/Turret/Ambusher. 속성 스태킹(속도 3 × 사이즈 2 × 원소 4 × 발사체 2 = 48 조합)으로 8 AI가 40-60 체감 다양성 커버.

### 7.4 보스 패턴
페이즈: P1 2-3패턴(학습) / P2 +2-3(에스컬레이션) / P3 풀 아스널. 보스당 고유 5-8 패턴, 2-3 페이즈(인디는 2 기본). 텔레그래프 선딜+시각단서 분리, 3시도 학습 원칙.

### 7.5 스킬 (4슬롯)
Hades 모델(Attack/Special/Cast/Dash 4슬롯). 슬롯 적을수록 선택 무거움. 16-20 스킬을 발동조건/무기연동/원소결합/트레이드오프/패시브 트리거로 차별화. 쿨다운 단일 기본.

### 7.6 원소/상태이상 (4원소 최소설계)
Fire→Burn(초당 ATK 15%) / Ice→Freeze(이동불가 1.5s) / Thunder→Shock(다음피해 +50%) / None.
반응 3종만: Melt(Fire→Freeze 적, ×1.5) / Overload(Thunder→Burn 적, 소폭발) / Shatter(물리→Freeze 적, ×2.0). 단방향 조건으로 단순. 저항/약점은 보스·엘리트만, 잡몹 중립.
