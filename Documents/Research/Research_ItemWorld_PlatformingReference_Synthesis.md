# RES-IWS-02 — 아이템계 플랫포밍 레퍼런스 종합 (Galaxy · Wonder · Odyssey)

> **목적:** 슈퍼 마리오 갤럭시(1·2)·원더·오디세이의 플랫포밍/변환/이동 메커닉을 전수조사하고, ECHORIS 아이템계가 "들어간다=던전"을 넘어 *"이 아이템 안엔 어떤 세계가?"* 의 판타지를 뾰족하게 살리도록 정합 종합한다.
> **상태:** 설계 리서치 (미결정 포크 다수 — §9). 캐논 확정 아님.
> **선행:** [RES-IWS-01](Research_ItemWorld_MonsterSpawn_Balancing.md) (2축 스폰 모델 — 강도축×정체성축, 계열→원질 매핑).
> **후속:** [RES-IWS-03](Research_ItemWorld_WonderAxisSystem.md) (경이 생성 축 시스템 — 부록 B 렉시콘을 곱셈 생성기로 조작화).
> **작성:** 2026-06-17.

---

## §0. 요약 — 세 게임은 우리와 같은 난제를 같은 방식으로 풀었다

ECHORIS의 난제: **모든 아이템 세계가 새로운 세계처럼 느껴지게 하되, 그것이 incoherent해지거나 별개 게임이 되지 않게 한다.**

세 게임의 공통 해법은 넷이다.

1. **깨끗한 계층 분리** — 섞이지 않는 시스템 층위.
2. **가독 가능한 원자 라이브러리** — 무한 변주를 *소수의 명료한 부품 재조합*으로 (Hades/Slay the Spire 모델).
3. **지각의 자동 재정렬** — 경이롭되 혼란스럽지 않게 (Galaxy 카메라).
4. **조밀한 보상 케이던스** — 호기심→보상 루프를 짧게 반복 (Odyssey 문).

각 게임이 ECHORIS의 한 계층을 가르친다.

| 게임 | 가르치는 것 | ECHORIS 계층 |
|:---|:---|:---|
| **Galaxy** | 구역마다 *법칙(중력)* 을 재정의해도 학습 가능·경이롭다 | **Layer 1 — MEDIUM** (아이템의 법칙) |
| **Wonder** | 단일 재사용 트리거가 규칙을 *되돌릴 수 있게* 뒤집는다 | **Layer 2 — WONDER** (다이브 중 변환) |
| **Odyssey** | *모든 적이 곧 동사* — 원질 토착 존재가 이동 문법을 쥔다 | **Layer 3 — VERB/WEAPON** (내 키트) |

**종합 척추:**

> **MEDIUM(아이템의 법칙) × VERB(내 영구 키트) + WONDER(다이브 중 변환).**
> 세 계층은 절대 섞이지 않는다.

## §1. 수렴 교훈 (왜 세 게임이 같은 답에 도달했나)

- **Galaxy:** "down을 재정의"하는 구역을 *카메라 자동 재정렬*로 멀미 없이 학습시킨다. 구역=법칙이 가독성을 잃지 않는 이유는 라이브러리(구체/원환/큐브/선/원뿔 중력)가 *명료*하기 때문이다.
- **Wonder:** 단일 트리거(원더 플라워)가 7축 중 하나의 변환을 뿌리고 *되돌아온다.* 모프(임시)·파워업(영구)·배지(선택) 3계층이 절대 안 섞여 2000개 순간이 가독성을 유지한다.
- **Odyssey:** 각 킹덤이 *단일 원질 정체성 + 시그니처 이동*을 갖고, 적 로스터 전체가 캡처로 *동사 라이브러리*가 된다. 같은 적이 장애물이자 도구다. 문(moon)이 조밀해 보상 케이던스가 끊기지 않는다.

세 게임 모두 **"분리된 계층 + 명료한 원자 + 재정렬 + 케이던스"** 로 *무한히 다른 구역이 가독성을 잃지 않게* 만든다. 이것이 ECHORIS가 그대로 이식할 아키텍처다.

## §2. 원자 라이브러리 (전수조사 증류 — 설계 관련만)

### §2.1 Galaxy — 중력=법칙

- **중력 유형:** 구체(orbit/cling) · 평면(walk) · 큐브(edge-flip) · 선/철사(wrap) · 원뿔(scale) · 원환/디스크(loop/underside) · 실린더(spiral) · 중공 내부(inside-cling) · 무한 튜브(endless-run) · 절대 하강(fall-fail) · **중력 플립 존**(flip) · 중력 스포트라이트/빔(beam-ride) · 물 구체(swim-orbit) · 모래/용암 구체(sink/scorch).
- **지오메트리:** 마이크로 구체 · 원환 · 큐브 · 실린더 · 디스크 · 중공 내부 · 무한 튜브 · 물/모래/용암 구체 · 미끄럼 빙면.
- **파워업=원질 도구:** Ice(물→발판) · Cloud(발판 생성) · **Bulb Yoshi(빛으로 숨은 길 드러냄)** · Rock(roll-smash) · Spin Drill(관통) · Spring(auto-bounce).
- **이동 기믹:** 런치/슬링 스타(launch) · 풀 스타(zero-G reel) · 볼 롤링 · 플립스왑 패널 · 중력 플립 플랫폼.
- **재실행 변형(Prankster Comet):** 스피드런 · 1HP · **자기 클론과 경주(outrun-ghost)** · 고속 적 · 퍼플코인 수집.
- **카메라:** *자동 재정렬 up* (멀미 없는 경이) · 마이크로 행성 지평선 컬(숨은 길 암시) · 우주로 풀백(스케일 경외) · 플립 시 월드 회전.

### §2.2 Wonder — 단일 트리거 7축

변환 7축: **시점**(탑다운/실루엣/스케일) · **지오메트리**(범람·배수/틸트/살아있는 파이프/표면 변질) · **적**(무리/적-발판/투사체비) · **플레이어 모프**(임시: 굼바=스텔스, 스파이크볼=롤, 풍선=부상, 용암유영=무적) · **리듬**(노래하는 식물/비트 발판) · **흐름**(부유/자유낙하/시간 진동/원질 스왑) · **초현실**(장르 스왑).

3계층 규율: **이펙트(임시)** ≠ **파워업(영구·아이템)** ≠ **배지(영구·선택, 한 번에 1개)**. 절대 안 섞임.
배지 동사: 글라이드 · 벽타기 · 돌고래킥 · 호버점프 · 그래플바인 · 차지점프 · 스핀부스트.

### §2.3 Odyssey — 모든 적이 곧 동사

- **킹덤=단일 원질 정체성:** Luncheon(용암 바다 — 용암유영 필수) · Lake/Seaside(수중/물제트 호버) · Snow(눈보라+빙결수+미끄럼) · Bowser's(스파크 파일런 와이어 질주+포키오 벽찍기) · Sand(역중력 방) · Lost(독성 바다+스트레치/글라이드) · Moon(저중력).
- **캡처 동사(증류):**
  - *이동:* 치프치프(swim) · 용암버블(swim-lava) · Gushen(물제트 호버) · 스파크 파일런(와이어 질주) · Glydon(glide) · 불릿빌(fly-dash) · 트로피컬위글러/Uproot(stretch) · 포키오(벽찍기 fling) · 프록(고점프).
  - *물질:* 파이어브로(throw fire) · Ty-foo(blow wind) · 굼바(stack+ice-walk).
  - *스케일:* 체인촘프(launch-smash) · T-Rex(rampage) · Sherm(artillery).
  - *유틸:* **Moe-Eye(선글라스로 숨은 발판 드러냄)** · Zipper(레벨 표면을 열다) · 쌍안경(scan) · Lakitu(fish).
- **메타 원리:** ① 모든 적=잠재 동사/탈것(장애물이자 도구) ② 캡처=구역 키 이동 게이팅(영구 인벤토리 아님 — 디자이너가 구역별 동사셋 통제, *소프트 메트로베니아*) ③ 문=조밀 케이던스 통화(미니 발견 10초, 수량이 진행 게이팅) ④ 2D 평면화 구간(시점 전환·향수).

## §3. ECHORIS 3계층 아키텍처 (종합 척추)

### Layer 1 — MEDIUM: 아이템의 법칙

**원천:** Galaxy 중력 + Odyssey 킹덤 원질 + RES-IWS-01 계열→원질.

핵심: **아이템 세계는 단일 원질 + 중력 서명을 가진 작은 세계다.** 그 안으로 *떨어진다(plunge)* — 던전 문을 걷지 않는다. Galaxy 마이크로 행성이 "이 아이템 안엔 어떤 세계가?"의 문자 그대로의 답이고, Odyssey가 "킹덤=단일 원질+시그니처 이동"으로 이 구조의 승리를 입증한다.

| 원질(계열) | 중력 법칙 | 이동 동사 | 풍덩의 정체 | 외부 검증 |
|:---|:---|:---|:---|:---|
| 마그마(forge) | 바닥=죽음, 하향 | 공중·냉각지각 체류 | 용암 구체로 추락 | Galaxy 용암 구체 + Odyssey Luncheon |
| 물(iron) | 구체 부력 | 유영·물제트·궤도 | 대양 오브에 빠짐 | Galaxy 물 구체 + Odyssey Lake/Seaside |
| 기름(shadow) | 점성·둔화 | 느린 표류 + 인화 | 점성 바다로 가라앉음 | Wonder 오일/발화 |
| 빙결(cyro) | 저마찰 | 스케이트·관성 | 미끄러지는 빙면 | Galaxy 빙면 + Odyssey Snow(눈보라=시야차단=memory-dark) |
| 방전(spark) | 자기 레일 | 와이어 질주·극성 | 전류 격자 사이 | Odyssey Spark Pylon + Galaxy 전기 레일 |
| +무중력 공동 | zero-G | reel·부유 | 정적 속 부유 | Galaxy 풀스타 + Odyssey Moon |
| +붕괴 폐허 | 무한 전진/실시간 붕괴 | endless-run | 무너지는 통로 | Galaxy 무한튜브 + Wonder 틸트/낙하 |

**채택:** 마이크로 행성 지오메트리(아이템=작은 세계) · 중력=원질 법칙 · 런치/풀스타식 챔버 간 이동 · 카메라 자동 재정렬(§6).

### Layer 2 — WONDER: 다이브 중 변환

**원천:** Wonder 단일 트리거 7축 + Odyssey 역중력 방 + 기존 FluidSystem 반응.

핵심: **단일 재사용 트리거(기억 서지 memory surge)** — 코어 접근·특정 셀 파괴 시 세계가 한 축으로 변환되고 *되돌아온다.* **항상 기회, 절대 락**([RES-IWS-01](Research_ItemWorld_MonsterSpawn_Balancing.md) 의 물질=옵션 규칙 계승). 작은 라이브러리에서 추출:

- **배수·범람**(지오메트리) — 물이 빠지며 아래 구조가 드러남 = **memoryRecovery=빛** 직결, 잊힌 세계가 스스로를 기억해냄.
- **원질 변환**(흐름) — 기름 바다 *발화* → 불 이동. FluidSystem 반응 직결.
- **중력 플립 포켓**(Sand 역중력 방) — 2D 번역: 화면 회전/천장-바닥 반전 구간.
- **실루엣/소등**(시점) — 침묵의 어둠 구간 = 고독 톤 + memory-dark.
- **무리·적-발판**(적) — 원질 토착 적이 잠시 유일 발판 → 액션 바닥 유지.
- **임시 모프**(플레이어) — *드물게·절정에만.* 마그마 세계에서 잠깐 용암유영체. Layer 2 임시 — 무기(Layer 3)와 안 섞임.

장르 스왑(범람→수영 탈출)은 *절정 한 번*만. 남발 금지.

### Layer 3 — VERB/WEAPON: 내 키트

**원천:** Wonder 배지(한 번에 1개) + Galaxy 파워업 + **Odyssey 캡처(핵심 추가)**.

- **무기 물질 동사 × 원질 = 조합 경이**(북극성): forge×기름=전체 발화, cyro×마그마=길 굳히기. 같은 원질이 무기마다 다른 문장.
- **이동 렐릭 1종 활성**(Wonder 배지 규율) — 글라이드·벽타기·그래플 등. 로드아웃 선택 = 다이브마다 의미. 파워크리프 차단. 빌더 정체성 정합.
- **memoryRecovery=빛 도구** — Galaxy Bulb Yoshi + Odyssey Moe-Eye(숨은 발판 드러냄). 잊힌(어두운) 세계를 *밝혀* 길을 드러내는 것이 곧 복원.

### §3.1 캡처 질문 (Odyssey의 큰 기여 — 결정 필요)

Odyssey의 "모든 적이 곧 동사"는 원질 토착 몬스터가 *장애물이자 이동 도구*가 되게 한다. ECHORIS 정합 옵션:

- **(A) 점령(commandeer) — 약한 캡처:** 원질 토착 생물을 *타거나 조작*해 그 이동 동사를 잠시 얻는다(빙의 아님). 용암 세계에서 용암유영 생물을 점령해 용암을 건넌다. 전투 통합(제압 후 점령) + 원질 토착 몬스터 작업에 목적 부여.
- **(B) 미채택:** 무기 정체성을 흐릴 위험. 원질 이동은 무기/렐릭(Layer 3)으로만.

**긴장:** 전면 캡처는 *무기 기반 액션 RPG*를 *빙의 게임*으로 바꿔 정체성을 침식한다. 권장: **(A) 제한적 점령** — 이동 동사에 한정, 전투 동사는 무기가 유지. 단 스파이크 검증 필수.

## §4. 재다이브 엔진 (Galaxy 코멧 + Odyssey 문/Darker Side)

- **재진입 변형(Prankster Comet):** 스피드런 · 1HP · 고속 적 · **자기 과거 다이브의 메아리와 경주(outrun-ghost)**. 마지막 것은 고독·기억 톤에서 시적 — 더 또렷해진 세계에서 *과거의 나*를 마주친다. 캐논 재진입 루프에 감정+변주.
- **심층 마스터코스(Darker Side):** 모든 원질 동사를 한 다이브에 연쇄하는 고난도 종착 → Ancient+심연 티어와 정합.
- **발견 케이던스(Odyssey 문):** 기억 파편을 *조밀한 10초 발견*으로 — 호기심→보상 루프 유지. **단, [[feedback_premium_not_liveservice]] 가드:** 수량 그라인드가 아니라 *발견 페이싱*으로 프레이밍. 진행 게이팅용 양치기 금지.

## §5. 카메라/지각 법칙 (Galaxy) + 2D 번역 문제

- **자동 재정렬 up = 멀미 없는 경이.** 협상 불가. 중력이 바뀌어도 화면 up이 따라간다.
- **2D 번역 제약(PixiJS 2D, 횡스크롤):** Galaxy 3D 구체 중력은 직역 불가. 번역 후보 — ① 화면 회전(중력 플립) ② 원질 부력(수직 자유) ③ 천장-바닥 반전 구간 ④ Odyssey식 2D 평면화의 역(잠깐 탑다운/심도). §9 결정 대상.

## §6. 거부 목록 (디자이너 규율 — 대부분 버린다)

| 거부 | 이유 |
|:---|:---|

## 부록 B — 경이 렉시콘 (Wonder Lexicon — 20 패밀리)

> 레퍼런스 채굴 2라운드 종합(2026-06-17). 공간(1~12) + 감각·시간·생명(13~20). 각 패밀리: 기법 / 대표 / ECHORIS 매핑(L1 풍덩·L2 원더·톤) / 2D 실현성. **톤 필터: 숭고·고독·위로 — 점프스케어 호러 제외.**

### B.1 공간 경이 (Spatial — 1라운드)

1. **무한 수평선/흰 보이드** — 참조점 제거 + 고독한 단일 형상; 메가스트럭처의 *완전한 반대*. Journey·Friedrich·Rothko·2001. → L1 *희소 경이*(Surveyor/안식). 2D-OK.
2. **풍덩의 문턱/은폐후개방** — 좁은 통로→바닥 제거→보이드 + 사운드 머플. Journey 사구·Subnautica·INSIDE·Galaxy 물구체. → L1 매 진입. **2D-OK 최우선**.
3. **심해 하강/원질 침잠** — 하강 그라디언트 + 상하 상실 + 부유 입자. Subnautica·SOMA·ABZÛ·Outer Wilds. → L1 원질 척추. 2D.
4. **위험 원질/죽이는 아름다움** — 바닥=위험 + 이중상태(치명↔이동, 게이트). Hades 용암·Izalith·HK 산성·Luncheon. → L1 + 게이트×무기. *즉시 채택*.
5. **생물발광 어둠/빛=기억** — 단일 광원 + 발광미 + 어둠=비용 정보. Below·HK 루마플라이·ABZÛ·Avatar·Noita. → memoryRecovery=빛. 톤 핵심.
6. **시한부 드러남/보이지 않는 구조** — 빛/렌즈에 떠오르고 재소멸, 외워서 건넘. Bulb Yoshi·Moe-Eye·Teslagrad·Witness. → L2; *기억하기=동사*. 2D-OK.
7. **압도적 거대함/메가스트럭처 숭고** — 누구를 위함도 아닌 건축 + 미소한 플레이어. NaissanceE·BR2049·SotC. → 기존 미감. 2D 패럴랙스.
8. **스케일 상실/미소함(안이 밖보다 큼)** — 연속 줌 + 비유클리드 중첩 + 친숙 재맥락. Dark Bramble·Everything·Mountain·Interstellar 파도. → *아이템계 판타지 직답*. 2D-FAKE.
9. **불가능 기하/비유클리드** — 국소 정합/전역 불가 + 오프카메라 스왑 + 원근 정렬. Antichamber·Monument Valley·Escher·Fez. → 특정 인물 법칙. 2D-OK/FAKE.
10. **중력 재정향/down은 선택** — 어느 표면이든/이진 플립. Manifold Garden·VVVVVV·Galaxy. → 갤럭시 법칙 2D 번역. VVVVVV식 2D-OK.
11. **만화경·굴절 변이/살아있는 원질** — 대칭 접힘 + 굴절 변이 + 글리치 + 원질=행위자. Dr.Strange·Annihilation·HLD·Abyss 물촉수. → L2 셰이더. 2D-OK.
12. **리듬 공간/비트 재조립** — 건축이 비트에 재조립. Control 애쉬트레이·Wonder 비트. → L2 절차 지층 결합. 보류 후보.

### B.2 감각·시간·생명 경이 (Sensory/Temporal/Life — 2라운드)

13. **침묵·드론·오디오 문턱** — 머플 on 진입 + 리버브 확장 + 웜홀 스윕 + 침묵 후 단일 큐. SotC·Subnautica·INSIDE·Dunkirk 쉐퍼드톤. → L1 진입의 가장 싼 강한 단서. 오디오.
14. **흩어진 기억의 수렴** — 분산 스템이 한 곡으로 락인 + 변형된 라이트모티프 회귀. Outer Wilds 밴드·NieR·Undertale. → **memoryRecovery 사운드 메커닉**.
15. **색의 복원 = 기억의 귀환** — 흑백 베이스라인→획득 색, 계열별 영속(맵=일기), 흉터 남음. Gris·Okami·Flower. → **memoryRecovery 시각 백본** + areaPalettes. 2D-OK.
16. **대기·날씨·입자 경이** — 갓레이·오로라·안개=리빌·입자 날씨·매직아워. Ori·Sky·Tsushima·Firewatch·Turner. → 살아있는 공허. 2D-네이티브.
17. **풍덩 합성 스택** — 정지→능선 풀백→매치모프(무기→세계)→방사 블러+런치→화이트아웃→지층 타이틀. Journey·2001 매치컷·Galaxy·Celeste. → L1 진입 연출 레시피. 2D-OK.
18. **원더 합성 스택 + 시간 변조** — 화면 리플 트리거→팔레트 범람→중력 플립 리프레임(추락=상승)→슬로우+레터박스→스코어 스웰. Wonder·Gris·Spider-Verse·Hades·NieR 평면전환. → L2 변환 연출. 2D-OK.
19. **세계가 깨어난다/개화** — 발자국 빛(어둠 속) + 부트업 캐스케이드 + 개화; *개화-와-쇠락 동반*(Mononoke)=사적·전이적. Avatar·Okami·Gris·ABZÛ·Mononoke. → memoryRecovery=세계가 삶을 기억; 복원=진행(Okami 칭찬·Gris 색 게이트). 2D-OK.
20. **모든 셀이 반응한다** — 폴링샌드 CA(웹 네이티브) / 단일 공유 영향장(저비용 중도). Noita·Sandspiel·Tsushima 바람장·Terraria. → **셀 상호작용 북극성** + FluidSystem. 2D-OK(청크 더티렉트).

### B.3 교차 레버 키트 (재사용 기법)

- 진입 사운드 머플→드론/침묵 (가장 싼 강한 침잠 단서)
- 참조점 제거(안개·균일광·보이드) → 스케일 불가독
- 고독한 단일 형상 대비(Rückenfigur) + 낮은 수평선 = 고독-숭고 *구도 규칙*
- 빛=자원 (어두울수록 한 점이 신성)
- 드로우디스턴스=리빌 장치 (원질 불투명도로 은닉→폭로)
- 이중상태 원질(치명↔이동, 게이트) = 공포와 숙달 동시
- 색 복원 계열별 영속 = 존재의 일기
- 안개·개화는 *드러냄/전이적*, 절대 은폐/영구 승리 아님 (Silent Hill·디즈니 반전)

### B.4 두 기둥 기술 정착

- **memoryRecovery = 세계가 스스로를 기억함** — 단일 "기억" 비트가 4감각 동시 발화: 색 귀환(Gris) + 라이트모티프 회귀(NieR/Outer Wilds) + 부트업 개화(Avatar/캐스케이드) + 빛이 잊힌 기하 드러냄(Bulb Yoshi). 복원=진행 보상(Okami/Gris).
- **모든 셀이 반응 = 셀 상호작용 북극성** — 폴링샌드 CA가 웹 네이티브(Sandspiel 증명, 청크 더티렉트 성능 패턴). 저비용 중도 = Tsushima 단일 공유 영향장(grass+입자 한 그리드). FluidSystem 승격 경로.

### B.5 연출 레시피 (PixiJS 2D)

- **풍덩(진입):** I2 정지 → A1 능선 풀백 → D1 매치모프(무기→세계) → G4 방사 블러 + E2 런치 → G3 화이트아웃 → K1 지층 타이틀.
- **원더(변환):** E1 화면 리플 → D3 수채 팔레트 범람 → J2 중력 플립 리프레임(추락=상승) → C2 슬로우 + F1 레터박스 → H2 스코어 스웰.

### B.6 톤 재정의 (Mononoke 교훈)

개화는 *승리의 디즈니 개화*가 아니라 **개화-와-쇠락이 함께**(전이적·사라지는). 발밑에 꽃이 피고 곧 시드는 것이 고독+위로 톤([[project_tone_solitude]])을 승리주의보다 정확히 맞춘다. 복원은 따뜻하되 흉터를 남기고(Gris), 빛은 머물지 않는다(Bulb Yoshi).
