## 1. 개요

**A-08 Summoner = 전장 증폭 위협 축.** 직접 교전을 피하고 후방에서 아군 강화 또는 Swarmer 소환으로 위협을 증폭. **우선 제거 대상**. Kill Bonus·코옵 역할 분담(D/B/G)의 검증 표면.

- Type 키 = `Conduit` (확정 — CSV·LDtk enum 등재 완료).
- **의존성:** Swarmer 소환 옵션은 A-06(Cinder Imp) 선구현 권장.

- **실루엣:** 후드/지팡이형 또는 부유 구체. 16×20px.

---

## 4. AI 거동 스펙

| 상태 | 동작 |
|:---|:---|
| Hold | 후방 유지(Cautious), 플레이어 접근 시 후퇴 |
| Cast | 주기적 (a) 인근 아군 강화(속도↑/ATK↑/방어막) 또는 (b) Swarmer 1-2체 소환 (Tell: 시전 발광 6f) |
| Retreat | 근접 진입 시 후퇴(무방비) |
| OnDeath | 제거 시 강화·소환 효과 **즉시 소멸** |

신규 = **아군 버프 시스템**(인근 적 강화) + **런타임 소환**(Swarmer 인스턴스 생성) + 시전자 사망 시 효과 회수.

---

## 5. 핵심 난제 · 공정성

- **우선 제거 가치 = 명확한 신호** — 시전 빔/연결선으로 "이놈을 먼저 잡아야 한다"가 읽혀야 함.
- **소환 상한** — 무한 소환 금지. 동시 소환물 수 상한 + 쿨다운으로 눈덩이 방지.
- **단독 출현 금지** — Summoner는 조합 전제. 단독이면 위협 0이라 배치 규칙에서 제외.
- **사망 시 효과 회수** — 강화·소환물 정리로 처치 보상이 즉각 체감.

## 7. 인수 기준

1. 직접 공격하지 않고 후방에서 강화/소환만 한다.
2. 시전 시 강화 대상·소환 게이트가 시각적으로 읽힌다(우선 처치 신호).
3. 동시 소환물 수가 상한을 넘지 않는다.
4. 제거 시 강화·소환 효과가 즉시 소멸한다.
5. 단독 출현하지 않고 다른 아키타입과 조합된다.
