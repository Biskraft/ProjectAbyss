## 0. 이 문서의 목적

ECHORIS의 전체 콘텐츠 볼륨과 기능 범위를 한 장에서 정의한다. "맵 몇 개, 무기 몇 종, 적 몇 종, 어떤 기능이 필요한가"의 단일 답을 제공한다. 라이브서비스 운영 지표가 아니라, 완성형 프리미엄 액션 RPG로서 만들어야 할 제작 대상의 목록과 수량이 본 문서의 내용이다.

수치는 1차 초안이며, 제작 진행에 따라 갱신한다. 내러티브 명칭(캐릭터·지명·아이템 서사)은 2026-05-28 리셋 라운드 미종결로 본 문서에서 구조적 자리표시자(T1-T7 등)로만 다루고, 캐논 확정 후 배선한다.

## 1. 스케일 기준 — 레퍼런스 벤치마크

ECHORIS는 1인 웹 개발 컨텍스트의 프리미엄 인디 규모를 지향한다. AAA급 SotN의 볼륨을 그대로 따르지 않고, Dead Cells급 인디 볼륨 + 아이템계의 무한 깊이로 콘텐츠 수명을 확보한다.

| 레퍼런스 | 지역/맵 | 적 종류 | 보스 | 무기/장비 | 핵심 차용점 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Castlevania: SotN | 약 14 | 약 140 | 약 30 | 약 170 | 비선형 탐험, 능력 게이트, 숨겨진 보스 |
| Dead Cells (1.0) | 약 13 | 약 40 | 약 6 | 약 90 | 인디 볼륨 현실선, 무기 차별화 축 |
| Disgaea Item World | 무한 절차 | 공유 풀 | 아이템 군주 | 무한 강화 | 아이템계 무한 깊이, 이노센트 |

> **결론:** 핸드크래프트 볼륨은 Dead Cells 현실선(맵 7-9, 적 약 40, 보스 약 18)으로 잡고, 반복 수명은 아이템계 절차 생성 + 무한 강화로 확보한다. 콘텐츠를 무한히 그리지 않고 깊이로 푼다.

## 3. 월드 / 맵 스펙

### 3.1 매크로 구조 (D-20 정합 — 상승 주축)

> **SSoT:** 월드 구조는 `Design/Design_World_Master.md` (D-20)가 권위. 본 절은 그 요약이며 충돌 시 D-20 우선.

상승 주축 + 급강하/급상승 3박자. 가장 깊은 바닥에서 깨어나 정상까지 기어오르며, 중반 1회 급강하(All Is Lost) 후 누적 능력으로 급상승한다. 7구역 직관 명칭(각 구역 = 묻힌 옛 세계 화석 + 빌더 시공물). 허브 폐기 → 잔존자 마을 거점. 구역마다 2-3 서브 바이옴(단조로움 방지).

> **두 축 구분:** 월드 탐험 = 상승. 아이템계 다이브 = 하강. 직교. 시놉시스 "내려갈수록 깊은 기억"은 다이브 축이다.

| 순서 | 구역 | 정서 | 게이트 (D-20 §4.2 D-GATE 확정) |
| :---: | :--- | :--- | :--- |
| 1 | 침수 바닥층 (게임 시작, 백업 깨어남) | 고립·혼란 | 점착 클램프 (빌더 5분 후크) |
| 2 | 무너진 거주 구역 (잔존자 마을 거점) | 정·향수 | 빌더 제어 노드 |
| 3 | 거대 공장층 (빌더 작업장) | 경외·긴장 | 극성 부츠 + ATK 게이트 |
| 4 | 무너진 환승역 (상승 정점) | 광활·불안 | 반중력 capstone + surge |
| — | ⤓ 급강하 (환승역 붕괴 → 추락) | 상실 (All Is Lost) | diveAttack |
| 5 | 봉인된 하부 (미답 심부, 말소자) | 무력·공포 | INT 봉인 게이트 (자유시간 개방) |
| 6 | 대 안치소 (등재 성소, sci-fi 대성당) | 신비·섬뜩 | (재상승 경로) |
| 7 | 정상 — 관제정 (빈 옥좌) | 불가지·종착 | 최종 게이트 |

> 수중 호흡은 침수 서브 구역(침수 바닥/환승역 침수 승강장 등) 렐릭. 데모는 침수 바닥층 → 거주 구역 → 공장층(3구역).

> **D-GATE 확정(2026-06-01):** 11렐릭(코어 6 + 빌더 4 + 반중력)을 전반 Z1~급강하(~57%)에 전부 배치. 빌더 동사를 미니 5분(Z1 점착 클램프)부터 매 구역 하나씩 지급(스파이크 선행). 반중력은 Z4 인버전 capstone, 후반 Z5-7은 신규 능력 없이 자유시간 백트래킹(SotN 개방형). 상세·근거 SSoT = D-20 §4.2.

### 3.2 맵 제작 방식

- 매크로(층위 배치, 격벽, 보스방, 랜드마크): 핸드크래프트 고정. LDtk.
- 마이크로(Room 내부 지형): Chunk 절차 조립. ChunkAssembler.
- 1 Room = 60x34 타일 기준. 평균 2-3분 탐험.
- 전체 1회 클리어 목표: 3-4시간 (Critical Path), 완전 정복 30-40시간 (아이템계 포함).

### 3.3 데모 범위 (Build 3)

침수 바닥층 → 무너진 거주 구역(마을 거점) → 거대 공장층 (3구역). 능력 게이트 점착 클램프·제어 노드·극성 부츠 + 대시·이단점프·벽 타기, ATK 스탯 게이트 체험. 나머지 4구역(환승역/봉인된 하부/안치소/관제정)은 1.0.

### 4.1 무기 모델 수량

- 각 타입 x 5-6 레어리티 = 기본 스파인 약 35-42 모델 (1.0).
- 무한 변이는 아이템계 강화 + 기억 단편 부착으로 확보. 별도 수백 종 그릴 필요 없음.
- 현재 CSV: 7 타입 x 5-6 레어리티 행 존재 (기본 스파인 정의 완료, 수치 일부 공란).

### 4.2 제작 방식

- 타입별 공격 모션(1-3타 콤보 + 공중/하방)을 핸드크래프트 1세트씩. 레어리티는 동일 모션 + 색/이펙트 차등.
- Temperament 컬럼(rust/forge/spark/iron/shadow)이 무기 시각·아이템계 웨더 테마를 결정. WeatherSystem 연동.

### 4.3 데모 범위

Blade 전 레어리티 + Cleaver/Shiv/Railbow 중 2-3 타입. 원거리 1종 필수(Railbow 또는 Emitter).

### 6.2 아키타입 (제작 단위) — 11종 (SSoT 확정), 8 핵심 AI 구현

아키타입 분류 SSoT = `Documents/System/System_Enemy_MonsterArchetype.md` (2026-06-03 정합으로 11종 확정. A-07 앰부시형(적 은신)은 유지, 플레이어 스텔스(FoV/LoS)·Tier 진화만 폐기). 본 스펙은 8 핵심 AI를 구현 대상으로 잡고, 속성 스태킹(속도 3 x 사이즈 2 x 원소 4 x 발사체 2)으로 40-60 체감 다양성을 확보한다.

| ID | 아키타입 | 행동 | 구현 |
| :--- | :--- | :--- | :--- |
| A-01 | Charger (근접 추격) | 감지 → 접근 → 공격 | Skeleton 구현됨 |
| A-03a | Shooter (원거리 견제) | 거리 유지 → 사격 → 회피 | Ghost 구현됨 |
| A-02 | Jumper (돌진/도약) | 차징 → 도약 궤적 | 신규 |
| A-05 | Flier (비행) | 사인파 → 급강하 | 신규 |
| A-04 | Shielder (방패) | 정면 방어 → 후방 약점 | 신규 (스탯 게이트 교육) |
| A-06 | Swarmer/Splitter (군집/분열) | 처치 시 분열 / 떼 밀집 | 신규 (아이템계 밀집) |
| A-07 | Ambusher (앰부시/은신) | HIDDEN 은신·위장 → 기습 반경 진입 시 출현 1타 | 신규 |
| A-10 | Sentinel (고정 포탑) | 이동 없음, 고정 발사 | 신규 (환경 적) |

> A-07 앰부시형(적 은신)은 유지 — 화면 안 단서 노출 + 출현 Tell 필수, 화면 밖 기습 금지(`System_Enemy_AI.md` §2.2-C). 잔여 A-03b Bombardier / A-08 Summoner / A-09 Elite는 1.0 확장. Phase 1 최소 로스터는 7-9종(Research 권장).

### 6.3 제작 방식

EnemyFactory + StateMachine 재사용. 아키타입 1개 = AI 1세트. 층위 변형은 데이터(enemyStats) + 스프라이트 + 원소 파라미터 주입. 신규 AI 약 6종만 추가하면 8 핵심 AI 완성. 아이템계 적(10-15종)과 월드 적(25-30종)을 같은 AI 풀에서 파라미터로 분기.
