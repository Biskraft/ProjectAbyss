## ⚠️ 캐논 카운트 — "왜 N종인가" (먼저 읽을 것)

렐릭 수가 문서마다 다르게 보이는 이유는 **세 레이어가 시점이 달라서**다. 이 표가 단일 진실이다.

| 레이어 | 수 | 구성 | 상태 |
| :--- | :---: | :--- | :--- |
| **A. 코드 실측 (LOCKED)** | **6** | dash · doubleJump · wallJump · waterBreathing · surge · diveAttack | 구현 완료 |
| **B. 출시 캐논 (target)** | **11** | 코어 6 (A) + 빌더 전용 4 + 반중력 1 | 6 LOCKED + 5 제안(스파이크) |
| **C. 구 GDD 캐논 (STALE)** | 5 | dash · 벽 타기 · 이단 점프 · 수중 호흡 · **역중력** | **폐기 예정 표기** — §8 동기화 |

**핵심:** "5종"은 **구 캐논**(Design_World_Master §4.2 / Glossary / CLAUDE.md)이며 현재와 다르다. 실제 차이:
- 구 캐논의 **역중력** 은 코드에 없다 → **surge**(역류 상승)가 그 상승-게이트 역할을 대체했고, 중력 조작 톤은 **반중력**(사물/유체) + **극성 부츠**(천장 보행)로 재정의됨. 플레이어 중력 반전(R-V04)은 보류.
- 구 캐논에 없던 **surge · diveAttack** 이 추가 구현됨(코드 6종).
- 빌더 전용 4종이 출시 캐논으로 신규 확정됨.

→ "나머지"는 §3(확정 추가 5) + §4(후보) + §5(폐기)에 전부 있다.

## 0. 세계관 정합 필터

렐릭 채택 기준은 출처(어느 게임 카피냐)가 아니라 **ECHORIS 세계관 정합성**이다.

| 앵커 | 정의 |
| :--- | :--- |
| Builder | 메가 스트럭처를 끝없이 짓는 거대 산업 시공자. 의지·계획 없음. 파괴 불가. BLAME!/Biomega 계보 |
| Forge | 빌더 내부 거대 단조 장치. 에코 격발 = 아이템계 진입 in-universe 메커니즘 |
| Echo | 잊힌 자가 무기에 남긴 마지막 한 마디 응결체 = 모든 장비. 작품명 어원 |
| Grid/Blueprint | 시공 격자. 에코의 응답이 그리드를 한 박자 멈춤 |

**정합성 테스트:** "이 능력이 sci-fi 메가스트럭처(빌더/포지/에코)에 어떻게 정합하는가?" 판타지·마법·뱀파이어·정령·저주 톤만 배제. **중력·자기·신호·구조 조작 등 산업/물리 메타포는 채택 가능.**

> 안개 변신 폐기 사유 = 안개=판타지=드라큘라 톤이 sci-fi와 충돌(출처가 SotN이어서가 아님). 중력 조작 톤은 정합 → 반중력/극성부츠로 채택.

## 2. 확정 캐논 추가 (5) — 빌더 전용 4 + 반중력 1

출시 캐논(11)의 나머지. 전부 ECHORIS 고유 sci-fi 재프레임. 상태 = **제안(스파이크 검증 대상)**, 본편 Critical Path 필수 배분(M-BUILDER 해소).

### 2.1 빌더 전용 렐릭 (4) — 거인-형 빌더 조우의 핵심

| # | KO (EN) | 기능 | 차별화 의도 | 레퍼런스(재프레임) |
| :--- | :--- | :--- | :--- | :--- |
| 7 | 자기 점착 클램프 (Mag-Clamp) | 빌더 금속 표피 전용 자기 등반. **활성 시 일반 벽 타기/점프 무효(트레이드오프)** | 범용 업그레이드 아님 — 빌더 표면이 "다른 규칙의 공간"임을 이동 체계로 각인. 파워 크리프 없음 | SotC 그립 |
| 8 | 빌더 제어 노드 (Builder Control Node) | 빌더 관리 터미널 접속, 구조 섹션 회전/기울임 → 내부 지형 재편 | 환경을 플레이어가 재구성 | TOTK 신수 터미널 / BLAME! NTG |

| 10 | 공명 펄스 (Resonance Pulse) | 에코로 그리드를 한 박자 정지. 정지 중 빌더 시공/이동 부위 횡단 | **캐논 정합 최고** (에코 응답=그리드 정지) | Inertia Lock의 에코-캐논 버전 |

### 2.2 반중력 (Anti-Gravity, 물리 조작) — #11

> 플레이어 자신의 중력을 바꾸지 않는다. 발동 시 **일정 반경 내 사물의 중력 방향을 반전**한다. (구 캐논 "역중력"의 재정의태)

| 항목 | 사양 |
| :--- | :--- |
| 범위 | 일정 반경(area) 광역 — 반경 내 모든 대상 동시 작용 |
| 대상 | throwable container(상자/잔해), fluid(유체). **플레이어·적은 무영향** |
| 효과 | 사물 위로 부유 / 유체 역류 상승 |
| 탑승 | 부유 컨테이너 위 플레이어 탑승 가능 → **이동 발판** (확정) |
| 게이트 | 부유 컨테이너 발판 도달 게이트 + 역류 유체 수위 게이트 |
| 코드 정합 | 기존 `ThrowableContainer` + `FluidSystem.ts` 활용. 신규 충돌 반전 시스템 불필요(사물 단위 중력 벡터 반전) |

## 3. 후보 보존 (Boneyard) — 캐논 미채택

조사·기획됐으나 출시 캐논에 미포함. 향후 확장 시 재검토. **현재 구현/발주 대상 아님.**

### 3.1 수직 이동 R-V 시리즈 (Research_Vertical_Movement_Relics)
- R-V02 심연의 날개(이단점프 후 활공) — 제거(코어 6이 이동 세트 완성)
- R-V04 중력 반전 코어(플레이어 천장 보행 5초) — **보류**(충돌 비용; 극성 부츠가 천장 보행 대체)
- R-V05 속박의 쇄도(방향성 차지) — surge와 역할 중복
- R-V06 덩굴의 기억(기억 토양 등반) — 제거

### 3.2 빌더/구조 조작 후보 (캐논 4종 외)
자기 견인 장갑(Magnesis) · 관성 록(Stasis) · 궤적 역재생기(Recall) · 중력 천공 드라이버(GBE) · 구조 분석기(Scan) · 위상 관통기(Ascend) · 앵커 랜스(그래플) · 레일 리더(Spider Ball) · 엘리베이터 재인가 칩 · 네트 터미널 파편 · 압출 서핑 · 상흔 진입 · 빌더 탑승 운송.

> 이들은 §0 정합 필터를 통과한 sci-fi 후보다. 캐논 11에 미포함일 뿐 폐기는 아니다.
