# ECHORIS 렐릭 종합 카탈로그 (Relic Catalog)

> **문서 ID:** PLN-RELIC
> **최근 업데이트:** 2026-05-31
> **용도:** 전체 렐릭(능력) 목록의 단일 정리처. 구현/기획/후보/폐기 + 세계관 정합성 판정.
> **범위:** 전체 출시 계획 기준 후보 풀. 즉시 구현이 아니라 출시까지의 렐릭 정합성을 관리한다.
> **경계:** 본 문서는 능력(렐릭)만 다룬다. 아이템계 깊이로 능력·장비를 획득/영속화하는 진행 메커니즘은 렐릭이 아니라 시스템이므로 `Plan/Spec/Spec_ItemWorld_Progression.md`(PLN-IWPROG)로 분리.
> **근거:** 코드 실측(Player.ts), `System/System_Player_Abilities.md`, `System/System_World_AbilityGating.md`, `Research/Research_Vertical_Movement_Relics.md`, `Research/Reference_Metroidvania_ActionRPG_Digest.md`, 신규 레퍼런스 조사(메가스트럭처 렐릭).

## 0. 세계관 정합성 필터

렐릭 채택의 기준은 출처(어느 게임 카피냐)가 아니라 ECHORIS 세계관 정합성이다([[feedback_reference_worldview_consistency]]).

### 세계관 앵커 (Glossary)

| 용어 | 정의 |
| :--- | :--- |
| Builder (빌더) | 메가 스트럭처를 끝없이 짓는 거대 산업 시공자. 의지·계획 없음. 인간을 인지조차 안 함. 파괴 불가. BLAME!/Biomega 계보 |
| Megastructure (메가 스트럭처) | 빌더가 짓는 거대 구조물. 작품 전체 무대. 수직 T1-T7 |
| Forge (포지) | 빌더 내부의 거대 단조 장치. 에코를 격발해 내부 위상 진입 = 아이템계 진입의 in-universe 메커니즘 |
| Echo (에코) | 잊힌 자가 무기에 남긴 마지막 한 마디의 응결체. 곧 모든 장비. 작품명 어원 |
| Cascade (단절) | 인간이 빌더 블루프린트에서 누락된 사건. 코스믹 호러 |
| Grid/Blueprint | 시공 격자/패턴. 에코의 응답이 그리드를 한 박자 멈춤 |

### 정합성 테스트

각 렐릭은 다음에 답해야 한다: "이 능력이 sci-fi 메가스트럭처 세계관(빌더/포지/에코)에 어떻게 정합하는가?" 판타지·마법·뱀파이어·정령·저주 톤만 배제한다. 중력·자기·신호·구조 조작 등 산업/물리 메타포는 채택 가능.

> 안개 변신이 폐기된 이유는 안개=판타지=드라큘라 톤이 sci-fi 세계관과 충돌해서다. SotN 출처여서가 아니다. 역중력(중력 조작)은 톤상 정합하며, 보류 사유는 충돌 시스템 구현 비용 + 서사 앵커 불명확이다.

## 4. 아이템계 / 에코 진행 시스템 → 분리됨

아이템계 깊이로 능력·장비를 획득하고 영속화하는 메커니즘은 렐릭(능력)이 아니라 진행 시스템이다. 설계 방향 2026-05-31에 따라 본 카탈로그에서 완전 분리했다.

조사된 후보(아이템계 깊이→해금 매핑, 에코 해체/기록소/각인 = Kanai's Cube 동형, 공진 모드/추적, 슈트 패치, 빌더 터미널 등)는 전부 `Plan/Spec/Spec_ItemWorld_Progression.md` (PLN-IWPROG)로 이전 보존했다.

> 단, 슈트 패치(보스 능력 흡수)처럼 "렐릭을 어떻게 획득하는가"는 PLN-IWPROG의 획득 시스템이고, 그렇게 획득되는 능력 자체는 본 카탈로그(§1-3)에 정의된다.

### 7.0.1 반중력 (Anti-Gravity) 상세 (확정 2026-05-31)

플레이어 자신의 중력을 바꾸지 않는다. 발동 시 일정 반경(area) 내 사물의 중력 방향을 반전한다.

- 범위: 일정 반경(area) 적용. 반경 내 모든 대상 사물·유체에 동시 작용 (광역).
- 대상: throwable container(상자/잔해 등 물리 사물), fluid(유체). 플레이어·적은 무영향.
- 효과: 반경 내 사물이 위로 부유. 유체는 역류해 위로 흐름.
- 탑승: 부유한 컨테이너 위에 플레이어 탑승 가능 → 이동 발판으로 사용. (확정)
- 게이트 역할: 부유 컨테이너를 발판으로 한 도달 게이트(이동) + 역류 유체 수위 게이트.
- 용도: 컨테이너를 띄워 발판 삼아 상승, 역류 유체로 막힌 통로/수위 퍼즐 해결, 빌더 잔해 부유 활용.
- 코드 정합: 기존 `ThrowableContainer` + `FluidSystem.ts` 활용. 신규 충돌 반전 시스템 불필요(사물 단위 중력 벡터 반전). 부유 컨테이너 탑승은 기존 컨테이너 상단 지지 로직 재사용.

해소된 결정:
- 코어 6 이동 세트 확정. 확장 렐릭(심연의 날개·덩굴의 기억)·구조 분석기 제거.
- 빌더 전용 4종 확정: Mag-Clamp, 제어 노드, 극성 부츠, 공명 펄스.
- 반중력 채택. 정의 변경: 플레이어가 아니라 주변 사물·유체의 중력을 반전 (M-GRAV 해소). 천장 보행(플레이어)은 극성 부츠가 별도 담당.
- surge가 T1 상승 게이트 담당. diveAttack 정식 렐릭 UI 노출 (M-DIVE 해소).

확정: 빌더 전용 4종은 본편 Critical Path에 필수 배분 (M-BUILDER 해소). 격벽별 배치는 D-GATE에서 확정.
반중력: 일정 반경(area) 적용 + 부유 컨테이너 탑승 가능(이동 발판) 확정.

### 7.1 코어 이동 렐릭 (확정 6)

확정 6(dash/wallJump/doubleJump/waterBreathing/surge/diveAttack)이 수직 자유 이동 세트를 완성한다. 확장 렐릭(심연의 날개·덩굴의 기억)은 제거. R-V 시리즈는 후보 보존(§2)하되 캐논 미채택.

### 7.2 빌더 상호작용 렐릭 (스파이크 — ECHORIS 고유)

거인-형 빌더 조우 경험의 핵심. 캐논 2종: Mag-Clamp + 빌더 제어 노드. Mag-Clamp는 트레이드오프(일반 벽 타기 무효, 빌더 전용)로 차별. 구조 분석기 외 후보(Inertia Lock/Anchor Lance 등)는 §3 후보 보존, 캐논 미채택.

### 7.3 아이템계/에코 진행 (분리)

진행/획득/영속화는 렐릭이 아니라 시스템이다. `Plan/Spec/Spec_ItemWorld_Progression.md` (PLN-IWPROG)로 분리 관리. 본 카탈로그는 능력 정의만 보유한다.

### 7.4 D-GATE 연동

격벽 배치는 확정 11 렐릭의 게이팅 능력을 7층위 Critical Path에 배분한다. 빌더 전용 4종은 필수 포함(M-BUILDER 확정). T1 상승 게이트 = surge. 반중력은 부유 컨테이너 발판 게이트로 활용.
