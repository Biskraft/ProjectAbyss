## 0. 위치 (D-20 정합)

상점 공간 = 잔존자 마을(D-20 §5.1, 패턴 A). 별도 로딩 없는 월드 내 거점. 세이브와 상점은 별개 기물. 다이브(포지)는 빌더 내부 산재로 상점과 분리. 초기 NPC: 노다·율(D-20 §5). 추가 벤더는 생존자 구조로 합류(이름 미확정 — 내러티브 리셋 대기).

## 1. 핵심 원칙 (D-07)

- P0 — 상점은 파밍을 대체하지 않는다. 장비·기억 단편은 상점 판매 금지. 상점은 소모품·서비스·정보만. (D3 RMAH 교훈)
- P1 — 상점은 두 번째 HL sink. 1순위 sink는 기억 단편 복종, 2순위가 소모품 구매. 없으면 HL 인플레이션.
- P2 — NPC는 생존자 구조로 해금. 탐험이 경제 인프라를 확장(Ori Grom / Dark Souls 모닥불 모델).
- 거래소(플레이어 간) 없음. Legendary+ 귀속.

## 2. 자원 (D-07 §3.1)

| 자원 | Faucet | Sink | 인플레 위험 |
| :--- | :--- | :--- | :--- |
| HL (골드) | 몹/상자/판매 | 복종·수리·소모품·승급 수수료 | 높음 (다중 sink 필요) |
| 장비 | 몹/보스 드랍 | 아이템계 진입(비소모)·분해 | 낮음 (슬롯 상한) |
| 기억 단편 | 아이템계 포획 | 합성·이식·복종 | 중간 (슬롯 상한) |
| Remnant Fragment | 단편 분해·보스·지층 클리어 | 레어리티 승급(지수 비용) | 중간 |

세션 기대수입(D-07 §7.1): 솔로 Normal 10-15분 순이익 0-400 HL / Legendary 파티 25-35분 500-1500 HL.

## 5. V2 소모품 (반복 sink, 가격 고정 앵커)

> 회복 드랍은 이미 구현됨(Ember 10%/Forge 25%/Anvil 50%, `System_Healing_Recovery.md`). 상점은 그와 별개로 구비용 소모품 판매.

| 아이템 | 가격 | 재고 | 해금 |
| :--- | :--- | :--- | :--- |
| HP 소회복 | 50 HL (고정 앵커) | 무제한 | 초기 |
| HP 중회복 | 150 HL | 무제한 | 마을 인구 3+ |
| HP 대회복 | 400 HL | 무제한 | 마을 인구 6+ |
| Mr. Gency Exit (탈출권) | 200 HL (고정) | 무제한 | 초기 |
| 일시 무적(5s) | 350 HL | 1세션 3개 | 인구 4+ |
| 이동속도(30s) | 100 HL | 무제한 | 초기 |
| 적 분석경 | 80 HL | 무제한 | 인구 2+ |

> 50 HL/200 HL 고정 앵커가 플레이어 "세션 예산"의 기준점. 초반 Gency Exit=수입 50%, 후반 5% → 성장 체감.

## 6. V3-V6 요약

- V3 정보: 구역 지도 150 / 비밀 탐지기 250 / 적 DB 100 / 아이템계 사전 보고 80. 파밍 가속재(대체 아님).
- V4 소재: Remnant Fragment 하위 300(주간 5개) / 에코 증폭 수정 500(주간 3개). 상위 Remnant는 파밍 전용(Dark Souls Titanite 모델).
- V5 플라스크: 용량+1 = 500 HL+소재(최대 5회) / 회복량+10% = 300 HL+소재(최대 3단). HL+소재 복합.
- V6 로어: 해석 200 / 방랑자 힌트 150 / 고급 정보 500.

| 등급 | 판매 | 근거 |
| :--- | :--- | :--- |

## 8. HL sink 균형 (D-07 §4-8)

| sink | 비율 | 비고 |
| :--- | :--- | :--- |
| 기억 단편 복종 | 50-60% | 세션당 발생, 주 sink |
| 소모품 구매 | 20-25% | 안정적 반복 |
| 플라스크 업그레이드 | 5-10% | 중반 1회성 고비용 |
| 레어리티 승급 수수료 | 5-10% | Remnant + HL |
| 정보 구매 | 5% | 선택 |

인플레 억제: 복종 비용 지수 스케일 + 승급 비용 지수 + 소재 주간 한도 + Legendary+ 귀속(거래소 부재).

## 9. 재고 언락 (생존자 구조)

```
[초기] 노다(대장간) + 율(소모품 기본)
  ↓ 구조 2명 → 탐험 정보상 + 소모품 중회복 해금
  ↓ 구조 4명 → 소재 브로커 + 무적 소모품 해금
  ↓ 구조 5명 → 플라스크 장인 + 대회복 해금
  ↓ 구조 7명 → 로어 NPC + 전체 재고 최대
```

구조 가능한 생존자를 심층·가지 경로에 배치. 구조 = 마을 활성화 = "탐험→구출→귀환" 순환과 결합. (D-20 NPC 이주 §5.1)
