## 0. 모델 — 3축 거동 × 속성 곱 × 풀 선택

`SYS-ENM-ARC §2.11`/`DEC-045` 정합: **속성은 디자인의 일부가 아니라 곱셈 레이어다.** 따라서 거동을 속성과 분리한다.

```
거동(Behavior) = 크기(3) × 이동(5) × 위협(7)   ← 속성 무관, 손저작 단위
   × 속성(Attribute 6: magma/water/oil/acid/charged/cyro)   ← 풀이 결정, 곱셈
   × MOD(8 행동 변형)                                       ← 지층 깊이
풀(Pool/SpawnTable) = (가족→속성) + (지층→허용 거동) 선택
```

- **크기(3):** 소 / 중 / 대 — 대형 비행체(건쉽)는 소형(다트)과 전술이 다르다. 명시 축.
- **이동(5):** 지상 / 공중 / 고정 / 은신 / 벽·천장
- **위협(7):** 돌진 · 근접 · 직사 · 포물선 · 방어 · 소환 · 봉쇄 (※ 군집=소+근접, 기습=은신+근접 으로 흡수)
- **속성:** 같은 거동이 forge 풀=magma, rust 풀=acid 로 등장. 가족 커버리지는 곱셈으로 자동.

## 3. 속성 레이어 (곱셈 — 풀이 결정)

| 가족(무기 기질) | 속성(fluid) | 라이더 효과(잔류/접촉/사망) |
|:--|:--|:--|
| forge | magma | 잔열 / Burn / magma 풀 |
| iron | cyro/water | 결빙 슬릭 / 둔화 / 빙결 |
| rust | acid | 산 장판 DoT / DEF 저하 / 산 분출 |
| spark | charged | 정전기 / 감전 / 연쇄 |
| shadow | oil | 기름 슬릭(가연) / 시야방해 / 확산 |

- **속성은 거동에 박지 않는다.** B07(거너)이 rust 풀에선 산 거너(=구 Spitter), forge 풀에선 화염 거너(=구 Pyrelance)가 된다. **하나의 거동이 6속성을 커버.**
- fluid 모듈 6종(magma/water/oil/acid/charged/cyro)은 1회 구현, 전 거동 공유. FluidSpawner/화학 매트릭스 재활용 확인 선행.
- SpawnTable 스키마: `Family, Behavior, MinStratum, MaxStratum, Weight, ClusterMin, ClusterMax` (속성은 Family→고정 또는 지층 혼합).

## 5. 손저작 빌드 리스트 (~40 of 52)

- **구현 완료(11):** B02·B04·B05·B09·B11·B13·B17·B18·B22·B31·B43.
- **신규 손저작(~29 거동, cut 12 제외):** §2 표의 P0~P3.
- **우선:** P0 = B07(거너). P1 = B03·B06·B15·B23·B24·B33·B39·B44·B49·B50. (rust/shadow 결핍 + 신 이동축).
- 말소자 4 스킨은 별도(세트피스, 속성 무바인딩).

**규모 정합:** 거동 52(천장) → 손저작 40 → ×6 속성 = ~240 변종 → ×MOD 8 = 조우 라이브러리 수백 (DEC-045/§2.12.3 정합). 코드 FSM ≈15-20(위협 패턴 공유, 크기·이동·속성은 파라미터/모듈).
