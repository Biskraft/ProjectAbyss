# TASK-IWGEN-01 — 아이템계 가변-큰 방 생성 (패킹 + 연결)

> **1순위 단일 과제:** 절차 생성기가 *가변-큰 방*을 겹침 없이 배치(패킹)하고 연결하게 만든다. 이것만 풀리면 수로 던전·넓은 평원·Dead Cells 형태가 *같은 생성기*에서 나온다(형태 무제약).
> **근거:** [RES-IWS-03](../Research/Research_ItemWorld_WonderAxisSystem.md) §8 생성 포크 / `Reference/DeadCells-LevelGeneration-ReverseGDD.md` / 현재 코드 조사(RoomGraph·RoomGraphAdapter·TemplatePicker·FullGridRuntime).
> **상태:** 작업 계획 (착수 전 §4 파라미터 핀 필요). 점진적·게이트 통과식.
> **작성:** 2026-06-18.

---

## §0. 확정된 설계 전제 (이 작업서의 입력)

- **형태 무제약 = 방 크기 자유로 달성.** 유일 레버 = 가변-큰 방의 *절차적 배치*. 방 내용(수로/평원/미궁)은 저작 자유.
- **세로 이동은 큰 방 *내부* 사다리·샤프트로 흡수.** 방-대-방 세로 소켓 불필요.
- **방-대-방 소켓 = 가로(L/R) + 하강 드롭(D).** U 없음(신규 콘텐츠). 하강은 커넥터/트랩도어가 처리(매칭 아님). 기존 UDLR 매칭은 레거시 방에 유지.
- **일방향 하강 + 곁가지는 옆 주머니(L/R)만** (되돌아 올라가지 않음).
- **소켓 축소 {LR, L, R, LRD}는 *선택적 폴리시*** — 현 UDLR이 이미 작동하므로 필수 아님. 패킹 위에 나중에.
- **보존:** 씨드 결정론(재다이브=같은 맵), 크리티컬 패스 보장, 유체·카메라·스폰(이미 가변 크기 작동 — 변경 없음).
- **이음매 타일 정합:** 수작업 커넥터(사전 타일) 우선. 자유형 갭 오토타일(LDtk 룰 재실행)은 후속 별건.

## §2. 작업 티켓 (잘게 · 우선순위순)

> 설계 상세 = [DGN-IWGEN-01](../Design/Design_ItemWorld_GenerationArchitecture.md) .
> 원칙: **가장 위험한 패킹 코어를 먼저 스파이크로 분리 검증**(합성 더미, LDtk·통합 없이) → 데이터 모델 → 통합 → 세로 슬라이스 → 가로 → 개방/하이브리드. 페이즈마다 게이트.

### Phase 0 — 패킹 스파이크 (최우선 · 합성 더미)
통합·템플릿 없이 패커 코어만 분리 검증.
- **T0.1** 점유 그리드(16×16 불리언) + 충돌 검사.
- **T0.2** config-space 계산(템플릿쌍·엣지방향 → 비겹침·문정렬 오프셋 집합).
- **T0.3** 그리디 BFS 배치 + 체인 백트랙(합성 그래프: 노드 footprint·엣지 입력).
- **T0.4** 코리도 삽입(평탄/사다리/드롭) — 오프셋 규칙(하강 ∞ · 상승 ≤4 · >4 사다리).
- **T0.5** 해시 기반 per-node RNG + SplitMix64 시드 믹스.
- **게이트:** 100 시드 0 겹침 · CP 연결 · 재현 동일 · 순환 그래프 캡 내 종료.

### Phase 1 — 데이터 모델 (Phase 0과 병렬 가능)
- **T1.1** `RoomNode += footprint{w,h}, orientation, encounterType`.
- **T1.2** `RoomEdge += corridorId, kind 'tree_with_corridor'`.
- **T1.3** 템플릿 메타 자동화 — footprint 자동측정 + 입구 자동검출(테두리 갭 · 4셀 스냅 · 최소 3셀) + 클래스 판별(밀폐 vs 개방).

### Phase 2 — carve / 토폴로지 리팩터 (의존 T1.1)
- **T2.1** `buildVerticalDive`: 좌표 직접 할당 분리 → 토폴로지+CP+footprint만 산출(좌표는 패커로).
- **T2.2** bias 벡터 추출(cpD/L/R → 프리셋).

### Phase 3 — 패커 통합 (의존 Phase 0 + 1 + T2.1)
- **T3.1** `embedVertical → packGraph`(Phase 0 코어를 실 RoomGraph 출력에 연결).
- **T3.2** 코리도 노드 실삽입.
- **T3.3** 플라자 정렬 footprint-aware(bbox).
- **T3.4** `validateRoomGraph` 확장(겹침 · 코리도 · CP flood-fill 백스톱).
- **T3.5** 실패 사다리(캡 · 리시드 · 고정셀 폴백).

### Phase 4 — 세로 슬라이스 검증 (단일 biome)
- **T4.1** 저작 훅: 자동검출 footprint/입구 소비(*사용자 제작 테스트 템플릿 사용*).
- **T4.2** 단일 biome 세로 다이브를 가변 방 3~4 + 코리도로 생성.
- **게이트:** §5 — 겹침 0 · 연결 · CP 통행 · 재다이브 동일 · Shift+2 그래프 코리도 표시 · 이음매 타일(커넥터 사전타일).

### Phase 5 — 가로 빌더 (세로 패킹 입증 후)
- **T5.1** `generateRoomGraph += layoutDirection` + 가로 bias 프리셋.
- **T5.2** 통합 carve+bias 가로 스파인.
- **T5.3** 가로 슬라이스 검증.

### Phase 6 — OPEN 필드 + 페이즈 스파인 (하이브리드 · 후속)
- **T6.1** OPEN 세그먼트(1D fBm 바닥 + 지터드 산포 + POI 다양성 + 케이던스).
- **T6.2** 페이즈 스파인 컴포저(세그먼트 결합 + 커넥터 mate; OPEN→V).
- **T6.3** 점프 궤적 갭 검증.
- → *평원→집→미궁* 완성(DIR-IWS-01 풍덩 연동).

**우선순위 한 줄:** Phase 0(스파이크) → 1 → 2 → 3 → 4(세로 슬라이스 입증) → 5(가로) → 6(개방/하이브리드). 0에서 막히면 설계 재검토, 4 실패면 고정셀 폴백.

## §3. 보존 불변값 (검증 필수)

- **결정론:** 신규 RNG(패킹 순서·코리도 선택) 전부 `item.uid` 씨드. 재다이브=동일 맵.
- **크리티컬 패스:** 입구→코어 통행 보장(현 검증 확장 — 가변 크기·코리도 포함 flood-fill).
- **카메라·유체·스폰:** 가변 크기 이미 대응 — 변경 없음(회귀만 확인).
- **타일 그리드:** 전부 16px 정렬. 풋프린트는 기본단위 정수배.

## §4. 착수 전 핀할 파라미터

| 파라미터 | 용도 | 현재 |
| :--- | :--- | :--- |
| 점프/사다리 도달 | 연결 허용오차 | **확정(2026-06-18): 점프 4셀 · 이단 미정(의존 금지) · 사다리 ∞ → §4.1** |
| 기본 단위 크기 | 풋프린트 단위 | **확정: 16×16 타일(256×256px). 48×32 = 3×2 풋프린트(레거시 호환).** |
| 코리도 풀 구성 | 변 브리징 | 평탄·사다리·드롭 3종(§4.1) |

### §4.1 연결 허용오차 규칙 (점프 4 · 이단 미정 · 사다리 ∞에서 도출)

- **세로 단차는 비대칭.** 하강(내려가 진입) = *무제한*(낙하 무료). 상승(올라가 진입) = **≤4셀(점프)**, 초과 시 **사다리 코리도**(∞라 어떤 높이든).
- **이단점프 의존 금지** — 미정이므로 단일 점프 4셀 기준 설계(나중 추가되면 여유).
- **문 세로 위치 스냅 = 4셀 격자** — 두 문의 상승 오차가 4의 배수가 됨. 4 = 1점프, ≥8 = 사다리.
- **문 개구 규격:** 세로문(L/R) ≥ 3셀(플레이어 2 + 여유), 바닥구멍(D) ≥ 2~3셀. 미만은 문으로 안 봄(봉합).
- **코리도 3종이면 충분:** 평탄(가로·≤4 상승) / 사다리(상승, ∞ 높이) / 드롭(하강·무료). 사다리 ∞ 덕에 세로는 *단일 사다리 코리도*로 전부 커버.
- **일방향 하강과 정합:** 세계가 내려가니 대부분 연결은 낙하(무료)·동레벨. 사다리는 *드문 상승*에만 → 복잡도 최소.

## §5. 슬라이스 & 게이트

- **슬라이스:** 한 지층을 *가변-큰 방 3~4개 + 코리도*로 패킹(수로 던전 한 토막).
- **통과 게이트:**
  1. 겹침 0.
  2. 모든 방 연결(고립 0).
  3. 입구→코어 통행.
  4. 재다이브 동일 맵(씨드).
  5. Shift+2 RoomGraph 디버그에 코리도 노드 표시.
  6. 이음매 타일 정합(커넥터 사전타일).
- **실패 시:** 고정 48×32 셀로 후퇴(안전망 — 바닥은 작동 중).

## 저작 가이드 (방 손제작)

> 생성기가 footprint·입구·클래스·기능을 *자동 파생*한다. 당신은 *그리기 규칙*만 지키면 된다.

### 크기
- **16×16 타일(256px) 배수**로 그린다. 방 = N×M 기본단위. *큰 방 권장*(세로 이동·꺾임을 내부에 흡수).
- 예: 1×1 = 256² · 2×1 = 512×256 · 3×2 = 768×512(기존 방 크기).

### 문 (벽 구멍)
- **가로 문(L/R 변):** 세로 위치 **4타일 격자 스냅**, 높이 **≥3타일**(플레이어 2 + 여유).
- **하강(바닥 구멍 D):** 너비 ≥2~3타일.
- **위(U) 매칭 문 만들지 말 것** — 세로 연결은 드롭/사다리(커넥터 처리). 위에서 떨어져 받는 쪽은 *그냥 열어두면* 됨.
- 소켓 6종 {LR, LRD, UD, L, R, D} = *어느 변에 구멍을 내는가*. 일방향 하강.

### 두 종류 (자동 판별)
- **밀폐 방:** 테두리 벽 + 구멍(=문).
- **개방 필드:** 테두리 없음, 변 전체 열림(seamless). 평원용.

### 세로 이동
- 방 안 오르내림이 필요하면 **내부에 사다리/샤프트 직접 그리기**(U 소켓 없음).

### 안 해도 되는 것 (자동)
- footprint · 입구(변/위치/크기) · 클래스 · 기능(엔티티 추론) = 시스템이 읽음. *숫자 메타 안 적어도 됨.*

### 해야 할 것
- **biome 폴더**에 넣기. **엔티티**(시작/보스/보물/상점/적) 배치. 레벨명 컨벤션 유지(예: `Combat_LRD`).

### Phase 4 슬라이스용 우선 제작 (최소 세트)
1. **입구 방** 1 (상단 시작점).
2. **가변 전투 방** 3~4 (L/R + D 구멍, 크기 다양).
3. **보스 방** 1 (하단).
4. **코리도 풀**: 평탄 · 사다리 · 드롭 + L-jog (작은 사전타일 조각).
