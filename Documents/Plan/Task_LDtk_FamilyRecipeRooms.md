# LDtk 계열 레시피 방 5종 — 배치 명세 (조우 체감 테스트)

> 준거: `Research_ItemWorld_MonsterSpawn_Balancing.md` §6.4 레시피 · §7 M1-C(test map) · `Task_Enemy_00_DistinctnessAudit.md`
> 상태: 배치 대기 (LDtk 에디터 수작업) · 우선순위: P1 (스폰 시스템 체감 검증 선행물)
> 목적: **레시피(조성 단위) 조우 체감 검증.** 개별 거동은 기존 스트립(Overworld_Level_63~90)으로 이미 커버 — 본 작업은 낱개 배치가 아니라 §6.4 레시피 그대로의 혼합 방 5개.

## 0. 검증 범위 한계 (착수 전 인지)

- 본 테스트로 판정되는 것: **레시피 자체의 재미** — 동사 혼합 밀도, 텔레그래프 겹침, 처치 순서 퍼즐 성립 여부.
- 판정되지 않는 것: 계열 fluid 컨텍스트(월드 방엔 기질 타일·속성 분기 없음 — Slime은 water 고정, rust "바닥이 적" 체감 불완전) + 스폰 시스템 자체(역할 예산·가중치·깊이 게이팅) → **아이템계 5기질 다이브로 별도 검증**.
- 여기서 재미없으면 레시피(§6.4) 수정, 다이브에서만 다르게 나오면 시스템(SpawnTable 가중치/비율) 수정 — 판정 분리가 본 작업의 존재 이유.

## 1. 공통 규격 (기존 스트립 관례 준수)

| 항목 | 값 |
|:--|:--|
| 룸 크기 | 768×384 px (48×24 셀, gridSize 16) — Overworld_Level_63 동일 |
| 위치 | 기존 스트립 밴드(worldY −11520) 우측 연장, Overworld_Level_90 다음 |
| RoomType 필드 | `Debug` |
| 엔티티 | `Enemy_Spawn` (pivot 하단중앙) — `type`=MonsterType enum, `level`=1, TargetDoor 비움 |
| 지형 | 평평한 바닥(하단 2~3셀 벽) + 좌측 진입. 좌표는 (col, row) 셀 단위, row 20 = 바닥 서있는 줄 기준 |
| 진입 여유 | 첫 교전을 col 18+ 에 배치 — 진입 직후 시야 확보 후 아그로(불공정 기습 금지) |

### 간격 가이드 원칙 (detect 기반)

- **군집(스워머):** 2~3셀 간격 클러스터 — 광역기 1회 판정 범위 검증.
- **R11(자폭계):** 군집 사이 1~2셀 인터리브 — "어느 게 폭탄인가" 식별이 성립하려면 섞여 있어야 함. 분리 배치 금지.
- **후방 화력(원거리·리테넌트):** 진입점에서 detect 직전(B07 280px=17.5셀, Sentry 320px=20셀) — 전열 교전 중 후열이 깨어나는 시차 연출.
- **공중:** 지상열과 수직 6셀 이상 분리(row 10~13) — 시선 2축 분할 검증.
- **은신·함정:** 플레이어 동선 한가운데(col 24~32) — 우회 불가, 예측/정찰 동사 강제.

## 3. 공통 검증 체크리스트 (5방 전체)

- [ ] 방마다 대응 동사 2~3개가 실제로 요구되는가 (1개=단조 / 4개+=과부하)
- [ ] DEC-049 데미지 앵커(피격당 ~20%)에서 방 전체 위협이 과하지 않은가
- [ ] 텔레그래프 동시 다발 시 가독성 (특히 Room 1 점멸 + Room 4 공중)
- [ ] 처치 순서 선택이 매 방 존재하는가 (자유도 0 = 레시피 실패)
- [ ] 재미 판정 → §6.4 레시피 수정 / 다이브와 체감 차이 → SpawnTable·비율 수정 (판정 분리)
