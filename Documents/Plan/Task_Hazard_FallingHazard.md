## 1. 개요

**FallingHazard = 천장에서 플레이어 머리 위로 떨어지는 낙하 함정.** 기존 `Spike`(바닥 접촉)·`Trapdoor`/`CollapsingPlatform`(플레이어 낙하)과 **방향이 반대** — 위에서 *떨어지는 물체*다. 바닥 붕괴(⑧)와 상·하 환경 위협 짝.

**세계관 원칙:** "누가 설치한 가시"가 아니라 **무관심한 거신(메가 스트럭처)이 부패·시공·성장하며 떨군다.** 거대한 무관심·외로움(고독) 첨점과 정합.

## 3. 동작 스펙 (확정 — 2026-06-06)

### 3.1 시퀀스

```
[대기] 천장에 부착(정적)
   │  플레이어가 트리거 밴드 진입
   ▼
[텔레그래프 1000ms] 터치 즉시 → 낙하 지점 바닥으로 먼지가 떨어짐(예고)
   │  1000ms 경과
   ▼
[낙하] 2×1 타일(가변) 천장에서 분리 → 중력 낙하
   │  낙하 중 플레이어 접촉 → 데미지
   ▼
[착지] 바닥/솔리드 충돌 → 파쇄(PropShatter) + 잔해
   │  착지 셀에 fluid 있으면 → 유체 상호작용(§5)
```

### 3.2 핵심 규칙

- **트리거 = 긴 밴드 배치.** 단일 점이 아니라 **가로로 긴 트리거 존**. 플레이어가 통로를 지나는 동안 진입하면 무장 → "구조물이 내 통과에 반응한다" 체감. 트리거 폭은 디자이너 지정.
- **텔레그래프 1000ms.** 터치 즉시 시작. 예고 신호 = **낙하 지점 바닥으로 먼지(dust)가 떨어짐** — *어디에* 떨어질지 명시. 1000ms 동안 회피 창.
- **낙하체 = 2×1 타일 기본, 크기 가변.** 타일 W×H 는 디자이너가 LDtk/메타로 지정(기본 2×1).
- **낙하 물리:** base 중력 + `resolveY` 솔리드 충돌 재사용. 바닥/솔리드 도달 시 정지·파쇄.

## 5. 유체 상호작용 (바닥 fluid)

낙하체가 **fluid가 있는 셀에 착지하면 상호작용 발생** — `FluidSystem`/`FluidReactionRuntime` 연동.

- **변위/튐(splash):** 착지 충격으로 해당 셀 유체가 인접으로 변위·비산.
- **속성별 반응:** 물=튐·확산, 기름=슬릭 확산(가연 연쇄 가능성), magma/acid 등=착지 셀 반응. (구체 반응표는 FluidReaction 정합 후 확정.)
- 착지 잔해가 유체 위에 남는지(부유/침전) 여부는 후속 결정.

> 침수 바닥층 특성상 바닥 유체(물)가 흔하므로, 낙하-유체 상호작용은 이 존에서 상시 발생한다. "구조물이 무너져 물을 튀긴다"가 기본 체감.

## 6. 공정성 제약 (P0)

1. **1000ms 예고 필수** — 먼지 낙하 신호 없이 즉발 낙하 금지. 먼지가 *낙하 지점*을 명시해야 회피 가능.
2. **화면 밖 낙하 금지**(§1.3) — 낙하 지점·예고가 화면 안에서 읽혀야 함.
3. **무회피 배치 금지** — 1000ms 안에 벗어날 수 있는 공간/동선이 있는 위치에만 배치. 좁은 막다른 곳 금지.
4. **첫 등장 = 단독** — 오프닝 첫 낙하 함정은 다른 위협과 겹치지 않게 단독 도입(맛보기 후 조합).

## 8. 인수 기준

1. 플레이어가 긴 트리거 밴드 진입 시, 낙하 지점 바닥에 먼지가 떨어지며 1000ms 예고된다.
2. 1000ms 후 2×1(가변) 타일이 천장에서 분리·낙하하고, 접촉 시 데미지를 준다.
3. 타일 크기를 디자이너가 변경할 수 있다(기본 2×1).
4. 바닥에 유체가 있으면 착지 시 유체 상호작용(튐/변위·속성 반응)이 발생한다.
5. 1000ms 안에 회피 가능한 동선이 보장되며, 화면 밖에서 낙하하지 않는다.
6. 바닥 붕괴(⑧)와 상·하 환경 위협 짝으로 읽힌다.
