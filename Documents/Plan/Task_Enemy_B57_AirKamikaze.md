- FSM: 감지 → **공중 호밍 가속 추적**(가까울수록 점멸·경고음 빨라짐) → 근접 진입 시 정지 + 강한 플래시 "프라임" 0.2~0.3s → 폭발 → 자가 소멸. **즉발 금지** — B53과 동일하게 프라임이 점블랭크 대시 회피 창을 보장. 프라임 진입 전 처치 시 폭발 취소(요격=보상).

- 구현 노트: B53 위협 모듈(프라임·폭발) + 기존 공중 호밍 이동 모듈(MawDrone/SparkBat 계열) 조합. 신규 FSM 비용 ≈0.
