---

## 1. 개요

**A-07 Ambusher = 기습/은신 위협 축.** 환경에 위장·은신하다 기습 반경 진입 시 출현해 강한 1타. 지속전 약함, **1회 기습**이 핵심. 저HP 패시브·카운터(C/A/D)의 검증 표면.

- Type 키 = `Lurker` (확정 — CSV·LDtk enum 등재 완료).

---

## 2. 정체성 · 세력 · 배치

- **세력:** 드론(환경 위장) 확정 — 말소자는 세트피스 한정·일반 스폰 테이블 배치 금지(§2.12.6)이므로, 일반 출현 아키타입 A-07은 드론으로 귀속.
- **실루엣:** 평상시 환경 타일 유사 위장(미세 단서만). 출현 시 절지동물형. 16×20px.
- **출현:** 벽/천장/바닥 부착. 좁은 통로·세트피스. Ch.4 이후 적합.
- **로스터:** A-07 고유 디자인 3종 중 1번 base.

저HP·고버스트 ATK·짧은 감지 반경(기습 반경 ~2.5타일). DetectRange 작게 = 근접 진입 시에만 발현.

---

## 4. AI 거동 스펙

| 상태 | 동작 |
|:---|:---|
| Hidden | 환경 위장(비활성). 화면 안 미세 단서(질감 변화·깜빡이는 눈) |
| Reveal | 기습 반경(~2.5타일) 진입 → 출현 애니 **4f**(Tell 자체) |
| Strike | 출현 직후 강한 1타 |
| Recover | 기습 후 짧은 경직 → 도주 또는 재은신 |

신규 = **은신/위장 상태 머신** + 출현 4f Tell + 재은신 로직.

---

## 5. 핵심 난제 · 공정성 (P0)

- **화면 밖 출현·기습 금지**(§1.3) — 반드시 화면 안에서 4f 출현 모션을 거친다.
- **감지 = 반경 기반**(FoV/LoS 아님, §2.3) — 은신 상태에서 기습 반경 진입 시에만 발현.
- **미세 단서 노출 필수** — 완전 무경고 기습 금지. 화면 안이면 질감/발광 단서가 보여야 한다.
- **은신 = 적 위협 수단** — 플레이어 측 스텔스/엄폐와 별개(§A-07 공정성 주석).

## 7. 인수 기준

1. 은신 중 화면 안에서 미세 단서가 보인다(완전 불가시 아님).
2. 기습 반경 진입 시에만 4f 출현 모션을 거쳐 발현한다.
3. 화면 밖에서 출현·공격하지 않는다.
4. 기습 1타 후 경직이 생겨 카운터 윈도우가 열린다.
5. 저HP로 빠르게 처치 가능하다(지속전 약함).
