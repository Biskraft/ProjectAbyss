# VARCO Game AI 크레딧 지원 신청 — 프로젝트 소개 및 개발 현황

> **문서 ID:** PLN-VARCO
> **작성:** 2026-05-31
> **용도:** VARCO Game AI 크레딧 지원 신청서 본문. 제출 전 스튜디오/담당자 실명·연락처만 확인 후 사용.

---

## 1. 게임 소개

ECHORIS는 웹 브라우저에서 즉시 플레이하는 횡스크롤 온라인 액션 RPG입니다. 메트로베니아의 비선형 탐험과, 장비 아이템 내부로 진입해 무한 강화하는 디스가이아식 "아이템계" 파밍을 결합했습니다.

핵심 설계는 2-Space 모델입니다. 플레이어는 거대 구조물(메가 스트럭처)을 수직으로 하강 탐험하는 월드와, 장비 하나하나의 내부에 생성되는 절차적 던전(아이템계)을 오가며 순환합니다. 월드에서 장비를 얻고, 아이템계에서 강화하고, 강해진 장비로 더 깊은 층위를 여는 구조입니다.

- 장르: 웹 기반 횡스크롤 온라인 액션 RPG (메트로베니아 + 야리코미)
- 플랫폼: PC 웹 브라우저
- 기술 스택: PixiJS v8(WebGL/WebGPU), TypeScript, Vite, WebSocket(멀티), PostgreSQL/Redis(서버)
- 핵심 차별점: 모든 장비가 "에코(잊힌 자가 남긴 마지막 한 마디)"이며, 그 내부 기억으로 진입해 강화하는 아이템계 무한 파밍

## 2. 팀 소개

1인 인디 개발 프로젝트입니다. 기획·프로그래밍·아트 디렉션·데이터 설계를 단독으로 수행하고 있으며, 생성형 AI 파이프라인을 적극 활용해 1인 체제의 제작 한계를 보완하고 있습니다.

- 구성: 1인 (디렉션/개발/콘텐츠 총괄)
- 개발 방식: 기획 문서 SSoT 체계 + CSV 데이터 시트 + 자동화 파이프라인. 에셋 일부는 생성형 AI로 제작 후 직접 후처리

> 제출 시 스튜디오/대표자 실명 및 연락처를 이 항목에 기입.

## 3. 현재 개발 단계

프로토타입을 넘어 플레이 가능한 라이브 빌드를 운영 중인 알파 단계입니다. 정식 출시와 완성을 목표로 합니다.

- 라이브 웹 빌드 운영: 브라우저 접속 즉시 플레이 가능한 빌드 가동 중
- 검증 완료: 지인 테스트 약 50명 + 공개 테스트 진행, 첫 30분 수직 슬라이스 연속 플레이 성립
- 데이터 인프라: GA4 기반 플레이 분석, 인게임 피드백 수집(원클릭 폼) 연동
- 구현된 핵심 시스템: 캐릭터 물리/3타 콤보 전투, LDtk 기반 월드, 아이템계 진입 연출 및 절차적 지층 생성, 웨더/유체 시스템, 세이브/로드, 설정, 게임패드 지원, 능력 렐릭(대시/이단점프/벽점프/수중호흡 등)
- 현재 진행: 전체 출시 스펙 확정(월드 7층위, 무기 7종, 적·보스 로스터, 렐릭/아이템계 시스템) 및 콘텐츠 제작 확장

## 4. VARCO AI 기술 적용 계획

ECHORIS는 무한 절차 콘텐츠와 풍부한 서사를 1인 체제로 채워야 하는 구조라, 생성형 AI의 적용 가치가 큽니다. VARCO를 다음 영역에 적용할 계획입니다.

### 4-1. 절차적 아이템 서사 생성 (VARCO LLM) — 최우선

ECHORIS의 모든 장비는 "에코", 즉 잊힌 자가 무기에 남긴 마지막 한 마디입니다. 아이템계는 그 기억의 내부 공간입니다. 절차적으로 등장하는 수많은 장비 각각에 고유한 짧은 서사를 부여해야 하는데, 이는 1인 수작업으로는 불가능한 분량입니다.

- 아이템별 에코 서사(마지막 한 마디·기억 단편) 생성
- 거주자(Resident) NPC 대사, 인덱서(Indexer)의 영창 등 환경 서사 텍스트 생성
- 아이템 속성/레어리티/테마(11종 아이템계 테마)를 조건으로 한 맥락 일관 서사 생성
- 세계관 정합성(sci-fi 메가스트럭처 톤, 금지 어휘 가드)을 프롬프트 규칙으로 통제

### 4-2. 비주얼 컨셉·에셋 생성 (VARCO Image)

이미 생성형 이미지 파이프라인으로 패럴랙스 배경과 컨셉을 제작 중이며, VARCO Image로 일관된 아트 디렉션 하에 확장할 계획입니다.

- 메가 스트럭처 배경/패럴랙스 레이어
- 무기·방어구·아이템 아이콘, 적·보스 컨셉 시안
- 아이템계 테마별 데코레이션 컨셉

### 4-3. (확장) 행동·대사 다양화

- 적/보스 행동 패턴 변주 및 조우별 짧은 반응 텍스트
- 멀티플레이 아이템계의 적응형 연출 텍스트

## 5. 기대 효과

- 1인 체제에서 절차적 콘텐츠(아이템 서사)의 분량 한계를 돌파해 정식 출시 볼륨 확보
- 세계관 일관성을 유지한 대규모 텍스트·비주얼 자산을 빠르게 생성
- 무한 파밍 구조의 핵심 매력(매 아이템이 고유한 기억을 가짐)을 실제 콘텐츠로 구현
