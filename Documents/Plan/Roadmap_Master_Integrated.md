## 0. 이 문서의 목적

ECHORIS는 코드, 내러티브, 문서 세 축이 서로 다른 속도로 전진해 왔다. 코드는 stale 문서가 기록한 "Phase 1 프로토타입"을 이미 추월했고, 내러티브는 2026-05-28 전면 archive 후 재정의 라운드 중이며, 문서 인덱스는 38/78 완료에서 정체되어 있다. 본 로드맵은 세 축을 하나의 진행 기준선으로 묶어, 데모 공개(Build 3)까지의 장기 경로를 단일 SSoT로 제시한다.

## 2. 3축 통합 원칙

1. 코드가 SSoT를 추월한 경우, 문서를 코드에 맞춰 갱신한다(역방향 동기화). 단 수치 SSoT는 항상 CSV가 권위.
2. 내러티브 캐논은 코드 배선의 선행 의존이다. 캐논 미확정 상태에서 대사/서사를 코드에 하드코딩하지 않는다.
3. 모든 플레이어 노출 문자열은 `Sheets/Content_Localization.csv` 선등록 후 키 참조.
4. 각 Build는 독립적 성취 단위다. 번아웃 방어를 위해 빌드마다 "완성"을 체감할 수 있게 닫는다.
5. 신규 시스템 추가는 "이것이 아이템계 경험을 강화하는가?" 스파이크 검증 통과 시에만.

## 3. 장기 로드맵 개요

```
[현재]        Build 0          Build 1         Build 2          Build 3
프로토타입     내부 수직슬라이스  지인 테스트      클로즈드 알파     퍼블릭 데모
세 축 분기     세 축 정렬         폴리시+온보딩    콘텐츠 확장       최적화+i18n
              =Phase 1 종결      =Phase 2 진입    =Phase 2 종결     =Phase 3 진입
```

Phase 정의는 CLAUDE.md 기준을 따른다. Phase 1(프로토타입) 종결 = Build 0 통과. Phase 2(알파) = Build 1-2. Phase 3(베타) = Build 3 + 멀티플레이.
