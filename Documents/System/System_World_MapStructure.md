## 1. 개요

### 1.1 설계 의도

ECHORIS 의 월드는 빌더가 끝없이 짓는 메가 스트럭처다. 백업으로 깨어난 에르다는 가장 깊은 바닥(침수 바닥층) 에서 정상(관제정) 을 향해 기어오른다. 단조로운 상승을 피하기 위해 중반에 한 번 급강하(환승역 붕괴 → 봉인된 하부) 하고, 누적된 능력으로 다시 급상승한다. (거시 철학은 D-20 §2.)

본 문서는 이 구조를 토폴로지 그래프로 명세한다 — 노드 연결, 격벽 위치, Critical Path, 난이도 곡선, 보상·단서 배치. 구역의 정체·서브 바이옴·보스·동료 에코는 SYS-WLD-02 가 SSoT.

### 1.2 두 수직 축 (혼동 주의)

월드 탐험 = 상승(메가 스트럭처를 기어오름). 아이템계 다이브 = 하강(에코 안 기억으로). 본 문서는 월드 상승 토폴로지만 다룬다.

## 2. 토폴로지 (Topology)

### 2.1 상승 그래프 + 급강하/급상승

```
  ═══ [정상 — 관제정 / Z7] ═══  ⌖ 클라이맥스. 빈 옥좌
        ▲  대격벽: 누적 렐릭 최종 게이트 → 역방향 구간 (SotN 역전 성 변형)
  [대 안치소 / Z6]  (인덱서 가짜 송신소. 묵정 대면)
        ▲  재상승 경로 (게이트 아님). 공명 펄스·빌더 제어 노드 획득
  [봉인된 하부 / Z5]  ⌖ 최저점. 급강하 착지
        ▲  격벽 ④: 이단 점프 + 극성 부츠 (Z5 보스 보상)
        ⤓  급강하 (환승역 붕괴 → 하부 추락)
  [무너진 환승역 / Z4]  ── 상승 정점
        ▲  격벽 ③: INT 스탯 게이트 (도면 봉인 해제)
  [거대 공장층 / Z3]
        ▲  격벽 ②: 벽 타기 + ATK 스탯 게이트 (시공 단위 파괴)
  [무너진 거주 구역 / Z2]  ← 마을 거점 (단조소)
        ▲  격벽 ①: 대시
  [침수 바닥층 / Z1]  ← 게임 시작. 백업 기상
```

구조 설명:

- 수직 축 (상승): Z1 → Z2 → Z3 → Z4 → [급강하] → Z5 → Z6 → Z7. 격벽이 각 경계를 막고, 능력·스탯 게이트로 돌파.
- 급강하 분기: Z4 정점에서 붕괴로 Z5(미답 심부) 로 추락. 새 탐험 강제. (트리거: D-20/SYS-WLD-02 §2.5, 확정 대기.)
- 급상승: Z5 에서 이단 점프·극성 부츠 획득 → Z6 → Z7 재상승. 누적 렐릭 최종 게이트 돌파 후 역방향 구간 개방(SotN 역전 성 변형).
- 횡방향 가지: 각 구역 내부는 좌우 메트로베니아 가지. 잠긴 가지는 이후 능력으로 백트랙 해금.

### 2.2 백트랙 해금 (Backtrack)

| 능력 | 백트랙 대상 |
| :--- | :--- |
| 수중 호흡 (Z1) | Z1 침수 바닥 깊은 갱도 — 비밀·동료 단서 |
| 누적 렐릭 최종 게이트 (Z7) | 전 구역 역방향 가지 — 엔드게임 수집 |
| 이단 점프 (Z5) | Z2~Z4 높은 단차 가지 |
| 반중력 (Z2) | 부유 컨테이너·역류 유체 잠긴 가지 |

수직성 노출(RES-MV-WT-01 §3.3, Ender Lilies) — 상승 중 위/아래의 도달 불가 지점을 시야에 미리 보여 백트랙 욕망을 키운다.

## 3. 격벽 연결 규칙 (Bulkhead Connectivity)

| 격벽 | 위치 | 진입 조건 | 보스 보상 |
| :---: | :--- | :--- | :--- |
| ① | Z1→Z2 또는 Z2 초입 | 대시 | — (초반 렐릭) |
| ② | Z2→Z3 | 벽 타기 + ATK 스탯 게이트 | Z3 메카 보스 |
| ③ | Z3→Z4 | INT 스탯 게이트 | Z4 대형 말소자 |
| 급강하 | Z4→Z5 | (붕괴, 게이트 아님) | — |
| ④ | Z5 내부·상행 | 이단 점프 + 극성 부츠 | Z5 망각형 보스 |
| 대격벽 | Z6→Z7 / 역방향 | 누적 렐릭 최종 게이트 | Z7 prime |

핵심 — 능력 렐릭(출시 캐논 11종, D-20 §4.2 / PLN-RELIC) 은 월드 전용 획득(파밍 불가). ATK/INT 스탯 게이트만 아이템계 강화로 돌파 → 월드 ↔ 아이템계 순환 동력(D-20 §8). 격벽이 물리 구조로 게이트를 정당화한다.

## 4. Critical Path 정의

```
[Z1 침수 바닥 — 백업 기상] → 첫 포지 다이브(러스트본) → 마을(Z2)
  → 대시 → [Z2] → 벽타기+ATK → [Z3] → INT → [Z4 정점]
  → ⤓ 급강하 → [Z5 봉인된 하부 — 최저점]
  → 이단점프+극성부츠(Z5 보스) → [Z6 대 안치소 — 묵정·반전]
  → 누적 렐릭 최종 게이트(Z7 보스) → [Z7 관제정 — 빈 옥좌] → 결말 분기
```

설계 원칙:

- Critical Path 는 항상 통과 가능(Always Winnable, SYS-WLD-05). 급강하·재상승 경로는 핸드크래프트 고정.
- 시놉시스 정합: 마을(Z2)·이리 Midpoint(Z4)·급강하 All Is Lost·묵정 안치소(Z6 반전)·결말 정상(Z7).
- 스탯 게이트(②③) 는 아이템계 강화 없이 통과 불가 — 순환을 강제. 능력 게이트는 월드 보스 처치로만.

## 5. 난이도 곡선 (Difficulty Curve)

| 구역 | 난이도(1-5) | 곡선 위치 |
| :--- | :---: | :--- |
| Z1 침수 바닥 | 1 | 입문·튜토리얼 |
| Z2 거주 | 2 | 상승 초반 |
| Z3 공장 | 3 | 상승 중반 (첫 스탯 게이트 벽) |
| Z4 환승역 | 3.5 | 상승 정점 |
| Z5 봉인된 하부 | 5 | 급강하 직후 최고 위협 (코스믹 호러 절정) |
| Z6 대 안치소 | 4 | 재상승 (묵정 반전) |
| Z7 관제정 | 5 | 최종 |

급강하 직후 Z5 가 난이도 최고점 — 정서적 바닥(상실) + 기계적 최고 위협(말소자 출몰) 이 겹친다. 재상승은 이단 점프 획득으로 기동성 해방되며 난이도 체감 완화.

## 6. 단서 trail 배치 (Clue Trail)

선택적 발견 단서를 두 trail 로 구성한다(구 마르타 흔적 trail 폐기·대체, D-20 §10):

| trail | 내용 | 배치 |
| :--- | :--- | :--- |
| 동료 에코 trail | 흩어진 실험 팀(러스트본·이름없는 동료·이리) 점진 재회 | SYS-WLD-02 §5 (Z1·Z3·Z4) |
| 관리 권위 단서 trail | Cascade·관리 권위의 정체 조각 (코스믹 호러 점진 발견) | 심부일수록 집중 (Z5·Z7). Critical Path 밖 |

설계 원칙:

- Critical Path 에 배치하지 않는다(선택적 발견).
- 발견 순서 무관, 각 단서 독립 의미.
- 단서는 환경 서사·검 음성으로만 전달. 정보 덤프 금지(신파 차단 #4).
- 관리 권위 단서는 모아도 진짜 원인을 밝히지 않는다 — 불가지 보존(코스믹 호러, 가이드 §14.2).

## 7. 귀환·빠른 이동

- 마을(Z2) 즉시 귀환 — 각 구역 세이브 포인트·포지에서. 물리 역등반 불필요.
- 도달한 격벽 앞 빠른 이동 지점 자동 활성화.
- 급강하 후 봉인된 하부(Z5) 에서도 귀환 가능(고립감은 연출로, 기능은 보장).
