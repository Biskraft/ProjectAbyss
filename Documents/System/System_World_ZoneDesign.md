## 1. 개요

본 문서는 D-20 의 7구역(상승 주축 + 급강하/급상승) 을 플레이 가능한 단위로 상세화한다. 거시 구조·톤·게이트 철학은 D-20 이 SSoT. 본 문서는 구역마다 (a) 서브 바이옴 2-3, (b) 게이트 위치, (c) 보스, (d) 동료 에코, (e) 핸드크래프트 랜드마크, (f) 내러티브 비트, (g) 말소자 결을 정의한다.

상승 순서: 침수 바닥층(1) → 무너진 거주 구역(2) → 거대 공장층(3) → 무너진 환승역(4) → [급강하] → 봉인된 하부(5) → 대 안치소(6) → 정상 관제정(7).

## 2. 7구역 상세

### 2.1 침수 바닥층 (Zone 1) — 시작

| 항목 | 내용 |
| :--- | :--- |
| 정체 | 가라앉은 옛 도시 최하층 + 시공 멈춘 녹슨 격자. 백업이 깨어나는 곳 |
| 서브 바이옴 | (a) 완전 침수 갱도 (b) 물 빠진 폐기물 처리장 (c) 녹슨 격자 수면 위 |
| 게이트 | 입문(없음). 깊은 침수 갱도는 수중 호흡 획득 후 재방문(후반 백트랙) |
| 보스 | 미니 — 부패 말소자 (대형 슬라임형). 전투 튜토리얼 마무리 |
| 동료 에코 | 시작 검 = 러스트본 (첫 포지 다이브에서 재회, [7]) |
| 랜드마크 | 깨어남 지점(시체 더미=이전 복원 잔해), 첫 고장 빌더(포지=첫 다이브) |
| 내러티브 | 시놉시스 [1]~[3]. 백업 기상, 표면 한 마디 "나도 들리고 싶었어" |
| 말소자 결 | 부패형(형체 무너진 말단). 증오 없는 절멸 첫 체감 |

### 2.2 무너진 거주 구역 (Zone 2) — 마을 거점

| 항목 | 내용 |
| :--- | :--- |
| 정체 | 무너진 아파트·골목·간판 + 거주 사이로 자란 시공 단위. 잔존자 거점 |
| 서브 바이옴 | (a) 무너진 아파트 협곡 (b) 좁은 시장 골목 (c) 시공 단위 관통 거주동 |
| 게이트 | 대시 (시작 보유, 콤보 후딜 캔슬·좁은 간격) + 반중력 (부유 컨테이너 발판·역류 유체 수위) |
| 보스 | 말소자 수호형 (중) — 마을 외곽을 배회. 처치 = 거주 구역 안정 |
| 동료 에코 | — (잔존자 NPC 노다·율 거주, 동료 에코 아님) |
| 랜드마크 | 단조소 마을(세이브·상점·노다·율), 마을 입구 식은 죽 자리 |
| 내러티브 | 시놉시스 [3]~[5]. 마을 정, 율의 검 음성 따라 부르기, Catalyst(시공 광원 접근) |
| 말소자 결 | 수호형(느리고 집요) |

### 2.3 거대 공장층 (Zone 3)

| 항목 | 내용 |
| :--- | :--- |
| 정체 | 옛 제철소 위에 덮인 빌더 작업장 + 활성 조립 라인 |
| 서브 바이옴 | (a) 정지한 조립 라인 (b) 활성 용광로(시공 광원 hazard) (c) 컨베이어 수직 통로 |
| 게이트 | 벽 점프 (수직 통로) + 자기 점착 클램프(빌더 — 빌더 표피 등반) + ATK 스탯 게이트 (금 간 시공 단위 파괴 — 첫 아이템계 순환 동력) |
| 보스 | 침입형 메카 (boss_01 계열) — 단일 광원, 무감정 추적. 벽 점프/ATK 게이트 수호 |
| 동료 에코 | 이름 없는 동료 (중반 다이브 — 흩어진 팀의 두 번째 재회) |
| 랜드마크 | 거대 용광로(시공 광원 hazard), 움직이는 빌더 등(박자 동기화 진입) |
| 내러티브 | 시놉시스 [8] Fun & Games. 다이브 사이클, 누적, 녹쇠 1-3단계 |
| 말소자 결 | 침입형(공격적 메카) |

### 2.4 무너진 환승역 (Zone 4) — 상승 정점

| 항목 | 내용 |
| :--- | :--- |
| 정체 | 반쯤 묻힌 대합실·승강장 + 시공 관통 거대 홀 |
| 서브 바이옴 | (a) 거대 대합실 (b) 침수 승강장 (c) 끊긴 선로 외벽 |
| 게이트 | 역류의 쇄도(surge — 높은 공동 상승) + INT 스탯 게이트 (도면 잠금 해제 — 봉인 문) |
| 보스 | 대형 말소자 — 상승 정점 보스. 처치 직후 급강하 트리거 |
| 동료 에코 | 이리 (Midpoint [9] "낯선 검" — 등재 택한 동료 backup. "나는 너를 미워했다") |
| 랜드마크 | 거대 대합실(광활 노출), 붕괴 지점(급강하 발생) |
| 내러티브 | 시놉시스 [9] Midpoint. 이리 발견, 시공 박자 가속(글로벌 시한) |
| 말소자 결 | 대형 단일 유닛 |

### 2.5 [급강하] — 환승역 붕괴

상승 정점에서 환승역이 붕괴(트리거 결정 필요 — Q 참조) → 봉인된 하부로 추락. 추락 비트에서 추락의 영혼(diveAttack) 렐릭 획득 — 하방 층 관통. 시놉시스 All Is Lost([11]) 와 결합 — 마을 상실·율 끌려감의 정서적 바닥.

### 2.6 봉인된 하부 (Zone 5) — 최저점

| 항목 | 내용 |
| :--- | :--- |
| 정체 | 봉인된 옛 격리 시설 + 가장 오래된 빌더 핵. 한번도 못 간 심부 |
| 서브 바이옴 | (a) 격리 감방동 (b) 가장 오래된 빌더 핵 (c) 말소자 침식 글리치 구역 |

## 3. 게이트·렐릭 상승 진행표 (Always Winnable)

| 순서 | 구역 | 획득/돌파 | 여는 것 |
| :---: | :--- | :--- | :--- |
| 1 | 거주(2) | 대시 (시작 보유) | 좁은 간격, 콤보 캔슬 |
| 2 | 거주(2) | 반중력 | 부유 컨테이너 발판 + 역류 유체 수위 |
| 3 | 공장(3) | 벽 점프 · 자기 점착 클램프(빌더) | 수직 통로 / 빌더 표피 등반 |
| 4 | 공장(3) | ATK 스탯 게이트 | 시공 단위 파괴 (아이템계 순환 시작) |
| 5 | 환승역(4) | 역류의 쇄도(surge) | 높은 공동 상승 (상승 정점) |
| 6 | 환승역(4) | INT 스탯 게이트 | 도면 봉인 해제 |
| — | [급강하] | 추락의 영혼(diveAttack) | 하방 층 관통 — 봉인된 하부 추락 |
| 7 | 하부(5) | 이단 점프 (보스) · 극성 부츠(빌더) | 높은 단차 — 재상승 시작 / 빌더 금속 천장 보행 |
| 8 | 하부(5) | 수중 호흡 | 침수 바닥(1) 깊은 갱도 백트랙 |
| 9 | 안치소(6) | 공명 펄스(빌더) · 빌더 제어 노드(빌더) | 그리드 한 박자 정지 횡단 / 구조 재편 재상승 |
| 10 | 정상(7) | (누적 렐릭 최종 게이트) | 종착 — 결말 분기 |

핵심 — 코어 렐릭(대시·벽 점프·수중 호흡·surge·diveAttack·이단 점프)과 빌더 전용 4종(자기 점착 클램프·극성 부츠·공명 펄스·빌더 제어 노드)은 월드 전용 획득(파밍 불가). ATK/INT 스탯 게이트는 아이템계 강화로 돌파(순환 동력). diveAttack/이단점프/수중호흡은 급강하 이후 재상승의 추진력. 빌더 전용 4종은 거인-형 빌더 조우를 Critical Path 에 고정한다(M-BUILDER). 렐릭 정의 SSoT = `Plan/Spec/Spec_Relic_Catalog.md` (PLN-RELIC). 모든 게이트는 SYS-WLD-05 Always Winnable 보장.
