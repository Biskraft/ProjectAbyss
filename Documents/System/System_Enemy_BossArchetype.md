## 1. 설계 원칙 (Design Principles)

> §7(구 SYS-ENM-ARC)에서 이관. 보스 분류의 공통 전제.

### 1.1. 보스 = 아키타입 매시업 + 위상 전환

보스는 새로운 행동 유형을 발명하지 않는다. 기본 몹 아키타입의 핵심 행동 2-3개를 하나의 개체에 통합하고, **위상(Phase) 전환**이라는 고유 메커닉을 추가한다. 보스가 특정 아키타입 모드일 때 그 아키타입의 **약점이 그대로 계승**된다.

### 1.2. 처벌 윈도우 보장

모든 보스 패턴은 Tell(예고) → Action(행동) → Recovery(경직) 구조를 따르며, Recovery는 최소 500ms를 보장한다. 이 구간이 "무기 패시브가 빛나는 순간"이다.

```
Tell      Action     Recovery
 |           |          |
 v           v          v
[예고 3-6f] [공격 수행] [경직 8-16f = 패시브 검증 윈도우]
```

### 2.3. 절차 생성 레이어 (아이템계 보스 — Procedural Layer)

> 아이템계 보스("기억의 문")는 **각 아이템이 외형·약점이 다른 보스를 절차 생성**한다. 근거 역기획서: `Documents/Research/ProceduralBoss_ReverseGDD_Research.md` (Warframe Lich · Nemesis · DF Forgotten Beast 3종 병렬 역분석 종합). 월드 보스(핸드크래프트)와 달리 아이템계 보스에만 적용.

**생성 공식:**
```
아이템계 보스 = [시드 = 아이템]
  × [마스터 키 = 속성(fluid)]        ← 색·VFX·면역·약점·죽음 연출 파생
  × [형태 F1~F7]                      ← 기본 실루엣 풀(§2.2)
  × [무기 카테고리 본체 템플릿]        ← IWB-10-A
  × [레어리티 = trait 예산 + 약점 단계 깊이]
```

**3대 불변식 (공정성):**
1. **보상은 조준 가능, 약점은 블라인드.** 플레이어는 어느 아이템이 걸렸는지 *보고* 도전. RNG는 도전 축에만.
2. **약점 ≥1 보장 + 면역은 경직/스턴 중 일시 해제.** 무작위 면역이 막다른 길이 되지 않음.
3. **약점은 추론된다.** 속성색 오라 + 생성 설명문 + 전투 피드백(올바른 단계 시 보스 경직).

**핵심 정합 — 속성 = 약점 엔진(0비용):** 보스의 *본체 재질 = 속성(fluid)* 으로 두면, **이미 구현된 `Design_ChemicalReactions_FullMatrix.md`가 약점 데이터를 자동 제공**한다(magma→water/cyro 취약, oil→charged/magma 점화, charged→water 전도). 보스별 약점 수기 정의 불필요. 자해 루프(oil 보스가 자기 슬릭 점화 등)는 아레나 퍼즐이 된다.

**처치 = 전리품:** 처치 시 *그 아이템* 강화·접사 확정(보스 = the loot). 선택적으로 보스 강점 1개를 아이템에 각인. 살려보내면 그 아이템의 보스가 흉터·레벨업·약점1 제거로 재등장(per-item 기억).

## 3. 보스 패턴 아키타입 (Boss Pattern Archetypes)

## 4. 위상 전환 + 약점 계승 (Phase & Weakness)

> §7(구 SYS-ENM-ARC)에서 이관.

**위상 전환:** 보스는 HP 임계값에 따라 아키타입 행동 모드를 전환한다.

```
예시: 아이템 왕 (Rare 보스)
  Phase 1 (HP 100-60%): Charger 모드 — 직선 추적 + 근접 콤보
  Phase 2 (HP 60-30%):  Sentinel 모드 — 후퇴 + 투사체 연사
  Phase 3 (HP 30-0%):   Charger+Sentinel 동시 — 추적하며 투사체 발사
```

**약점 계승:** 보스가 특정 아키타입 모드일 때 그 약점이 적용된다.
- Charger 모드: 배후 노출 (A축)
- Sentinel 모드: 이동으로 회피 (F축)
- Shielder 모드: 정면 방어 (관통/배후 필요)
- Flier 모드: 공중 체류 (리치/원거리 필요)

## 5. 보스별 구성 예시 (Seed Examples)

> §7.4에서 이관. 시드 — 정식 인스턴스는 각 보스 인스턴스 문서에서 확정.

#### 아이템 장군 (Item General) — Boss01 확장

```
기본 아키타입: Charger + Sentinel

Phase 1 (HP 100-50%): Charger 주도
  - 직선 추적 → Swipe(근접 스윙)
  - 가끔 후퇴 → 단발 투사체 1회 (Sentinel 전조)

Phase 2 (HP 50-0%): Enrage + Charger-Sentinel 혼합
  - Charge(돌진) 후 정지 → 투사체 3연발
  - Slam(점프 슬램) 착지 시 충격파 + 방사형 투사체 4발
  - Attack Cooldown x0.6

검증 축: A(돌진 후 배후 노출), E(Recovery 윈도우에서 콤보 완성)
```

#### 아이템 왕 (Item King) — 신규

```
기본 아키타입: Shielder + Flier + Sentinel

Phase 1 (HP 100-60%): Shielder 주도 — 전면 방패 전진. 약점: 배후
Phase 2 (HP 60-30%):  Flier 전환 — 비행 + 급강하 x2. 약점: 착지 경직
Phase 3 (HP 30-0%):   Sentinel + Flier 혼합 — 체공 투사체 연사. 약점: 패턴 사이 윈도우

검증 축: A(배후) + F(이동/체공) + B(착지 경직 집중 타격)
```

#### 아이템 신 (Item God) — 신규

```
기본 아키타입: Charger + Shielder + Flier (3 아키타입 순환 전환)

Phase 1 (HP 100-66%): Charger
Phase 2 (HP 66-33%):  Shielder
Phase 3 (HP 33-0%):   Flier + 이전 Phase 패턴 랜덤 삽입

각 Phase 전환 시 rage_transition 연출(3f 무적 + 팔레트 전환)
검증 축: A+E+F (전환 패턴 읽기 + 즉시 대응)
```

#### 아이템 대신 (Item Great God) — 신규 (Ancient 심연 전용)

```
기본 아키타입: 다수 아키타입 행동을 Phase별로 전환

Phase 1: Charger + Swarmer (추적 + 소환물)
Phase 2: Shielder + Sentinel (방어 + 포격)
Phase 3: Flier + Bombardier (비행 + 범위 착탄)
Phase 4 (HP 10%): 전 Phase 패턴 무작위 혼합 + Attack Cooldown 최소

화면 절반 이상 차지하는 대형 보스. 야리코미 최종 도전. 전 축 종합 검증
```
