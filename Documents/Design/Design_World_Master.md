## 1. 월드 정체성 (v3)

> 월드는 빌더가 끝없이 짓는 거대 시공 구조물 — 메가 스트럭처 — 그 자체다. 수천 년 전 Cascade 이후 인간의 세계는 이 격자에 묻혔고, 빌더는 그 위에 끝없이 새 층을 쌓아 올렸다. 백업으로 가장 깊은 바닥에서 깨어난 에르다는 이 거대한 무관심의 구조물을 위로 기어오르며, 묻힌 옛 세계와 잊혀진 자들의 에코를 지나간다.

> 두 수직 축 (혼동 주의): 월드 탐험 = 상승(메가 스트럭처를 기어오름). 아이템계 다이브 = 하강(에코 안 기억의 깊이로 내려감). 두 축은 직교한다. 시놉시스의 "내려갈수록 깊은 기억" 은 다이브 축이며, 월드 공간 진행은 상승이다.

핵심 결:

- 톤: BLAME!/Biomega 식 산업적 거대 구조 + 코스믹 호러(빌더·말소자·관리 권위, 가이드 §14). RES-LMN-01 의 리미널은 가벼운 질감으로만.
- 스케일: 작은 에르다(32px) ↔ 거대 빌더(1:40). 수직 무한.
- 무관심: 빌더는 적의 없이 짓는다. 말소자는 증오 없이 지운다(미등재 절멸). 세계가 플레이어를 위해 존재하지 않는다.
- 솔로 고독: 월드는 혼자다. 잔존자 마을·인덱서 의례장에서만 사람을 만난다.

## 2. 거시 구조 — 상승 주축 + 급강하/급상승 리듬

플레이어는 가장 깊은 바닥에서 깨어나 위로 기어오른다. 단 단조로운 상승을 피하기 위해, 중반에 한 번 급강하(추락) 하고 다시 급상승하는 롤러코스터 리듬을 둔다. 허브(폐기) 대신 잔존자 마을이 거점.

```
   [정상 — 관제정 / the Crown]   ⌖ 클라이맥스. 빈 옥좌(부재의 관리 권위)
          ▲  (급상승: Act 3, 새 능력으로 빠르게 재상승)
   [대 안치소 / the Great Internment]   (인덱서의 가짜 송신소 — 닿지 않는 권위에게)
          ▲
   [봉인된 하부 / the Sealed Underworks]  ⌖ 최저점. 급강하로 떨어진 미답 심부 (Act 2 말 All Is Lost)
          ⤓  (급강하: 무너짐/추락으로 바닥까지)
   [무너진 환승역 / the Broken Concourse]  ── 상승의 정점 직전
          ▲
   [거대 공장층 / the Great Works]
          ▲
   [무너진 거주 구역 / the Collapsed Wards]  ← 잔존자 마을(단조소). 게임 초반 거점
          ▲
   [침수 바닥층 / the Drowned Floor]   ← 게임 시작. 백업으로 깨어나는 곳
```

리듬 설계 (3박자):

| 박자 | 구간 | 정서 곡선 | 시놉시스 정합 |
| :--- | :--- | :--- | :--- |
| 1. 점진적 상승 | 침수 바닥 → 환승역 (Act 1~2) | 성취·확장 — 위로 오를수록 시야·자유 확대 | Fun & Games |
| 2. 급강하 | 환승역에서 무너짐/추락 → 봉인된 하부 (Act 2 말) | 상실·무력 — 그동안 오른 것을 잃고 미답 심부로 | All Is Lost |
| 3. 급상승 | 봉인된 하부 → 대 안치소 → 정상 (Act 3) | 해방·돌파 — 누적된 능력으로 단숨에 재상승 | Finale |

설계 원칙:

- 상승이 주축 진행 — 바닥에서 깨어나 정상을 향함. "올라갈수록 시야가 트이고 진실에 가까워진다."
- 급강하 1회 — 단조로운 상승을 깨는 정서적 바닥. 추락이 미답 심부(봉인된 하부) 를 열어 새 탐험을 강제. 추락은 패배가 아니라 더 깊은 곳을 보게 하는 장치.
- 급상승 — 급강하에서 얻은 새 능력(역중력/이단 점프) 으로 이전 구간을 단숨에 역주파. 메트로베니아 역행의 카타르시스.
- 각 구역 내부는 횡방향 메트로베니아 가지 — 비선형 자유도(D-04).
- 구역 간 경계 = 격벽(Bulkhead). 능력·스탯 게이트로 돌파(§4).

> 저주받은 문제 — 단조로운 상승 vs 진행 명료성: 순수 상승은 단조롭다. 급강하 1회로 곡선을 꺾되, 추락 지점·재상승 경로는 핸드크래프트 고정해 혼란을 막는다. 급강하는 "길을 잃음" 이 아니라 "더 깊이 떨어져 새 길을 봄".

> 레퍼런스 검증 (RES-MV-WT-01): 상승 주축은 Hollow Knight: Silksong(바닥 거점 Bone Bottom → 정상 성채, "중력이 진척의 지표") 의 직접 선례로 장르적으로 정당하다. 하강 기본형(Hollow Knight) 은 아이템계 다이브가 담당. 수직성 노출(Ender Lilies — 위/아래 도달 불가 지점을 시야에 미리 보여줌) 을 상승 구간에 적용해 급강하/급상승 인지를 강화한다. 엔드게임 역방향은 월하의 야상곡 역전 성의 거울 효과 변형.

## 3. 구역(Zone) 체계 — 직관적 장소 + 세계관

> 설계 원칙: 추상 라벨("빌더 시공 전선") 대신 누구나 즉시 아는 장소(침수층·공장·환승역·대성당) 로. 메가 스트럭처는 옛 인간 세계를 묻고 그 위에 지어졌으므로, 각 구역 = 묻힌 옛 세계의 화석(직관적) + 빌더 시공물(이질적) 의 혼합. 직관성과 세계관을 동시에.

| 순서 | 구역 (직관적 정체) | 옛 세계 화석 | 빌더 시공물 | 정서 | 게이트 |
| :---: | :--- | :--- | :--- | :--- | :--- |
| 1 | 침수 바닥층 / the Drowned Floor | 반쯤 잠긴 옛 도시 최하층 | 시공이 멈춘 녹슨 격자 | 고립·혼란 (깨어남) | 입문(없음) |
| 2 | 무너진 거주 구역 / the Collapsed Wards | 무너진 아파트·골목·간판 | 거주 사이로 자란 시공 단위 | 정·향수 (마을 거점) | 대시 |
| 3 | 거대 공장층 / the Great Works | 옛 제철소 위에 덮인 | 활성 조립 라인·시공 광원 hazard | 경외·긴장 | 벽 타기 + ATK 게이트 |
| 4 | 무너진 환승역 / the Broken Concourse | 반쯤 묻힌 대합실·승강장 | 시공이 관통한 거대 홀 | 광활·불안 (상승 정점) | INT 게이트 |
| — | ⤓ 급강하 — 환승역 붕괴로 추락 | | | 상실 (All Is Lost) | — |
| 5 | 봉인된 하부 / the Sealed Underworks | 봉인된 옛 격리 시설 | 가장 오래된 빌더 핵 | 무력·공포 (말소자 출몰) | 이단 점프 / 역중력 |
| 6 | 대 안치소 / the Great Internment (Registry Sanctum) | 옛 대공회당·집회장 | 수직 안치 포드 열(산 얼굴) + 중앙 송신탑 | 신비·섬뜩 | (재상승 경로) |
| 7 | 정상 — 관제정 / the Crown (Empty Throne) | 옛 관제·통제 시설 | 진짜 관리 권위의 자리 — 텅 빔 | 불가지·종착 | 최종 게이트 |

> sci-fi 대성당 정합: 구역 6 은 고딕 돌 성당이 아니라 sci-fi 안치소다. 대성당의 본질(거대 수직·대칭·수직 광선·합창·경외) 은 유지하되 재질을 교체 — 벽 = 등재된 자들의 수직 안치 포드 열(살아있는 산 얼굴), 제단 = 부재의 관리 권위로 신호를 쏘는 중앙 송신탑, 수직 광선 = 그 송신 빔, 합창 = 닿지 않는 권위에게 보내는 송신 기도. 묵정의 "등재되어라" = "저 안치 포드 중 하나가 되어라".
> 권위 모티프 역할 분담: 안치소(6) = 인덱서가 만든 가짜 송신소(권위는 응답하지 않는다, 거짓 신앙). 정상 관제정(7) = 진짜 권위의 자리이나 텅 빈 옥좌(응답할 자가 처음부터 없었다). 거짓 교회 → 텅 빈 신의 옥좌 의 코스믹 호러 escalation.

각 구역 = 단순 배경이 아니라 v3 세계관의 한 단면. 핵심 랜드마크(보스방·마을·의례 대성당·동료 에코·서사 오브젝트)는 핸드크래프트 고정, Room 내부 Chunk 만 절차 변화(§7).

> 직관성 점검: 침수층/거주 폐허/공장/정거장/대성당/꼭대기 — 모두 플레이어가 한 단어로 즉시 그리는 장소. 그 위에 "옛 세계를 묻은 빌더의 시공물" 이라는 세계관 결이 얹혀, 익숙하되 이질적인 메가 스트럭처가 된다.

> 장르 어휘 검증 (RES-MV-WT-01 §5): ECHORIS 7 구역은 메트로베니아 핵심 구역 어휘(침수·도시폐허·산업·심부·신전·정상) 를 빠짐없이 커버한다. 빠진 어휘(화염·빙결·녹지) 는 판타지 색이라 의도적 배제 — 산업 메가 스트럭처로 통일.

### 3.1 서브 바이옴 — 단조로움 방지 (필수, Super Metroid 원칙)

> 핵심 위험: "전부 회색 산업" 의 단조로움. 해법(RES-MV-WT-01 §4.1, §6): Super Metroid 의 "테마 내 지역 다양성" — 각 구역을 단일 미감으로 평탄화하지 말고 2~3 서브 바이옴으로 분할. 같은 구역 테마를 공유하되 기하·조명·위협을 달리한다.

| 구역 | 서브 바이옴 (2~3) |
| :--- | :--- |
| 침수 바닥층 (the Drowned Floor) | 완전 침수 갱도 / 물 빠진 폐기물 처리장 / 녹슨 격자 수면 위 |
| 무너진 거주 구역 (the Collapsed Wards) | 무너진 아파트 협곡 / 좁은 시장 골목 / 시공 단위 관통 거주동 |
| 거대 공장층 (the Great Works) | 정지한 조립 라인 / 활성 용광로(시공 광원 hazard) / 컨베이어 수직 통로 |
| 무너진 환승역 (the Broken Concourse) | 거대 대합실 / 침수 승강장 / 끊긴 선로 외벽 |
| 봉인된 하부 (the Sealed Underworks) | 격리 감방동 / 가장 오래된 빌더 핵 / 말소자 침식 글리치 구역 |
| 대 안치소 (the Great Internment) | 안치 포드 본당 / 산 얼굴 포드 회랑 / 송신탑 제단부 |
| 정상 — 관제정 (the Crown) | 외부 노출 발판 / 관제 시설 내부 / 빈 옥좌의 방 |

서브 바이옴은 구역 가독성(RES-MV-WT-01 §4.2) 도 강화 — 톤·기하가 "여기가 어디고 무엇이 가능한가" 를 즉시 알린다.

## 4. 이중 게이트 — 스탯 + 능력

옛 6대 스탯 게이트(STR/INT/DEX/VIT/SPD/LCK) 폐기. ATK/INT 이중 + 능력 렐릭 5종으로 확정(CLAUDE.md, Glossary 정합).

### 4.1 스탯 게이트 (아이템계 순환의 동력)

| 스탯 | 게이트 | 메가 스트럭처 fiction |
| :--- | :--- | :--- |
| ATK | 물리 장벽 | 금이 간 시공 단위·바리케이드·봉인 격벽을 부숨 |
| INT | 마법 봉인 → 시공 봉인 | 빌더 봉인 문양·도면 잠금·아케인 잠금을 해제 |

핵심 — 장비를 아이템계에서 강화해 ATK/INT 를 올려야 격벽이 열린다. 이것이 월드 ↔ 아이템계 순환의 동력(§8).

### 4.2 능력 게이트 (렐릭 5종)

| 렐릭 | 해금 | 열리는 것 |
| :--- | :--- | :--- |
| 대시 (최초) | 폐 시설층 초반 | 콤보 후딜 캔슬, 좁은 간격 |
| 벽 타기 | 빌더 시공 전선 렐릭 | 수직 통로, 좁은 갱도 |
| 이단 점프 | 심층 보스 | 높은 단차 |
| 수중 호흡 | 특정 구역 렐릭 | 침수 구역 |
| 역중력 | 엔드게임 보스 | 반전 구역(역방향 상승) |

> 폐기: 안개 변신(2026-05-18, SotN Mist Form 카피 우려). 재도입 금지.

능력 게이트는 월드에서만 획득(파밍 불가). 스탯 게이트는 파밍으로 해결 — 두 게이트의 분리가 양쪽 콘텐츠를 모두 경험하게 만든다.

## 5. 거점·세이브·포지

허브(폐기) 대신:

| 요소 | 정의 |
| :--- | :--- |
| 잔존자 마을 (단조소) | 월드의 거점. 세이브·회복·잔존자 NPC(노다·율). 게임 시작점. |
| 세이브 포인트 | 마을 + 필드 산재. 대장간/상점 기능 통합(허브 폐기 대체). |
| 포지 (빌더 내부) | 아이템계 진입 장치. 빌더 내부에만 존재(고장 빌더 옆구리로 진입). 에코 격발 → 다이브(DES-IW-LMN-01, 야누스 문지방). |

빠른 이동 — 도달한 격벽 앞에 빠른 이동 지점. 깊은 층에서 마을까지 물리 역행 회피.

### 5.1 상점 공간 지정 (레퍼런스 패턴 A)

프리미엄 메트로베니아 12종 조사 결과, 지배적 상점 배치는 패턴 A — 세계 거점부 첫 안전 공간의 마을 + 소수 산재 상인이다(Hollow Knight 더트마우스, Bloodstained 아반트빌, Blasphemous 알베로, Ori 웰스프링 글레이즈, Afterimage Resting Town). 핵심은 거점이 별도 로딩 존이 아니라 세계 내 물리적 위치라는 점으로, ECHORIS의 "별도 허브 없음" 제약과 동일 조건이다.

> **지정:** ECHORIS의 상점 공간 = 잔존자 마을(단조소). 게임 초반 거점이며, 별도 로딩 없이 월드와 물리적으로 연결된 정착지.

| 요소 | 배치 | 레퍼런스 |
| :--- | :--- | :--- |
| 세이브 포인트 | 마을 내 + 필드 산재 (기물) | Bloodstained Save Room |
| 상점 NPC (상인) | 마을 집중, 세이브와 별개 기물 | 더트마우스 Sly/Iselda |
| 대장간 (강화/수리 = 골드 sink) | 마을 집중 | Aria of Sorrow Hammer |
| 산재 행상 | 중층·심층 세이브 인근 1-2인, 층위 특화 소모품 | Blasphemous 칸델라리아 |
| 포지 (아이템계 다이브) | 마을 아님 — 빌더 내부 산재 (§5) | ECHORIS 고유 |

설계 규칙:

- 세이브와 상점을 기능적으로 분리(별개 기물)해 거점 정서를 확보한다. 통합형(Ender Lilies)은 마을 애착이 약하다.
- NPC 이주: 심층에서 잔존자를 구출하거나 이벤트를 완료하면 해당 NPC가 마을로 귀환·정착한다. 마을이 점진 활성화되며 "탐험 → 구출 → 귀환" 순환과 결합한다(더트마우스/Afterimage 패턴).
- ECHORIS 고유 분리: 상점(골드 sink — 수리/복종/승급, D-07)은 마을 중앙집중, 다이브(포지)는 빌더 내부 산재. 상점 중앙집중 + 다이브 분산의 이중 구조가 양쪽 모두 귀환·순환 동기를 만든다.

## 6. 환경 위협 — 빌더·말소자

월드의 위협은 몬스터 처치가 아니라 거대 무관심의 구조다.

| 위협 | 정체 | 플레이 |
| :--- | :--- | :--- |
| 빌더 (이동) | 무의지 시공자. 적의 없음 | 시공 광원 = 데미지 지대. 움직이는 빌더 등에 매달려 박자 동기화로 진입(첫 30분 [7]) |
| 말소자 (the Eraser) | 미등재 절멸 시스템 | 몬스터 = 그 말단 개체(증오 없는 절멸, 코스믹). 대규모 출몰 = 후일 웨이브 디펜스 시스템(트리거 시) |
| 시공 갱신 | 메가 스트럭처가 자람 | 글로벌 시한(시놉시스 Midpoint 가속). 마을이 묻힐 시한 |

말소자 웨이브 디펜스(게임 디자인 우선, 후속) — 상시 추격이 아니라 깊은 침입·미등재 행위 트리거 시 절멸 웨이브. 메트로베니아 페이싱 숨 쉴 틈 보존.

## 7. 절차적 생성 (매크로 핸드크래프트 + 마이크로 절차)

| 계층 | 방식 |

## 8. 순환 구조 연결 (월드 ↔ 아이템계)

```
월드 탐험 → 에코(아이템) 획득 → 빌더 내부 포지에서 다이브
   → 아이템계에서 강화(ATK/INT↑) + 마지막 한 마디 회수
   → 월드 귀환 → 스탯 게이트 해금 → 더 깊은 층 하강
```

월드가 동기(격벽), 아이템계가 수단(강화). 두 공간이 순환으로 한 게임(D-02).
