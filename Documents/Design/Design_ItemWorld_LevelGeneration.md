# 아이템계 레벨 생성 — 쉬운 설명 + 확장 계획

> **이 문서의 목적:** (1) *지금* 아이템계 레벨이 어떻게 만들어지는지 코드를 몰라도 알 수 있게 설명한다. (2) [DIR-IWS-01](Design_ItemWorld_HookAndSpike.md) 방향("던전은 걸어 들어가고, 아이템 세계는 빠진다")을 위해 *무엇을 더해야 하는지* 자세히 적는다.
> 용어는 나올 때마다 풀어쓴다. 압축하지 않는다.
> **작성:** 2026-06-17.

---

## 먼저, 용어 3개만 풀어둔다

이 세 단어만 알면 아래 전부가 읽힌다.

- **씨앗(seed):** 계산의 출발 숫자. 같은 씨앗을 넣으면 *항상 똑같은 결과*가 나온다. 주사위를 굴리는 대신, "이 숫자로 시작해" 하고 정해두면 매번 같은 모양이 나오는 것. 우리 게임은 아이템마다 고유 번호(uid)가 있어서, 그 번호를 씨앗으로 쓴다. → **같은 아이템에 들어가면 항상 같은 세계가 나온다.**
- **템플릿(template):** 사람이 미리 손으로 그려둔 방 한 칸. 레고 블록처럼, 이 방들을 끼워 맞춰 던전을 만든다. 우리는 LDtk라는 에디터로 이 방들을 그려둔다.
- **원질(medium) / 유체(fluid):** 세계를 채운 물질 — 물, 마그마, 기름, 산성액, 냉기, 전기. 단순 배경이 아니라 실제로 작동한다(걸으면 느려지고, 데미지 주고, 기름+불=발화).

---

# 1부. 지금은 이렇게 만든다 (현재 시스템)

예시 하나를 끝까지 따라가자. **"불의 검"을 주워서, 열고, 들어간다.**

## 1-1. 같은 아이템 = 항상 같은 세계 (씨앗)

들어가는 순간, 게임은 그 검의 고유번호(uid)를 씨앗으로 삼는다. 이 씨앗으로 모든 걸 계산하니까, **이 검에 몇 번을 다시 들어가도 똑같은 세계**가 나온다. (다음에 또 와도 길이 바뀌지 않는다. 적만 다시 살아날 뿐.)

→ 이건 매우 중요하다. 우리 방향(DIR-IWS-01)의 "다시 올수록 그 세계를 더 또렷이 기억한다"가 성립하려면 *세계가 그대로 있어야* 하니까. 이미 그렇게 되어 있다.

## 1-2. 먼저 '방 배치도'를 그린다 (수직 다이브)

씨앗으로, 게임은 방들을 어떻게 놓을지 *배치도*부터 그린다. 지금은 모양이 딱 하나다 — **위에서 아래로 내려가는 한 줄기.**

```
   [입구 / 광장]        ← 맨 위, 여기 떨어진다
        │
       [방] ─ [곁방]
        │
       [방]
        │
       [방] ─ [곁방]
        │
     [보스 방]          ← 맨 아래, 보스를 잡으면 다음 층으로
```

가운데 세로줄이 *반드시 통하는 길*(크리티컬 패스)이고, 양옆 곁방은 선택(보너스). **막혀서 못 가는 경우는 설계상 없다.**

## 1-3. 각 칸에 '손으로 그린 방'을 끼운다 (템플릿)

배치도의 각 칸에, 미리 그려둔 방(템플릿) 중 *문 위치가 맞는 것*을 골라 끼운다. 방 한 칸은 48×32 타일(가로 48, 세로 32칸) 크기로 고정이다. 방 안의 지형, 발판, 함정은 전부 사람이 LDtk에서 직접 그려둔 것이라 품질이 보장된다.

→ 정리하면: **배치도는 컴퓨터가 자동(절차적), 방 속 내용은 사람이 수작업.** 이 둘을 섞은 게 지금 방식이다.

## 1-4. 물·마그마를 채운다 (유체 = 무기 따라 달라진다)

템플릿에는 "여기는 액체 자리"라고 *추상적으로만* 표시되어 있다(A/B/C 슬롯). 들어온 무기가 무엇이냐에 따라 그 액체가 *구체적으로* 정해진다.

- 불 계열(forge) 검 → 그 액체가 **마그마**
- 얼음 계열(iron) → **냉기물**
- 녹 계열(rust) → **산성액**
- 전기 계열(spark) → **전류**
- 그림자 계열(shadow) → **기름**

그리고 이 액체는 **장식이 아니다.** 실제로 — 걸으면 느려지거나 떠오르고, 데미지를 주고, 기름에 불이 붙는 식의 반응을 한다. 색과 분위기(팔레트)도 무기 테마에 맞춰 바뀐다.

> 참고: 우리가 예전에 손본 "유체 증발 연출"은 액체의 *시각 잔류물* 측면이었다. 세계를 채운 유체 *본체*는 위처럼 게임플레이에 관여한다. (둘은 별개다.)

## 1-5. 적·보물·기억방을 놓는다

- **적:** 방 템플릿에 사람이 직접 놓아둔 적이 있으면 그걸 쓰고, 없으면 규칙(역할 예산)으로 자동 배치한다.
- **보물:** 방마다 보물 표식(ItemSpawner)에서 골드/회복을 뿌린다.
- **기억방:** 무기별 사연이 담긴 특별한 방을, 층마다 하나씩 곁가지에 놓는다.

## 1-6. 층(지층)이 여러 개다

아이템 등급이 높을수록 층이 깊다(노멀 1~2층 … 에인션트 5~7층). 한 층의 보스를 잡으면 아래로 내려가는 문이 열리고, 다음 층이 같은 방식으로 만들어진다.

## 1부 정리 — 지금도 꽤 튼튼하다

| 항목 | 현재 상태 |
| :--- | :--- |
| 같은 아이템 = 같은 세계 | 이미 됨 (씨앗 결정론) |
| 길이 항상 통함 | 이미 됨 (크리티컬 패스) |
| 유체가 게임플레이에 관여 | 이미 됨 |
| 무기별 테마(유체+색) | 이미 됨 |
| 층 깊이 = 등급 | 이미 됨 |

**즉, 바닥은 이미 잘 깔려 있다. 새로 갈아엎을 필요가 없다.** 방향(DIR-IWS-01)을 위해 *위에 얹을* 것만 정하면 된다.

# 2부. 새 방향을 위해 더할 4가지

지금 *없는* 것 4가지다. 각각 **[지금은] → [이래야 한다] → [왜] → [어떻게]** 순서로 설명한다.

## 2-1. 풍덩 — "들어가는 순간"을 만든다

- **[지금은]** 광장 방에 플레이어가 *툭* 나타난다. 던전 문으로 걸어 들어가는 느낌.
- **[이래야 한다]** 무기를 열면 *떨어져서* 그 세계의 바다·심연으로 **빠진다.** 화면이 뒤집히고, 소리가 먹먹해지고, 원질에 풍덩.
- **[왜]** DIR-IWS-01의 1번 약속이자 가장 중요한 후크. "던전은 걸어 들어가고, 아이템 세계는 빠진다."
- **[어떻게]** 레벨 구조는 안 바꿔도 된다. 광장에 *나타나는* 그 자리에 **추락 연출**(낙하 애니메이션 + 카메라 워크 + 소리 먹먹 효과 + 원질 스플래시)을 씌우면 된다. → **가장 싸고, 임팩트가 가장 크다.** 먼저 만들 것.

## 2-2. 세계 모양 — 항상 수직 말고 다양하게

- **[지금은]** 모든 아이템계가 '위→아래 수직' 한 가지 모양.
- **[이래야 한다]** 물 아이템은 *트인 바다*, 미궁 아이템은 *꼬인 미로*, 허공 아이템은 *떠다니는 섬*… 원질마다 세계의 모양이 다르다.
- **[왜]** 10 캐논 다이브가 저마다 다른 모양을 요구한다(바다·미궁·수직 추락·빈 지평).
- **[어떻게 — 쉬운 길 먼저]** 새 배치도 엔진을 짜는 건 크고 위험하다. 그 전에, **방 템플릿을 다양하게 그려서 끼우는 것만으로** 체감이 크게 달라진다.
  - 예: 내부가 거의 다 물이고 벽이 적은 *'트인 바다 방'* 들을 만들어, 기존 수직 배치도에 끼운다 → "트인 바다를 내려가는" 느낌이 난다. **배치도 엔진은 그대로 두고 방 내용만 바꾸는 것.**
  - 진짜로 다른 모양(떠다니는 섬을 옆으로 건너기 등)만 나중에 배치도 엔진을 확장한다.
  - → **싼 것(템플릿 그리기) 먼저, 비싼 것(엔진 확장) 나중.**

## 2-3. 원더 — 다이브 도중 세계가 한 번 변한다

- **[지금은]** 한 층에 들어가면 나올 때까지 세계가 안 변한다. (층이 바뀔 때만 새로 만든다.)
- **[이래야 한다]** 다이브 *중간에* 한 번, 극적인 변화가 일어난다. 예: 물이 쫙 빠지며 아래 숨은 구조가 드러난다. 또는 기름 바다에 불이 붙어 불바다가 된다.
- **[중요]** 강제가 아니라 *기회*다. 안 일으켜도 깰 수 있어야 한다(퍼즐 자물쇠 금지).
- **[왜]** "이 세계는 어떻게 작동하지?"를 매번 새로 묻게 만드는 중층 후크. 던전이 식는 이유는 규칙이 늘 같아서다.
- **[어떻게]** 유체 시스템이 이미 있으니 **'물 빼기'가 가장 쉬운 첫 원더.** 특정 지점에 닿거나 무언가를 부수면, 유체 본체를 비워 아래를 드러낸다. 이게 곧 "잊힌 세계가 스스로를 기억해내는" 연출(memoryRecovery=빛)과 이어진다.

## 2-4. 코어 — 복원이냐 파괴냐

- **[지금은]** 맨 아래 보스를 잡으면, 아래로 내려가는 문(트랩도어)이 생긴다. 그게 끝.
- **[이래야 한다]** 맨 아래 **코어**에 닿으면 *선택*한다.
  - **복원** = 되살린다. 색·소리·빛·생명이 한 번에 돌아온다. 다음에 또 오면 세계가 더 밝다(누적). 정서: 증언, 돌려줌.
  - **파괴** = 부순다. 즉시 강한 보상 하나. 대신 그 세계는 끝난다(다시 못 봄). 정서: 안식, 끝냄.
- **[왜]** DIR-IWS-01의 4번 약속. 선택에 감정적 무게를 준다.
- **[어떻게]** 보스+트랩도어 자리를 *코어 + 선택*으로 바꾼다. 4감각 연출(색·소리·빛·생명)은 *이미 있는 시스템 재활용*: 팔레트=색, 유체=생명/개화, 라이팅=빛, 사운드.

## 그리고, 이 4가지를 잇는 '다리' — 아이템 → 세계 설정표

- **[지금은]** 게임이 아이템에서 *무기 종류 하나만* 본다(불검 → 마그마).
- **[이래야 한다]** 아이템의 여러 정보(무기 종류 + 기억회복도 + 정체성)를 보고, 세계의 여러 설정(모양 + 밝기 + 날씨 + 어떤 원더)을 한꺼번에 정한다.
- **[쉽게]** **"아이템을 넣으면 그 세계의 설정표가 나오는 변환기"** 하나를 만든다. 위 2-1 ~ 2-4가 전부 이 변환기를 공유한다. 설정표의 항목이 곧 [RES-IWS-03](../Research/Research_ItemWorld_WonderAxisSystem.md) 의 8개 축이다.
  - 예: 불의 검 → {모양: 마그마 바다, 밝기: 용암빛, 날씨: 잔열·재, 원더: 발화}.

# 3부. 그래서 뭘 먼저 만드나 (첫 시험판)

한 번에 다 만들지 않는다. **물 계열 아이템 하나 × 무기 두 종(불/얼음)** 으로 작은 시험판을 만든다.

들어갈 것:
1. **풍덩**(2-1) — 물에 빠지는 진입.
2. **트인 바다 방 몇 개**(2-2) — 새 템플릿 몇 장.
3. **물 빼기 원더**(2-3) — 중간에 물이 빠지며 아래가 드러남.
4. **코어 복원/파괴**(2-4) — 맨 아래 선택.

그리고 DIR-IWS-01 §8의 5가지 질문에 "그렇다"가 나오는지 본다:
1. 풍덩이 던전 문보다 자극적인가.
2. 같은 바다를 불 무기 / 얼음 무기로 *다르게* 푸는가.
3. 원더(물 빼기)가 자물쇠가 아니라 기회로 느껴지는가.
4. "다음 아이템 안엔 뭐가?"라는 호기심이 드는가.
5. 복원/파괴 선택이 마음에 남는가.

→ "그렇다"면 다른 원질·모양으로 확장. "아니다"면 축소하고 순수 액션으로 후퇴(바닥은 이미 튼튼하니 안전).

# 부록 — 개발자용 (코드 위치, 가볍게)

코드 모르면 건너뛰어도 된다. "어디를 손대는가"만.

| 무엇 | 현재 코드 위치 | 우리가 할 일 |
| :--- | :--- | :--- |
| 들어가는 순간 | `ItemWorldScene.ts` 진입(플레이어 스폰) | 풍덩 연출 추가(2-1) |
| 방 배치도 | `RoomGraph.ts` / `RoomGraphAdapter.ts` (수직 다이브) | 당분간 그대로. 모양은 템플릿으로(2-2) |
| 손제작 방 | LDtk + `ItemWorldTemplatePool.ts` / 픽커 | 원질별 새 템플릿 추가(2-2) |
| 유체 채우기 | `ItemWorldFluidMapping.ts` (무기→유체) | 변환기로 확장 + 물 빼기 원더(2-3) |
| 보스/출구 | 보스 처치 → 트랩도어 | 코어 복원/파괴로 교체(2-4) |
| 아이템→설정 | 지금은 무기 종류만 봄 | 8축 변환기 신설(다리) |

> 핵심: **갈아엎지 않는다. 이미 튼튼한 바닥 위에, 풍덩 → 모양 → 원더 → 코어 순으로 얹는다.**
