# DGN-MED-LIGHTNING — 번개 물리: 레벨 디자인 어휘 (스파이크 시범 케이스)

> **목적:** 한 물리(번개)를 끝까지 구체화해 스파이크("무기마다 물리가 바뀌고 레벨 디자인이 그 무대")의 시범 케이스로 세운다. §구조 = 모든 물리의 어휘 템플릿.
> **선정 근거:** *저작 비용 렌즈*(§0). 폭풍(바람)은 연속 힘이라 보류 — 번개는 단순 타이밍 + 기존 타일로 성립.
> **상위:** [Design_ItemWorld_RoomTemplates](Design_ItemWorld_RoomTemplates.md) · [RES-IWS-03](../Research/Research_ItemWorld_WonderAxisSystem.md)
> **작성:** 2026-06-19. (구 DGN-MED-STORM 대체 — 바람=연속힘=고비용으로 폐기, 상승기류만 잔존)

---

## §0. 왜 번개인가 — 저작 비용 렌즈

> **채택 원칙: 물리는 *정적 구역* 또는 *단순 타이밍 위험*으로 표현되는 것만 쓴다.** 그래야 레벨 디자인 = 평소 플랫포밍 실력 + 규칙 오버레이. *연속 힘*(바람)은 전 엔티티·투사체에 영향 + 배치마다 방향 튜닝이라 손이 너무 간다.

| 물리 | 표현 방식 | 비용 |
| :--- | :--- | :--- |
| 마그마 | 죽음 바닥 + 식은 지각 발판 (정적) | 쉬움 |
| 물 | 부력·유영 구역 (정적, `TILE_WATER` 존재) | 쉬움 |
| 산성 | DoT 구역 (정적, `TILE_ACID`) | 쉬움 |
| 기름 | 미끄럼 + 인화 (정적, `TILE_OIL`) | 쉬움 |
| 빙결 | 저마찰 (정적, `TILE_CYRO`) | 쉬움 |
| **번개** | **텔레그래프 전격 + 전도면 (단순 타이밍, 타일 존재)** | **쉬움–중간 ← 채택** |
| 바람/폭풍 | 연속 방향 힘 + 돌풍 (전 엔티티 영향, 배치 튜닝) | 어려움 → 보류 |
| 무중력 | 연속 중력 변경 | 중간–어려움 |
| 붕괴 | 연속 파괴 | 어려움 |

→ **쉬운 물리부터.** 번개·마그마·물이 1순위. 바람은 *상승기류 한 가지*만 잔존(아래 §2).

---

## §1. 핵심 법칙 (The Physics — 단순)

| 법칙 | 규칙 |
| :--- | :--- |
| **천둥번개(Strike)** | 지정 구역이 텔레그래프(~0.5–1s 경고 섬광) 후 *전격*. 주기 리듬(예: 3s) 또는 구역별 타이머. **이게 전부.** |
| **전도면(Conductor)** | 금속·물 위/안에 있으면 전격 시 *직격 구역 밖에서도* 감전. `TILE_METAL`·`TILE_WATER` 재사용. |
| **(선택) 상승기류** | 수직 바람 기둥(`TILE_UPDRAFT`)으로 상승. 폭풍에서 남긴 *유일한* 바람 요소. 정적 타일이라 저비용. |

연속 힘·풍향 없음. 플레이어는 *언제·어디가 안전한가*만 읽으면 됨.

---

## §2. 이동 동사 (Traversal Verbs)

1. **박자 횡단(Beat-cross):** 전격 텔레그래프를 보고 *안전 박자*에 이동. 타이밍이 곧 동선.
2. **전도면 회피:** 금속·물을 *밟지 않고* 우회(전격 박자에). 지형 읽기.
3. **(선택) 기류 상승:** 상승기류 기둥으로 큰 상승(사다리 대체 보조).

> 동사가 적고 단순 — 그래서 싸다. 깊이는 *배치(레벨)* 가 만든다.

---

## §3. 위험 (Hazards)

1. **전격 타격** — 텔레그래프 후 구역 감전. 타이밍 실패 = 피해.
2. **전도면 감전** — 금속·물 위에서 박자에 걸림(직격 아니어도).
3. **(조합) 물+번개** — 물 구역이 전도 → 침수 구간이 박자마다 위험지대.

---

## §4. 방 유형 (Room Types — 클래스 매핑)

| 번개 방 | 클래스 | 설계 핵심 |
| :--- | :--- | :--- |
| **박자 평원** | M-H / L-H | 텔레그래프 전격 패턴. 안전 박자에 횡단 + 박자 맞춰 전투 |
| **전도 미로** | M-V / S | 금속·물 바닥 사이 *비전도 발판*만 안전. 박자 + 경로 읽기 |
| **엄폐 회랑** | S / M-V | 전격 노출 구간과 안전 포켓의 교대 리듬 |
| **기류 상승실** | SHAFT / L-V | 상승기류로 오르되 *중간 전격 박자* 회피(선택 요소) |
| **고요실(눈)** | PLAZA | 전격 없는 안전 중심 / 보스 아레나 / 대비·휴식 |

---

## §5. 인카운터 패턴 (Combat)

1. **공유 전격** — 적·플레이어 모두 박자 회피. *적을 전격 구역·전도면으로 유인*.
2. **물+적** — 침수 구간에서 적과 싸우면 박자마다 양쪽 위험.
3. **번개 검 조합** — 검의 전격 동사로 *유인된 번개를 흡수·반사*(§6).

---

## §6. 로드아웃 × 물리 (디버는 *방문자*다)

> **다이브할 아이템은 앤빌에 *두고* 들어간다 — 그 무기를 들고 못 들어간다.** 번개 세계는 *당신의 다른 장비*로 정복하고, 그 정복으로 번개 아이템을 벼린다(디스가이아 방문자 모델). "번개 검으로 번개를 헤친다"는 성립하지 않는다.

- **소프트 매치업(하드락 금지):** 모든 로드아웃으로 클리어 가능, 단 일부가 번개 물리에 *더 맞음*.
  - 빠른·원거리 무기 = 박자 사이 타격에 유리.
  - 느린·중량 무기 = 전격 박자에 묶일 위험(긴장).
  - 전도면 활용형 = 적을 금속·물에 묶고 박자에 처형(보너스).
- **전략층:** "이 번개 세계엔 내 *어떤 장비*를 데려갈까"가 매 다이브의 선택. ([[RES-IWS-03]] Q-C 전부 허용 + 정의된 해소)

## §7. 시스템 매핑 (구현 그라운딩 — 거의 다 존재)

| 번개 요소 | 우리 시스템 | 상태 |
| :--- | :--- | :--- |
| 전도 DoT | **`TILE_CHARGED=8`(Thunder DoT) 존재** | ✅ 재사용 |
| 금속 전도체 | **`TILE_METAL=12`(Thunder conductor) 존재** | ✅ 재사용 |
| 물 전도 | **`TILE_WATER=2` 존재** | ✅ 재사용 |
| 상승기류 | **`TILE_UPDRAFT=4` 존재** | ✅ 재사용 |
| **텔레그래프 전격 타이밍** | 구역 + 경고 섬광 + 주기 타이머 | ⬜ **신규(유일)** |

> 신규 구현 = *타이밍 텔레그래프 전격 시스템 하나*. 나머지는 전부 기존 타일. 번개가 *싼* 이유.
> [Content_BiomeConfig](../../Sheets/Content_BiomeConfig.csv) 의 기존 `charged` 행을 이 번개 medium으로 확정(폭풍/바람 행 불필요).

---

## §8. 스파이크 테스트 (번개 합격선)

1. **타이밍이 곧 동선** — 전격 박자를 읽고 움직이는 게 핵심인가?
2. **전도면이 지형을 만드나** — 금속·물 배치가 안전/위험 경로를 가르나?
3. **무텍스트 만족** — 글 없이 *번개 박자를 마스터*하는 것만으로 만족스러운가?
4. **로드아웃 매치업** — 일부 장비가 번개 물리를 *더 잘* 다루나(소프트, 하드락 없이)?
5. **저비용 확인** — 신규 시스템 1개(텔레그래프) + 기존 타일로 한 지층이 서나?

통과하면 같은 §구조로 마그마·물(더 쉬움)을 찍어낸다.

---

## §9. 한 줄
> **번개는 단순 타이밍 위험이다 — 텔레그래프 후 전격, 금속·물이 전도. 연속 힘(바람) 없이, 기존 타일 + 신규 시스템 하나로 성립하고, 깊이는 *배치*가 만든다. 싸고 날카로운 물리.**
