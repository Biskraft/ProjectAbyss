# 아이템의 세계 — 몬스터·주민, 그리고 리미널 질감 (Item World Identity)

> 문서 ID: DES-IW-LMN-01 (v2)
> 작성: 2026-05-29 / v2 전면 개정 2026-05-29
> 정합: SYS-IW-01 아이템계 코어(DEC-046 인생 복원), SYS-IW-02 지층 생성, DEC-039 수직 딥 다이브 그래프, D-15 비주얼 디렉션, CNT-STR-001 시놉시스 v2, CNT-ECO-001 에코 배치, RES-LMN-01 리미널 전수조사(참고), 가이드 §9·§13·§14
> 성격: 아이템계의 정체성 통합 설계. 채택 시 SYS-IW-01/02 갱신.

> ★ v2 변경 (방향 전환): v1 은 아이템계를 "리미널 스페이스" 로 전면 재설계하여 전투/몬스터를 "응고된 감정" 으로 재프레임했다. 그러나 리미널의 핵심 공포는 대상 없는 불안(텅 빔·어긋남) 이며, 몬스터가 화면에 등장하는 순간 플레이어의 뇌가 "위협=처치 대상" 으로 전환되어 그 공포가 깨진다. 몬스터와 주민은 아이템계의 본질이므로 버릴 수 없다. 따라서 v2 는 리미널을 핵심 설계 드라이버에서 가벼운 질감("플레이어가 '이건 아이템의 세계다' 라고 느끼는 감각") 으로 대폭 축소하고, 아이템 세계 + 몬스터 + 주민을 다시 중심에 둔다.

---

## 0. 한 줄 정의

> 아이템계는 한 사람의 인생을 품은 살아있는 세계다. 플레이어는 장비 속으로 다이브하여, 그 세계에 사는 주민(기억된 사람들) 을 만나고, 그 세계를 위협하는 몬스터(부패한 기억) 와 싸우며, 끝내 그 사람의 마지막 한 마디(Memory Fragment) 를 회수한다.

핵심 플레이어 감각: "이건 던전이 아니라, 한 아이템의 세계다." 이 감각이 야리코미 동기를 감성으로 운반한다(DEC-046).

---

## 1. 핵심 원칙 — 리미널은 질감, 세계는 본체

### 1.1 리미널 대폭 축소

| 구분 | v1 (폐기) | v2 (채택) |
| :--- | :--- | :--- |
| 리미널의 위상 | 핵심 설계 드라이버 | 가벼운 분위기 질감 |
| 몬스터 | "응고된 감정" 으로 재프레임 (사실상 회피) | 정면 채택 — 명백한 적, 전투의 핵심 |
| 주민 | 거의 부재 (고독의 미학) | 정면 채택 — 세계를 살아있게 만드는 핵심 |
| 텅 빔 | 설계의 심장 | 드문 질감 양념 |
| 공포 | 대상 없는 리미널 공포 | 몬스터의 능동적 위협 + 약간의 이질감 |

### 1.2 리미널이 남기는 것 (RES-LMN-01 에서 가볍게 차용)

리미널 전수조사(RES-LMN-01) 는 폐기하지 않는다. 다만 적용을 "아이템 세계의 질감" 으로 한정한다:

- 장소 기억의 결 — 특정 사건이 아니라 한 사람의 삶의 패턴이 공간에 배어 있음 (§6.4).
- 꿈 논리의 약한 이질감 — 여기가 현실이 아니라 아이템 내부임을 알리는 미세한 어긋남.
- 척도와 깊이의 경이 — 작은 아이템 안에 거대한 세계가 있다는 BLAME!식 스케일.

이것들은 "공포를 만드는 장치" 가 아니라 "여기가 아이템의 세계임을 느끼게 하는 양념" 이다.

---

## 2. "아이템의 세계다" 감각 (The Item-World Feeling)

리미널에서 가져온 유일한 핵심 — 플레이어가 던전이 아니라 한 아이템의 내부 세계에 들어왔다고 느끼게 하는 장치.

| 장치 | 구현 |
| :--- | :--- |
| 진입의 경이 | 포지 격발 → 작은 검 한 자루 안으로 빨려 들어가 거대한 세계가 펼쳐짐. 스케일 대비(작은 아이템 → 거대 공동). |
| 세계의 일관된 결 | 각 아이템 세계는 그 주인의 삶을 반영한 통일된 톤(§5 감정 변주). 어부의 검 = 물·항구의 결, 병사의 검 = 참호·연기의 결. |
| 꿈 논리의 미세 이질감 | 가끔 비현실적 배치(공중에 뜬 계단, 끝나지 않는 복도) — 과하지 않게. "여기는 기억이지 현실이 아니다" 신호. |
| 주인의 흔적 | 세계 전체가 한 사람의 인생을 말한다 — 주민·소품·몬스터 모두 그 사람에게서 파생. |

핵심 — 이 감각은 텅 빔이 아니라 통일성에서 나온다. 던전이 무작위 조합처럼 보이면 "절차 생성" 으로 느껴지고, 한 사람의 세계처럼 통일되면 "아이템의 세계" 로 느껴진다. §5 감정 변주가 이 통일성의 엔진.

## 3. 몬스터 (Monsters) — 전투의 핵심

### 3.1 정체 — 부패한 기억

몬스터는 그 사람의 기억 중 부패하거나 잊혀져 적대적으로 변한 것. 단, "응고된 감정" 같은 추상이 아니라 명백히 싸우는 적으로 등장한다 — 플레이어는 망설임 없이 전투에 들어간다.

| 몬스터 결 | 정체 |
| :--- | :--- |
| 부패형 | 시간에 부식된 기억 — 형체가 무너진 적 (기존 슬라임·스켈레톤 자산 활용) |
| 침입형 | 빌더의 시공이 아이템 세계 내부까지 침식한 잔해 (boss_01 계열 메카) |
| 수호형 | 주인이 끝내 지키려던 것의 변질 — 미니보스급 |
| 망각형 | 잊혀짐 그 자체가 형체를 얻은 것 — 심층 전용 |

### 3.2 전투 = 야리코미 엔진 (복원)

v1 이 약화시킨 전투를 중심으로 되돌린다:

- 기존 전투 시스템(자동 콤보·대시·스킬 4슬롯) 전면 사용.
- 지층 깊이별 적 스케일링(IWC-09). 협동 인원 스케일링.
- 보상 — 아이템 EXP·HL·기억 단편. "한 층만 더" 의 파밍 추진력 유지.

### 3.3 보스 = 핵심 기억의 수호자

- 각 지층 보스(DEC-039 맨 아래) = 그 사람 인생의 핵심 장면을 지키는 존재.
- 최종 보스 처치 → 마지막 한 마디(Memory Fragment) 회수 → 검에 새김.
- 보스는 명백한 전투. 단, 처치 후 연출이 "이김" 이 아니라 "그 사람의 한 장면을 마침내 봄" 으로 마무리(내러티브 §7).

### 3.4 깊이 = 기억 깊이 (유지)

| 깊이 | 기억 단계 | 몬스터 |
| :--- | :--- | :--- |
| 표층 | 최근·선명한 기억 | 약한 부패형 |
| 중층 | 흐려지는 기억 | 침입형·수호형 |
| 심층 | 핵심·잊혀진 순간 | 망각형 + 핵심 보스 |

## 4. 주민 (Residents) — 세계를 살아있게

### 4.1 정체 — 기억된 사람들

주민은 그 아이템 주인이 인생에서 기억한 사람들이다. 주인의 기억 속에 사는 작은 공동체. 다이브할 때마다 한 사람의 인생뿐 아니라 그가 기억한 얼굴들을 만난다.

> 검 한 자루에 들어갔더니, 그 사람만이 아니라 그가 사랑했고 미워했고 그리워한 사람들이 작은 마을을 이루고 있다.

이것이 아이템계를 "텅 빈 던전" 이 아니라 "살아있는 세계" 로 만드는 핵심. (그림자 마을 개념의 NarrativeWorldReset 이후 신규 재정박 — archive 인용 아님.)

### 4.2 역할

| 기능 | 내용 |
| :--- | :--- |
| 안전지대 | 다이브 중 전투 없는 정착지(DEC-039 Plaza/Archive). 회복·검 음성 청취. |
| 맥락 제공 | 주민과의 짧은 대화가 주인의 인생을 다이제틱하게 전달(가이드 §9, 텍스트 덤프 회피). |
| 세계의 온기 | 케놉시아의 반대 — 사람이 사는 곳의 작은 활기. 리미널 불안의 균형추. |
| 주인 인생의 단서 | 주민들의 관계·반응이 주인이 누구였는지를 암시. |

### 4.3 주민의 결 (감정 변주 연동)

주인의 지배 감정(§5) 이 주민 공동체의 분위기를 결정:

- 그리움의 세계 — 주민들이 누군가를 기다리는 결.
- 원망의 세계 — 주민들이 서로 등 돌린 결.
- 평온의 세계 — 주민들이 조용히 일상을 사는 결.

같은 "마을" 이라도 아이템마다 다른 공동체. 300개 세계가 다른 사람들로 채워짐.

### 4.4 World 잔존자 마을과의 구별

| | World 단조소 마을 | 아이템계 주민 |
| :--- | :--- | :--- |
| 위치 | 메가 스트럭처 (현실) | 아이템 내부 (기억) |
| 정체 | 살아있는 잔존자 (노다·율 등) | 죽은 주인이 기억한 사람들 |
| 지속 | 영구 | 그 아이템 세계 한정 |

## 5. 키스톤 — 감정 구동 변주 (유지·재배치)

v1 의 가장 강한 부분. 단 적용 대상을 "텅 빈 공간의 톤" 에서 "세계 전체(몬스터+주민+팔레트)" 로 확장.

각 에코는 주인의 마지막 한 마디 감정(CNT-ECO-001 10종) 을 메타데이터로 갖고, 이것이 세계 전체를 결정:

| 감정 | 팔레트 | 주민 분위기 | 몬스터 편향 | 세계의 결 |
| :--- | :--- | :--- | :--- | :--- |
| 분노 | 청록+적열 | 다투는 | 공격적 부패형 | 부서진 항구·참호 |
| 후회 | 청록+회색 | 등 돌린 | 느린 수호형 | 되돌아가는 길 |
| 평온 | 청록+옅은 호박 | 일상적 | 적 희소 | 넓고 정돈된 |
| 그리움 | 청록+황혼 | 기다리는 | 다가오다 멈춤 | 열린 창·빈 의자 |
| 체념 | 탈색 청록 | 무기력한 | 약한 망각형 | 먼지·반복 |
| 원망 | 청록+탁한 자색 | 반목하는 | 집요한 추격 | 미로·닫힌 문 |
| 긍지 | 청록+금색 | 기리는 | 정면 대결 | 기념비적 |
| 수치 | 청록+짙은 그림자 | 숨는 | 기습형 | 가림막·틈 |
| 안도 | 청록+부드러운 빛 | 풀어진 | 비켜주는 | 출구가 보이는 |
| 공포 | 청록+명멸 | 겁먹은 | 예측 불가 출현 | 시야 차단 |

구현 — 에코 CSV 의 emotion 필드 1개가 팔레트 LUT·주민 대사 풀·몬스터 AI 프리셋·레이아웃 가중치를 선택. 같은 절차 시드라도 감정이 다르면 완전히 다른 세계. 이것이 300개 핸드크래프트의 환상.

## 6. 레벨 디자인 (Level Design)

### 6.1 마을 + 던전 구조 (복원)

아이템 세계 = 주민의 정착지(안전) + 부패한 기억의 던전(전투) 의 고전적 구조를 아이템 내부에 둔다:

| 구역 | 룸 타입(기존 6타입) | 역할 |
| :--- | :--- | :--- |
| 정착지 | Rest/Archive | 주민·안전·맥락 (DEC-039 Plaza) |
| 던전 | Combat | 몬스터·전투 (핵심) |
| 기억의 방 | Memory | 한 문장 회수 |
| 보물 | Treasure | 보상 |
| 비틀린 길 | Puzzle | 꿈 논리 이동 퍼즐(가벼운 리미널 질감) |
| 텅 빈 단면 | (드문) Empty | 아이템 세계의 이질감 양념 — 비율 낮게 |

v1 과 차이: Combat 룸이 다시 핵심, Empty 룸은 드문 양념으로 격하.

### 6.2 수직 딥 다이브 (DEC-039 유지)

- Plaza(맨 위, 주민 정착지) → 분기(던전) → Boss(맨 아래, 핵심 기억).
- 천장 부서짐으로 위 지층 노출 — 깊이의 시각화 + 아이템 세계의 거대 스케일감.
- Archive(분기 안전지대) 유지.

### 6.3 기억 깊이 그래디언트 (유지·완화)

내려갈수록 기억이 흐려지는 결은 유지하되, v1 의 "심층 = 완전 붕괴/글리치" 는 완화. 붕괴가 과하면 아이템 세계의 통일감(§2) 이 깨진다. 심층은 "오래되고 어둡고 위험한" 정도로, 위어드코어 글리치는 절제.

## 7. 내러티브 (Narrative — 가이드 §9, §13)

### 7.1 다이브 = 한 사람의 인생을 봄

- 표층(정착지) — 주인이 기억한 사람들을 만남. 그가 어떤 사람이었는지 단서.
- 던전 — 부패한 기억과 싸우며 깊이 내려감.
- 핵심 기억(보스) — 그 사람 인생의 결정적 장면. 처치 = 그 장면을 끝까지 봄.
- 마지막 한 마디 회수 — 한 문장(Memory Fragment), 검에 새김.

### 7.2 주민을 통한 환경 서사 (가이드 §9)

- 주민과의 짧은 대화(60자 이내) 가 주인의 인생을 다이제틱하게 운반. 텍스트 덤프 회피.
- 주민의 관계·반응이 주인의 감정(§5) 을 보여줌 — 말하지 않고 보여주기.

### 7.3 한정흥 — 다이브 한 회차

- 맺힘(주인의 미해결) → 풀이(던전 하강·전투) → 흥(한 문장 회수의 작은 해방).
- 야리코미 반복이 곧 위로의 반복.

### 7.4 침입이 아니라 방문

v1 의 "사적 기억 침입의 불안" 은 과한 리미널이었다. v2 — 주민이 있는 살아있는 세계를 방문하는 것에 가깝다. 불안보다 발견·만남의 정서.

## 8. 아트 디렉션 (D-15 정합)

| 요소 | 방향 |
| :--- | :--- |
| 아이템 세계 진입 | 작은 검 → 거대 세계의 스케일 대비(§2) |
