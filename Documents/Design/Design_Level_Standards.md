## 최상위 설계 원천 — 3축 이동 원칙 (Foundational Axiom)

> 본 절은 ECHORIS 모든 레벨·공간 설계의 **최상위 원천(root source)** 이다. 이하 §1 이후의 모든 규격·원칙·체크리스트는 이 3축에서 파생되며, 충돌 시 **본 절이 우선**한다.

ECHORIS의 모든 공간은 세 개의 이동 축 위에 놓인다. 각 공간은 자기 고유의 **1차 축**을 가지며, 그 축이 곧 그 공간의 정체성이다.

| 공간 / 주체                  | 1차 이동 축      |   방향   | 한 줄 정의                                               |
| :--------------------------- | :--------------- | :------: | :------------------------------------------------------- |
| 월드 (World)                 | X — 수평        | ← 횡 → | 플레이어는 주로 좌우로 이동하며 탐험한다                 |
| 빌더 (Builder)               | Y⁺ — 수직 상승 |  ↑ 위  | 빌더는 메가 스트럭처를 위로 시공하며, 침입은 위로 오른다 |
| 아이템계 지층 (Item Stratum) | Y⁻ — 수직 하강 | ↓ 아래 | 다이브는 지층을 아래로 한 층씩 내려간다                  |

### A. 월드 = 수평 (X축)

* 월드 탐험의 1차 동선은 **좌우 횡 이동**. 횡스크롤 메트로베니아의 근간이다.
* 수직 이동(점프·사다리·상하 구역 전환)은 **국소적 보조 축**으로만 허용한다. 한 구역의 정체성이 "위로 오른다"가 되어선 안 된다 — 그것은 빌더의 축이다.
* Room 규격(60×34, 가로:세로 ≈ 2:1)이 횡 우위를 물리적으로 강제한다.
* 구역 간 연결은 수평 인접을 기본으로 하고, 수직 연결은 엘리베이터·수직 갱도 등 *명시적 장치*로만 표현한다.

### B. 빌더 = 상승 (Y⁺축)

* 빌더는 시공(施工)을 **위로** 진행한다. 시공 광원은 위에서 내려오고, 응결재는 아래에서 위로 차오른다.
* 빌더 침입 시퀀스(서사상 포지 진입의 길)는 **등반(climb-up)** 동선이다. 멈춘 빌더의 옆구리로 기어오르거나, 움직이는 빌더의 등을 타고 위로 오른다.
* 따라서 빌더 내부·표면 구간은 §3 수직 플랫폼 규격을 *주 동선*으로 사용하는 **유일한 예외 공간**이다.
* 위로 갈수록 시공 굉음·위험이 증가한다 (상승 = 외부 긴장의 고조).

### C. 아이템계 = 하강 (Y⁻축)

* 아이템계 다이브는 **아래로** 내려간다. 지층(地層)을 한 층씩 하강하며, 깊을수록 위험·보상이 동시에 증가한다.
* "더 깊이 = 더 깊은 한(恨)" — `Content_Story_Synopsis.md` 의 수직 한(Parasite z축) 정합. 하강 자체가 정서의 메타포(Mechanics as Metaphor)다.
* 지층 전환은 보스 처치 후 **하강 게이트**(아래로 향하는 통로·낙하)로 표현한다. 위로 되돌아가는 동선은 *귀환(월드 복귀)* 시에만 발생한다.
* 레어리티가 높을수록 지층이 깊다 (Normal 1 → Ancient 4+심연). 하강 깊이 = 레어리티의 시각적 번역이다.

### D. 3축이 강제하는 것

1. **공간 정체성의 혼선 금지** — 월드 구역을 "수직 등반 위주"로 설계하면 빌더와 혼동된다. 각 공간은 자기 축을 지킨다.
2. **카메라·스크롤 우선 축** — 월드: 수평 스크롤 우선 / 빌더: 상향 스크롤 / 아이템계: 하향 스크롤.
3. **정서의 방향성** — 상승(빌더) = 외부 위협의 고조, 하강(아이템계) = 내면·한의 심화, 횡(월드) = 탐험과 일상.
4. 본 3축과 이하 규격이 충돌하면 **3축이 우선**하며, 규격을 3축에 맞춰 조정한다.

## 1. 개요 (Overview)

### 1-1. 문서 목적

본 문서는 ECHORIS의 **월드(World)** 및 **아이템계(Item World)** 레벨을 설계할 때 준수해야 할 물리적 규격, 배치 원칙, 난이도 설계 가이드를 정의한다. Room Template과 Chunk를 제작하는 모든 작업자(인간/AI)가 이 문서를 기준으로 레벨을 구성한다.

### 1-2. 핵심 원칙

> 아래 모든 원칙은 **최상위 원천 — 3축 이동 원칙**에서 파생된다. 충돌 시 3축이 우선한다.

| 원칙              | 설명                                                                         |
| :---------------- | :--------------------------------------------------------------------------- |
| 3축 이동 (최상위) | 월드=횡(X) / 빌더=상승(Y⁺) / 아이템계=하강(Y⁻). 모든 공간 설계의 근간 원천 |
| 물리 기반 설계    | 모든 지형은 캐릭터 물리 파라미터(점프 높이, 이동 속도)에서 역산하여 배치한다 |
| Always Winnable   | 기본 능력만으로 Critical Path를 반드시 통과할 수 있어야 한다                 |
| 능력 보상 탐험    | 능력 게이트 너머에는 반드시 보상(아이템, 숏컷, 비밀)이 존재해야 한다         |
| 읽히는 공간       | 플레이어가 시각적으로 경로와 위험을 판단할 수 있어야 한다                    |
| 2-Space 구분      | 월드와 아이템계의 레벨 규격은 분리하여 정의한다                              |

## 3. 플랫폼 배치 규격 (Platform Placement Standards)

### 3-1. 수직 간격 규칙

캐릭터의 공칭 점프 높이(**5타일 = 80px**, 코드/CSV 검증값)를 기준으로 모든 수직 간격을 설계한다.

> **2026-05-30 재보정:** 코드 검증 결과 기본 점프가 4타일이 아니라 **5타일**이었다. 아래 표는 5타일 기준으로 한 칸씩 상향 재보정됨. 정점 부유(`ApexGravityMult`)로 실제 도달은 5타일보다 약간 높으므로 게이트는 여유를 둔다.

| 구간           | 수직 간격  | 난이도 | 요구 능력                    |
| :------------- | :--------- | :----- | :--------------------------- |
| 쉬운 오르막    | 2-3 타일   | 초급   | 기본 점프                    |
| 표준 오르막    | 4 타일     | 중급   | 기본 점프                    |
| 도전 오르막    | 4.5 타일   | 상급   | 기본 점프 (여유 0.5타일)     |
| 불가 구간      | 6+ 타일    | -      | 이단 점프 필요 (능력 게이트) |
| 이단 점프 표준 | 6-7 타일   | 중급   | 이단 점프 (정점 연계 총 ~8타일) |
| 이단 점프 도전 | 7-8 타일   | 상급   | 이단 점프 (여유 없음)        |

**핵심 규칙:**

* Critical Path의 수직 간격은 **4 타일 이하**로 제한한다 (기본 점프 5타일로 1타일 여유 확보, 100% 도달 가능).
* 4.5 타일 간격은 보상 경로에만 배치한다 (숙련자 보상, 정점 타이밍 요구).
* 5 타일 간격은 배치하지 않는다 (점프 최대치와 동일 — 실패 확률 높아 스트레스 유발).
* 6 타일 이상은 반드시 이단 점프 능력 게이트로 분류한다 (기본 점프 도달 불가).

### 3-2. 수평 간격 규칙

점프 중 수평 이동 거리(약 6-7타일, 이동 8타일/s × 체공 ~0.8s)를 기준으로 설계한다. 대시(4타일 수평)는 갭 횡단 보조 수단.

| 구간    | 수평 간격 | 난이도 | 비고                                |
| :------ | :-------- | :----- | :---------------------------------- |
| 좁은 갭 | 2-3 타일  | 초급   | 달리기 없이 점프로 통과             |
| 표준 갭 | 4-5 타일  | 중급   | 달리기 + 점프 필요                  |
| 넓은 갭 | 6 타일    | 상급   | 최대 거리 점프 (여유 약 0.5타일)    |
| 불가 갭 | 8+ 타일   | -      | 능력 게이트 (벽 타기, 수중 호흡 등) |

**핵심 규칙:**

* Critical Path의 수평 간격은 **5 타일 이하**로 제한한다.
* 7 타일 간격은 배치하지 않는다 (이론상 한계치로 스트레스 유발).
* 8 타일 이상은 능력 게이트 구간으로만 사용한다 (단, 대시 보유 시 대시 점프로 추가 ~4타일 횡단 가능 — 대시 게이트 설계에 활용).

### 3-3. 천장 높이 규칙

| 구간      | 천장 높이 | 용도                         |
| :-------- | :-------- | :--------------------------- |
| 표준 통로 | 4 타일    | 점프 가능, 전투 가능         |
| 넓은 공간 | 6+ 타일   | 보스 방, 전투 아레나         |
| 낮은 통로 | 2 타일    | 서서 통과 가능, 점프 불가    |
| ~~좁은 틈새~~ | ~~1 타일~~ | ~~안개 변신 전용~~ **DEPRECATED 2026-05-18 (안개 변신 폐기 — SotN Mist Form 카피 우려, CLAUDE.md 능력 게이트 5종)** |

> **충돌 박스 정합 주의 (2026-05-30):** 캐릭터 충돌 박스는 9×16px(높이 1타일)이라 **물리적으로는 1타일 통로도 통과**한다. 위 "낮은 통로 2타일"은 시각 스프라이트(2타일)의 머리 여유를 위한 설계 기준이며, 물리 통과 한계와 다르다. 1타일 강제 통로(포복 등) 메커닉은 현재 없음 — 안개 변신 폐기로 1타일 게이트 자체가 폐기됨.

## 4. 게이트 배치 설계 원칙 (Gate Placement Philosophy)

### 4-1. 능력 게이트 설계

플레이어가 "저기 못 간다" → 능력 획득 → "이제 갈 수 있다!"를 경험하는 구조.

| 능력            | 레벨 디자인 표현                             | 시각적 단서                        |
| :-------------- | :------------------------------------------- | :--------------------------------- |
| 이단 점프       | 6-8 타일 수직 간격 (기본 점프 5타일 초과)    | 높은 곳에 빛나는 아이템/통로       |
| 벽 타기/벽 점프 | 수직 벽면 양쪽에 발판 없음, 벽면에 긁힌 흔적 | 벽면 텍스처 변화 (잡을 수 있는 벽) |
| 수중 호흡       | 긴 수중 구간 (산소 게이지 초과)              | 물속 깊은 곳의 빛/보물             |
| 극성 부츠 (빌더) | 천장(빌더 금속)에 통로/아이템 배치           | 천장의 반전된 구조물               |

**핵심 규칙:**

* 능력 게이트 너머는 반드시 **보상**이 존재해야 한다 (빈 방 금지).
* 게이트 직전에 **티저(Teaser)**를 배치한다: 능력이 없어도 게이트 너머를 **볼 수 있게** 설계한다.
* 한 층위에 동일 능력 게이트는 **최대 3개**까지 배치한다 (과잉 차단 방지).

### 4-2. 스탯 게이트 설계

장비 강화(아이템계)의 동기를 부여하는 게이트.

| 스탯            | 레벨 디자인 표현                     | 시각적 단서                                  |
| :-------------- | :----------------------------------- | :------------------------------------------- |
| ATK (물리 장벽) | 파괴 가능한 벽/바리케이드/중문/바위  | 금이 간 벽면, 쇠사슬, 부서질 듯한 바리케이드 |
| INT (시공 봉인) | 빌더 봉인 문양 문/도면 잠금/아케인 잠금장치 | 빌더 봉인 문양, 발광하는 봉인, 시공 진 |

> **설계 변경:** 기존 6대 스탯 게이트(STR/INT/DEX/VIT/SPD/LCK)는 ATK/INT 이중 게이트로 재설계. ATK는 물리 장벽(파괴), INT는 시공 봉인(해제). 기동성/환경 저항/시간 제한 등은 능력 게이트나 환경 퍼즐로 재설계 예정.

**핵심 규칙:**

* 스탯 게이트는 Critical Path에 배치하지 않는다 (선택적 도전).
* 스탯 게이트 너머의 보상 가치는 요구 ATK/INT에 비례한다.
* 스탯 게이트는 수치로 표시한다: "ATK 150 필요" 또는 "INT 80 필요" (모호함 금지).

## 6. 난이도 곡선 설계 (Difficulty Curve)

### 6-1. 층위별 난이도 매핑

`System_World_ProcGen.md`의 층위 난이도와 일치시킨다.

| 구역 (D-20 §3, 상승 순)   | 난이도 | 전투 강도 | 플랫폼 난이도          | 게이트 밀도           |
| :------------------------ | :----: | :-------- | :--------------------- | :-------------------- |
| 침수 바닥층               |   1   | 낮음      | 초급 (2타일 간격 중심) | 없음 (튜토리얼)       |
| 무너진 거주 구역          |   2   | 보통      | 초-중급 + 잔해 요소    | 스탯 게이트 소수      |
| 거대 공장층               |   2   | 보통      | 중급 + 조립 라인 hazard | 능력 게이트 1-2개     |
| 무너진 환승역             |   3   | 높음      | 중-상급 + 광활 공동    | 능력+스탯 게이트 혼합 |
| 봉인된 하부               |   3   | 높음      | 중-상급 + 말소자 출몰  | 능력+스탯 게이트 혼합 |
| 대 안치소                 |   4   | 매우 높음 | 상급 (수직 안치 구조)  | 능력 게이트 다수      |
| 정상 — 관제정             |   5   | 극한      | 극상급 (복합 위험)     | 스탯 게이트 고수치    |

### 6-2. 난이도 곡선 원칙

1. **점진적 상승**: 층위 내에서 입구 → 보스 방향으로 난이도가 상승한다.
2. **안식처 리듬**: 고난이도 구간 후에는 반드시 안전 구간(세이브 포인트, 빈 통로)을 배치한다.
3. **스파이크 제한**: 한 Room 내에서 전투 + 플랫폼 + 함정이 동시에 최고 난이도인 구간은 보스 방에만 허용한다.
4. **학습 공간**: 새로운 위험 요소는 안전한 환경에서 먼저 노출한다 (독립 소개 → 조합).

## 8. Room Template 제작 체크리스트

Room Template 또는 Chunk를 제작할 때 다음 항목을 검증한다.

* [ ] 기본 점프(5타일)만으로 Critical Path를 통과할 수 있는가
* [ ] 수직 간격이 4타일을 초과하는 구간은 Critical Path 밖에 배치했는가
* [ ] 수평 갭이 5타일을 초과하는 구간은 Critical Path 밖에 배치했는가
* [ ] 천장 높이 4타일 미만인 구간에서 전투가 요구되지 않는가 (점프 불가 전투 회피)

* [ ] 게이트 직전에서 게이트 너머를 시각적으로 확인할 수 있는가 (티저)
* [ ] 새로운 위험 요소가 안전 환경에서 먼저 소개되는가
* [ ] 고난이도 구간 후 안식처(세이브/빈 통로)가 존재하는가
* [ ] 밟을 수 있는 발판과 배경이 시각적으로 명확히 구분되는가
* [ ] 함정/위험 요소에 시각적 경고가 존재하는가
* [ ] 비밀 경로에 미묘하지만 발견 가능한 단서가 있는가
* [ ] 화면 표시 영역(40x22.5 타일) 기준으로 적 스폰이 화면 밖에서 기습하지 않는가
