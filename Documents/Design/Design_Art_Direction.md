### 0.4 빌더 — `sprites/builder_sprite_01.png`

이는 시놉시스의 "빌더는 무지능 시공자, 적의 없음" 톤과 완벽히 정합한다. 인간형 메카는 인격을 암시하지만, 움직이는 건축물은 무관심한 본성 그 자체.

### 1.3 두 인물의 시각 친연성 = 진엔딩 통찰의 시각 운반

본 디렉션의 가장 중요한 결정 — 에르다와 러스트본의 시각적 닮음이 작품의 핵심 통찰을 운반한다:

> 러스트본은 에르다의 자기 이전 고리. 또는 자기 다음 고리. 닮음은 우연이 아니다.

이 결정이 다음을 자동 결정한다:

| 함의 | 적용 |
| :--- | :--- |
| 러스트본 = 가능성 1 (자기 이전 고리) 시각 캐논 | 시놉시스 §5.4 의 3 가능성 중 1 이 시각으로 굳어진다 |
| 진엔딩의 통찰 시각화 | 플레이어가 두 인물의 닮음을 인지하는 비트가 진엔딩 도달의 사전 단서 |
| 25시간 플레이어가 두 번째 플레이에서 발견 | 첫 플레이는 닮음을 자각하지 못한다. 두 번째 플레이에서 — 또는 진엔딩 도달 후 — 회수된다 |
| 인덱서 지도자도 같은 결인가? | 시놉시스의 가능성 2 — 그가 한때 가장 깊이 들었던 자였다는 설정. 그도 같은 머리카락 색이라면 진엔딩의 통찰이 또 한 층 회수된다. 결정 보류 (Q3 참조). |

### 1.4 인덱서 일반 잔존자 (미제작)

신규 작업 대상. 디렉션:

- 다양한 머리카락 색 — 잔존자 카테고리의 다양성
- 같은 청-회색 천 베이스 + 의례용 검은 천 한 자락 추가
- 표정 — 평온함, 그러나 미세한 떨림 (눈가·손)
- 인덱서 지도자만 가장 어두운 의례 천 + 모자 (silhouette 구별)

### 1.5 신규 인물 시각 캐논 (시놉시스 v2 정합)

시놉시스 v2 가 추가한 인물의 시각 방향. 대부분 미제작 — 신규 작업 대상.

| 사용처 | 효과 |
| :--- | :--- |
| 에코 내부 위상의 부유 입자 | 차가운 청록 발광 |
| 잔재 음성의 시각화 | 마지막 한 마디가 청록 결정체로 응결 |
| 검에 새겨진 에코의 후광 | 청록 라인이 검 표면에 흐름 |
| 러스트본의 눈 발광 | 자기 잔존의 신호 |

청록 잔향 = 에르다의 정체성 색이 곧 잔재의 색. 그녀 자신이 한 에코임을 시각이 운반.

## 5. 에코 내부 위상 — 신규 디렉션

### 5.1 메가 스트럭처와의 시각적 단절

에코 내부는 메가 스트럭처와 명백히 다른 위상.

| 메가 스트럭처 | 에코 내부 |
| :--- | :--- |
| 회색 + 호박색 듀얼리티 | 청록 잔향 + 호박 |
| 단단한 실루엣 | 부드러운 가장자리 |
| 시공의 굉음 | 정적 + 한 음성 |
| 거대한 스케일 | 친밀한 스케일 |
| 산업적 텍스처 | 비물질적 입자 |
| 적색 액센트 | 적색 부재 |

### 5.2 일반 에코의 시각

- 부유하는 단편들 — 한 사람의 마지막 한 마디의 시각화
- 청록 잔향 후광 지배
- 호박색 빛 조각이 단편들 사이에 흩어짐
- 마지막 음성의 응결체 — 한 점의 따뜻한 호박 광원, 회수 가능
- 적이 있는 에코 — 미해결 응답이 추상 적대 형상으로 응고

### 5.3 러스트본 에코의 시각 (특이)

- 부유하는 단편이 아니라 완전한 공간 — 한 사람의 의식이 온전히 응결
- 러스트본이 화면 중앙에 서 있음 (실 자산 portrait 결 그대로)
- 호박색 빛 지배 — 청록 잔향은 가장자리에만
- 안식·따뜻함의 분위기 — 메가 스트럭처와의 극한 대비
- 빌더 외피 침입 비트 — 청록 잔향이 점점 사라지고 회색 침입, 공간 무너짐

### 5.4 아이템계 던전 구조와의 정합

에코 내부 위상은 분위기 레이어다. 그 아래에는 플레이 가능한 아이템계 던전이 있다(용어집 Item World / Floor·Stratum).

## 6. 검의 진행 시각화 — 5등급 무기 + 에코 누적

### 6.1 시작 무기 = 러스트본의 검

`sword_rustborn.png` 가 시작 무기. 작은 청동/구리 검. 이는 그의 자기 잔존 — 자기 검을 다음 자에게 남기는 진엔딩의 시각적 인증.

플레이어는 이 검을 가지고 깨어난다. 첫 다이브 시 이 검의 에코로 들어가 러스트본을 만난다. 검은 그의 잔재이자, 그가 그녀에게 남긴 응답.

> 무기 명칭 정합 (Glossary): 시작 검 = 녹날(Rustedge, sword_rustborn) — 프롤로그의 절개도(Scalpel) 가 수천 년 부식 + 러스트본 의식 응결로 변한 것. 본편 첫 다이브 = 녹날의 에코(러스트본).

### 6.1.1 프롤로그 다이브 비주얼 — 멸균 ↔ 부식 대비

프롤로그(0막) 의 첫 다이브는 시각 대비가 핵심이다 — 깨끗한 흰 절개도(Scalpel, 멸균 연구 도구) 가 녹슨 미완검(Halfblade, 어린 단조공의 잊혀진 에코) 속으로 들어간다.

| 요소 | 절개도 (들고 가는 도구) | 미완검 (들어가는 에코) |
| :--- | :--- | :--- |
| 색 | 멸균 흰색·금속 광 | 검은 단조 스케일 + 호박 담금선(한쪽만) |
| 결 | 사연 없는 깨끗함 | 부식·미완성(비대칭 검신) |
| 잔향 | 없음 | 거친 날에서 청록 에코 잔향 |

멸균(가해자 도구) 이 부식(잊혀진 자) 속으로 — 이 시각 충돌이 작품 첫인상이자, "절개도가 훗날 녹날이 된다(멸균→부식)" 호의 복선. 미완검 외형 상세 = CNT-ECO-001 에코 02.

### 6.2 검 등급별 시각 (이미 보유)

| 등급 | 자산 | 결 |
| :--- | :--- | :--- |
| Normal (러스트본) | sword_rustborn | 청동/구리 |
| Magic | sword_magic | (자산 보유 — 분석 필요) |
| Rare | sword_rare | (자산 보유 — 분석 필요) |
| Legendary | sword_legendary | 청-백색 발광 |
| Ancient | sword_ancient | 녹색 발광 |
| Broken | sword_broken | 부서진 — 잔존자 흔적 |

### 6.3 에코 누적의 시각화 (신규 작업)

검 자체가 진행 시각화 운반:

검 시각 단계는 녹쇠 7단계 각성(시놉시스 v2)과 1:1 정합한다.

| 누적 에코 | 녹쇠 단계 | 검의 시각 변화 |
| :--- | :--- | :--- |
| 0 | 1. 도구 | 시작 무기 그대로. 진동만 |
| 50 | 2. 질문 | 칼날에 미세한 호박색 줄무늬 첫 발현 |
| 100 | 3. 타인 관찰 | 청록 잔향 후광 추가 — 다른 에코 식별 |
| 150 | 4. 감각 인식 | 발광 줄무늬 굵어짐 — 칼날 무게감 시각화 |
| 200 | 5. 감정 폭발 | 칼날 따뜻한 빛 발광 + 에르다 주위 미세 후광 |
| 280 | 6. 부분적 이해 | 청록 + 호박 혼합 발광 안정 |
| 300+ | 7. 감정 수용 | 칼날 미세 진동. 300 음성의 합창처럼 살아 있음 |

UI 코너 텍스트 부담 없이 검 시각만으로 진행 파악. 단계 전이가 곧 녹쇠 발화 비트와 동기.

### 6.4 등급과 에코 누적의 결합

레어리티별 검에 에코 누적이 더해지면 — Ancient 검에 300 에코가 모두 새겨진 상태가 작품의 최종 시각 — 청록 잔향 + 호박 광원 + 녹색 발광이 합쳐진 한 자루.

## 7. 인덱서 의례 — 신규 디렉션 (sci-fi 안치소)

> sci-fi 정합: 의례 공간은 고딕 돌 성당이 아니라 sci-fi 안치소(대 안치소, D-20 §3 구역 6). 대성당의 본질(거대 수직·대칭·수직 광선·합창·경외) 은 유지, 재질만 교체 — 돌 성상/부조 → 안치 포드의 산 얼굴, 돌 제단 → 중앙 송신탑, 스테인드글라스 빛 → 송신 빔의 수직 광주.

### 7.1 안치 포드 벽 — 등재 lore 의 시각 핵심

- 빌더 표면·안치소 벽에 수직 안치 포드 열 — 작품 등재 lore 의 시각 핵심
- 각 포드 표면에 살아 있는 인간 얼굴 — 처음엔 한두 개(빌더 옆구리), 안치소에선 천 개·만 개
- 얼굴들의 눈이 미세하게 움직임 — 살아 있다(보존되었으나 발화 못 함)
- 신규 자산 — 안치 포드 + 산 얼굴 sprite (석상 아님, 기계 보존 셀 결)

### 7.2 의례 합창단

- 잔존자들이 둘러서서 chant
- 단순한 정렬
- 신규 자산 — 합창 모션 잔존자 sprite

### 7.3 인덱서 지도자 — 묵정 (Mukjeong)

- 다른 인덱서와 silhouette 구별 — 가장 어두운 의례 천 + 모자
- 한쪽 다리에 시공 단위 응결재가 자람 — 걸음새 비대칭. 다리를 만질 때 굉음 결로 진동(신체 한, 본인만)
- 발화 대신 지팡이로 다리를 두드리는 박자 — 신도들이 그 박자로 합창(비언어 신호 device)
- 손 — 가까이서 보면 미세하게 떨림 (애니메이션 디테일)
- 헌납된 잔존자의 무기 한 자루 들고 있음
- High Tower Surprise — 적이 아니라 자기를 등재해 줄 자를 70년 기다린 자. 시선은 강하게 직접적이나 그 아래 갈망

### 7.4 첫 30분 의례 노출 (22-25분 비트)

- 멀리서 의례장이 보임 — 빌더 옆구리 표면
- 잔존자들 chant
- 빌더 표면에 작은 얼굴 부조 1-2 개 (자세히 봐야 인지)
- 가까이 가면 chant 멈춤
- 인덱서들이 그녀를 본다, 적대 아님

## 9. 시각 강도 곡선 — 평행 구조 (방법론)

> 출처: [The Visual Story — Bruce Block](../../Reference/visualstory_인사이트.md) . 보조: [artdirection_인사이트.md](../../Reference/artdirection_인사이트.md) .

§2.3 톤 비중 표는 화면별 색 분포를 정의한다. 본 절은 그 분포를 **시간축의 강도 곡선**으로 운영한다. Block 의 평행 구조 원리 — 시각 강도 곡선은 극적 강도 곡선과 평행하게 움직인다. 대비를 키우면 강도가 오르고(긴장), 친연으로 묶으면 강도가 내린다(이완).

### 9.1 핵심 루프 1주기 강도 곡선

핵심 루프: 메가 스트럭처 탐험 → 단서·의례 노출 → 포지 격발(다이브) → 에코 내부 → 에코 보스 → 귀환·안식 → 게이트 해금.

| 루프 단계 | 극적 단계 | 대비/친연 | 주도 강도 요소 | §2.3 연결 |
| :--- | :--- | :--- | :--- | :--- |
| 메가 스트럭처 탐험 | 발단 | 친연 우세 | 회색·흑 톤 친연. 붉 5% 닻만 돌출 | 일반 탐험 |
| 인덱서 의례·단서 | 상승 | 의미 대비 도입 | 부조 얼굴·합창 — 의미 현저성(§12) | 의례장 |
| 포지 격발 | 전환 | 대비 급상승 | 호박 톤 폭발 + 움직임 + 리듬 | 빌더 내부(작동) |
| 에코 내부 | 이완 속 긴장 | 친연(부드러움) + 청록 대비 | 색(청록 잔향) + 공간 친연 | 에코 내부 |
| 에코 보스·미해결 응답 | 절정 | 최대 대비 | 톤 대비 + 사선 선 + 움직임 가속 | (에코 내부 변주) |
| 귀환·안식처 | 해소 | 친연 회복 | 호박 온기 + 수평 안정 | 안식처 |
| 게이트 해금 | 보상 비트 | 순간 대비 스파이크 | 톤 플래시 + 리듬 1회 | (상태 전환) |

이 곡선이 §2.3 정적 분포와 §4.2 포지 격발 5단계를 하나의 시간 설계로 묶는다.

### 9.2 규칙 확립 후 위반

일관된 5톤 규칙이 먼저 서야 위반이 충격으로 작동한다(Block §4). 심연(Ancient 레어리티 추가 층)·이변 구간에서 톤 규칙을 의도적으로 깨 시각 충격을 부여한다. 일반 구간에서는 규칙을 엄격히 유지한다.

## 10. 명도 우선 + 컬러 스크립트 워크플로 (방법론)

> 출처: [Hans Bacher — Vision](../../Reference/bacher_vision_인사이트.md) , [Framed Ink](../../Reference/framedink_인사이트.md) .

색은 명도 골격 위에 입히는 층이다. 두 레퍼런스 모두 채색 이전에 **흑백 명도 패턴**으로 구성을 확정할 것을 요구한다.

### 10.1 픽셀 자산 제작 4단계 (PixelLab → Aseprite 표준 순서)

| 단계 | 활동 | 검수 |
| :---: | :--- | :--- |
| 1. 명도 썸네일 | 3톤 흑백(밝음·중간·어둠)으로 화면/스프라이트 골격 | 명도 대비가 초점에 박히는가 |
| 2. 실루엣 검수 | 검은 실루엣만으로 형태 확인 (§11.2 게이트) | 주제·행동이 읽히는가 |
| 3. 채색 | 5톤 팔레트를 명도 골격 위에 입힘 | 명도 골격이 무너지지 않는가 |
| 4. 강조색 닻 | 붉 5% / 청록 / 호박 강조색 배치 | 시각 닻이 1순위 초점에 오는가 |

채색을 먼저 하고 명도를 나중에 맞추는 역순을 금지한다.

### 10.2 컬러 스크립트

§9.1 강도 곡선을 5톤 비중의 시간축 흐름으로 한 줄로 펼친 정서 지도가 컬러 스크립트다. 신규 구역·시퀀스 제작 전 컬러 스크립트를 먼저 그려 인접 구간과의 색 흐름(친연·대비)을 검증한다. 회색·흑 친연 구간 → 호박 격발 스파이크 → 청록 위상 → 호박 안식 회복의 흐름이 기본 골격이다.

## 11. 가독성·실루엣 검수 게이트 (방법론)

> 출처: [Adam deGrandis — 5초 읽기](../../Reference/degrandis_인사이트.md) , [Hans Bacher](../../Reference/bacher_vision_인사이트.md) , [Framed Ink](../../Reference/framedink_인사이트.md) .

### 11.1 5초 읽기 검수 (Five-Second Read)

플레이어가 5초 안에 읽어야 할 정보 항목. 각 항목이 5초 내 구분되지 않으면 가독성 결손으로 판정한다.

| 검수 대상 | 5초 내 읽혀야 할 것 |
| :--- | :--- |
| 레어리티 5등급 | Normal~Ancient 색 구분 (흰/청/황/주황/녹) |
| 게이트 2종 | ATK(물리 장벽) vs INT(마법 봉인) 시각 구분 |
| 적 카테고리 | 거대 빌더(환경 위협·격파 불가) vs 작은 메카(전투 적) |
| 인터랙터블 | 세이브포인트·대장간·게이트 vs 비상호작용 배경 |
| 검의 에코 누적 | §6.3 단계(0/1-50/51-150/151-250/251-300)의 시각 차 |

### 11.2 실루엣 가독성 검수

32px 스프라이트를 검은 실루엣으로 환원해도 구별되어야 한다. 에르다 / 빌더 / 보스(boss_01) / 일반 적 / 인덱서가 실루엣만으로 분리되는지 점검한다. 형태가 겹쳐 뭉개지면 구성을 다시 잡는다.

신앙 집단 3자 실루엣 분리 — 인덱서 본류와 그 하위 분파(사적 등재단, 등재인/색인체) 가 한 화면에 공존할 수 있으므로, 다음 3자가 검은 실루엣만으로 분리되어야 한다(설정 출처: `Documents/Narrative/Narrative_World_PrivateRegistration.md` §6.1-6.2).

| 대상 | 실루엣 키 | 분리 포인트 |
| :--- | :--- | :--- |
| 인덱서(본류) | 줄 없는 독립 로브 | 단독 직립. 부속물·연결선 없음 |
| 등재인(분파 주) | 줄을 거두는 권양 실루엣 | 등·어깨의 계류 릴 + 모여 감기는 탯줄들 |
| 색인체(분파 종) | 줄에 묶인 실루엣 | 봉합 보존복 + 목/등의 탯줄 1가닥(등재인·벽 정박점에 예속), 빈 손 |

### 11.3 명료성 vs 드라마 (비트별 역할)

Framed Ink 의 핵심 긴장. 비트마다 정보 전달(명료성)인지 감정 고조(드라마)인지 역할을 먼저 정한다. 충돌하면 그 비트의 서사 역할이 우선순위를 정한다.

| 비트 | 우선 |
| :--- | :--- |
| 단서·게이트 조건 제시 | 명료성 |
| 포지 격발 절정·에코 보스 | 드라마 |
| 러스트본 대면(§5.3) | 드라마 우선, 명료성 보존 |

## 12. 횡스크롤 공간 연출 — 의미 현저성·어포던스·형태 (방법론)

> 출처: [Miriam Bellard — 공간적 시네마토그래피](../../Reference/bellard_인사이트.md) .

환경이 곧 카메라다. 횡스크롤은 화면이 처음부터 2D 이므로 "3D 를 2D 로 작곡한다" 명제가 더 직접 성립한다.

### 12.1 의미 현저성 > 대비 현저성

시선 유도에서 색·라이팅 대비보다 **건축적 흥미(의미)** 가 더 무겁게 작동한다(Bellard). 빌더의 통일된 어두운 회색 + 무수한 디테일은 색 대비를 절제하고 메가 스트럭처 형태 자체로 시선을 끈다. 신규 구역도 색 강조를 남발하지 않고 공간 구조의 의미로 시선을 유도한다.

### 12.2 어포던스 · 시그니파이어

| 개념 | ECHORIS 적용 |
| :--- | :--- |
| 표면적 어포던스 | 넓고 시야 좋은 명료 경로 — 크리티컬 패스 |
| 복합 어포던스 | 좁고 보상 있는 경로 — 게이트 너머 야리코미 분기 |
| 시그니파이어 | 빌더 적색 시공 광원 = 작업 신호(적대 아님) / 게이트 시각 신호 |

### 12.3 형태 심리

| 형태 | 정서 | ECHORIS 적용 |
| :--- | :--- | :--- |
| 수직·부피 | 권력·압도 | 빌더 수직 부피 = 무관심한 거대 권력 |
| 날카로움 | 위험 | 보스 메카의 각진 실루엣 = 전투 위협 |
| 원형 | 안전 | 안식처·세이브포인트의 둥근 형태 |

### 12.4 공간 = 시간, 강도 진동

동일 건축 요소의 반복이 탐험 리듬을 만들고, 요소 밀도 변주가 시간축 강도를 통제한다. 강도를 오르내리게 유지해 탐험 마비·지루함을 방지한다(§9.1 곡선과 연동). 탄젠트 회피·삼분할·전경/중경/배경 레이어링을 패럴랙스 3층(§0.6) 가독성 기준으로 채택한다.

## 13. 스타일 프레임 게이트 + 품질 등급 (방법론)

> 출처: [Austin Shaw — Design for Motion](../../Reference/designformotion_인사이트.md) , [Adam deGrandis](../../Reference/degrandis_인사이트.md) .

### 13.1 스타일 프레임 우선 게이트

디자인이 애니메이션의 성패를 가른다(Shaw). 신규 스프라이트·이펙트의 모션 작업 전, 완성도 높은 **스타일 프레임 1장**을 먼저 확정해 제작 기준선을 고정한다. 순서: 무드보드·썸네일 발산 → D-15 톤에 수렴 → 스타일 프레임 승인 → PixelLab → Aseprite → 인게임. 스타일 프레임 미승인 자산은 모션 제작에 진입하지 않는다.

### 13.2 품질 등급 — "충분히 좋음"

소규모 팀은 멈출 시점을 안다(deGrandis). 모든 자산을 최고 품질로 끌어올릴 시간은 없으므로, 품질 투자를 전달 기여도 순으로 배분한다.

| 등급 | 자산 | 품질 기준 |
| :--- | :--- | :--- |
| 핵심 | 에르다·러스트본·빌더·포지·보스·검 5등급 | 최고 완성도. 5초 읽기·실루엣 게이트 필수 |
| 준핵심 | 일반 적·인덱서 잔존자·에코 내부 환경 | 가독성 통과 선까지. 디테일 절제 |
| 배경 | 장식 타일·먼 패럴랙스 요소 | "충분히 좋음" 하한선에서 멈춤 |

### 13.3 3축 균형 (전달·마케팅·생산)

모든 자산 결정은 세 축의 합을 최적화한다. 한 축의 극단을 피한다.

## 14. 핵심 요소 식별 체계 — 구분 채널 분리

> 방법론 근거: §11 5초 읽기, §9 대비·친연, [The Visual Story](../../Reference/visualstory_인사이트.md) 요소 분리.

플레이어가 한 화면에서 동시에 구분해야 하는 요소 군이 많다. 모든 요소가 같은 채널(예: 색)로 신호하면 채널이 포화되어 5초 읽기가 무너진다. 해법은 **요소 군마다 1순위 식별 채널을 배타적으로 배정**하는 것이다. 한 채널을 한 요소 군이 점유하면 다른 군과 충돌하지 않는다.

### 14.1 식별 대상과 1순위 채널

| 요소 군 | 항목 | 1순위 채널 | 충돌 회피 |
| :--- | :--- | :--- | :--- |
| 공간 3축 | World / Builder / Item Stratum | 환경 색온 + 형태 언어 + 모션·사운드(동시 다중) | §15 |
| 레어리티 5등급 | Normal~Ancient | 아이템 전용 채도 높은 외곽 발광(흰/청/황/주황/녹) | 소형 오브젝트 글로우로 한정 — 환경 색과 분리 |
| 스탯 게이트 2종 | ATK물리 / INT마법 | 아이콘 형태 + 장벽 재질 | ATK = 균열·쇠사슬(파괴) / INT = 룬 문양 발광(해제) |
| 적 카테고리 | 빌더 / 작은 메카(boss_01) / 지층 보스 / 드론(잡몹) / 말소자 | 실루엣 + 스케일 (말소자만 흰색 예외) | 색이 아니라 형태·크기로(§14.2-14.4). 말소자만 5톤 위반 흰색 |
| 인터랙터블 | 포지 / 세이브 / 게이트 / Trapdoor / 상점 | 호박 점광 시그니파이어 | 비상호작용은 발광 없음 |
| 검 진행 | 녹쇠 0-300 7단계 | 칼날 발광 누적(§6.3) | 플레이어 손의 검에 한정 |

핵심 규칙 — 환경(3축)은 색온·형태·모션을 점유하고, 아이템·레어리티는 소형 오브젝트의 채도 높은 글로우를 점유한다. 두 채널이 분리되므로, 청록 위상(Item Stratum) 안에서도 녹색 Ancient 아이템이 환경과 섞이지 않고 또렷이 떠오른다.

### 14.2 적 카테고리 — 색이 아닌 실루엣·스케일

색 채널은 환경·아이템이 점유하므로, 적은 형태로 구분한다. 단 말소자만 흰색을 예외적으로 점유한다(§14.4).

| 적 | 실루엣·스케일 | 인지 |
| :--- | :--- | :--- |
| 빌더 | 화면을 넘는 수직 부피, 1:40 | 환경 위협·격파 불가 |
| 작은 메카(boss_01) | 65px 각진 단일 발광 눈 | 전투 적 (말소자 아님) |
| 지층 보스(Tier 1-4) | 미해결 응답의 응고 — 비정형 거대 형상 | 다이브 절정 |
| 드론(일반 적) | 32px 소형 둥근 실루엣 | 잡몹 — 평범한 환경 생물(슬라임·골격·부유형) |
| 말소자 | 비정상 비율 흰색 인간형(언캐니) | 희귀 언캐니 위협 — 유일한 흰색 예외(§14.4) |

### 14.3 세력 비주얼 정체성 — 4그룹 공유 문법 (DEC-044, 2026-06-02)

세력은 메커닉이 아니라 **디자인 정체성 그룹**이다(평판·소속·퀘스트 없음). 각 세력은 실루엣·팔레트·모티프의 공유 문법으로 묶여, 한 화면에서 "어느 세력인가"가 즉시 읽힌다(§11.2 실루엣 게이트). 말소자만 5톤 팔레트(§2.1)를 의도적으로 위반한다(§9.2 규칙 확립 후 위반).

| 세력 | 공유 실루엣 | 팔레트 (5톤 기준) | 모티프 | 톤 |
| :--- | :--- | :--- | :--- | :--- |
| 잔존자 | 인간형, 누더기·생활 천, 굽음/작음. 비대칭 생활감 | Cold Cyan-Teal 정체성 + Warm Amber 점광, 무채색 바탕 | 식기·죽·단조 망치·천 | 따뜻함·손때 |
| 인덱서 | 인간형이나 의례 천·모자로 균질화. 합창 정렬 군집 | Deep Black 의례 천 + 응결재(Industrial Grey 굳은 질감) | 지팡이 박자·안치 포드·부조 얼굴·chant | 신앙·균질·섬뜩 |
| 말소자 | 비정상 비율 인간형(언캐니). 단일/무 광원 | **Near-White (5톤 위반) — 무균·부재의 흰색** | 흰 표면·잘못된 대칭·무감정 | 절대 이질·증오 없는 절멸 |
| 드론 | 32px 소형, 둥근 단순 잡몹 실루엣 (귀엽게 연출하지 않음) | 환경 색온에 동화(채도 낮음) | 평범한 잔존 생물(슬라임·골격·부유형) | 일상·무해(반어적, 정서 중립) |

세력 구분 규칙:

- **잔존자 vs 인덱서:** 같은 인간형이나 인덱서는 의례 천·모자로 실루엣을 균질화하고 응결재 질감을 입는다. 잔존자는 개별 생활감.
- **말소자 vs 그 외 전부:** 유일한 흰색. 5톤을 깨는 단 하나의 신호 → "이것은 다른 질서다."
- **드론 vs 말소자:** 동시 등장하지 않는다(DEC-044). 드론=평범한 일상, 말소자=절대 이질. 한 공간에 섞지 않음으로 대비를 보존. (드론은 "귀여운"이 아니라 "평범·무해·정서 중립" — 2026-06-05 폐기.)

### 14.4 말소자 — 흰색 언캐니 32px 사양

말소자는 BLAME! 세이프가드식 흰색 언캐니 인간형 호러다. 희귀(특정 공간·이벤트, DEC-044). 32px·픽셀 정합에서 "소름끼침"을 실루엣 게이트(§11.2)로 통과시키는 최소 규칙:

| 채널 | 규칙 |
| :--- | :--- |
| 명도 | 단일 near-white. 내부 디테일 최소 — 평면적 흰 덩어리가 더 불쾌(uncanny) |
| 비율 | 인간형이되 잘못된 비율 — 과긴 사지/목, 머리 비대, 좌우 미세 비대칭. 정상 인체 실루엣을 어긋냄 |
| 모션 | 절제·비인간 — 정지가 길고, 이동이 끊기거나(stutter) 비관절적. 무감정 |
| 윤곽 | Deep Black 외곽선으로 흰 덩어리를 배경에서 분리(밝은 환경에서도 읽히게) |
| 등장 | 정적 + 사운드 부재 + 드론 부재가 선행 신호. 화면 점유는 위협 시 크게, 평소 부분 가림(형체 다 안 보임 — §14.2 불가지·고독) |

검수: 32px 흰 실루엣만으로 (a) 인간형임이 읽히되 (b) "정상이 아님"이 동시에 읽혀야 통과. 둘 중 하나만이면 재설계.

## 15. 3축 시각 차별화 — World / Builder / Item Stratum

> 방법론 근거: §9 평행 구조·대비, §10 컬러 스크립트, §12 형태 심리, 시놉시스 "수직 한 — 메가 스트럭처 → 빌더 → 포지 다이브 3중 z축".

### 15.0 2-Space(시스템) vs 3-Zone(시각)의 정합

용어집의 2-Space 모델(World / Item World)은 솔로 탐험 vs 협동 파밍의 **시스템 구분**이다. 본 절의 3축은 플레이어가 눈으로 겪는 **시각·경험 구분**이다. Builder 내부는 시스템상 World 의 세이브 포인트(대장간·포지)이나, 시각상 World 외부 탐험과 Item Stratum 다이브 사이의 독립 위상이다. 두 분류는 충돌하지 않는다 — 시스템 2분, 시각 3분.

### 15.1 차별화 원리 — 동시 다중 컴포넌트 대비

한 요소만 바꾸면 차이가 약하다. Block 의 시각 강도 원리에 따라, 축이 바뀔 때 **7요소 중 5개 이상을 동시에 뒤집는다**. 색만이 아니라 공간·선·형태·움직임·사운드가 한꺼번에 전환되어야 플레이어가 차이를 강렬하게 인지한다.

| 컴포넌트 | World (메가 스트럭처) | Builder (내부) | Item Stratum (에코 위상) |
| :--- | :--- | :--- | :--- |
| 공간 (Block) | 딥 스페이스 — z축 광활, 3층 패럴랙스 | 리미티드 — 좁고 낮은 천장, z축 압축 | 앰비규어스 — 무중력 부유, 방향 모호 |
| 지배 색 | Industrial Grey + Deep Black | 어두운 청-회색 + Warm Amber 점광 | Cold Cyan-Teal 발광 + Amber 조각 |
| 색온 | 차가움(중성 회색) | 따뜻함(호박 침투) | 비물질 한색(청록) |
| 명도 | 로키, 명도 친연(거대 단조) | 국소 고대비(포지 발열) | 발광 하이라이트, 어둠 속 점광 |
| 선·형태 | 수직 격자·직선(질서·경직) | 곡선·유기(내장 조직, 둥근 안식) | 불규칙·해체·부드러운 가장자리 |
| 형태 심리 | 수직 부피 = 압도·무관심 | 원형 = 안전·둥지 | 비정형 = 내면·비물질 |
| 움직임·리듬 | 느린 거대 펄스(시공 박자) | 감쇠된 굉음 + 단조 박자(풍물 5조) | 정적 + 느린 표류(보스 시 가속) |
| 사운드 닻 | 시공 굉음(저역 지배) | 굉음 먹먹 + 망치 + 죽 끓음 | 굉음 완전 부재 + 잔향 + 한 음성 |
| 정서 | 외경·고독 (恨) | 안도·온기 (情) | 응답·비물질 (응결) |

### 15.2 불변 닻 — 전환 중 방향 상실 방지

모든 것이 뒤집혀도 두 요소는 3축에 걸쳐 유지된다(연속성, Framed Ink). 이 닻이 플레이어를 잃지 않게 한다.

- 붉 5%(에르다 머리) — 어느 축에서도 화면의 시선 1순위(에코 내부 §5.1 의 적색 부재 검토 시에도 인물 실루엣은 유지).
- 호박 실(thread) — World 점광 → Builder 안식 → Stratum 조각으로 형태만 바뀌며 끊기지 않음.

### 15.3 전환 설계 — 경계에서 가장 강하게 인지

차이는 경계 통과 순간에 가장 강렬하다. 세 전환마다 다중 컴포넌트를 동시에 플립한다.

| 전환 | 트리거 | 동시 플립 | 효과 |
| :--- | :--- | :--- | :--- |
| World → Builder | 빌더 옆구리 균열 진입 | 굉음 감쇠 + 공간 압축 + 색온 상승(회색→호박) + 격자→곡선 | 톤 휘플래시 시작 — 외경에서 안도로 |
| Builder → Item Stratum | 포지 격발 5단계(§4.2) | 호박 폭발 → 청록 잔향 → 메가 스트럭처 소멸 → 굉음 정지 | 최대 강도 스파이크 — 컬러 스크립트 정점 |
| Item Stratum → World | Trapdoor 귀환(DEC-039) | 청록 페이드 → 굉음 복귀 → 회색·z축 복원 | 비물질에서 거대 물질로 회귀 |

포지 격발(중앙 전환)이 가장 자주·가장 강하게 겪는 경계이므로 §4.2 5단계가 본 차별화의 핵심 비트다.

### 15.4 단일 프레임 명료성 검수

3축 차별화의 합격 기준 — 임의의 한 프레임(스크린샷)을 색온·형태·모션만으로 World / Builder / Item Stratum 중 무엇인지 1초 내 분류 가능해야 한다. 분류가 모호하면 그 화면의 컴포넌트 대비가 부족한 것이며, §15.1 표에서 아직 뒤집지 않은 컴포넌트를 추가로 플립한다.
