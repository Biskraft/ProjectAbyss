> **월드·아이템계 단일 통합 모델 (2026-06-08 확정):** 미니맵은 월드·아이템계 **동일한 단일 시스템**이다 — 진입 즉시 룸-셀 공개, 상시 위치 도트, 실시간 갱신, 자동 마커. **유일한 차이 = 맵 수명**: 월드는 영구 저장(누적), 아이템계는 절차 생성이라 지층 전이 시 리셋. 이는 미니맵 동작의 차이가 아니라 레벨 수명의 차이다. 아이템계 고유 오버레이 마커(DOWN·분기·보물·Archive)는 §2.1 참조.

## 0. 설계 원칙

### 0.1. 적용 범위

- **게임 전체 단일 시스템.** 미니맵은 월드·아이템계 **양쪽에 동일 시스템**으로 적용된다.
- **월드:** 상시 HUD 미니맵. 영구 저장(누적).
- **아이템계:** 동일 시스템. 단 절차 생성이라 지층 전이 시 리셋(맵 수명 차이뿐, 미니맵 동작은 동일).

### 0.2. 핵심 결정

| 결정 | 근거 |
|:---|:---|
| 미니맵 = 게임 전체 단일 시스템 | 월드·아이템계 동일 적용. 두 공간을 별도 모델로 가르지 않음 |
| 두 공간의 유일한 차이 = 맵 수명 | 월드=영구 저장, 아이템계=지층 전이 리셋(절차 생성 레벨 수명). 표현·조작은 동일 |
| 진입 즉시 공개 (Blasphemous식) | 별도 조건(벤치/구매) 없이 방 진입만으로 맵 공개. 학습 비용 최소 |
| HUD 패널 16:9 | 게임 화면 비율(640x360)과 정합. 공간 낭비 최소 |
| 세이브 포인트 항상 표시 | 사망 페널티가 있는 게임에서 귀환 지점 인지는 심리적 안전망 |

## 1. HUD 미니맵 — P1

### 1.1. 패널 사양

| 항목 | 값 |
|:---|:---|
| **위치** | 화면 우상단 |
| **크기** | 128 x 72 px (16:9 비율) |
| **배경** | 반투명 검정 (alpha 0.6) |
| **테두리** | 1px 회색 (#666666) |
| **투명도 (평상시)** | 70% 불투명 |
| **투명도 (전투 중)** | 40% 불투명 |
| **토글** | TAB 키로 표시/숨김 |
| **공간 전환 시** | 진입한 공간(월드/아이템계 지층)의 맵으로 콘텐츠 전환. 패널 자체는 상시 유지 |

### 1.2. 표시 범위

현재 방 + 인접 방 (상하좌우 3칸 이내). 방은 크기가 다양하므로, 현재 방을 중심에 놓고 주변 방을 상대 위치로 배치.

### 1.3. 방 상태와 표시

| 상태 | 조건 | 미니맵 표시 |
|:---|:---|:---|
| `UNDISCOVERED` | 진입 없음, Map Station 미활성 | 표시 안 함 |
| `OUTLINED` | Map Station 활성화로 외곽선 공개 (P2, 월드 전용) | 층위색 어두운 외곽선 |
| `VISITED` | 한 번 이상 진입 | 층위 테마색으로 채움 |
| `CLEARED` | 방 내 모든 적 처치 | VISITED + 작은 체크 기호 |

**상태 전환:**
- `UNDISCOVERED` → `VISITED`: 방 진입 순간 즉시 (Blasphemous 모델)
- `UNDISCOVERED` → `OUTLINED`: Map Station 활성화 시 (P2, 월드 전용)
- `VISITED` → `CLEARED`: 방 내 적 전멸 시
- 월드에서 상태는 **영구 저장**(사망/로그아웃 후에도 유지). 아이템계에서는 지층 전이 시 리셋

### 1.4. 층위별 색상 (월드)

| 구역 (D-20 §3, 상승 순) | 맵 색상 |
|:---|:---|
| 침수 바닥층 (Zone 1, 시작) | #2A4A6C (남색) |
| 무너진 거주 구역 (Zone 2, 잔존자 마을) | #5A7A8C (회청) |
| 거대 공장층 (Zone 3) | #8C5A2A (산업 적갈) |
| 무너진 환승역 (Zone 4) | #4AACCC (청록) |
| 봉인된 하부 (Zone 5) | #4A3A2A (어두운 갈색) |
| 대 안치소 (Zone 6) | #6A4A8C (청보라) |
| 정상 관제정 (Zone 7, 정상) | #8C2A2A (심홍) |

> 아이템계 지층은 자체 지층 테마색을 사용한다(베이스 아이템 레어리티/속성 기반). 색상 동작 자체는 월드와 동일.

### 1.5. 현재 방 표시

현재 방은 **흰색 테두리 (2px)** + **깜박이는 플레이어 점 (3x3 px, 흰색)**.

## 2. 자동 마커 — P1

시스템이 자동으로 배치하는 아이콘. 해당 방 최초 진입/발견 시 표시.

| 마커 | 아이콘 | 색상 | 조건 |
|:---|:---|:---|:---|
| **세이브 포인트** | 별 ★ | 빨강 | 발견 즉시 |
| **모루 (아이템계 진입)** | 모루 ⚒ | 금색 | 발견 즉시 |
| **보스 방 (미처치)** | 해골 ☠ | 주황 | 진입 시 |
| **보스 방 (처치 완료)** | 해골에 X | 회색 | 보스 처치 시 변경 |
| **스탯 게이트** | 방패 | 파랑 | 접근 시 |
| **능력 게이트** | 열쇠 | 초록 | 접근 시 |
| **상점** | 동전 | 노랑 | 발견 즉시 |

### 2.1. 아이템계 지층 오버레이 마커 (MAP-08)

아이템계 지층에서만 추가로 배치되는 자동 마커. 절차 생성 지층의 진행 분기를 표시한다.

| 마커 | 아이콘 | 조건 |
|:---|:---|:---|
| **DOWN (다음 지층 계단)** | 하강 화살표 | 발견 즉시 |
| **LR 분기 (좌·우 갈림길)** | 분기 노드 | 진입 시 |
| **보물 방** | 상자 | 발견 즉시 |
| **Archive (기록실)** | 문서 | 발견 즉시 |

## 3. 전체 맵 (Full Map) — P2

### 3.1. 접근

일시정지 메뉴 → 맵 탭. 또는 전용 키 (M).

### 3.2. 사양

| 항목 | 값 |
|:---|:---|
| **표시 범위** | 월드: 전체 세계 (7 층위 수직 배치) / 아이템계: 현재 지층 전체 |
| **스크롤** | 상하 자유 스크롤 |
| **줌** | 2단계 (전체 조감 / 층위 상세) |
| **현재 위치** | 깜박이는 흰색 점 |
| **완료율** | 우하단 "탐험: XX%" |

### 3.3. Map Station (월드 전용)

- 각 층위에 1개의 Map Station 방 존재
- 활성화 시 해당 층위의 모든 방이 `OUTLINED` 상태로 공개 (외곽선만, 내부 미공개)
- Map Station은 세이브 포인트 인접 배치 (안도 구간에서 준비하는 패턴)
- 아이템계는 절차 생성·휘발성이므로 Map Station 미적용

### 3.4. 수동 마커

- 최대 10개 배치 가능
- 종류: 방문 필요 / 미수집 아이템 / 미해결 퍼즐 / 위험 구역
- 탐험한 방에만 배치 가능
- HUD 미니맵에도 표시

## 4. 구현 가이드

### 4.1. 데이터 구조

```typescript
interface RoomMapState {
  levelId: string;        // LDtk level identifier
  state: 'undiscovered' | 'outlined' | 'visited' | 'cleared';
  markers: string[];      // auto-marker IDs
  userMarkers: string[];  // player-placed markers
}
```

월드의 각 LDtk 레벨에 대해 RoomMapState를 SaveManager에 저장(영구). 아이템계 지층은 동일 구조를 사용하되 지층 전이 시 폐기(저장하지 않음).

### 4.2. 렌더링 구조

```
MinimapContainer (128x72)
├── Background (반투명 검정)
├── RoomRects (인접 방들, 층위색으로 채움)
│   └── 현재 방: 흰색 테두리
├── MarkerIcons (자동 마커 아이콘)
├── PlayerDot (3x3 깜박이는 점)
└── TierLabel ("Tier 2")
```

### 4.3. 표시/숨김 조건

| 상황 | 미니맵 |
|:---|:---|
| 월드 탐험 중 | 표시 (70% 불투명) |
| 월드 전투 중 | 표시 (40% 불투명) |
| 아이템계 탐험 중 | 표시 (현재 지층 맵, 70% 불투명) |
| 아이템계 전투 중 | 표시 (40% 불투명) |
| 일시정지 메뉴 | 숨김 (전체 맵 사용) |
| 대화/컷신 | 숨김 |

## 5. 스파이크 검증

> "아이템에 들어가면, 그 아이템의 기억이 던전이 된다"

| 요소 | 스파이크 강화 방식 |
|:---|:---|
| **단일 미니맵** | 월드·아이템계 동일 미니맵 = 두 공간을 잇는 일관된 탐험 언어. 채워지는 맵 = 진전 보상 |
| **수명으로만 대비** | 월드 맵은 영구 누적(알려진 구조물), 아이템계 맵은 지층마다 휘발(휘발성 기억). 동일 미니맵이 영속성으로만 갈린다 |
| **아이템계 = 회상 은유** | 지층 전이 리셋이 "기억을 매번 새로 더듬는다"로 읽힌다 |
