## 0. 북극성 — 정서·서사 비전 (Emotional & Narrative Spine)

> 아카이브 `Project_Vision_Abyss.md` 병합. ECHORIS의 모든 설계는 이 척추로 수렴한다.

### 0.1 한 문장 (Logline)

> **"끝없이 자라는 메가 스트럭처에서, 잊혀진 자들이 무기에 남긴 마지막 한 마디를 들으며, 자기 자신에게 도달하는 이야기."**

### 0.2 정서적 척추 — 한정흥(恨情興) (DEC-042)

마케팅엔 이 단어를 쓰지 않되, 모든 설계가 세 정서의 순환을 만든다.

| 정서 | 게임 내 구현 |
| :--- | :--- |
| **한 (恨)** — 미완의 응어리 | 잊혀진 자들의 에코(미완의 마지막 한 마디). 빌더가 인간을 지운 코스믹한 상실 |
| **정 (情)** — 끈끈한 유대 | 무기 Ego(Rustborn)와의 관계. 코옵 파트너. 잔존자 마을 |
| **흥 (興)** — 신명·생명력 | 야리코미(아이템계 무한 강화). 전투의 쾌감. 단조(Forge)의 리듬 |

핵심: 한(상실) → 정(유대) → 흥(생명력) 의 순환.

### 0.3 세 기둥 (Three Pillars)

| 기둥 | 한 줄 |
| :--- | :--- |
| **탐험** | "묻힌 세계를 오른다" — 메가 스트럭처를 기어올라 빌더의 무관심과 잊혀진 흔적을 목격 |
| **야리코미** | "기억을 되살린다" — 아이템계에서 무기의 에코를 회상시켜 강화 |
| **연결** | "함께 듣는다" — 코옵으로 깊은 곳에 함께 도달 (URL 링크 합류) |

### 0.4 세계관 핵심 (World Premise, v3)

> 거대한 빌더들이 의도 없이 끝없이 짓는다. 시공 경로상의 모든 것은 묻혀 간다. 인간은 한때 빌더의 블루프린트 안에 있었으나, 단절(Cascade) 이후 누락되었다. 빌더가 자랄수록 인간이 머물 빈 공동이 줄어든다.

| 요소 | 설정 |
| :--- | :--- |
| **빌더 (Builder)** | 메가 스트럭처를 끝없이 짓는 거대 산업 시공자. 의지·적의 없음. 인간 인지 못 함. 파괴 불가 |
| **메가 스트럭처** | 빌더가 짓는 거대 수직 구조물. 게임의 무대 |
| **에코 (Echo)** | 잊혀진 자가 무기에 남긴 마지막 한 마디 응결체 = 모든 장비. 작품명 어원 |
| **포지 (Forge)** | 빌더 내부 거대 단조 장치. 에코 격발 = 아이템계 진입 메커니즘 |
| **단절 (Cascade)** | 인간이 블루프린트에서 누락된 사건. 코스믹 호러의 근원 |
| **잔존자 (Remnant)** | 아직 지워지지 않은 인간들. 마을을 이루거나 인덱서가 됨 |

### 0.5 주인공 — 에르다 (Erda)

| 항목 | 내용 |
| :--- | :--- |
| 정체 | 메가 스트럭처 가장 깊은 바닥에서 *백업으로* 깨어난 자. 자기 이름·과거를 모름 |
| 목표 | 무기의 에코를 들으며 자기 자신에게 도달 |
| 변화 호 | 들리고 싶었던 자 → 들어주는 자 → 자기 자신에게 응답하는 자 |
| 침묵 | 대사 0줄. Sculpted Avatar. 진엔딩에서만 1줄 발화 |

> 상세 서사: `Documents/Content/Content_Story_Synopsis.md` v3.

### 0.6 절대 규칙 (Inviolable Rules)

1. **무기는 사람이다.** 모든 강화는 한 사람의 기억(에코)을 되살리는 것.
2. **빌더는 적이 아니다.** 무관심한 자연력. 증오 없는 절멸.
3. **에르다는 침묵한다.** 대사 0줄(진엔딩 1줄 예외).
4. **한정흥을 마케팅에 노출하지 않는다.** 정서는 경험으로 전달.
5. **2-Space를 지킨다.** 월드=탐험, 아이템계=파밍.
6. **상점이 파밍·강화·이동 능력을 대체하지 않는다.** (D3 RMAH 교훈)

## 2. 2-Space 분리 모델

게임 세계를 **월드(World)**와 **아이템계(Item World)** 두 공간으로 분리하여, 각 공간이 고유한 규칙과 목적을 갖도록 설계한다.

> **변경 이력 (2026-04-04):** 허브(Hub)는 독립 공간에서 폐기. 대장간/상점은 월드 세이브 포인트에 통합. 파티 합류는 URL 링크 공유로 아이템계 직접 진입.

### 2.1 공간 비교표

| 항목                  | 월드 (World)                                         | 아이템계 (Item World)                          |
| :-------------------- | :--------------------------------------------------- | :--------------------------------------------- |
| **핵심 목적**   | 탐험, 능력 획득, 스토리, 대장간/상점 (세이브 포인트) | 아이템 강화, 야리코미                          |
| **인원**        | 솔로(1인)                                            | 1 ~ 4인                                        |
| **맵 유형**     | 핸드크래프트 + 절차적 혼합                           | 완전 절차적 생성                               |
| **진행 방식**   | 능력 게이트 (메트로베니아)                           | 지층 클리어 (레어리티별 2-4 지층)              |
| **사망 페널티** | 세이브 포인트 복귀                                   | 진행 지층 손실 (탈출 아이템 미사용 시)         |
| **고유 자원**   | 능력 렐릭, 맵 데이터, 월드 소재                      | Memory Recovery, Memory Fragment, 정체성 결 |

### 2.2 공간 구조도

## 3. 월드 (World) 설계

> v3 정합 (D-20 기준, 2026-06-01): 하강→상승, 판타지 바이옴→메가스트럭처 7구역, 마르타·심연의 구·중앙 성채·심연 전쟁 폐기.

### 3.1 월드 구조 원칙

월드는 빌더가 끝없이 짓는 거대 시공 구조물(메가 스트럭처) 그 자체다. 플레이어는 가장 깊은 바닥에서 깨어나 정상을 향해 **위로 기어오른다(상승 주축)**. 단조로운 상승을 피하기 위해 중반에 한 번 급강하(추락)했다가 다시 급상승하는 3박자 리듬을 둔다. 거점은 잔존자 마을(단조소)이며, 하강은 다이브(아이템계) 축이 전담한다. (상세: `Documents/Design/Design_World_Master.md` D-20 §2)

```
   [정상 — 관제정 / the Crown]   ⌖ 클라이맥스. 빈 옥좌(부재의 관리 권위)
          ▲  (급상승: 누적 능력으로 빠르게 재상승)
   [대 안치소 / the Great Internment]   (인덱서의 가짜 송신소)
          ▲
   [봉인된 하부 / the Sealed Underworks]  ⌖ 최저점. 급강하로 떨어진 미답 심부
          ⤓  (급강하: 무너짐/추락으로 바닥까지)
   [무너진 환승역 / the Broken Concourse]  ── 상승의 정점 직전
          ▲
   [거대 공장층 / the Great Works]
          ▲
   [무너진 거주 구역 / the Collapsed Wards]  ← 잔존자 마을(단조소). 초반 거점
          ▲
   [침수 바닥층 / the Drowned Floor]   ← 게임 시작. 백업으로 깨어나는 곳
```

### 3.2 스탯 게이트 시스템

월하의 야상곡의 렐릭 시스템 + 디스가이아의 스탯 시스템을 결합한 **스탯 게이트**를 도입한다. 장비의 스탯이 월드 진행의 열쇠가 된다.

| 스탯          | 게이트 유형 | 예시                                            |
| :------------ | :---------- | :---------------------------------------------- |
| **ATK** | 물리 장벽   | 금이 간 시공 단위·바리케이드·봉인 격벽 파괴   |
| **INT** | 시공 봉인   | 빌더 봉인 문양·도면 잠금·아케인 잠금장치 해제 |

> **설계 변경:** 기존 6대 스탯 게이트(STR/INT/DEX/VIT/SPD/LCK)는 ATK/INT 이중 게이트로 재설계. ATK는 물리 장벽(파괴), INT는 마법 봉인(해제). 기동성/환경 저항/시간 제한 등은 능력 게이트나 환경 퍼즐로 재설계 예정.

**핵심 설계 의도:** 아이템계에서 장비를 강화하면 월드의 새로운 구역이 열린다. 이것이 월드 ↔ 아이템계 순환의 핵심 동력이다.

### 3.3 능력 게이트 시스템

전통적인 메트로베니아 능력 게이트도 병행한다. 보스를 처치하거나 숨겨진 렐릭을 발견하여 획득한다. 렐릭 배치는 D-20 §4.2(7구역 Critical Path 격벽 배분) 기준.

| 능력                            | 해금 구역        | 열리는 구역                                 |
| :------------------------------ | :--------------- | :------------------------------------------ |
| 대시(시작 보유)·수중 호흡      | 침수 바닥층      | 좁은 간격 / 침수 구간                       |
| 반중력                          | 무너진 거주 구역 | 부유 컨테이너 발판 + 역류 유체 수위         |
| 벽 점프·자기 점착 클램프(빌더) | 거대 공장층      | 수직 통로 / 빌더 표피 등반 (+ATK 게이트)    |
| 역류의 쇄도(surge)              | 무너진 환승역    | 높은 공동 상승 (상승 정점, +INT 게이트)     |
| 추락의 영혼(diveAttack)         | 급강하 비트      | 하방 층 관통                                |
| 이단 점프·극성 부츠(빌더)      | 봉인된 하부      | 높은 단차 / 빌더 금속 천장 보행             |
| 공명 펄스·빌더 제어 노드(빌더) | 대 안치소        | 그리드 한 박자 정지 횡단 / 구조 재편 재상승 |

> **역중력 재정의(2026-06-01):** 구 캐논의 역중력은 보류. 기능은 **반중력**(사물·유체 부유)과 **극성 부츠**(빌더 금속 천장 보행)로 분할 흡수, 상승 게이트는 **surge**가 담당.
> **폐기:** 안개 변신(2026-05-18, SotN Mist Form 카피 우려). 재도입 금지.

### 3.4 맵 생성 방식: 스펠렁키 하이브리드

- **매크로 구조:** 핸드크래프트. 구역 간 연결, 보스 방, 세이브/워프 룸은 고정 배치
- **마이크로 구조:** 절차적 생성. 각 구역 내부의 방(Room)은 스펠렁키 방식의 템플릿 조립
- **시드:** 서버 고정 시드
- **Always Winnable:** 모든 시드에서 클리어 가능한 Critical Path 보장

## 4. 아이템계 (Item World) 설계

### 4.1 핵심 개념

> 모든 장비 아이템은 내부에 **던전**을 가지고 있다. 플레이어는 아이템 속에 들어가 층을 클리어하며, 아이템을 직접 강화한다.

### 4.2 기본 구조 (레어리티 지층 모델, DEC-039/037)

> 옛 "100층 단일 던전"(디스가이아 직차용)은 폐기. 현 캐논은 **레어리티별 지층(Strata)** 모델이다.

| 항목          | 사양                                                                                          |
| :------------ | :-------------------------------------------------------------------------------------------- |
| 지층 수       | 레어리티별: Normal 1 / Magic 2 / Rare 3 / Legendary 4 / Ancient 4 + 심연 (DEC-039 단일 다이브 기준) |
| 토폴로지      | 방사형 RoomGraph (DEC-037, hub_spoke / Ancient = multi_hub). 지층당 노드 7-20. SSoT: `Sheets/Content_StrataConfig.csv` |
| 테마          | 5기질(forge/iron/rust/spark/shadow). 무기 기질이 fluid·container·날씨를 자동 바인딩 |
| 보스          | 각 지층 보스 처치 시 다음(더 깊은) 지층 개방. 최심 지층 클리어 = 월드 세이브 포인트 귀환 |
| 탈출          | Mr. Gency Exit (200 HL 소모품) 또는 지층 클리어                                               |
| 시드          | `hash(itemID + 지층)` → 동일 아이템의 동일 지층은 항상 같은 맵                             |
| 인원          | 1-2인 (Phase 3) / 최대 4인 (Phase 4+). 파티 리더의 아이템에 진입                             |
| 순환 진입     | 아이템계 획득 아이템은 월드 귀환 후 해당 아이템계에 재진입 (중첩 진입 없음)                  |
| 하강 축       | 다이브는 지층을 **아래로** 내려감 (3축 원칙 — `Design_Level_Standards`). 깊을수록 위험·보상↑ |

### 4.3 지층 생성 규칙 (RoomGraph, DEC-037)

```
[지층 생성 파이프라인]

1. 시드 결정
   seed = hash(itemID + 지층 인덱스)

2. RoomGraph 생성 (DEC-037)
   - 토폴로지: hub_spoke(단일 허브 방사형) / Ancient = multi_hub(2 허브)
   - 노드/가지/허브 수 = Content_StrataConfig.csv (레어리티·지층별)
   - Critical Path: 입구 → 하강 게이트(보스) 보장 (Always Winnable)

3. 지형 조립
   - 각 Room 노드에 Chunk 템플릿 삽입
   - 5기질 테마가 fluid·container·날씨·팔레트 자동 바인딩

4. 오브젝트 배치
   - 적 배치 (지층 깊이 기반 난이도 스케일링, 8 BASE 아키타입 × 속성)
   - 환경 서사 오브젝트 배치 (측량 일지·결정질 표지 등 → 상호작용 시 Recovery 점진 수급)
   - 보상·미스터리 룸·지오 이펙트·비밀방 (선택)
```

### 4.4 보스 시스템 (지층 보스)

각 지층의 보스(기억의 문)를 처치하면 다음(더 깊은) 지층이 열린다. 보상의 본체는 ATK +N이 아니라 **한 문장(Memory Fragment)**이다 (DEC-046). 최심 지층 클리어 = 그 인생의 *진명(True Name)* 확정.

| 위치 | 처치 보상 (DEC-046) |
| :--- | :--- |
| 각 지층 보스 (Tier 1-4) | Memory Fragment 1개 해금(Identity Archive 영구 등록) + Recovery 단계 점프(Stage +1) + 이름 진화 + 정체성 결(Identity Trait) 가동 |
| Ancient 심연 보스 | Re-Dive 영역 개방. 같은 인생의 다른 해석 단편 + Network Fragment(인물 관계 1차 자료) |

> 보스 디자인 SSoT: `System_ItemWorld_Boss`. 디스가이아 장군/왕/신/대신 티어는 *명칭 차용*이며, 구조는 레어리티 지층에 매핑된다. **폐기(DEC-046):** 보스 영구 스탯 +N, 핵심 기억(Core Memory), 레어리티 승급 기회.

### 4.5 순환 진입 (Sequential Entry Loop)

> **변경 (2026-04-05):** 재귀적(중첩) 진입은 삭제되었습니다. 아이템계 진입은 항상 월드에서만 가능합니다.

```
[순환 진입 루프]
  월드 → 아이템 A의 아이템계 진입 → 아이템 B 획득 → 월드 귀환
  월드 → 아이템 B의 아이템계 진입 → 아이템 C 획득 → 월드 귀환
  월드 → 아이템 C의 아이템계 진입 → ...
  (무한 순환)
```

**핵심 원칙:** 아이템계 내부에서 다른 아이템의 아이템계에 중첩 진입할 수 없다. 아이템계에서 획득한 아이템은 인벤토리에 저장되며, 월드로 귀환한 뒤 세이브 포인트/대장간에서 해당 아이템의 아이템계에 새로 진입한다. 스파이크("아이템 속으로 들어간다")는 유지되며, 순환 구조가 끝없는 파밍 루프를 제공한다.

## 5. 기억 복원 시스템 (Memory Recovery System) — DEC-046

> **DEC-046 (2026-05-24):** 장비 성장의 정체성이 *강화(없던 힘을 더함)*에서 **복원(원래 있던 힘을 깨움)**으로 전환되었다. 구 "5색 기질 Memory Shard / 정체성·기억 슬롯 / 단편 전이·합성·변이 / 아이템 레벨·EXP / 레어리티 승급" 메커닉은 **전면 폐기**되었다.
> 활성 SSoT: `Documents/System/System_Equipment_Growth.md` (SYS-EQP-03, 재설계 완료). 진행 규칙 본래 SSoT였던 `System_Memory_Core.md`는 2026-05-28 리셋으로 아카이브됨(헤더 SSoT 경고 참조).

### 5.1 개요 — 복원의 언어

모든 장비 아이템은 *드랍된 잠재력의 씨앗*이 아니라 **100년 전에 끝난 한 사람의 완성된 인생**이다. 그 기억은 흩어져 있고, 무기는 잠재력의 절반(40%)만 발현된 채 발견된다. 플레이어는 아이템계에서 그 흩어진 기억을 회수하여 무기를 100% 발현 상태로 *해방*한다.

> **"이 무기를 한 번 더 두드리면 다음 단계로 올라간다"는 강화의 언어다.**
> **"이 사람의 다음 페이지를 보면 또 한 면이 드러난다"는 복원의 언어다.** ECHORIS는 후자를 택한다.

### 5.2 단일 진행 축 — Memory Recovery (0-100%)

장비 성장은 **단일 게이지 Memory Recovery**로 통합된다. 모든 효과(스탯, 이름, 정체성 결, 컬렉션)가 이 게이지에서 자동 파생된다.

| 수급원 | Recovery 증가 | 비고 |
| :--- | :---: | :--- |
| 지층 보스 처치 | +25% 단위 점프 | Stage +1. Memory Fragment 해금 동시 발생 |
| 비밀방 발견 | +1.0% | 가장 강한 점진 보상 |
| 환경 서사 오브젝트 | +0.5% | 측량 일지 등, 1회 한정 |
| 방 클리어 | +0.3% | — |
| 일반 적 처치 | +0.1% | 점진 누적 |

- Recovery 증가는 **아이템계 내에서만** 발생 (월드 탐험으로는 증가하지 않음).
- 보스 점프는 `Recovery = max(현재, stageJumpTarget)` — 점진 누적분은 흡수되어 손실되지 않음.
- effective stat 공식 (§7.x·§11.2 정합): `effectiveStat = baseStat × (0.4 + Recovery × 0.006) × rarityMultiplier × (1 + reDive × 0.05)`. Recovery 0% → 잠재력 40%, 100% → 100%.

### 5.3 보상의 본체 — Memory Fragment + Identity Trait

보스 처치의 본체 보상은 수치가 아니라 **한 문장**이다.

| 요소 | 정의 | 획득 |
| :--- | :--- | :--- |
| **Memory Fragment (문장)** | Identity Archive에 영구 등록되는 한 문장. 보상의 *서사적* 본체. 무기 분실·판매해도 보존 | 지층 보스 처치 시 1개 |
| **Identity Trait (정체성 결)** | Fragment에 귀속된 무기의 본질적 효과. 무기의 모든 스킬·효과는 *가동 결의 합* | Fragment 해금 즉시 자동 가동 (상시, 발동 조건 내포 가능) |
| **Network Fragment (관계 단편)** | 두 인물 모두 100% 복원 시 해금되는 두 사람의 관계 1차 자료 | 인물 카테고리 교차 100% |

> 무기 교체 = 가동 결 조합 전체 교체. 같은 무기 타입이라도 복원된 인물이 다르면 완전히 다른 빌드.

### 5.4 이름 진화 (Name Evolution, 5 Stage)

Recovery 단계(`floor(Recovery / 25)`)가 바뀌는 순간 모든 UI에서 표시 이름이 즉각 갱신된다. 예 (측량사의 에코 쐐기):

`Unknown Wedge` → `Survey Tool` → `Guild Survey Tool` → `The Last Wedge` → `Surveyor's Echo Wedge` (진명)

Stage 4 = 진명(True Name) 확정 = 그 인생의 *Fire 모멘트* 문장 해금.

### 5.5 Identity Archive — 인물 컬렉션

야리코미의 정서적 핵심. 모으는 대상은 *물건*(인벤토리)이 아니라 **사람**이다.

- 무기 첫 획득 → `[Unknown]` 등록. Stage 1 도달 → 직업 분류. Stage 4 도달 → 진명 + 전체 Fragment 표시.
- 인물은 18개 카테고리(측량사/수리공/잠수사 등)로 분류. 카테고리 5인 100% 복원 시 **Echo Chord** 해금, 30인 이상 시 **Era Echo** 해금.
- 규모: 300인 × 4 Fragment + Re-Dive + Network = 약 5,000개 텍스트 컬렉션. 100% 도달 200-400시간(야리코미).

### 5.6 Re-Dive (재다이브) — 무한 야리코미

100% 복원 후에도 동기를 유지하는 장치. 같은 인생을 *다른 해석*으로 재방문.

| 항목 | 변화 |
| :--- | :--- |
| 지층·보스 | 동일 (같은 절차 시드) |
| 환경 시각 | 팔레트 시프트 (회상의 색조: 1차 시안 / 2차 자주 / 3차 회색) |
| Memory Fragment | 다른 해석 (회한 → 자긍심 → 후회) |
| Identity Trait | 결의 효과 변형 |
| effective stat | 회차당 +5% (최대 3회 = +15%) |

### 5.7 폐기 (재도입 금지, DEC-046)

- ~~5색 기질 (Forge/Iron/Rust/Spark/Shadow)~~ — 시각 토큰으로만 잔존 가능
- ~~정체성 슬롯 / 기억 슬롯 / Active·Passive 역할 분리~~ → 정체성 결은 상시 가동
- ~~단편 전이(Transfer) / 합성(Bond) / 효과 변이~~ → Re-Dive·Identity Archive로 대체
- ~~아이템 레벨 0-99 / 아이템 EXP / 핵심 기억(Core Memory)~~ → Recovery·Fragment로 대체
- ~~레어리티 승급(피티 시스템)~~ → 레어리티는 드랍 시점에 확정
- 단편 직접 발화 (화자는 검 Ego 1명), 단편 거래 시장, 무기 외 사용처, 자동 일괄 흡수

| 순환 요소              | 동력                            | 효과               |
| :--------------------- | :------------------------------ | :----------------- |
| 월드 → 아이템계       | 새 장비 획득, 더 강한 장비 필요 | 아이템계 진입 동기 |
| 아이템계 → 기억 복원  | 지층 클리어, Memory Fragment 회수 | 파밍/야리코미 + 서사 만족 |
| 기억 복원 → 월드      | Recovery → effective stat → 스탯 게이트 해금 | 새 구역 탐험 동기 |
| 월드 탐험 → 능력 획득 | 보스 처치, 렐릭 발견            | 이동 범위 확대     |
| 능력 → 월드 접근성    | 이단점프, 반중력 등             | 미탐험 구역 접근   |

### 7.3 자원 순환표

| 자원             | 획득처                   | 소비처                          | 역할                |
| :--------------- | :----------------------- | :------------------------------ | :------------------ |
| 장비 아이템      | 월드 드랍, 아이템계 보상 | 아이템계 진입 소재              | 순환의 핵심 매개    |
| Memory Recovery  | 아이템계 내 전투·탐험·서사 | effective stat 산정 (소비 아님, 게이지) | 야리코미 깊이 + 스탯 게이트 |
| Memory Fragment  | 지층 보스 처치           | Identity Archive 영구 등록 (소비 아님) | 무기 정체성 결 가동 + 서사 컬렉션 |
| 골드             | 적 처치, 아이템 판매     | 상점, 소모품                    | 기본 경제           |
| 월드 소재        | 월드 채집, 보스 드랍     | 장비 제작, 세이브 포인트 대장간 | 월드 탐험 동기      |

## 8. 멀티플레이어 설계

### 8.1 공간별 인원 구조

| 공간     | 최소 인원 | 최대 인원 | 매칭 방식                 |

| 아이템계 | 1         | 4         | URL 링크 공유로 직접 합류 |

### 8.2 멀티플레이 설계 원칙

1. **월드는 개인의 영역:** 탐험의 발견감을 보존하기 위해 솔로 전용
2. **아이템계는 협동의 영역:** 높은 난이도의 깊은 지층은 파티 플레이로 설계. 역할 분담 (탱커, 딜러, 서포터). URL 링크 공유로 친구가 아이템계에 직접 합류
3. **비동기 멀티:** 다른 플레이어의 유령(고스트)이 월드에 나타나 힌트를 남기는 시스템 (Dark Souls 메시지)

### 8.3 파티 역할과 시너지

## 11. RPG 성장 시스템

### 11.1 캐릭터 스탯

| 스탯     | 약어 | 역할                                                                                                      |
| :------- | :--- | :-------------------------------------------------------------------------------------------------------- |
| 공격력   | ATK  | 물리 데미지 산출. 장비 ATK + 캐릭터 기본 ATK. ATK 게이트(물리 장벽) 해금                                  |
| 지력     | INT  | 원소/인챈트 데미지 산출. 장비 INT + 캐릭터 기본 INT. INT 게이트(마법 봉인) 해금. 상태이상 지속시간 스케일 |
| 체력     | HP   | 생존. MaxHP는 캐릭터 레벨 + 장비 부여 HP(Recovery 기반 effective)로 성장                                  |
| 방어력   | DEF  | 물리 피해 감소. 장비에서 직접 제공                                                                        |
| 마법저항 | RES  | 원소 피해 감소. 장비에서 직접 제공                                                                        |

> **설계 변경:** 기존 9개 스탯(HP/MP/STR/INT/DEF/RES/DEX/SPD/LCK) → ATK/INT/HP 3스탯 + DEF/RES(장비 제공)로 단순화. MP 삭제 (스킬은 쿨다운). 크리티컬/드랍률/이동속도는 정체성 결(Identity Trait)로 보정. 원소 적중률 100% (상태이상 항상 발동, 지속시간은 INT 스케일).

### 11.2 성장 공식

```
Final_ATK = Base_ATK + Equipment_ATK
Final_INT = Base_INT + Equipment_INT
Final_DEF = Equipment_DEF + Buff_DEF
Final_RES = Equipment_RES + Buff_RES
Final_MaxHP = Base_HP + Level_Bonus_HP + Equipment_HP

- Base_ATK: 캐릭터 기본 공격력, Base_INT: 캐릭터 기본 지력 (3스탯 ATK/INT/HP, DEC-003)
- Equipment_ATK/INT/HP: 장비 effective stat (Memory Recovery 기반, §5.2 `effectiveStat` 공식)
- 크리티컬/드랍률/이동속도 등 부가 보정은 정체성 결(Identity Trait, DEC-046)이 담당
```

### 11.3 데미지 공식

```
물리 데미지 = (ATK × 스킬 배율 - DEF × 0.5) × 크리티컬 배율 × 랜덤(0.9-1.1)
원소 데미지 = (INT × 원소 배율 - RES × 0.5) × 크리티컬 배율 × 랜덤(0.9-1.1)

- 최소 데미지: 1 (0 이하 방지)
- 크리티컬 배율: 고정 1.5x
- 크리티컬 확률: 고정 5% (정체성 결로 보정 가능, 최대 50%)
```
