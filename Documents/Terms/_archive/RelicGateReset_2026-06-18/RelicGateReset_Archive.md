## 3. Design_World_Master.md §4.2 — D-GATE 확정안 원본

> 원래 §4.2 제목: "능력 게이트 (렐릭 — 출시 캐논 11) · D-GATE 확정 (2026-06-01)"
> 설계 원칙 원문:
> 1. **빌더 스파이크 선행** — 빌더는 이 게임의 스파이크(후크). 평면 보행은 일반 메트로베니아와 같으므로, 빌더 동사를 **미니 5분(Z1)부터 매 구역 하나씩** 지급해 빌더 상호작용이 진행의 척추가 되게 한다. 이동 6종은 빌더 사이를 잇는 베이스라인.
> 2. **SotN 개방형 페이싱** — 11렐릭 전부를 전반(Z1~급강하, ~57%)에 완성하고, **반중력을 Z4 인버전 capstone**으로 두어 후반 Z5-7(43%)을 자유시간 백트래킹 보상으로 전환한다.

| 구역 (진행률) | 획득 렐릭 | 빌더 동사 / 이동 | 열리는 것 |
| :--- | :--- | :--- | :--- |
| 1 침수 바닥층 (0-14%) | 대시(시작) · 수중 호흡 · **자기 점착 클램프**(빌더) | 빌더 점착·등반 — 첫 빌더 5분 후크 | 좁은 간격 / 침수 / 빌더 표피 등반 |
| 2 무너진 거주 구역 (14-28%) | **빌더 제어 노드**(빌더) · 이단 점프 | 빌더 구조 회전/기울임 (장애물→발판 재편) | 높은 단차 / 빌더 구조 재편 통행 |
| 3 거대 공장층 (28-43%) | **극성 부츠**(빌더) · 벽 점프 | 빌더 금속 외피·천장 부착 보행 | 수직 통로 / 거대 빌더 3D 보행 (+ATK 게이트) |
| 4 무너진 환승역 (43-57%) | **공명 펄스**(빌더) · 역류의 쇄도(surge) · **반중력** | 그리드 한 박자 정지 + 상승류 + **인버전 capstone** | 정지 횡단 / 높은 공동 상승 / 부유 컨테이너·역류 유체 (세계 재맥락화) |
| — ⤓ 급강하 (All Is Lost, ~57%) | 추락의 영혼(diveAttack) | 하방 관통 — 나디르 도구 | 봉인된 하부로 강하 → **자유시간 개방** |
| 5 봉인된 하부 (57-72%) | (신규 없음) | full kit 재방문 | INT 봉인 게이트 → 급상승 개시 |
| 6 대 안치소 (72-86%) | (신규 없음) | 반중력 백트래킹 보상 | 구조 재편 재상승 |
| 7 정상 — 관제정 (86-100%) | (누적 렐릭 최종 게이트) | 종합 숙련 | 종착 |

> 원본 주석:
> - **자유시간 구조 (SotN 모델):** 11렐릭이 급강하(~57%)에 완성. 후반 Z5-7 = full kit + 반중력으로 기존 Z1-4 재맥락화 백트래킹.
> - **빌더 동사 5 (스파이크 척추):** 점착 클램프(Z1) → 제어 노드(Z2) → 극성 부츠(Z3) → 공명 펄스(Z4) → 반중력(Z4).
> - **스탯 게이트 이동(2026-06-01):** INT 봉인 게이트 Z4→Z5 봉인된 하부 진입. ATK는 Z3 유지.

## 4. System_World_AbilityGating.md — 전문 (구역별 획득·게이트 배치 포함)

### 6대 능력 해금 테이블 (원본)

| 능력 | 획득 방식 | 획득 층위 | 획득 트리거 | 게이트 표현 |
| :--- | :--- | :--- | :--- | :--- |
| **대시** | 렐릭 발견 | 무너진 거주 구역 | 첫 아이템계 클리어 후 | 대시로만 건너는 수평 간격 (3-4 타일 갭) |
| **벽 타기** | 보스 처치 후 렐릭 | 거대 공장층 | 공장층 보스 처치 | 연속 수직 벽면 + ATK 게이트 병행 |
| **이단 점프** | 보스 처치 후 렐릭 | 봉인된 하부 | 하부 보스 처치 | 5-6 타일 수직 간격 |
| **수중 호흡** | 보스 처치 후 렐릭 | 침수 바닥층 (침수 서브) | 침수 서브 바이옴 보스 처치 | 산소 게이지 초과 수중 구간 |
| **surge(역류의 쇄도)** | 보스 처치 후 렐릭 | 무너진 환승역 (상승 정점) | 환승역 보스 처치 | 높은 공동 상승 |

### Critical Path 순서 (원본)

```
0단계: 침수 바닥층 → 수중 호흡 획득
1단계: 무너진 거주 구역 → 대시 획득
2단계: 거대 공장층 → 벽 타기 획득 (+ATK 게이트)
3단계: 무너진 환승역 → surge 획득 (+INT 게이트)
  ⤓ 급강하
5단계: 봉인된 하부 → 이단 점프 획득
6단계: 대 안치소
7단계: 정상 — 관제정
```
