## 1. 정체 — 인덱서 본류

**빌더 등재 시스템의 정통 행정체.** 에코·도면·신체를 빌더 마스터 색인에 등재·대조·보존·말소하는 차가운 의례 기구. 사적 등재단(#1)이 본류의 **이단**(살아있는 주인에게 신체 등재)이라면, 본류는 **정통** — 여전히 빌더(주인)를 믿고 모든 것을 시스템에 헌납한다. "주인이 언젠가 장부를 읽는다"는 전제로 견딘다.

> **§13 결속:** 본류는 (다) *「세계는 기다림만으로 돈다」* 의 행정적 얼굴이다. 그 기다림은 **절차**의 형태 — 마스터 색인에 영원히 쓰되, 읽힘(회신)은 오지 않는다. 본류는 무응답을 *정상*으로 분류한다("주인은 집계로 읽는다"). **(가) 주인 부재 인지는 없음 — 7얼굴 중 진실에서 가장 멀다.** 진실에 멀수록 의심도 멀어, 끝내 균열하지 않는다.

### 1.1 기원

메가 스트럭처 **수평 복도·플랫폼 구역**의 행정 본부. 캐스케이드 이전부터 등재 시스템을 운용했고, 이후에도 마스터 색인이 무응답인 채로 절차만 자동 지속됐다. 봉인 의례 길드(신체 경계 표준화), 검역 의료단(측정), 안치소(정지 보존)는 본류 행정에서 갈라지거나 계약된 하위·인접 기구.

### 1.2 인구

- **직분자:** 색인관·기록자·대조자·등재관(직분+등급/기호 명명, §14.2). 개인명 억제.
- **등재 항목:** 살아있는 색인체(교단), 정지 라인(안치소), 의뢰 봉인부(길드) — 본류 장부에선 모두 **한 줄**.

## 3. 행정 철학 (절차 틀 — 거짓 신앙)

1. **등재 = 충성** — 마스터 색인에 쓰는 행위 자체가 헌납이다. 읽힘은 절차의 목적이 아니다.
2. **대조 = 질서** — 이탈 항목은 도덕 타락이 아니라 정합 오류 → 봉인 처치 의뢰 / 말소 발령.
3. **무응답 = 정상** — 마스터 색인이 회신한 적 없음은 결함이 아니라 "지연" 또는 "집계 독해"로 분류. **갇힘의 본진.**
4. **해피엔드 없음** — 항목은 등재되어 "보존"되나, 읽을 주인은 없다(§13 (다) 가장 차가운 형태).

> **틀 정합 (확정 2026-06-08):** RES-BDSM-01 §4.1 **틀 C — Contract D/s**(조항·한계·전용 공간·"서명한 날부터") · §4.2.2 직접 매핑(50 Shades "Written contract" → 인덱서 본류 행정·문서). RES-PWX-01 「통제=충성」 결합. 본류의 "취향"은 *장부의 한 줄로 환원됨*(객체화 효과)이되 양식은 **계약·등재**다. 신체 처치 실연은 위성(길드) 레인.

## 4. 체계 — 행정 양식 (기능)

> 신체 처치 실연은 봉인 의례 길드(NAR-FAC-003). 여기는 설계자가 인용할 행정 규칙만.

### 4.1 등재·대조

| 항목 | 정의 |
| :--- | :--- |
| **마스터 색인** | 빌더의 등재 원장. **회신 없음**(쓰기 전용) |
| **등재** | 항목을 한 줄로 색인에 기입(기능 참조 — "등재됐다") |
| **대조** | 정합/이탈 판정. 이탈 → 처치 의뢰, 복원 불가 → 말소 |

### 4.2 보존 등급 함수

- 항목 수·압력 분포·서고 적체가 임계에 닿으면 **봉인제 자동 소집**(서명자 없음). 봉인 길드 봉인제 주기(G13)의 발신처.
- 회차 상한·일정이 함수 출력 — 사람이 정하지 않음(무인 프로세스).

### 4.3 말소 발령

- 복원 불가 항목 → 말소 발령. 발령의 종착 체현 = **말소자**(NAR-WLD-005).

## 9. 줄거리 골격 (대조자 시점 아크 — 묘사 대기)

> 사건·캐논 결속만. 명시 묘사는 위성 레인. 의례·처치는 기능 참조만("등재됐다·처치 의뢰됐다·말소 발령됐다").

**시점:** **대조자 라-9**(직분+기호). 등재 항목을 마스터 색인에 대조·등재, 이탈 항목 봉인 의뢰·말소 발령.

1. **A — 쓰기 전용 장부.** 매일 수천 항목을 마스터 색인에 등재. 이탈 항목은 길드에 처치 의뢰(G11 거울 — 그쪽 수신, 이쪽 발신), 복원 불가는 말소.
2. **B — 응답 없는 마스터 색인.** 마스터 색인은 단 한 번도 확인 회신을 돌려준 적 없음. 그러나 "정상"으로 분류("주인은 집계로 읽는다 / 지연은 영원").
3. **C — 봉인제 자동 소집의 정체.** 봉인 길드 봉인제 주기(G13)가 본류 함수의 출력임이 확정. 서명자 없는 이유 = *결정 주체 없음*. 라-9는 "주인이 프로세스에 위임"으로 읽음.
4. **D — 균열하지 않음.** 하급 색인관이 묻는다 — "마스터 색인이 응답한 적 없다면, 우리 등재는 누가 읽습니까." 라-9: "읽힘은 절차의 완결이 아니다. 등재 자체가 충성이다." 의심하지 않음.
5. **E — 무한 쓰기.** 그날 마지막 항목을 등재. 회신 없음. 다음 항목을 연다. 세계가 기다림으로 도는 동안, 본류는 응답 없는 장부에 영원히 쓴다.

**화 순서(예정):** `Idea_Lore_Indexer_01.md`(대조자 아크) → 말소 발령편·빈 옥좌 대면편 후보.
