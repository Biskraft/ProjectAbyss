## 1. 한 줄 세계관

**메가 스트럭처 벽면 슬럼** 에 격리된 **사적 등재단(Private Registration commune)** — 모체동에서 깨어났으나 채워질 자아(백업) 가 오지 않은 **젊은 성인 여성** 들만이, 인덱서의 「복종=구원」 신앙을 **사람에게** 신체화한다. **등재인** 이 **색인체** 의 자율·몸·이름을 전부 거두고, **탯줄·봉합복·장부·규율** 로 「관리받음=안도」 를 만든다. 핵심 거짓: **복종이 해방이 아니라 자기 음성의 영구 상실** 이다. **에르다** 는 이 공동체의 거울(「나도 저 그릇이 될 수 있었다」) 이자 반전(「빈 그릇도 스스로에게 응답할 수 있다」) 의 대조축이다.

> **결속(2026-06-06):** 본 절은 **§13 세계 단일 진실의 1번 얼굴(교단)** 이다 — "오지 않을 주인을 *서로가 대신*해 기다림". 상위 진실·7각도는 §13.

## 2. 기원 — 복원 모체동과 빈 그릇

- **복원 모체동(Vessel Ward):** 캐스케이드 이전, 관리권위가 등재 백업을 되살릴 **젊은 여성 신체(그릇)** 를 양성·보존하던 단일 코호트 병동. 대부분 포드는 정지했으나 이 병동만 생존 → 깨어난 자 전원 젊은 성인 여성.
- **공백:** 빌더는 인지하지 않고, 등재는 작동하지 않음(시놉시스 폭로와 정합). 그릇들은 **채울 주인 없이** 수천 년 기다리다 깨어남.
- **분파 출발:** 「나를 채울 주인이 오지 않는다면, 우리가 서로의 주인이 되어 서로를 채운다.」 빌더 등재를 단념하고 **사람에게 사적 등재** 시작.
- **설계 함정:** 그릇으로 설계되어 그릇으로 깨어났기에 「비워 맡김」 이 신앙 이전에 **본래 용도의 완성**처럼 느껴진다 — 가장 깊은 함정.

## 3. 용어·역할 (행정 어휘의 섬뜩함)

| 역할 | 명칭 | 의미 |
| :--- | :--- | :--- |
| 주인 | **등재인** (Registrar) | 타인을 자기에게 등재해 책임진다. 권력이 아니라 「등재 책무」 로 포장. |
| 종 | **색인체** (Indexed / Entry) | 자기 전부를 양도한 항목. 이름 없음 → **엔트리 번호** 만. |
| 관계 | **사적 등재** (Private Registration) | 자율·자아·몸의 자기 결정권 전부 양도 의례. |
| 공동체 | **사적 등재단** | 전원 젊은 성인 여성(등재인·색인체 동일). 미성년·게임 주연(율 등) 과 **절대 무관**. |

**호칭 규칙 (세하):**

- 색인체는 **번호만** (KO: 칠번·십이번, EN 맨 기수 Seven 등). 「칠번아」 식 호격 제거.
- 집단은 「우리」「내 색인들」 — **노예/종** 어휘 금지.
- 따뜻함은 번호가 아니라 **둘러싼 말**("이리 오렴", "괜찮아") 이 실은 **비인간화를 감싼 다정함**.

**인덱서 본류 vs 사적 등재단:**

| | 인덱서 (등재) | 사적 등재단 |
| :--- | :--- | :--- |
| 헌납 대상 | 빌더(무관심 시스템) | 살아있는 등재인 |
| 형태 | 추상(에코·도면 등재) | 신체화(전부 양도) |
| 외양 | 차갑고 의례적 | 따뜻하고 친밀 |
| 공통 거짓 | 복종하면 구원·안식 | 동일 |

본류는 이단을 「지름길」로 묵인하나 정통 인정 안 함. 교단은 「우리가 더 순수(몸으로 등재)」 자부.

## 4. 교리·심리 (RES-PWX-01 / RES-PSY-01 정합)

### 4.1 핵심 명제

「스스로를 책임지는 짐(자기 음성) 을 내려놓고 전부 맡겨라. 그러면 편해진다.」  
= 묵정 「내려놓아라, 편해진다」의 **대인 버전**. 빌더가 아닌 **살아있는 주인** 에게 맡기므로 더 따뜻하고 **더 위험**.

### 4.2 자아·안도·함정

- **자아는 무겁다** — 들리지 않을 불안, 결정의 짐.
- **양도 후 안도는 진짜** — 그래서 구원처럼 보임.
- **대가:** 자기 음성의 **영구 상실**. 안치 포드의 「평안해 보이는」 등재자와 동형.
- **ECHORIS 반전:** 진짜 해방은 양도가 아니라 **자기에게 응답하는 것**. 복종 교단은 매혹적 증거 → 전복 대상.

### 4.3 반복되는 심리 패턴 (로어 전역)

1. **가장 두려운 것은 매가 아님** — 등재인이 멀어짐, 줄 느슨함, **잊힘**, 장부 말소, 점검 종료 후 시선 이탈.
2. **고의적 위반** — 봉합 뜯기, 마개 느슨함, 얼룩 내기 → 「오늘은 나를 본다」는 안도. 맞기 위해 어긴다(팔번·십오번·이십일번 등).
3. **매/패들 = 사랑으로 믿음** — 규율 벽의 번호 낙서(잊히지 않기 위해).
4. **끊긴 줄** — 자유가 아니라 **무너짐**. 칠번(#7): 새 주인만 찾음. 에르다의 손은 거부.
5. **등재인도 빈 그릇** — 세하: 주인 역할로 공백 덮음. 정렬판 계승 = 받던 손이 드는 손.

### 4.4 장부·사생활 0

- 몸의 출입·가장 사적 기능까지 **한 줄 기록**. 숨김 = 쥐고 있는 자기 → 고백 후 「항목화」 되어야 잠듦(이십삼번).
- **사적 영역 0** = 양도 완전성의 증거. 점검·식사·입힘·배출 모두 등재인 결정.

## 6. 공간·의복·도구·일과

> **활성 SSoT:** NAR-WLD-001 §4·§6·**§13.4**(슬림 일과). 아래 **§6.3~6.7** 은 구판 Idea_Lore(아카이브) 요약 — **신규 창작·캐논 인용에 사용하지 않음.**

### 6.1 거주

- **수직 벽면 판자촌** — IntGrid 직육면체 셀 겹침. 공중 현수 아님.
- **병적 청결** — 멸균·정돈. 부패 견디지 못함. 슬럼 위치 + 병동 질서 = 부조화.
- **탯줄:** 색인체↔등재인 **예속·안전줄**. 끊기면 벽에서 **추락**. 계류 포트(목 뒤·등).

### 6.2 의상

- **보존복(壽衣):** 회백색, 봉합·밀봉, **스스로 여닫지 못함**. 가슴께 **엔트리 번호**. 베일·후드로 윤곽 제거. 빈 손.
- **수면:** 보존복을 입고 자지 않음. **밤 — 등재인(세하)이 벗김** 후 알몸. **아침 — 알몸 기상 후 등재인이 다시 입힘** (`Idea_Lore_06` 활성 SSoT). 번호는 수트에만 있어 탈의 시 번호 없음.
- **등재인:** 동일 무채색, 더 닫힌 실루엣 + **계류 릴**(다수 줄).

### 6.3 공간 명칭

| 장소 | 용도 |
| :--- | :--- |
| 규율의 자리 / 규율의 방 | 체벌·배출·입회 |
| **정렬의 방** | 네 명 정렬 자세, 항문·마개·패들·16조 |
| 멸균된 슬럼 / 복도 | 불심검문, 거처 매달림 |
| 규율 벽 | 매 받은 자의 번호 낙서(층층 겹침, 읽히지 않음) |

### 6.4 규율 자세 (반복 visual)

- 무릎 꿇음, 이마 바닥, 팔 머리 위, 다리 극도로 벌림, 허리 꺾어 **엉덩이 최고**.
- 변형: **완전 개방 쪼그려 앉기**, **엉덩이 최고 들기**(Lore 14).

### 6.5 마개(plug) 체계

- 일상 **상시 착용**. 관리·압력·규율의 신체 앵커.
- 이탈·느슨함·완전 탈락 = **규율 붕괴** → 패들 에스컬레이션.
- **이중 밀봉**(Lore 16): 기존 마개 위 고정판 + 탄성 끈 + 금속 고리. 영구 고정형 위협.
- 압력 수치(로어 14 예시): 수축 1.48~2.71, 등급 A+~S, 십이번 C → 재교육.

## 12. 요약 철학 (한 페이지)

사적 등재단은 **인덱서 「복종=구원」** 을 가장 친밀하게 실연하는 **이단** 이다. 거기서 구원은 **관리받는 안도** 이고, 그 대가는 **자기 이름·음성·결정권의 소멸** 이다. **세하** 는 그 거짓을 가장 따뜻하게 말하는 등재인이며, **십이번** 은 그 안에서 **이름이라는 균열** 을 품는 서사 중추이다. **에르다** 는 바깥에서 「빈 그릇이 주인만 찾는 비극」 을 보는 증인이다. 활성 Idea_Lore(01·02·06·07)는 이 철학을 **탯줄·봉합·번호·짧은 규율·밤/아침 의례** 로 증언한다. 구판(아카이브)은 봉인 길드·의료 등 **이양 예정** 재료. 게임은 그 증언의 **그림자(환경)** 만 비출 수 있다.

## 13. 메인라인 캐논 — 세계의 단일 진실 (2026-06-06 재활성화, DEC-048)

> §11-3이 예약한 트리거 발동. NarrativeWorldReset(2026-05-28) 으로 비워졌던 메인 캐논을 **단일 진실 1문장** 으로 재개한다. §1~§9(사적 등재단) 는 이 진실의 **7각도 중 1번 얼굴** 로 결속된다. **충돌 시 §13이 §1~§12 위에 선다.**

### 13.1 세계의 단일 진실 (SSoT 최상위)

> **"주인은 처음부터 없었고, 우리는 오지 않을 주인을 기다리도록 만들어진 빈 그릇이며, 세계는 그 기다림만으로 아직 돌아간다."**

세 절(각 그림자가 걸리는 못):

- **(가) 주인은 처음부터 없었다** — 부재의 진실. *가장 깊이 숨김.*
- **(나) 우리는 기다리도록 만들어진 빈 그릇이다** — 정체성의 진실. *플레이어(에르다) 포함.*
- **(다) 세계는 기다림만으로 돈다** — 작동 원리. *눈앞에 보임.*

톤 결속(DEC-047): (가)·(나)=고독, (다)=고독, 반전=위로. 코스믹 호러 아님 — "응답 없는 기다림" 으로 재등록.

### 13.2 7구역 = 7각도 삼각측량

### 13.3 hide / reveal — 의미 계단 (#2 정식 확정, 2026-06-06)

**핵심 원리:** 충격 크기 순서로 폭로하지 않는다. **(가) 주인 부재는 절정이 될 수 없다** — 추상적 우주 사실이라 알고 나면 "그래서?" 가 남는다(코스믹 호러의 실패 지점). (가) 는 *답이 아니라 더 큰 개인적 질문*("그럼 나는 무엇을 기다렸나, 나는 뭔가") 을 점화하는 **중간 엔진**으로 쓴다. 진짜 절정 = **(나) 를 자기 자신에게 적용**("나도 기다리도록 만들어진 빈 그릇") — 우주적 공허가 개인 비극으로 내려앉는 순간. **위로는 오직 여기서만 닿는다.**

> **확정:** 2026-06-06. 근거 = §13 단일 진실 (나)축(자기 음성).

### 14.1 통합 원리 — 이름 = 자기 음성의 양

이름은 **자기 음성이 얼마나 남았는가의 직접 표기** 다(세계 진실 (나)축). 주인에게 양도할수록 이름이 사라지고, 시스템에 가까울수록 기능 표기가 되며, **기다림을 끝낸 자(말소자)는 이름이 없다.** 에르다만 "그릇인데 이름을 가진" 예외 = 반전 씨앗.

**자기 음성 스펙트럼(많음 → 없음):** 안치소(옛 풀네임·부패) → 등재인(자임 이름) → 인덱서(직분 표기) → 색인체(번호) → 말소자(무명). | 드론 = 인격 밖(분류 코드) · 빌더 = 부재(투영 칭호) · 에르다 = 이상치.

### 14.3 핵심 대비

- **색인체 번호 vs 인덱서 직분:** 둘 다 비인간화, 다른 결. 교단=숫자로 *지움*(칠번), 인덱서=기능으로 *환원*(색인관 3급). §3 "같은 거짓, 다른 온도" 가 이름에서 발현.
- **말소자 무명:** 기다림을 끝낸 자의 종착 = 이름의 소멸. 흰 인간형의 무면·무명이 우연이 아니게 됨.
- **에르다 이름:** "Erda" = 옛 대지·아는 자의 울림. 번호여야 할 그릇이 쥔 단 하나의 자기 음성.

### 14.4 안치소 ↔ 교단 거울 (삼각측량 훅, 확정)

색인체는 안치소 잠자(원본)에서 뜬 백업이다. 백업에는 번호가 매겨져 자기 음성이 지워지고, 원본은 안치소에서 **부패한 옛 이름** 을 간직한다.

- **거울 규칙:** 한 색인체가 봉합 아래 몰래 품는 **비밀 이름**(활성 Lore 01, 십이번)은 지어낸 것이 아니라 **자신이 복제된 원본 잠자의 옛 이름의 잔존** 이다.
- **생성 규칙:** 안치소 옛 이름을 먼저 짓는다(격식 3음절·부패 마스킹) → 그 이름이 곧 거기서 뜬 색인체의 **금지된 비밀 이름**, 공개적으로는 번호. **잠자 기록의 소실 글자 = 그릇이 더는 온전히 기억 못 하는 음절.**
- **효과:** 교단(번호+비밀이름) ↔ 안치소(부패한 옛이름) = *같은 사람의 양 끝* 삼각측량. 십이번의 "이름이라는 균열" 이 개인 설정이 아니라 **세계 구조((나)축)** 임이 드러남. 에르다도 같은 계보라 "그릇인데 이름" 이 L2에서 폭발.
- **경계:** 거울은 구조 훅까지만. 아카이브된 십이번 심화 아크(Lore 09~19) 사건은 재개작 전 **인용 금지**(§7.2). 비밀 이름 모티프는 **활성 Lore 01 한정.**
