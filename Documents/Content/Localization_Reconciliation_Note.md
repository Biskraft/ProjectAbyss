## 1. 핵심 발견 — 기존 로컬라이제이션이 이미 내러티브를 구현 중

CSV 에 이미 성숙한 Rustborn 대사 시스템이 있다. 우리가 이번 라운드에 쓴 시놉시스(CNT-STR-001) 와 강하게 수렴한다:

| 기존 CSV 내용 | 우리 시놉시스 정합 |
| :--- | :--- |
| `ego.rustborn_awaken.0 = "…에르다"` | 시작 후 5분 러스트본의 이름 회수 비트와 정확히 일치 |
| `ego.rustborn_awaken.1 = "…들리니?"` | "나도 들리고 싶었어" 의 들림 테마와 정합 |
| `ego.anvil.0 = "…포지의 냄새"` | 포지(Forge) 메커니즘 정합 |
| `ego.iw_enter.0 = "여긴… 내가 처음 깨어난 자리지"` | 에코 내부 = 러스트본의 기억 공간 정합 |
| `ego.first_walk.1 = "...지금은 그냥... 녹"` | 러스트본 = "부식에서 태어난 자" 정합 |

이번 라운드 시놉시스는 이미 구현된 게임 내용과 수렴한다. 강한 검증 신호.

## 2. 발견된 톤 대결정 1건 — Ego vs Echo

| 항목 | 기존 CSV | v2 내러티브 (CNT-STR-001, D-15) |
| :--- | :--- | :--- |
| 검의 음성 호칭 | "Ego(자아)" — `ego.*` 키 네임스페이스 | "Echo(에코)" — 잊혀진 자의 잔존 |
| 함의 | 검에 자아가 깃든 디스가이아식 Item Ego | 검 = 한 사람의 마지막 한 마디의 잔존 |

두 개념이 충돌하지 않을 수도 있다 — "검의 Ego" 가 곧 "그 검에 응결된 한 사람의 Echo" 일 수 있다. 그러나 용어 표기(키 네임스페이스 `ego.*` vs 신규 `echo.*`) 와 작품명 ECHORIS 어원 정합은 Victor 결정 사항이다.

이는 톤 대결정이므로 자동 해결하지 않는다. 선택지:
- (a) Ego = Echo 통합 — "검의 자아 = 그 검에 깃든 잊혀진 자의 메아리" 로 두 개념 융합. 기존 `ego.*` 키 유지.
- (b) Echo 로 통일 — `ego.*` 키를 `echo.*` 로 마이그레이션. 작품명 어원 정합 강화. 코드 영향 큼.
- (c) 역할 분리 — Ego = 검의 인격(러스트본 같은 특이 에코), Echo = 일반 잔존 아이템. 두 용어 공존.

맹목적 키 추가는 보류했다 (기존 608줄과 충돌·중복 위험 + 톤 대결정 미해결). 대신:

- 신규 키 추가는 톤 결정 후로 보류.

## 4. ★ 결정 기록 (Victor, 2026-05-29)

> 결정: 아이템 = echo. "아이템은 echo 라고 불러."

해석 및 적용:

| 개념 | 용어 | 비고 |
| :--- | :--- | :--- |
| 잊혀진 자의 잔존체 = 수집·장착되는 모든 장비 아이템 | Echo (에코) | 확정. 이미 시놉시스·Glossary·에코 배치에 반영됨. |
| 검의 음성·점진적 인격 (검이 에코를 모으며 깨어남) | Ego / 녹쇠(Nokswi) | 별개 개념. 아이템(에코) 과 충돌하지 않음. 기존 `ego.*` 대사 키 유지. |
| 검 안 첫 만남의 특이 의식 | Rustborn | 녹쇠와도 구별 (시놉시스 v2 §녹쇠 정합). |

결론 — 두 용어는 역할 분리(노트 §2 선택지 c) 로 공존:
- echo = 사물(아이템). "300개의 에코를 모은다."
- ego(녹쇠) = 내 검이 에코를 누적하며 깨어나는 인격.

→ 기존 `ego.*` 608줄 대사 키 마이그레이션 불필요. echo.* 네임스페이스는 아이템/잔존 음성 신규 키에만 사용.

## 5. 잔여 검수 액션

1. ✅ Ego vs Echo 결정 완료 (위 §4).
2. 신규 로컬라이제이션 키 등재 — echo.* (아이템·잔존 음성), indexer.chant.*, resident.* — 선별 추가. 기존 ego.* 와 네임스페이스 분리.
3. 기존 `ego.*` 608줄이 이번 시놉시스와 정합하므로, 시놉시스를 기존 구현에 맞춰 미세 조정할지 검토 (역방향 정합).
