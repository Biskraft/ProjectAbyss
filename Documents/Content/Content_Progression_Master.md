## 0. 목적 — 왜 챕터인가

진행을 "첫 30분 / 30-60분" 같은 시간 단위로 끊으면 (a) 플레이 속도 편차에 깨지고, (b) 구역·게이트·서사 비트와 어긋난다. 본 문서는 진행을 **챕터** 로 끊는다. 한 챕터 = 한 구역(D-20) + 한 묶음의 Save the Cat 비트(시놉시스) + 그 구역의 게이트 해금. 챕터는 시간이 아니라 **공간 돌파와 서사 비트의 완료** 로 전진한다.

챕터 = 프롤로그(Ch.0) + 7구역(Ch.1~7). 중반 급강하는 Ch.4→Ch.5 막간으로 둔다(Act 2→3 경첩).

> 두 축 재확인(D-20): 월드 탐험 = 상승. 아이템계 다이브 = 하강. 챕터는 상승 축의 진행 단위다. 자루(에코 수집) 마일스톤은 다이브 축의 누적이며 챕터와 병행한다.

## 2. 챕터 상세

각 챕터: **진입 조건 · 목표 · 신규 메커닉 · 게이트 · 핵심 비트 · 보스/조우 · 종료 조건**.

### Ch.0 — 프롤로그 (콜드 오픈)

- **진입:** 게임 시작 (뉴 게임).
- **목표:** 빌더·말소자·메가 스트럭처의 기원 + 에르다가 왜 미등재 백업인지를 체험으로 세운다. 시그니처 메카닉(다이브)을 첫 5분에 노출.
- **신규 메커닉:** 이동·인터랙트·다이브(전환)·코어 전투(검 콤보·회피, 약한 적).
- **게이트:** 없음.
- **핵심 비트:** 실험실 일상(러스트본 각인) → 플레이 가능 다이브(에코 1지층) → 말소자 첫 등장(흰색 언캐니, 비교전 호러) → 말소자가 위상 찢음 + 시설 파괴 = Cascade → (암전) → 백업 복원 기상.
- **종료:** 백업으로 깨어남 → Ch.1.
- **상세 비트시트:** `Content_Ch0_Prologue.md` (CNT-CH0).

### Ch.1 — 침수 바닥층 (the Drowned Floor)

- **진입:** 백업 기상.
- **목표:** 코어 루프(다이브→에코 회수→귀환) 1회전 체득 + 자기 이름 회수(러스트본) + 잔존자 마을 도달.
- **신규 메커닉:** 포지 다이브(능동), 에코 회수(검에 새기기), 박자 동기화(빌더 등), 미니맵·세이브·메뉴.
- **게이트:** 대시(시작 보유) · 수중 호흡 · 점착 클램프(첫 빌더 후크).
- **핵심 비트:** 깨어남 → 샤프트 스케일 노출 → 첫 빌더 침입 → 식은 포지 첫 다이브 → 러스트본 조우(이름 회수) → 두 번째 빌더 → 첫 에코 회수(1/300) → 잔존자 마을 도달.
- **보스·조우:** 러스트본(에코, 비전투). 첫 외부 위협(약한 적/드론).
- **종료:** 잔존자 마을 세이브 포인트 도달 + 첫 에코 회수.
- **상세 비트시트:** `Content_Ch1_DrownedFloor.md` (CNT-CH1).

### Ch.2 — 무너진 거주 구역 (the Collapsed Wards)

- **진입:** 마을 거점 확립.
- **목표:** 정(情) 공동체 도입(노다·율) + 빌더 상호작용 척추화 + Fun & Games 진입.
- **신규 메커닉:** 빌더 제어 노드(구조 회전/기울임), 이단 점프, 기억 단편 기초.
- **게이트:** 빌더 제어 노드 · 이단 점프.
- **핵심 비트:** B Story(노다 죽 device·율 노래) → 다이브 사이클 본격화 → 녹쇠 2단계(50자루).
- **보스:** 구역 보스 1(처치 시 능력 렐릭).
- **종료:** 구역 격벽 돌파(이단 점프/제어 노드) + 50자루.

### Ch.3 — 거대 공장층 (the Great Works)

- **진입:** 거주 구역 상단 격벽.
- **목표:** 스탯 게이트(ATK) 첫 체험 — 막힘→강화→돌파 순환의 동력 자각.
- **신규 메커닉:** 극성 부츠(빌더 천장 보행), 벽 점프, ATK 스탯 게이트.
- **게이트:** 극성 부츠 · 벽 점프 · **ATK 물리 장벽**.
- **핵심 비트:** ATK 장벽 막힘 → 아이템계 강화 → 돌파 → 녹쇠 3단계(100자루).
- **보스:** 구역 보스 2(능력 렐릭).
- **종료:** ATK 게이트 돌파 + 100자루.

### Ch.4 — 무너진 환승역 (the Broken Concourse)

- **진입:** 공장층 정점.
- **목표:** 상승 정점 도달 + Midpoint(가짜 승리/시한 가속) + 11렐릭 완성(반중력 capstone).
- **신규 메커닉:** 공명 펄스(그리드 정지), surge(상승 비행), 반중력(사물·유체 부유 + 부유 탑승).
- **게이트:** 공명 펄스 · surge · **반중력(Z4 인버전 capstone)**.
- **핵심 비트:** 200자루 → 이리의 낯선 검 발견("나는 너를 미워했다") → 시공 굉음 박자 가속(글로벌 시한 도입) → 묵정 영향력 침투 시작.
- **보스·조우:** 이리(거울 동료, 환경 단서). 묵정 거짓 목표(복원→등재) 심기 시작.
- **종료:** 반중력 획득(전반 11렐릭 완성, ~57%) → 환승역 정점.

### 막간 — 급강하 (All Is Lost 진입)

- **트리거:** 환승역 붕괴 → 추락.
- **신규 메커닉:** 추락의 영혼(diveAttack) — 하방 관통, 나디르 도구.
- **비트:** 그동안 오른 것을 잃고 미답 심부(봉인된 하부)로 강하. 패배가 아니라 더 깊은 곳을 보게 하는 장치. 자유시간 개방의 문.
- **종료:** 봉인된 하부 착지 → Ch.5.

### Ch.5 — 봉인된 하부 (the Sealed Underworks)

- **진입:** 급강하 착지.
- **목표:** All Is Lost ~ Dark Night. 무력의 바닥 + INT 게이트 + 급상승(자유시간) 개시.
- **신규 메커닉:** (신규 렐릭 없음 — full kit 재방문). 말소자 출몰 이벤트(특정 공간).
- **게이트:** **INT 봉인 게이트**(자유시간 개방 직전 파밍 소프트 게이트).
- **핵심 비트:** 250자루 → 마을이 빔, 율 사라짐 → 노다 사라짐(자기 검 못 든 채) → Dark Night(에르다가 노다의 식기를 자기 손으로, 율의 노래를 처음 부름) → 말소자 이벤트(흰색 호러, 희귀).
- **종료:** INT 게이트 돌파 → 급상승 개시.

### Ch.6 — 대 안치소 (the Great Internment)

- **진입:** 봉인된 하부에서 재상승.
- **목표:** Break into 3 + Finale 시작. 거짓 목표의 정점과 거부.
- **신규 메커닉:** 반중력 백트래킹 보상(거꾸로 성급 재독해).
- **게이트:** 신규 없음 — 구조 재편 재상승.
- **핵심 비트:** 묵정 의례장 → 율 발견(응결재 발목) → 묵정의 합치기 제안(거짓 목표 정점) → Five-Point Finale 시작(합창 교란·율의 사양 댄스·High Tower Surprise·Dig Down Deep 반전 거부) → 280자루(녹쇠 6단계).
- **보스·조우:** 묵정(입체 빌런, 양측 균등 정당성).
- **종료:** 묵정 응결 + 율 구출 → 정상으로.

### Ch.7 — 정상 — 관제정 (the Crown)

- **진입:** 안치소 정점.
- **목표:** Finale · Final Image. 빈 옥좌 도달 + 5결말 분기.
- **게이트:** 최종 게이트(누적 렐릭 종합 숙련).
- **핵심 비트:** 300자루 → 진짜 권위의 자리이나 텅 빈 옥좌(응답할 자가 처음부터 없었다) → 5결말 분기(침묵/등재/잔존/막다 + 진엔딩 응답).
- **종료:** 결말 분기 선택.
