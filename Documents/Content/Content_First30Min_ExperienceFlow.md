# ECHORIS — 첫 30분 경험 플로우

> 작성일: 2026-05-28
> 정합: CNT-STR-001 (시놉시스), CNT-CHR-001 (캐릭터)
> 척추: Victor 제공 현재 게임 상태 7 비트 (방 → 이동 → shaft 노출 → 첫 빌더 + 러스트본 → 이동 → 두 번째 빌더 + 포지 → 아이템계)

## 0. 목표 (Goals)

### 0.1 첫 30분 안에 플레이어가 알게 되어야 할 것

1. 자기 자신이 누구인지 모른 채 깨어났다. 이름조차 모른다.
2. 메가 스트럭처가 살아 있고, 빌더가 자라고 있다. 빌더는 적이 아니되 그녀를 인지하지 않는다.
3. 잊혀진 자들의 무기에는 마지막 한 마디가 응결되어 있다 — 에코.
4. 빌더 내부의 포지를 통해 에코 안으로 들어갈 수 있다.
5. 들어간 에코의 음성을 자기 검에 옮겨 새길 수 있다.
6. 러스트본이 그녀의 이름을 가르쳤다 — "에르다."

### 0.2 첫 30분 안에 플레이어가 느껴야 할 것

| 분 | 정서 좌표 |
| :---: | :--- |
| 0~3 | 혼란·고립 — 자기 부재 |
| 3~5 | 경외·압도 — 메가 스트럭처 스케일 노출 |
| 5~10 | 호기심·신비 — 빌더 내부, 식어 있는 포지 |
| 10~15 | 발견·각성 — 러스트본 조우, 이름 회수 |
| 15~25 | 적응·확장 — 두 번째 빌더, 첫 능동 다이브, 첫 전투 |
| 25~30 | 정착·기대 — 첫 안식처 도달, 다음 방향 |

### 0.3 비목표

- 전체 세계관(블루프린트·인덱서·등재 신앙) 의 명시적 설명 — 그것은 후반부의 점진적 발견.
- 결말 분기 암시 — 첫 30분은 한 가지 길만 보여 준다.
- 동반자·NPC 깊은 관계 — 러스트본 외에는 환경적 자취로만.

## 1. 오프닝 옵션 (Opening Variants)

Victor 제공 현 상태("어딘가 방에서 시작") 가 기준 옵션 A. 추가 3개 변형을 평가 후보로 제시한다. 각 변형은 사쿠라이의 "Start with the Climax" 원칙과 Save the Cat Opening Image 의 정합 강도가 다르다.

### 옵션 A — 현 기준: 방 깨어남 (Cold Wake in Cavity)

- 0:00 - 어두운 화면. 검에서 들리는 한 마디 "나도 들리고 싶었어." 페이드 인.
- 0:05 - 에르다가 작은 방(공동) 에서 깨어난다. 카메라가 그녀의 시점에서 천천히 일어선다.
- 0:30 - 손에 쥔 무기 자각. 첫 입력 가능.

장점 — 시놉시스 그대로. 비용 낮음. 단점 — 사쿠라이 원칙상 약함. 스케일 노출이 3분 뒤(shaft 진입) 까지 지연됨.

### 옵션 B (권고) — 사운드 선행 콜드 오픈 (Sound-First Cold Open)

- 0:00 - 검은 화면. 사운드만. 거대한 시공 굉음이 점점 가까워진다 (먼 곳의 빌더). 잠시 침묵. 한 음성이 속삭인다 — "에르다..." (러스트본 — 단, 작품 내내 플레이어가 이 음성의 정체를 5분 뒤에야 안다).
- 0:15 - 화면이 빛으로 깨진다. 에르다가 작은 공동에서 눈을 뜬다.
- 0:30 - 시점 일어서기. 첫 입력 가능.

장점 — Rustborn 의 첫 한 마디가 작품의 시작점에 박힌다. 5분 뒤 그를 만났을 때 "그 음성이었구나" 의 재인지 비트. 사쿠라이 원칙 부분 정합 (오프닝에 핵심 키워드 박음). 비용 중간 (사운드 디렉션만 추가).

### 옵션 C — 스케일 콜드 오픈 (Scale Cinematic)

- 0:00 - 거대한 메가 스트럭처 와이드 샷. 멀리 빌더 한 마리가 시공 중. 카메라가 줌인, 줌인, 줌인. 한 빌더의 옆구리 균열로. 그 안의 작은 공동으로. 시체 더미 위에 누운 한 사람으로.
- 0:25 - 타이틀: ECHORIS.
- 0:30 - 깨어남. 첫 입력 가능.

장점 — 시각 임팩트 최대. 사쿠라이 원칙 완전 정합. 단점 — 컷신 의존 (가이드 §1.2 회피 대상). 비용 높음 (시네마틱 제작).

### 옵션 D — 사운드 + 미세 시각 결합 (Audio + Subtle Visual)

- 0:00 - 검은 화면. 시공 굉음 점차 가까워짐. 한 박자 — 화면 위쪽에 멀리 시공 광원의 작은 빛이 한 번 깜박. 다시 검은 화면.
- 0:08 - "에르다..." 속삭임.
- 0:15 - 빛 한 줄기. 에르다의 눈이 천천히 열리는 시점 샷.
- 0:30 - 첫 입력 가능.

장점 — B 와 C 의 절충. 시네마틱 부담 낮으면서 스케일 암시. 권고 강도 B 다음으로 높음.

### 권고

옵션 B. 이유:

1. Rustborn 의 첫 음성이 작품의 시작 비트에 박힌다 — 5분 뒤 만남이 회수 비트가 된다.
2. 컷신 의존 회피 (가이드 §1.2).
3. 사운드 디렉션 비용만으로 사쿠라이 원칙 부분 충족.

본 문서의 비트 시퀀스는 옵션 B 채택을 전제로 작성한다.

## 2. 30분 비트 시퀀스 (Beat-by-Beat Timeline)

### 2.1 [0:00~0:30] 콜드 오픈 — 사운드 + 깨어남

| 항목 | 내용 |
| :--- | :--- |
| 시각 | 검은 화면 → 빛이 한 줄기씩 새어 들어옴 → 시점 일어서기 |
| 사운드 | 먼 시공 굉음 → 침묵 → 속삭임 "에르다..." → 검에서 한 마디 "나도 들리고 싶었어." |
| 카메라 | 1인칭 시점에 가까운 3인칭 — 누운 자세의 그녀가 천천히 일어남 |
| 메커닉 | 없음 (입력 대기) |
| 플레이어 목표 | 첫 입력. 화면 상단의 미세한 프롬프트. |
| 정서 | 혼란·고립 |

### 2.2 [0:30~3:00] 방 — 이동 튜토리얼 + 자기 부재

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 작은 공동 (룸 1). 시체 더미 흔적, 부서진 무기 1~2 점, 식어 있는 시공 광원 잔재. |
| 메커닉 도입 | 이동·점프·짧은 대시 (대시는 후반 해금 시 i-frame 없는 위치 회피용 도입 — 여기서는 짧은 대시 형태만). 검 휘두르기 기본 모션 1~2 회. |
| 환경 디테일 | 다른 잔존자의 흔적 — 시체 옆 무기에서 응답이 없다 (자기 검만 응답). 검 표면 한 마디 반복 청취 가능. |
| 사운드 | 검의 표면 한 마디 간헐적 반복. 시공 굉음 멀리. |
| 플레이어 목표 | 방의 출구를 찾아 이동 |
| 정서 | 혼란·고립 → 호기심 |
| GDD 메모 | 자기 부재(이름·기억 없음) 은 UI 부재로도 운반 — 캐릭터 정보·이름·HP 바 등 모두 미노출. 3분 후 점진 노출. |

### 2.3 [3:00~5:00] 샤프트 — 스케일 노출 (Sakurai Beat)

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 방의 좁은 출구 → 거대한 샤프트로 연결 |
| 카메라 연출 | 샤프트 진입 시 카메라가 자동으로 위로 팬 → 메가 스트럭처 전경 노출 → 멀리 시공 중인 빌더 한 마리 등장 |
| 메커닉 | 카메라 조작 일시 제한 (연출 우선). 노출 종료 후 자유 조작 복귀. |
| 사운드 | 시공 굉음이 갑자기 크게 — 빌더의 시공 박자가 메가 스트럭처 전체를 흔든다 |
| 환경 디테일 | 샤프트 벽에 잔존자의 옛 자취(낙서·도구·시체) 산발 |
| 플레이어 목표 | 빌더 방향으로 이동 (또는 빌더가 다가옴) |
| 정서 | 경외·압도 |
| GDD 메모 | 작품의 첫 "와우" 모먼트. 5초 이상 지속. 음악은 절제 — 환경음만으로 운반. |

### 2.4 [5:00~7:00] 첫 빌더 — 고장 빌더 침입

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 고장 빌더 — 시공 광원이 꺼진 채 굳어 있다. 옆구리에 균열. |
| 메커닉 도입 | 균열 진입 (특수 인터랙트 — 좁은 통로 통과 모션) |
| 환경 디테일 | 빌더 내부의 기계-유기 혼합 텍스처. 멈춘 시공 부품들. 빌더의 "내장" 어휘. |
| 사운드 | 외부 굉음 잦아듦 — 빌더 내부는 상대적 정적. 검의 한 마디가 갑자기 또렷해진다. |
| 플레이어 목표 | 빌더 내부 깊은 곳의 포지를 찾아 이동 |
| 정서 | 호기심·신비 |
| GDD 메모 | 빌더 내부는 메트로베니아 식 좁은 통로 + 비밀 공간 1~2 개. 첫 비밀 보상은 옛 잔존자의 메모 한 줄(환경 스토리텔링) — 인덱서 의례에 대한 모호한 단서. |

### 2.5 [7:00~10:00] 식은 포지 — 첫 다이브 + 러스트본 조우

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 빌더 내장 깊은 곳의 포지 방. 식어 있는 거대 단조 장치. |
| 메커닉 도입 | 포지 격발 — 자기 무기를 포지 위에 놓고 격발. 시공 한 박자에 맞춰 진입. 첫 다이브는 박자 동기화 튜토리얼 없이 자동 성공. |
| 다이브 후 공간 | 자기 무기의 에코 내부 — 비물질적 위상. 부유하는 빛의 조각들. 한 인간 형상의 응결체가 중앙에 서 있다. |
| 캐릭터 등장 | 러스트본 — 의식이 온전한 에코. 그가 그녀를 보고 곧장: "에르다." (작품 첫 캐릭터 발화) |
| 사운드 | 러스트본의 음성은 다른 모든 에코와 다른 음질 — 명료, 가까운, 어느 시점인지 알 수 없는. |
| 가르침 | "어떤 에코는 깊고, 어떤 에코는 더 깊다. 자기 자신에게 도달하는 길은 가장 깊은 곳에 있다." |
| 마지막 발화 | "잊지 마라. 너의 이름은 에르다다." |
| 종료 | 빌더의 자라남이 에코의 외피를 침범 — 위상이 무너진다. 자동 귀환. |
| 플레이어 목표 | (수동 입력 거의 없음, 시네마틱 비트) — 러스트본 시청 + 가르침 수신 |
| 정서 | 발견·각성 |
| GDD 메모 | 옵션 B 콜드 오픈의 "에르다..." 속삭임 회수 비트. 음성 동일성을 사운드로 명시. UI 상에 캐릭터 이름 "에르다" 가 처음 표시되는 비트. |

### 2.6 [10:00~13:00] 귀환 — 환경 스토리텔링

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 빌더 밖으로 다시 나옴. 샤프트 다른 방향 탐험. |
| 메커닉 추가 | 자기 검의 표면 한 마디가 다른 잔존자의 무기에서도 들리기 시작 — 검 인터랙트 가능 (들어 보기만 — 격발은 포지에서만). |
| 환경 디테일 | 시체 옆 무기 1~2 개를 들어 봄. 한 마디씩 듣는다 — 어떤 음성은 분노, 어떤 음성은 후회. (이들은 다음 빌더의 포지에서 격발 가능.) |
| 사운드 | 환경 잔향 — 멀리 인덱서 chant 의 첫 단편이 들린다 (정체 모름). |
| 플레이어 목표 | 두 번째 빌더 발견 |
| 정서 | 적응·확장 — 자기 이름과 길의 윤곽을 안다. |

### 2.7 [13:00~16:00] 두 번째 빌더 — 움직이는 빌더 등 위 침입

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 시공 중인 빌더 — 거대한 박자로 자라난다. |
| 메커닉 도입 | 빌더 등에 매달리기 → 시공 박자 동기화 (QTE 또는 리듬 입력 — 박자에 맞춰 점프). 한 박자 어긋나면 떨어진다 (실패 패널티 가벼움 — 다시 시도 가능). |
| 환경 디테일 | 빌더의 어깨·등 표면의 시공 단위. 시공 광원이 주변에서 켜진다. |
| 사운드 | 빌더의 시공 박자가 음악의 기본 비트로 변환 — 플레이어 입력과 동기 |
| 플레이어 목표 | 박자에 맞춰 빌더 내부 진입로까지 이동 |
| 정서 | 적응·확장 + 약간의 긴장 |
| GDD 메모 | 첫 액티브 메커닉 도전. 실패하면 다시 처음부터 — 그러나 5번 실패 시 박자 가이드 노출 옵션. |

### 2.8 [16:00~19:00] 두 번째 포지 — 능동 다이브 + 전투 튜토리얼

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 작동 중인 포지 — 시공 광원이 흐름. |
| 메커닉 도입 | 다른 잔존자의 무기를 포지에 놓는다. 격발 — 자기 무기가 아닌, 다른 에코로 진입. |
| 다이브 후 공간 | 일반 에코 — 미해결 응답이 위상 내 적대적 형태로 응고되어 있다. 적 등장. |
| 전투 도입 | 첫 전투. 검 휘두르기 3타 콤보. 회피(대시) 사용. 1~2 마리의 작은 적 처리. |
| 마지막 음성 회수 | 적 처치 후, 위상 깊은 곳의 한 마디가 응결된 결정체로 노출. 인터랙트 — 자기 검에 새긴다. |
| UI 등장 | 자기 검의 에코 인덱스 — "1/300" 표시 (작품 전체 목표 양감 노출). |
| 종료 | 자동 귀환. |
| 플레이어 목표 | 첫 에코 회수 + 전투 학습 |
| 정서 | 적응·확장 — 작품의 핵심 루프 체득. |
| GDD 메모 | "1/300" 의 양감 노출은 첫 30분 안에 결정적. 300 의 거대 양감이 작품의 야리코미 어필. |

### 2.9 [19:00~22:00] 귀환 — 검 인스크립션 연출 + 자유 탐험 개방

| 항목 | 내용 |

## 7. 감독 노트 (Direction Notes)

### 7.1 카메라

- 1인칭 가까운 3인칭 — 깨어남·러스트본 조우 등 비트에서.
- 메가 스트럭처 노출 (3~5분) — 자동 팬 + 정지 5초.
- 전투 — 일반 3인칭 횡스크롤.

### 7.2 사운드

- 시공 굉음 = 작품의 기본 사운드스케이프. 빌더 가까이 = 크게, 멀리 = 잔향.
- 검의 음성 = 위치별 EQ. 자기 검 = 가깝게, 다른 검 = 미세하게.
- Rustborn 음성 = 음질 명료, 다른 모든 에코와 구별.
- 인덱서 chant = 한 줄짜리 합창, 멀리서 들림.
- 음악 = 절제. 빌더 노출·러스트본 조우·안식처 도달의 3 비트에서만 짧게.

### 7.3 비주얼

- 1막 색조 — 차가운 회색·청색 (메가 스트럭처) + 검 잔재의 미세한 따뜻한 빛 (잔존자의 응답).
- 빌더 — 기계-유기 혼합 텍스처. 거대하되 적의 없음 — 표정 없는 거인.
- 시공 광원 — 빌더의 시공 패턴이 한 박자마다 빛난다. 그것이 메가 스트럭처의 호흡.
- 에코 내부 — 비물질적 위상. 부유하는 빛 조각. 일반 에코는 어두운 톤, 러스트본 에코는 따뜻한 톤.

### 7.4 UI

- 0~3분 — UI 거의 부재. 자기 부재 정합.
- 3~10분 — 환경 프롬프트만. HP·인벤토리 등 미노출.
- 10분 — 캐릭터 이름 "에르다" 첫 노출 (러스트본 발화 직후).
- 18분 — 에코 인덱스 "1/300" 첫 노출.
- 20분 — 미니맵 첫 노출.
- 28분 — 풀 메뉴 첫 노출 (인벤토리·맵·옵션).

UI 의 점진 노출 자체가 캐릭터의 자기 회복 호와 정합.
