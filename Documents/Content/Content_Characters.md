## 1. 에르다 (Erda) — 주인공

### 1.1 유형 (가이드 §5.1)

Sculpted Avatar — 캐릭터성 중간 / 자유도 중간. Tim Cain 의 "I make the story, the player makes the character" 모형. 결함·비트는 시스템이 강제하고, 결정·감정의 결은 플레이어가 채운다. 0대사 원칙(침묵형). 이름은 캐논이되 플레이어 입력으로 덮어쓸 수 있다.

### 1.2 정체 (v3)

수천 년 전 아이템계 진입 실험의 백업 복원본. 원본은 Cascade 때 사망. 도면(블루프린트) 에 없는 미등재 존재 = 가장 순수한 아웃사이더. 과거를 캐지 않는다 — 정체성 회복은 동력이 아니다(거짓 목표이며 반전으로 거부됨).

### 1.3 호칭

| 층위 | 호칭 |
| :--- | :--- |
| 본명 (canon) | 에르다 (Erda) |
| 깨어날 때 | 백업 불완전 복원으로 자기 이름·기억 없음. 무명. |
| 외부 호칭 | 잔존자·인덱서는 "들리지 않은 자" / "응답자" 로 부른다. |
| 이름 회수 ([7], ~5분) | 첫 포지 다이브에서 동료였던 러스트본의 에코를 만남. 그가 "에르다" 라 부른다 — 동료였기에 안다. 단, 직접 호명 명령 라인("너의 이름은 …다") 은 금지(신파 차단 #6). 그녀는 빌더 밖에서 자기 입으로 처음 자기 이름을 발화. |
| 자기 호명 | "나" — 진엔딩 "나도, 들리고 싶었어" 의 "나" 가 작품 내 유일한 1인칭. |
| 플레이어 옵션 | 기본 에르다 / 입력 덮어쓰기 가능. 입력 시 러스트본도 그 이름을 부른다. |

### 1.4 Broken Compass (가이드 §4.1)

> "항상 남의 한 마디를 운반한다 / 절대 자기 한 마디를 발화하지 않는다." (시놉시스 v3)

### 1.5 핵심 결함 + 거짓 목표 + 반전 (가이드 §3.1, §6.5)

- 결함: 자기 이름·과거·정을 들일 자리가 없다. 들은 한 마디를 반복 재생할 뿐 자기 음성을 갖지 못한 자. "들리지 못한 채 끝날" 불안.
- 거짓 목표 (1-2막, 공모): 묵정/시스템이 심음 — "백업인 나는 가짜다. 에코를 모아 원본을 복원하면 등재되어 진짜가 된다." 편견의 약속.
- 반전 (해방): 진짜가 되려면 그동안 자기가 된 것(들어주는 자·유니크한 아웃사이더) 을 지워야 함을 깨닫고 거부. "나를 찾을 필요 없다. 백업인 나로 충분하다." (Ralph 자기수용 + Inside Out 자기위로.)

### 1.6 Rooting Resume (가이드 §5.5, 4 충족)

| 항목 | 충족 (시놉시스 v3) |
| :--- | :--- |
| 보상 없는 친절 | 노다의 식기를 자기 손으로 씻는다 |
| 객관적 고난 | 빌더의 시공 굉음 속에 맨발로 매달림 |
| 공개적 굴욕 | 자기 이름을 묻는 율의 질문에 답하지 못함 |
| 자기보다 강한 자에 도전 | 시공 단위에 정면 진입 |

3+ 충족 — PASS.

### 1.7 대화 톤 4축 좌표 (가이드 §7.1)

직접성 1 / 격식 2 / 감정 노출 1 → 클라이맥스 폭발 / 정보 농도 1. 0대사 원칙. 세계관 설명자는 그녀가 아니다(묵정·러스트본·환경이 운반).

### 1.8 감정 호 (가이드 §6.2, 시놉시스 v3 15비트 정합)

| 단계 | 위치 | 비트 |
| :---: | :--- | :--- |
| 0 | 프롤로그 | 과학자. 동료들과 실험. Cascade 로 원본 사망. |
| 1 | [3] 0-10% | 백업 복원·무명. 손의 검에서 표면 한 마디. |
| 2 | [7] ~22% | 첫 다이브 → 동료 러스트본 에코 재회. 이름 회수. |
| 3 | [8-10] 20-75% | 다이브 누적. 묵정이 거짓 목표(복원→등재) 를 심음. 공모. |
| 4 | [11-12] 75-80% | 마을 상실. 빈 마을에서 자성. |
| 5 | [13] ~80% | 묵정의 합치기 제안 = 거짓 목표의 정점. 진짜가 되기 한 걸음 앞. |
| 6 | [14] 반전 | 거부 = 해방. "나를 찾을 필요 없다." 그 후 묵정을 한 아웃사이더로서 들음. |

### 1.9 첫 등장 씬 (Rooting Resume 3+ 단일 씬)

> 프롤로그 P-6 직후. 메가 스트럭처 깊은 공동, 자기 이전 복원 잔해(시체 더미) 위에서 백업으로 깨어남. UI 한 줄 "백업 복원 완료." 손에 검 한 자루, 검에서 "나도 들리고 싶었어." 옆의 부서진 무기 하나를 함께 끌어안고 — 시공 광원이 내려오기 시작하는 가운데 — 일어선다.

충족 — Underdog(미등재 백업) + In Danger(시공 광원) + 보상 없는 친절(부서진 무기를 끌어안음).

### 1.10 동반자 시스템 (가이드 §5.4)

솔로 탐험자. 협동 다이브(1-4인) 는 같은 에코에 다른 잔존자가 함께 드는 메커닉 다중 자아. 솔로 정체성 유지.

## 2. 묵정 (默正, Mukjeong) — 인덱서 지도자 / 입체 빌런

### 2.1 유형 (가이드 §5.1, §5.2)

Defined. 작품의 인격적 안타고니스트(인격 층). 코스믹 시스템(말소자·관리 권위) 의 절멸 논리를 인간에게 번역하는 자.

### 2.2 호칭

| 층위 | 호칭 |
| :--- | :--- |
| 본명 (canon) | 묵정 (默正, Mukjeong) |
| 인덱서 내부 | "선구자" / "먼저 등재된 자" — 거짓이나 그들에게는 신앙 |
| 자기 호명 | "나" 거의 안 씀. "우리" / "한 사람" 으로 자기를 분리 |

### 2.3 Broken Compass (가이드 §4.1)

> "항상 다른 잔존자에게 등재를 설득한다 / 절대 자기 한 마디는 발화하지 않는다." (시놉시스 v3)

### 2.4 빌런 4조건 (가이드 §5.2)

| 조건 | 적용 |
| :--- | :--- |
| 믿을 수 있는 목표 | 인간 카테고리를 멸종 전 최대한 보존 — 등재가 최선이라는 광신 |
| Telegraphed | 의례 흔적·헌납 에코 더미·신도 행렬이 모든 빌더 내부·표면에 깔림 |
| 입체적 동기 | 70년 전 마지막 응답 시도 중 시공 단위에 한쪽 다리를 빼앗김. 이후 자기 합리화로 전향 |
| 이해 가능 | "지워지느니 등재되자" — 한 인간의 마지막 방어. 공감 가능 |

### 2.5 v3 역할 — 거짓 목표의 입

에르다에게 거짓 목표(복원→등재=진짜가 되기) 를 심는 자([10]). [13] 합치기 제안 = 그 정점. 에르다의 반전(거부) 의 대상이자, 반전 후 그녀가 듣는 대상.

### 2.6 신체 한 + 비언어 device (시놉시스 v3)

- 신체 한: 잃은 다리에 빌더 시공 단위가 응결재로 굳어 자라고 있음. 만질 때마다 시공 굉음 결로 진동. (클로즈업 금지, 본인이 만질 때만.)
- 비언어: 지팡이로 다리를 두드리는 박자. 발화 대신 박자, 신도가 그 박자로 합창.

### 2.7 대화 톤 4축 (가이드 §7.1)

직접성 높음(격언) / 격식 높음(의례) / 감정 노출 낮음(손 떨림이 유일) / 정보 농도 높음(lore 운반자).

### 2.8 대표 발화 (60자 이내)

| 발화 | 비트 |
| :--- | :--- |
| "들릴 자격이 없는 자는 차라리 등재되어라." | 거짓 목표 심기 |
| "합치면 네 원본이 복원된다. 둘 다 진짜가 된다." | [13] 합치기 제안 |
| "나도 들리고 싶었다." | [14] High Tower Surprise — 70년 만의 자기 발화 |

### 2.9 High Tower Surprise (가이드 §3 Five-Point Finale)

그는 적이 아니라 자기를 등재해 줄 사람을 70년 기다린 자. 에르다는 그를 베지 않고 듣는다 → 그의 한 마디가 검에 응결 → 그가 응결된다(카타르시스 없이).

## 3. 러스트본 (Rustborn) — 실험 동료 (에코)

### 3.1 정체 (v3 확정)

프롤로그의 실험 동료. 에르다와 가장 가까웠던 자. Cascade 때 지워져 그녀의 시작 검 안에 의식이 온전히 응결됨. 일반 에코(마지막 한 마디 단편) 와 달리 의식이 살아 있는 특이 에코.

핵심 — 그가 에르다 이름을 아는 이유 = 동료였기 때문. 정체성 미스터리 아님. (이전 3안 가능성 표 폐기.)

### 3.2 D-15 시각 친연성 해소

에르다·러스트본 포트레이트의 같은 결(붉은-갈색 머리·청록 눈) = 같은 연구소·같은 시대 동료라서. 이전의 "자기 이전 고리" 시각 캐논을 동료 설정으로 대체.

### 3.3 작품 내 역할

- [7] B-Story 입구. 첫 포지 다이브에서 재회.
- 가르침: "어떤 에코는 깊고, 어떤 에코는 더 깊다. 자기에게 도달하는 길은 가장 깊은 곳에 있다."
- 자기가 누구였는지 말하지 않는다 — 에르다가 과거를 캐는 것을 원치 않으므로(신파 차단 #4, 정보 덤프 회피). 동료였음은 후반 단편으로 서서히 암시.

### 3.4 녹쇠와의 구별

러스트본 = 한 동료(에코, 단일 인물). 녹쇠 = 검 전체의 점진적 자아(수백 음성 누적으로 깨어남, 7단계). 별개 개념.

### 3.5 대화 톤 4축 (가이드 §7.1)

직접성 매우 높음(곧장 부르고 가르침) / 격식 중간 / 감정 노출 중간(그녀가 모르는 슬픔 — 동료였으므로) / 정보 농도 낮음(가르침 하나).

### 3.6 대표 발화 (60자 이내)

| 발화 | 비트 |
| :--- | :--- |
| "에르다." | 첫 발화. 동료였기에 안다. |
| "어떤 에코는 깊고, 어떤 에코는 더 깊다." | 가르침 핵심 |
| "자기 자신에게 도달하는 길은 가장 깊은 곳에 있다." | 가르침 둘 |

> 금지: "잊지 마라. 너의 이름은 에르다다." 류 직접 호명 명령 라인(신파 차단 #6). 이름은 그녀가 자기 입으로 처음 발화한다.

### 3.7 재등장

기본 단일 등장([7]). 진엔딩에서 — 자기 검을 처음 공동에 내려놓을 때 — 검 안에서 그의 음성이 마지막으로 한 번 더 들릴 가능성. 첫 비트와 마지막 비트를 그가 잇는다.

## 4. 주요 대립축 (에르다 vs 묵정)

| 축 | 에르다 | 묵정 |
| :--- | :--- | :--- |
| 거짓 목표 | 거부 (반전 = 해방) | 신봉·전파 (등재) |
| 음성 | 한 번의 발화로 폭발 | 격언화된 단언, 자기 발화는 70년 침묵 |
