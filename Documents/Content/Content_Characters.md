## 1. 에르다 (Erda)

### 1.1 유형 (가이드 §5.1)

Sculpted Avatar — 캐릭터성 중간 / 자유도 중간. Tim Cain 의 "I make the story, the player makes the character" 모형. 결함과 비트는 시스템이 강제하고, 결정과 감정의 결은 플레이어가 채운다. 캐논 이름은 정해져 있되 플레이어 입력으로 덮어쓸 수 있다.

### 1.2 호칭

| 층위 | 호칭 |
| :--- | :--- |
| 본명 (canon) | 에르다 (Erda) |

| 외부 호칭 | 잔존자·인덱서들은 "들리지 않은 자" / "응답자" 로 부른다. |

### 1.3 Broken Compass (가이드 §4.1)

> "항상 다음 에코로 향한다. 절대 듣기를 멈추지 않는다."

모든 대사·반응·선택 분기가 이 한 줄에서 파생된다. 한 에코를 회수한 직후의 모션 — 다음 빌더를 향해 곧장 시선을 돌린다. 한 자루 검의 무게가 늘어날수록 어깨가 처지지만, 시선은 거두지 않는다.

### 1.4 핵심 결함 (Flaw)

들리지 못한 채 끝날 것이라는 불안. 자기에게 응답할 자격이 없다는 의심.

변화의 출발점 — 그녀가 듣는 모든 마지막 한 마디는 자기가 자기 자신에게 한 번도 발화하지 못한 한 마디였음을 마지막 에코 앞에서 깨닫는다 (가이드 §6.2 7단계 감정 각성의 6단계).

### 1.5 Rooting Resume (가이드 §5.5, 8 항목 중 5 충족)

| 항목 | 충족 |
| :--- | :--- |
| Save the Cat | 첫 공동에서 다른 잔존자의 부서진 무기를 발견했을 때, 자기 검 옆에 놓는다. 응답 가능한 한 마디든 아니든. |
| Underdog | 도면 누락 카테고리에서 깨어남. 시작부터 카테고리 외부. |
| Unfair Treatment | 인덱서들에게 "들릴 자격 없음" 으로 라벨링됨. 의례에 초대되었다가 거절당함. |
| Skilled | 움직이는 빌더의 등에서 시공 굉음과 호흡 박자를 일치시키는 능력. 한 박자 어긋나면 시공 단위에 갇힌다. |
| In Danger | 매 다이브가 죽음의 박자. 시공 광원이 매 비트 가까워진다. |

3+ 충족 — PASS.

### 1.7 작품 내 음성 분량

| 비트 | 발화 |
| :--- | :--- |
| 1막 | 0 — 듣기만 한다. |
| 2막 | 단발 — 인덱서 지도자와의 대치에서 짧은 응답 1~2 회. |
| 3막 클라이맥스 | "나도, 들리고 싶었어." 자기 검을 향해. |
| 진엔딩 | 위의 한 마디 + 검에 응결. 그것이 그녀의 마지막 발화. |

플레이어가 채우는 영역 — 그녀의 무발화 동안의 표정·시선·작은 동작. UI 옵션에서 "혼잣말 자막" 토글 제공 가능.

### 1.8 감정 호 7단계 (가이드 §6.2)

| 단계 | 위치 | 비트 |
| :---: | :--- | :--- |
| 1 | 0~2% | 깨어남. 무명. 자기 부재 — 이름·기억·소속 모두 없음. 손에 쥔 무기에서 표면 한 마디 청취. |
| 2 | 2~5% | 첫 빌더(고장 빌더) 진입. 첫 포지 발견. 자기 시작 무기를 포지에 격발. 첫 에코 다이브. |
| 3 (게임 시작 후 ~5분) | 5~8% | 러스트본 조우. 그가 그녀를 "에르다" 라고 부른다. 처음 자기 이름을 듣는다. 가르침 — 자기 자신에게 도달하는 길은 가장 깊은 곳에 있다. |
| 4 | 8~40% | 다른 에코들 다이브. 음성 회수의 학습. 무기 검에 응답들이 차례로 새겨진다. |
| 5 | 40~60% | 인덱서 의례 목격 + 거절. 등재의 거짓 신앙 인지. |
| 6 | 60~80% | 인덱서 지도자와의 대치. 베어 냄. 첫 자기 음성의 단초. |
| 7 | 80~95% | 마지막 에코 앞에서 자기 자신이 카테고리의 마지막 응답 가능한 에코였음 인식. 러스트본의 가르침의 진짜 의미가 명료해진다. |
| 7b | 95~100% | 자기 발화 — "나도, 들리고 싶었어." 결말 분기 선택. |

### 1.9 첫 등장 씬 (Rooting Resume 3+ 항목 단일 씬 노출)

> 메가 스트럭처의 가장 깊은 공동. 시체 더미 위에 한 손에 누군가의 검을 쥐고 누워 있다. 시공 광원이 천장에서 그녀가 누워 있는 자리로 내려오기 시작한다. 검에서 한 마디가 들린다. "나도 들리고 싶었어." 그녀는 일어선다. 옆의 부서진 무기 하나를 본다 — 응답이 없는 것. 그녀는 그것도 함께 끌어안는다. 그리고 달린다.

Rooting Resume 충족 — Underdog (도면 외부) + In Danger (시공 광원 임박) + Save the Cat (부서진 무기를 끌어안음).

### 1.10 동반자 시스템 (가이드 §5.4)

해당 없음. 그녀는 솔로 탐험자다. 다른 잔존자와의 조우는 있으나 동행은 아니다.

예외 — 협동 다이브 (1~4인 아이템계 협동) 는 메커닉 다중 자아 모델 — 같은 카테고리의 다른 잔존자가 같은 에코로 함께 들어가는 경우. 솔로 정체성은 유지된다.

## 2. 인덱서 지도자 (the Indexer Leader)

### 2.1 유형 (가이드 §5.1, §5.2)

Defined — 명확한 캐릭터성 + 낮은 자유도. 작품의 인격적 안타고니스트. 빌더의 무관심 한복판에서 유일한 인격적 적의의 대상이 그다 (가이드 §5.2 빌런 4조건 평가 대상).

### 2.2 호칭

| 층위 | 호칭 |
| :--- | :--- |
| 외부 (잔존자·에르다) | "지도자" / "그" / "인덱서 지도자" |
| 인덱서 내부 | "선구자" / "먼저 등재된 자" — 거짓이지만 그들에게는 신앙 |
| 자기 호명 | "나" 거의 사용 안 함. "우리" 또는 "한 사람" 으로 자기를 분리. |

이름은 작품 내 단 한 번만 노출 — 그가 베이는 순간 에르다가 마지막으로 부르는 한 음절. 또는 끝까지 무명 유지. (Q2 참조)

### 2.3 Broken Compass (가이드 §4.1)

> "항상 등재를 권한다. 절대 자기 신앙이 거짓임을 인정하지 않는다."

모든 의례 운영·잔존자와의 대화·에르다와의 대치가 이 한 줄에서 파생된다. 그러나 — 자기 손이 한 번이라도 떨릴 때, 그 떨림이 그의 모든 신앙을 균열낸다.

### 2.4 빌런 4조건 (가이드 §5.2)

| 조건 | 적용 |
| :--- | :--- |

| Telegraphed | 1막 후반에 그가 운영하는 의례의 흔적 — 빌더 시공 단위 표면의 부조 얼굴들 — 이 먼저 노출된다. |
| 입체적 동기 | 한때 가장 깊이 들었던 자. 응답의 무게를 견디지 못해 등재로 도망쳤다. 자기 결정을 정당화하기 위해 다른 자들도 그 길로 끌고 간다. |
| 이해 가능 | 플레이어가 공감할 수 있는 자기 합리화의 인물. 그의 거짓 신앙은 응답을 견디지 못한 한 인간의 마지막 방어다. |

4 조건 모두 충족.

자기에게 한 번 응답해 본 적이 있다. 그 무게를 견디지 못해 등재의 길로 돌아섰다. 그 한 번의 응답이 그의 모든 의례 운영의 동력이자, 모든 균열의 씨앗이다.

### 2.10 첫 등장 씬

> 잔존자들 사이. 빌더의 시공 경로 위 의례장. 그의 합창단이 한 줄로 노래한다. 그가 가장 앞에 선다. 손에는 다른 잔존자가 헌납한 검 한 자루. 의례의 다음 박자에 그 검을 빌더의 시공 단위 위에 놓을 참이다. 에르다가 의례장 가장자리에 도착한다. 그가 그녀를 본다. 그의 합창단이 한 박자 멈춘다. 그가 말한다.
>
> "들릴 자격이 없는 자는 차라리 등재되어라."

Rooting Resume 충족 — Skilled (의례 운영) + Underdog (자기도 카테고리 외부) + 빌런 4조건 Telegraphed (그의 의례 흔적이 1막에서 이미 보였다).

### 2.11 동반자 시스템 (가이드 §5.4)

해당 없음 — 인덱서들은 그의 추종자지 동반자가 아니다. 에르다와는 명백한 적대.

## 3. 러스트본 (Rustborn) — 시작 후 5분 에코

### 3.1 유형 (가이드 §5.1)

NPC / 특이 에코. 마지막 한 마디의 단편이 아니라, 한 사람의 의식이 온전히 응결된 자. 작품 안에서 일반 에코와 명백히 구별되는 유일한 사례.

### 3.2 호칭

| 층위 | 호칭 |
| :--- | :--- |
| 본명 | 러스트본 (Rustborn) — "부식에서 태어난 자" |
| 자기 호명 | "나" |
| 에르다에 대한 호명 | "에르다" — 그녀의 이름을 알고 있다. 작품 안에서 그녀의 이름을 입에 올리는 첫 자. |

### 3.3 작품 내 역할

- 게임 시작 후 약 5분 시점에 조우 — 에르다의 첫 포지 다이브(자기 시작 무기의 에코) 안에서.
- 에르다에게 자기 이름 "에르다" 를 가르치는 자.
- 자기 자신에게 도달하는 길의 가르침을 남기는 자.
- 그가 어떻게 그녀의 이름을 아는지는 작품 내내 밝혀지지 않는다.

### 3.4 미스터리 결 — 그가 누구였는가

세 가지 가능성을 모두 열어 둔다. 명시되지 않는다.

| 해석 | 내용 |
| :--- | :--- |
| 가능성 1 | 자기 이전 고리의 한 인물 — 진엔딩 통찰(에르다도 누군가의 에코였다) 과 정합. 그가 그녀의 이름을 아는 이유 가장 자연스러움. |
| 가능성 2 | 인덱서 지도자의 과거 자기 — 지도자도 한때 가장 깊이 들었던 자였다는 설정과 정합. 두 인물의 거울 가능성. |
| 가능성 3 | 우연히 잘 응결된 한 에코 — 가장 평범한 해석. 그가 어떻게 이름을 아는지의 미스터리만 남는다. |

플레이어 해석의 자리. 작품은 답하지 않는다.

> 시각 캐논 (D-15 아트 디렉션, 2026-05-29): 에르다와 러스트본의 포트레이트가 같은 결(붉은-갈색 머리·청록 눈) 이다. 이 시각 친연성은 가능성 1(자기 이전 고리의 한 인물) 을 *시각적으로만* 캐논화한다. in-universe 텍스트는 세 가능성을 끝까지 열어 두되, 닮음 자체가 진엔딩 통찰(에르다도 누군가의 에코였다) 의 사전 단서로 작동한다. 두 번째 플레이에서 회수.

### 3.5 대화 톤 4축 좌표 (가이드 §7.1)

| 축 | 좌표 | 비고 |
| :--- | :---: | :--- |
| 직접성 | 매우 높음 | 곧장 부른다, 곧장 가르친다. 변죽을 울리지 않는다. |
| 격식 | 중간 | 의례적이지도 일상적이지도 않은 정확한 한 줄. |
| 감정 노출 | 중간 | 그녀를 보는 시선에 그녀가 모르는 슬픔이 있다. |
| 정보 농도 | 낮음 | 가르치는 것은 하나뿐. 그러나 그 하나가 모든 것. |

### 3.6 대표 발화 (60자 이내)

| 발화 | 비트 |
| :--- | :--- |
| "에르다." | 첫 발화. 그녀의 이름을 부른다. |
| "어떤 에코는 깊고, 어떤 에코는 더 깊다." | 가르침의 핵심 한 줄. |
| "자기 자신에게 도달하는 길은 가장 깊은 곳에 있다." | 가르침의 두 번째 줄. |
| "잊지 마라. 너의 이름은 에르다다." | 마지막 발화. 빌더의 자라남이 에코의 외피를 침범하기 직전. |

### 3.7 첫 (그리고 유일한) 등장 씬

> 게임 시작 후 약 5분. 에르다가 첫 빌더(고장 빌더) 의 옆구리 균열로 기어 들어가, 식어 있는 포지를 찾아 자기 시작 무기를 격발한다. 자기 무기의 에코 내부로 떨어진다. 그곳에 그가 있다 — 다른 에코들과 달리 단편이 아니라 온전한 의식으로. 그가 그녀를 보고 곧장 부른다.
>
> "에르다."

### 3.8 재등장 여부

기본 설계 — 단일 등장 (시작 후 5분 시점 1회). 진엔딩 분기에서 — 그녀가 자기 검을 처음 깨어났던 빈 공동에 내려놓고 누울 때 — 검 안에서 그의 음성이 마지막으로 한 번 더 들릴 가능성을 열어 둔다. 작품의 첫 비트와 마지막 비트를 그가 잇는다.

## 4. 주요 인물의 대립축 (에르다 vs 인덱서 지도자)

| 축 | 에르다 | 인덱서 지도자 |
| :--- | :--- | :--- |
| 신앙 | 자기에게 응답한다 | 빌더에게 자기를 던진다 |
| 음성 | 한 번의 발화로 폭발 | 격언화된 단언의 연속 |
| 결말 정합 | 진엔딩 (응답) | 등재 / 막다 엔딩 — 그의 신앙이 거짓임에도 만 명을 끌고 간다 |
| Broken Compass 균열 | 자기에게 도달함으로써 결함을 변화로 전환 | 손의 떨림으로 균열, 그러나 인정하지 않음 |
| 가장 깊은 한 줄 | "나도, 들리고 싶었어." | "당신은 등재되었습니다." |

두 인물은 같은 질문의 두 답이다 — "들리지 못한 채 끝나는 것을 어떻게 견딜 것인가." 에르다는 카테고리 바깥에서 자기에게 응답한다. 그는 카테고리 안에 들어가서 자기를 잊는다.
