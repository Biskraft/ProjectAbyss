## 1. Etymology (Original Text by Fina)

> ECHORIS is a name created from the words **Echo** and **Iris**. The name flows smoothly to show the sci-fi genre.
>
> As we know, *echo* doesn't only represent sound but also represents *memories from the past*, while *iris* doesn't only symbolize vision but also *discovery*. In this game, **"Echo"** represents the *past world*, while **"Iris"** represents the *living world*. **Echoris is the connection between them.**
>
> The combined word **"Echoris"** means **"the eye that sees the echoes of the past."**
>
> The protagonist wanted to discover and explore a mysterious world. An echo is also *a signal guiding someone through darkness*. So, the character wants to reveal the hidden truths. For her, *memories never disappear*. The game gives the idea that the world of the game is alive with *traces of history*. Therefore, the character can hear echoes others cannot. In order for you to hear that echo, you have to enter this mysterious world of Echoris.

## 2. 한국어 핵심 요약

| 요소 | 의미 |
|:--|:--|
| **ECHO** | 소리의 메아리 + *과거의 기억* — 사라진 세계 (Echo-Bearers 의 잔향) |
| **IRIS** | 시각 (홍채) + *발견·드러냄* — 살아있는 세계 (지금의 에르다) |
| **ECHORIS** | 둘을 잇는 다리 — *"과거의 메아리를 보는 눈"* |
| **에르다의 역할** | 다른 이가 듣지 못하는 메아리를 듣는 자. 어둠 속 신호를 따라 진실을 드러내는 자 |
| **세계관 명제** | *기억은 사라지지 않는다.* 이 세계는 *역사의 흔적으로* 살아있다 |
| **플레이어 약속** | 메아리를 들으려면 — Echoris 라는 *불가사의한 세계 안으로 들어와야 한다* |

## 3. 락된 시놉시스(§1~§10) 와의 정합

| 시놉시스 요소 | 어원 정합 |
|:--|:--|
| Echo-Bearers (사라진 자들) | *Echo* = 과거의 메아리. 직접 어원적 호명 |
| 에르다 (잔존 인스턴스, 침묵) | *Iris* = 시각·발견. 에르다 = *메아리를 보는 눈* |
| Memory Shard (변질 보존) | "기억은 사라지지 않는다" — 보존되되 변질됨 |
| 아이템계 다이브 | "메아리를 들으려면 Echoris 안으로 들어와야 한다" — 진입 의례 |
| 한정흥 §8.2 | *한* = 풀리지 않은 메아리 / *정* = 메아리로 동료 알아봄 / *흥* = 메아리를 신명으로 |
| 다중 결말 §10 | 메아리의 해소 (천도) / 합침 / 진입 — 셋 다 "보는 눈" 의 결단 |

→ Fina의 어원 정의가 backbone 전체와 *충돌 0건*, 오히려 *명명을 통한 강화* 작동.

**작성자 노트 (Fina):** This naming framework treats Echoris as a *bridge concept* rather than a label. The protagonist's identity (the one who hears) and the world's identity (the layered past) emerge from the same etymological root. Every design decision downstream — sound design, UI iris motif, item world entry ritual — can be traced back to this single sentence: *the eye that sees the echoes of the past.*
