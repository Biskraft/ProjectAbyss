## 0.1. 락 / Hook 원칙

본 시놉시스는 *최소 락 (now-locking) + 장기 hook (보류)* 으로 분리. 락된 항목은 모든 대사·결정의 backbone. hook 은 진행하며 풀린다.

선행 의사결정: DEC-033 (검 Ego), DEC-036 (Memory Shard 5색 기질), DEC-038 (그림자 마을 sci-fi), DEC-039 (수직 딥 다이브), DEC-041 (판타지 톤 아이템 서사 폐기), DEC-042 (한정흥 근간 정서 — §8.2), DEC-043 (다중 결말 3+1 — §10).

## §1. 캐릭터

### §1.1. 에르다 (Erda) — 살아있는 자, 그림자 없는 자 (락)

| 속성 | 정의 |
|:---|:---|
| 정체성 | *살아있는 자, 그림자 없는 자.* 이 세계의 유일한 살아있는 존재 (또는 그에 가까움) |
| 행동 양식 | 침묵 (DEC-033 / DES-IW-ONB-01). 0줄 발화 |
| 소지품 | *부서진 검 한 자루* (Rustborn) — 시작부터 가지고 있다 |
| **미스터리** | **그녀가 왜 살아있는지, 왜 이 검을 가졌는지 — 락하지 않음 (장기 hook)** |
| 시각 | 그림자 없음 (DEC-038 §7). 잔류 신호들 사이의 *유일한 입체* |

### §1.2. Rustborn — 부서진 폭풍의 검 (락)

| 속성 | 정의 |
|:---|:---|
| 과거 | 한때 *폭풍의 검* — 빌더의 손에 만들어진 위대한 무기 |
| 현재 | 부수어졌고 부식·잠들었다. 자아 데이터만 손상 없이 잔류한 *유일한 무기* |
| 깨어남 | 에르다가 빌더의 옛 단조 흔적에 닿는 순간. *최초 발화: "…에르다." / "…들리니?" / "오랜만이야. 너무 오래…"* |
| 화자 | 검 Ego 단독 화자 (DEC-033). 에르다 대신 발화 |
| **미스터리** | **누가·언제·왜 부쉈는가 — 락하지 않음 (장기 hook)** |
| 기억 | 자신의 과거 대부분을 잊음. Memory Shard 회상으로 점진 복원 (DEC-036) |
| 톤 | 체념·부식·"…" 잔존 침묵. 깨어났으나 흐릿함 |

### §1.3. 둘의 관계 — 옛 동행자, 서로 잊음 (락)

> 에르다와 Rustborn 은 *전에 만난 적이 있다*. Rustborn 의 첫 발화 *"오랜만이야"* 가 이를 명시한다. 그러나 둘 다 그 사실의 *세부* 를 모른다. 에르다는 침묵으로, Rustborn 은 부식된 기억으로 — 둘 다 *어렴풋이만 인지*. 게임 진행 = 서로의 잊은 과거를 함께 회상하는 여정.

## §4. Goal & Loop — 잊혀진 기억의 회상 (락)

| 단계 | 행위 | 회상되는 것 |
|:---|:---|:---|
| Stratum 진입 | Rustborn 안으로 다이브 | 그가 한때 머물던 시기·장소 |
| Spoke 룸 진행 | Forgotten Shard 격파 → Recalled 전환 | 단편적 기억 (감정·인상) |
| Boss 처치 | 옛 누군가의 그림자 격파 (검을 부순 자, 만든 자, 들었던 자, 등) | 부서진 사건의 *한 조각* |
| Memory Shard 슬롯 장착 | Anvil 에서 Shard 끼움 | 해당 기억의 효과가 검의 현재 힘으로 환원 |
| 모든 지층 클리어 | 한 무기의 backstory 전모 회복 | 그 시기 검의 정체성 완성 |
| **5 Ancient 완성 + 심연 도달** | **True Ending 트리거 (§10)** | **원초 구조체 조우 — 모든 Echo-Bearers 의 합창 수렴** |

**진행 = 검의 정체 + 빌더의 흔적 + (장기 hook) 에르다 자신의 정체** 가 점진 풀림. 결말 분기는 §10 참조.

## §6. 월드 서사 — 7 Tier 수직 여정

### §6.1. 층위별 독립 서사

월드의 각 층위(바이옴)는 독립된 서사를 가진다. 그 층위에서 드랍되는 아이템은 해당 층위의 서사를 반영한다.

| 원칙 | 설명 |
| :--- | :--- |
| 층위 = 장소의 역사 | Concordia 층위에서 드랍되는 검은 "보안 순찰 블레이드" 테마가 높은 확률 |
| 교차 서사 | A 층위의 아이템계에서 B 층위에 대한 힌트 발견 → 탐험 동기 |
| 환경 서사 우선 | 벽에 긁힌 자국, 부서진 동상, 마른 분수 — 텍스트 없이 역사를 전달 |

### §6.2. 수직적 서사 (메트로베니아 + 야리코미 통합)

```
월드 탐험 (수평 서사) ──── 층위의 현재 상태를 목격
        │
        ▼
아이템 획득 ──────────── 층위의 과거 조각을 손에 쥠
        │
        ▼
아이템계 진입 (수직 서사) ── 과거 속으로 다이빙
        │
        ▼
깊은 지층 도달 ───────── 층위의 비밀 발견
        │
        ▼
월드 복귀 ──────────── "아, 그래서 이 층위가 이렇게 된 거구나"
```

플레이어는 월드를 탐험하면서 **현재**를 보고, 아이템계에서 **과거**를 체험하고, 다시 월드로 돌아와서 **이해**한다. 탐험과 야리코미가 서사적으로 하나의 축을 이룬다.

## §7. 장기 Hook (보류 — 진행하며 해소)

| Hook | 해소 시점 (제안) |
|:---|:---|
| 에르다는 누구인가? 왜 그림자가 없는가? 왜 살아있는가? | **해소 (2026-05-23):** 에르다 = Echo-Bearers 중 한 명의 *잔존 인스턴스*. 자기 자신을 잊은 채 깨어난 자. (§1.1 / §10 결말 분기) |
| Rustborn 을 *왜* 부수었는가? 그의 옛 주인은 누구인가? | 동일 무기 모든 Stratum 클리어 시 (단일 무기 backstory 완성) |
| 빌더는 왜 떠났는가? | True Ending 도달 시 (5 Ancient 완성 + 심연 — §10.3) |
| 검이 *기억하는 에르다* 와 *지금의 에르다* 는 같은 사람인가? | **해소 (2026-05-23):** 같은 사람이지만 *변질된 채로 보존*. 클라이맥스 = 변질된 원본과의 조우 (§10) |
| 결말 — 변질된 원본을 어떻게 할 것인가? | **해소 (2026-05-23):** 3 메인 결말 + 1 True (§10) |

> Hook 들은 *지금 락하지 않음*. 단 *서로 모순되지 않게* 진행 시점에 결정. backbone 은 모든 hook 이 *해소 가능* 한 형태로 설계.

## §8. 톤 (락)

### §8.1. 캐릭터·합 톤 (락)

| 축 | 정서 |
|:---|:---|
| 두 자아의 동행 | *재회한 옛 동행자* 의 정서. 그러나 둘 다 그 사실을 모른다 |
| 에르다 | 살아있으나 침묵. 행동으로 답한다 (Transistor Red 패턴) |
| Rustborn | 깨어났으나 부식·기억 결손. 체념 + 권한 양도 톤 |
| 합 | 무라카미 + Transistor + 메이드 인 어비스 의 결합 — *상실·회복·심연 하강* 의 3 축 |

### §8.2. 근간 정서 — 한정흥(恨情興) (락, 2026-05-23)

ECHORIS의 *근간 정서 골격* 은 한국 전통 정서인 **한(恨)·정(情)·흥(興)** 의 유기적 순환 구조다. 명시적 마케팅 어휘로 사용하지 않으며 (영어권 niche 디버전스 위험), 톤·사운드·캐릭터 곡선·대사 양식의 *내재적 기준* 으로만 작동한다.

| 정서 | 정의 | ECHORIS 내 작동 |
|:--|:--|:--|
| **한 (恨)** | 풀리지 못한 채 응어리진 슬픔·억울함. 시간으로 누적·정체 | Echo-Bearers가 자신을 무기에 결박하고 사라짐. 기억이 *변질된 채* 보존되며 응어리가 부식과 함께 깊어짐. 월드 탐험 = 한의 흔적 추적 |
| **정 (情)** | 시간으로 *체득* 되는 깊은 유대. 의식하지 못해도 몸에 남음 | 에르다와 Rustborn 의 *"오랜만이야"* — 기억은 잊었어도 정은 남음. 동료들 호명 시 직관으로 알아봄. 멀티플레이 동료와의 정도 동축 |
| **흥 (興)** | 응어리를 신명·카타르시스로 *승화* 시키는 발산 | 야리코미·단조·격파의 신명. 한을 흥으로 *전환* 하는 핵심 루프. 단조소(forge) 의례가 흥의 정점 |

#### 유기적 순환

```
   한 ──── 정으로 알아봄 ──── 흥으로 승화 ──┐
   ↑                                          │
   └────── 다음 한으로 진입 ─────────────────┘
```

이 순환이 ECHORIS *월드 탐험 → 아이템계 다이브 → 강화·격파 → 더 깊은 곳* 루프와 1:1 매칭한다. 판소리 *애원성 → 평조 → 진양조 → 자진모리 → 휘모리* 의 점층 구조와 동형.

#### 3 대 기둥 ↔ 한정흥 매핑

| 기둥 | 정서 | 검증 질문 갱신 |
|:--|:--|:--|
| 메트로베니아 탐험 (World) | **한** | "이것이 *한* 의 응어리를 깊게 하거나 풀어주는가?" |
| 야리코미 (Item World) | **한 → 흥** | "이것이 *한 → 흥* 의 전환을 강화하는가?" |
| 온라인 멀티 (Co-op) | **정** | "이것이 *정* 을 체득시키는가?" |

#### Rustborn 대사 곡선 — 판소리 5조 (락 후보, 미확정)

| 구간 | 판소리 조 | Rustborn 톤 | 예시 |
|:--|:--|:--|:--|
| 초반 | 계면조 (애원성) | **한** — 응어리 | *"…에르다. 오랜만이야. 너무 오래…"* |
| 중반 | 평조 | **정** — 동료 호명 회복 | *"공명자 카엘이… 너를 기억해달랬어."* |
| 후반 | 진양조 → 자진모리 | **흥** — 신명 전환 | *"이 자가 날 부쉈어. 갚아주자."* |
| 클라이맥스 | 휘모리 | **한 + 흥 동시** | (변질된 원본 앞에서) *"…여기 있었구나. 너무 오래…"* |

> 판소리 5조 채택은 narrative-designer 강제 참조 추가 여부와 함께 별도 결정 대기.

## §10. 다중 결말 (락, 2026-05-23 — DEC-043)

ECHORIS는 메트로베니아 컨벤션(SotN·Aria of Sorrow·Hollow Knight·Bloodstained)에 따라 **3 메인 결말 + 1 True Ending** 의 다중 결말 구조를 채택한다. 3 메인 결말은 §8.2 한정흥(恨情興) 3 정서의 정점 각각에 대응하며, True Ending은 Layer 5 Ancient 서사 체인의 수렴점이다.

### §10.1. 결말 4종 — 한정흥 정점 + 수렴

| ID | 결말 | 한정흥 정점 | 정서적 본질 | 트리거 |
|:--|:--|:--|:--|:--|
| **결말 A** | 천도 (해소) | **한 풀이** | 변질된 원본을 *해소시키고 보냄*. 굿의 결말. 살아남은 자는 잔존 인스턴스 하나뿐 | Shard 회복률 < 30% 또는 호명 Echo-Bearer < 임계치 |
| **결말 B** | 합침 | **정의 체득** | 잔존 인스턴스와 변질된 원본이 *하나로 융합*. 변질을 받아들이며 둘 다 더 이상 원본이 아니지만, 정으로 묶임 | Shard 회복률 30~70% + 핵심 동료 quest 1-2개 완료 |
| **결말 C** | 두고 떠남 | **흥으로의 진입** | 원본은 *그대로 두고* 잔존 인스턴스가 다음 길로. 살아남은 자의 신명·다음 한으로의 진입 | Shard 회복률 > 70% + 모든 Tier 분파 호명 회복 |
| **True** | 원초 구조체 조우 | **한 + 정 + 흥 수렴** | Echo-Bearers의 합창 + 빌더의 떠남 + 심연의 정체가 한 점에서 만남. 가장 깊은 회복이자 가장 깊은 비극 | 5 Ancient 무기 완성 *AND* 심연 도달 (둘 다 필수) |

### §10.2. 트리거 메커니즘 — 혼합 (D-G-2 락)

결말 분기는 **누적 진행 상태** 의 함수로 결정된다. 마지막 보스 직전 단일 선택이 아니라, *게임 진행 전체에서 누적된 행동* 이 자동으로 분기를 결정한다.

| 변수 | 가중 | 비고 |
|:--|:--:|:--|
| **Memory Shard 회복률 (%)** | 주축 | 야리코미 정합. Forgotten → Recalled 전환 누계 |
| **Echo-Bearer 호명 회복 수** | 보조 | 메트로베니아 정합. 분파별 핵심 quest 완료로 회복 |
| **핵심 동료 quest 완료 (1-2개)** | boost | 결말 B (합침) 활성화 핵심 트리거. 누가 핵심인지는 작성 시 결정 |

> **누적 분기 원칙:** 플레이어는 결말 직전에 *알지 못한 채* 자신의 결말을 만들어왔다. 디스가이아 야리코미 정합 — 자기 진행 자체가 결말을 결정.

### §10.3. True Ending — 둘 다 필수 (D-G-3 락)

True Ending은 *동시 충족* 조건이다. 어느 하나만으로는 활성화되지 않는다.

| 조건 | 의미 |
|:--|:--|
| **5 Ancient 무기 완성** | Echo-Bearers 5 대 분파의 마지막 기억 모두 회복. *수평적* 완성 (분파 전체) |
| **심연 도달** | 대공동 최하단 — 원초 구조체의 뿌리. *수직적* 완성 (깊이) |

수평 + 수직 동시 달성 시에만 *원초 구조체 조우* 가능. Hollow Knight *Embrace the Void* 와 동형 구조.

### §10.4. 결말 후 진행 — 디스가이아 패턴 (D-G-5 락)

결말 도달 후 게임은 *종료되지 않는다*. 야리코미 무한 계속 모드로 진입한다.

| 항목 | 처리 |
|:--|:--|
| 결말 컷신 | 환경 서사 + Rustborn 결말 대사 (DEC-038 정합 — 컷신 없음) |
| 결말 후 화면 | 시작 방 또는 최근 세이브 포인트로 복귀. 진행 상태 그대로 유지 |
| 새 게임+ | 비활성화. 동일 세이브 안에서 다른 결말 회수 가능 |
| 다른 결말 회수 | Shard 회복률·호명 수·quest 상태 변경 후 마지막 보스 재도전. 결말 분기 재계산 |
| Boss Rush 모드 | 결말 도달 시 해금 (선택) |
| 야리코미 무한 | 모든 결말 도달 후에도 아이템계 다이브·Memory Shard 사냥·강화 무한 지속 |

> 결말 도달은 *완료*가 아니라 *통과지점*. 디스가이아의 *Land of Carnage* 처럼 결말 후 콘텐츠가 본 게임. 한정흥 순환의 *다음 한으로의 진입* 이 메커니컬로 구현됨.

### §10.5. 결말 분기 시점 — 누적 (D-G-4 잠정)

결말 분기는 **누적** 이며 *단일 선택 지점 없음*. 마지막 보스 처치 직후 누적 상태를 함수로 평가하여 결말 시퀀스를 자동 결정. 플레이어는 *어떤 결말을 향하고 있는지 모른 채* 자신의 결말을 만들어왔다.

> **미확정:** D-G-4 잠정 결정. 마지막 보스 직전 *명시적 선택 화면* 을 추가할지 (Castlevania 패턴) 여부는 추후 결정.
