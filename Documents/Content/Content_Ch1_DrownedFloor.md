# ECHORIS — Ch.1 침수 바닥층 (the Drowned Floor)

> **준거 상위 (Authority):** T-03, D-20, CNT-PROG, CNT-STR-001
> **문서 ID:** CNT-CH1
> **작성:** 2026-06-03 (CNT-EXP-001 §1~§9 흡수 — 구 "첫 30분")
> **위상:** 진행 마스터(CNT-PROG) Ch.1 의 상세 비트시트. 구조 권위는 CNT-PROG, 서사 권위는 시놉시스 v3.2.
> **분량:** 참고 ~30분. 시간 라벨은 참고용 — 챕터는 공간 돌파 + 비트 완료로 전진(CNT-PROG §0).
> **척추:** 방 → 이동 → shaft 노출 → 첫 빌더 + 러스트본 → 이동 → 두 번째 빌더 + 포지 → 아이템계 → 안식처.

## 0. 목적

### 0.1 Ch.1 안에 플레이어가 알게 되어야 할 것

1. 자기는 수천 년 전 무너진 실험의 백업 복원본이다(Ch.0 프롤로그가 기원을 이미 보여줌).
2. 메가 스트럭처가 살아 있고 빌더가 자란다. 빌더는 적이 아니되 그녀를 인지하지 않는다.
3. 잊혀진 자들의 무기에는 마지막 한 마디가 응결되어 있다 — 에코.
4. 빌더 내부의 포지를 통해 에코 안으로 들어갈 수 있다.
5. 들어간 에코의 음성을 자기 검에 옮겨 새길 수 있다.
6. 시작 검 안에 동료 러스트본의 에코가 있다. 그가 "에르다"라 부른다 — 동료였기에.
7. 일반 몬스터(드론: 슬라임·스켈레톤·고스트) = 평범한 잔존 환경 생물(말소자 아님). 말소자는 희귀·특정 이벤트 흰색 호러(DEC-044).

### 0.2 정서 곡선 (비트 단계)

| 단계 | 정서 좌표 |
| :--- | :--- |
| 깨어남 | 혼란·고립 — 자기 부재 |
| 샤프트 | 경외·압도 — 메가 스트럭처 스케일 |
| 첫 빌더·포지 | 호기심·신비 |
| 러스트본 | 발견·각성 — 이름 회수 |
| 두 번째 빌더·첫 전투 | 적응·확장 |
| 안식처 | 정착·기대 |

### 0.3 비목표

- 전체 세계관(블루프린트·인덱서·등재 신앙)의 명시적 설명 — 후반부 점진 발견.
- 거짓 목표(복원→등재)는 Act 2(Ch.4 이후) 도입 — Ch.1 범위 밖(의도적 비포함).
- 동반자·NPC 깊은 관계 — 러스트본 외에는 환경적 자취로만.

## 1. 오프닝 — 백업 기상 콜드 오픈

Ch.0 암전(수천 년 경과) 직후 P6 백업 기상이 Ch.1 오프닝이다. 권고안 = **옵션 B(사운드 선행)**.

- 검은 화면. 사운드만. 먼 시공 굉음이 점점 가까워진다(먼 빌더). 잠시 침묵. 한 음성이 속삭인다 — "에르다..." (시작 검 안 러스트본 에코의 잔향. 플레이어는 5분 뒤 그를 만나 "그 음성이었구나" 재인지).
- 화면이 빛으로 깨진다. 에르다가 작은 공동에서 눈을 뜬다.
- 시점 일어서기. 검에서 첫 한 마디 "나도 들리고 싶었어." 첫 입력 가능.

> 대안: A(방 깨어남, 최소 비용) / C(스케일 시네마틱, 컷신 의존) / D(사운드+미세 시각, B 다음 권고). 채택 = B (Rustborn 첫 음성을 시작 비트에 박아 재인지 비트 생성, 컷신 의존 회피).

## 2. 비트 시퀀스

> 공간명이 1차 라벨. 시간은 참고용.

### B1 — 콜드 오픈 (깨어남)

| 항목 | 내용 |
| :--- | :--- |
| 시각 | 검은 화면 → 빛이 한 줄기씩 → 시점 일어서기 |
| 사운드 | 먼 시공 굉음 → 침묵 → 속삭임 "에르다..." → 검의 한 마디 "나도 들리고 싶었어." |

| 목표 | 첫 입력. 화면 상단 미세 프롬프트. |
| 정서 | 혼란·고립 |

### B2 — 방 (이동 튜토리얼 + 자기 부재)

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 작은 공동(룸 1). 시체 더미 — 자기 이전 복원 잔해. 부서진 무기 1-2점, 식은 시공 광원 잔재. |
| 메커닉 도입 | 이동·점프·짧은 대시(i-frame 없는 위치 회피 형태). 검 휘두르기 1-2회. |
| 환경 디테일 | 다른 잔존자 흔적 — 시체 옆 무기는 응답 없음(자기 검만 응답). 검 표면 한 마디 반복 청취. |
| 사운드 | 검의 한 마디 간헐 반복. 시공 굉음 멀리. |
| 목표 | 출구를 찾아 이동 |
| 정서 | 혼란·고립 → 호기심 |
| GDD 메모 | 백업 복원본 = 기억·이름 부재 → UI 부재로 운반(캐릭터 정보·이름·HP 바 미노출, 점진). Ch.0을 본 플레이어는 "그 실험의 백업이 깨어났다"를 안다. |

### B3 — 샤프트 (스케일 노출, Sakurai Beat)

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 방의 좁은 출구 → 거대한 샤프트 |
| 카메라 | 진입 시 자동 위로 팬 → 메가 스트럭처 전경 → 멀리 시공 중인 빌더 한 마리 |
| 메커닉 | 카메라 일시 제한(연출 우선) → 종료 후 자유 |
| 사운드 | 시공 굉음 갑자기 크게 — 빌더 박자가 전체를 흔든다 |
| 환경 디테일 | 샤프트 벽에 잔존자 옛 자취(낙서·도구·시체) 산발 |
| 목표 | 빌더 방향 이동(또는 빌더가 다가옴) |
| 정서 | 경외·압도 |

### B4 — 첫 빌더 (고장 빌더 침입)

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 고장 빌더 — 시공 광원 꺼진 채 굳음. 옆구리 균열. |
| 메커닉 도입 | 균열 진입(특수 인터랙트 — 좁은 통로 통과) |
| 환경 디테일 | 기계-유기 혼합 텍스처. 멈춘 시공 부품. 빌더 "내장" 어휘. |
| 사운드 | 외부 굉음 잦아듦 — 내부 상대 정적. 검의 한 마디가 또렷해진다. |
| 목표 | 빌더 내부 깊은 곳 포지 탐색 |
| 정서 | 호기심·신비 |
| GDD 메모 | 메트로베니아 좁은 통로 + 비밀 공간 1-2. 첫 비밀 보상 = 옛 잔존자 메모 한 줄(인덱서 의례 모호한 단서). |

### B5 — 식은 포지 (첫 다이브 + 러스트본 조우)

| 항목 | 내용 |
| :--- | :--- |
| 공간 | 빌더 내장 깊은 곳 포지 방. 식은 거대 단조 장치. |
| 메커닉 도입 | 포지 격발 — 자기 무기를 포지에 놓고 격발. 시공 한 박자에 진입. 첫 다이브는 박자 동기화 튜토리얼 없이 자동 성공. |
| 다이브 후 공간 | 자기 무기 에코 내부 — 비물질 위상. 부유하는 빛 조각. 중앙에 한 인간 형상 응결체. |
| 캐릭터 등장 | 러스트본 — 의식 온전한 에코. Ch.0의 그 동료. 그가 보고 곧장 "에르다." (작품 첫 캐릭터 발화. 동료였기에 안다 — 자기가 누구였는지는 말 안 함.) |
| 사운드 | 러스트본 음성 = 다른 에코와 다른 음질(명료·가까움). Ch.0 P1의 그 톤. |
| 가르침 | "어떤 에코는 깊고, 어떤 에코는 더 깊다. 자기 자신에게 도달하는 길은 가장 깊은 곳에 있다." |
| 금지 | "잊지 마라. 너의 이름은 에르다다." 류 직접 호명 명령 금지(신파 차단 #6). 이름은 그녀가 빌더 밖에서 자기 입으로 처음 발화. |
| 종료 | 빌더 자라남이 에코 외피 침범 → 위상 무너짐. 자동 귀환. |
| 목표 | (수동 입력 거의 없음, 시네마틱) 러스트본 시청 + 가르침 수신 |
| 정서 | 발견·각성(Ch.0 동료 재회 재인지) |
| GDD 메모 | Ch.0 P1 러스트본 각인 회수 — "그 동료였구나." 음성 동일성 사운드로 명시. UI에 이름 "에르다" 첫 표시. |

## 7. 감독 노트

### 7.1 카메라
- 1인칭 가까운 3인칭 — 깨어남·러스트본 조우.
- 메가 스트럭처 노출(샤프트) — 자동 팬 + 정지 5초.
- 전투 — 일반 3인칭 횡스크롤.

### 7.2 사운드
- 시공 굉음 = 기본 사운드스케이프. 빌더 가까이 크게, 멀리 잔향.
- 검의 음성 = 위치별 EQ. 자기 검 가깝게, 다른 검 미세.
- Rustborn 음성 = 명료, 다른 에코와 구별.
- 인덱서 chant = 한 줄 합창, 멀리.
- 음악 = 절제. 빌더 노출·러스트본 조우·안식처 3 비트에서만 짧게.

### 7.3 비주얼
- 1막 색조 — 차가운 회색·청색(메가 스트럭처) + 검 잔재의 미세 따뜻한 빛(잔존자 응답).
- 빌더 — 기계-유기 혼합. 거대하되 적의 없음 — 표정 없는 거인.
- 시공 광원 — 빌더 패턴이 한 박자마다 빛난다(메가 스트럭처의 호흡).
- 에코 내부 — 비물질 위상. 부유 빛 조각. 일반 에코 어두운 톤, 러스트본 에코 따뜻한 톤.

### 7.4 UI (점진 노출 = 자기 회복 호와 정합)
- 깨어남~방 — UI 거의 부재(자기 부재 정합).
- 빌더 내부 — 환경 프롬프트만.
- 러스트본 직후 — 캐릭터 이름 "에르다" 첫 노출.
- 첫 에코 회수 — 에코 인덱스 "1/300" 첫 노출.
- 자유 탐험 — 미니맵 첫 노출.
- 안식처 — 풀 메뉴 첫 노출.
