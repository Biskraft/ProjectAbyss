# Repairman's Patch Cleaver — Memory Fragment 텍스트

> **DEC-046 카테고리 2: 격벽 수리공 (Bulkhead Repairman).** 측량사의 *지적/내성적* 톤과 대비되는 *육체적/우직* 톤. "정직한 손이 답을 만든다"는 정서.

## Origin (4요소 요약)

| 요소 | 내용 |
|:---|:---|
| Creator | 100년 전 격벽 측량사 길드 산하 수리공 직영 단조소. 측량사가 표지한 균열을 *때워서 막는* 무거운 클리버 |
| Purpose | 격벽 균열에 합금 패치를 박아 넣는 도구. 한쪽 면은 *때리는* 망치, 반대쪽은 패치 모서리를 *베어내는* 칼날 |
| History | Era 3 말기. 한 수리공이 측량사 동료가 표지한 격벽 4 균열을 30일 동안 혼자 때웠다. 측량사는 그날 술집에 오지 않았고, 수리공은 *늘 그랬듯* 별 일 아닌 줄 알았다 |
| Fate | 수리공은 측량사가 사라진 후 1년을 더 격벽 4를 수리하다 은퇴했다. 은퇴 다음 날 사망. 가족은 *"손이 멈추면 살 수 없었던 사람"* 이라고 했다 |

> **Magic 등급 Stage 진행:** Stage 0 → Stage 2 → Stage 4. Stage 1/3은 데이터 등록만.
