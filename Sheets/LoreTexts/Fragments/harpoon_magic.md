# Bearer's Falling Harpoon — Memory Fragment 텍스트

> **DEC-046 카테고리 3: 케이블 운반자 (Cable Bearer).** *모험/유랑* 톤. 위험과 보상이 양면인 직업의 정서. 측량사(고요한 직업 윤리), 수리공(우직한 손)과 또 다른 결.

## Origin (4요소 요약)

| 요소 | 내용 |
|:---|:---|
| Creator | 격벽 사이를 *수직 케이블* 로 잇는 운반자 길드의 표준 도구. 추락 시 자기 몸을 *벽에 박는 첨두* — 즉, 작살 |
| Purpose | 케이블 통로에서 미끄러질 때 벽에 박아 추락을 멈추는 용도. 한 번 박으면 회수 불가 — 일회용 안전망 |
| History | Era 3 말기. 한 운반자가 케이블 통로 7개 격벽을 매일 왕복했다. 어느 날 평소처럼 미끄러졌고, 평소처럼 작살을 박았다. 단, 그날은 *마지막 작살이 부러졌다* |
| Fate | 운반자는 격벽 5 케이블 통로 끝에서 발견됐다. 작살 손잡이만 그의 손에 남아 있었다. 길드는 *"표준 케이블 사고"* 로 처리했다. 그날 그가 운반하던 것이 무엇이었는지는 기록되지 않았다 |
