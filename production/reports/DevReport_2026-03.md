## 2. 흐름

### 2-1. 개시 (03-23) — 프로젝트 탄생 + 배포 사투
- **프로젝트 초기화:** 종합 기획 문서 + AI 에이전트 구성 + 개발 툴링.
- **첫 게임플레이 축:** 사쿠라이식 히트 피드백, 디스가이아식 아이템 성장, GitHub Pages 배포.
- **배포 흑화면과의 싸움:** Vite base 경로, 폰트 로드 타임아웃, WebGL 렌더러 강제, PixiJS v8 동적 import 우회, 폰트 로컬 번들, 전 Text→BitmapText(픽셀 퍼펙트). 배포 안정화에 첫날 다수 커밋 소요.
- **초기 콘텐츠:** 골든 몬스터 rare+ 드랍, 아이템계 처치/방통과 EXP + 토스트, 무기 사거리 +1타일.

### 2-2. 시스템 골격 (03-24 ~ 03-25)
- **카메라 + 전투 시스템 + 아이템계 씬**(동적 방 생성·아이템 진행) 도입.
- 모바일 가상 패드·조작 오버레이·아이템계 온보딩, Ghost 적(투사체) + SaveManager.
- **Diablo식 레어리티 채택**(Normal/Magic/Rare/Legendary/Ancient).
- **Memory Strata 시스템** 도입 — 단층 아이템계를 다층 구조로 대체, 이후 단일 연결 그리드로 통합.
- `/update-dashboard` 스킬, 퀘스트 내러티브 프레임워크.

### 2-3. 메트로베니아 기본기 (03-26)
- **LDtk 핸드크래프트 월드 + Phase 1 GDD 완성.**
- 방 전환 시스템, 통로 개방 검증, 카메라 지터 다수 수정(픽셀 퍼펙트 스냅 + 데드존).
- Altar·Enemy_Spawn·NPC 엔티티 정의 + 배치 + 게임 로직 연결.
- **이동 능력 세트:** 수중 수영 물리, 일방통행 플랫폼(아래+점프 드롭), 플랫폼 오토타일, **벽 점프 렐릭 + 이단 점프 + 코요테 타임.**
- Spelunky식 아이템계 방 템플릿. 랜덤 스폰 제거 → LDtk 전용 배치.

### 2-4. 아이템계 정착 + 내러티브 (03-27 ~ 03-31)
